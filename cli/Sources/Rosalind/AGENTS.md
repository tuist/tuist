# Rosalind

Rosalind analyzes iOS, macOS, and Android application bundles for Tuist bundle inspection and reporting.

- Source files live in this directory.
- Unit and acceptance tests live in `cli/Tests/RosalindTests`.
- Test fixtures live in `cli/Tests/Fixtures/Rosalind`.
- The target is exported as the `Rosalind` product from the root `Package.swift` and is included in the Tuist-generated workspace.
