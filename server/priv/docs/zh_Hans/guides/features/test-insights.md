# 测试洞察 {#test-insights}

使用测试洞察来监控你的测试套件健康状况，通过识别慢速测试、跟踪不稳定测试以及快速理解失败的 CI 运行。目前支持 Xcode、Gradle、Bazel、Elixir 和 Rust。
