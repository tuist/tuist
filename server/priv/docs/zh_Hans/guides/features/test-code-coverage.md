# 代码覆盖率 {#code-coverage}

代码覆盖率会告诉你测试执行了代码中的哪些行。Tuist 会上传每次测试运行的覆盖率数据，并将一次提交中的所有运行结果合并为一个数值（按文件和整个项目分别统计），以便你在仪表板上逐次提交跟踪覆盖率变化。
