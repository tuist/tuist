隔离可以将不稳定测试隔离开来，避免在修复期间阻塞 CI。默认情况下，这是一项**手动操作**：你可以在仪表板的测试用例详情页面对测试进行隔离、解除隔离并切换模式。你也可以将其配置为**Settings → Automations**下的**自动化告警**，以便在测试超过不稳定阈值时自动静音（或跳过），并在恢复后解除隔离。每次转换，无论是手动还是自动，都会记录在测试用例的审计日志中。

默认情况下，恢复会等待触发条件不再满足，因此测试会保持隔离状态，直到其旧的不稳定运行离开触发窗口。若要更快恢复，请将**Recover when**设置为**No new flaky runs**：一旦在恢复窗口（天数或运行次数）内没有新的不稳定运行，测试就会恢复；每次出现新的不稳定运行都会重新开始等待；恢复后，只有新的不稳定运行才会再次将其隔离。
