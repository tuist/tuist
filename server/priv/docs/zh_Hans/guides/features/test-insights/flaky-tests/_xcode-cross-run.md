### 跨运行检测 {#cross-run-detection}

即使不启用测试重试，Tuist 也能通过比较同一提交、同一 Scheme 和同一报告目标（设备名称、平台和操作系统版本）下不同 CI 运行的结果来检测不稳定测试。如果某个测试在一次匹配的 CI 运行中通过，而在另一次中失败，则将该失败的执行标记为不稳定。无论哪个结果先到达，此机制均有效。

同一测试在不同 Scheme 或目标上的表现可能始终不同。例如，在 iOS 26 上通过而在 iOS 27 上失败并不构成不稳定。来自不同 Scheme、设备、平台或操作系统版本的结果不会相互标记为不稳定。

缺少目标元数据的运行，或涵盖多个目标的运行，仅彼此之间进行比较，因此它们之间的环境差异仍可能被报告为不稳定。基于重试的检测仍然适用。

这对于捕获那些因失败不够一致而无法通过重试发现、但仍会导致 CI 间歇性失败的不稳定测试尤为有用。
