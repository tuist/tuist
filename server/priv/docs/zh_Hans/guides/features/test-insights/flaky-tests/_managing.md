## 管理不稳定测试 {#managing-flaky-tests}

### 自动清除 {#automatic-clearing}

检测与清除通过项目上的 **自动化提醒** 执行。每个项目都会获得一个默认的“不稳定测试检测”自动化，其 *触发器* 会将测试标记为不稳定，而 *恢复* 会在测试在配置的恢复窗口（默认 **14 天**）内未再次触发后清除该标记。在 **设置 → 自动化** 中编辑它，以更改恢复窗口、调整恢复操作（例如，同时解除测试的隔离状态），或完全禁用恢复，使测试保持不稳定标记，直到你手动清除。

### 手动管理 {#manual-management}

你还可以在测试用例详情页面手动将测试标记为不稳定或取消标记。这在以下情况下很有用：
- 你希望在修复已知不稳定测试时先予以确认
- 测试因基础设施问题被错误标记
