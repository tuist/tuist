## 管理不稳定测试 {#managing-flaky-tests}

### 自动清除 {#automatic-clearing}

检测与清除通过项目上的**自动化提醒**执行。每个项目都会获得一个默认的“不稳定测试检测”自动化，其*触发器*会将测试标记为不稳定，而一旦测试在配置恢复窗口（默认**14 天**）内未再次触发，其*恢复*就会清除该标记。在**设置 → 自动化**中编辑它，可以更改恢复窗口、更改恢复操作（例如，同时将测试从隔离中释放），或完全禁用恢复，以便测试保持标记为不稳定状态，直到你手动清除它们。

### 手动管理 {#manual-management}

你还可以在测试用例详情页面手动将测试标记或取消标记为不稳定。这在以下情况下很有用：
- 希望在修复已知不稳定测试时予以确认
- 由于基础设施问题导致测试被错误标记
