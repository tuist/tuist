## 管理不稳定测试 {#managing-flaky-tests}

### 自动清除 {#automatic-clearing}

检测和清除通过项目上的**自动化警报**运行。每个项目都有一个默认的“不稳定测试检测”自动化，其*触发器*会将测试标记为不稳定，而一旦测试在配置的恢复窗口（默认**14 天**）内未再次触发，其*恢复*操作就会清除该标记。在**设置 → 自动化**下编辑它，以更改恢复窗口、更改恢复操作（例如，也将测试从隔离中释放），或完全禁用恢复，以便测试保持标记为不稳定状态，直到你手动清除它们。

### 手动管理 {#manual-management}

你还可以在测试用例详情页面手动将测试标记为不稳定或取消标记。这在以下情况下很有用：
- 你希望在修复已知不稳定测试时予以确认
- 由于基础设施问题，测试被错误地标记
