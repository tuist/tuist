# 语言 {#translate}

语言可能成为理解的障碍。我们希望确保尽可能多的人能够使用 Tuist。如果你使用的语言尚未得到 Tuist 支持，你可以通过改进英文源内容以及驱动我们翻译流水线的本地化上下文，来帮助 Tuist 支持该语言。

由于语言支持是一项持续的工作，我们会在有贡献者愿意协助维护时添加新语言。目前支持的语言包括：

- 英语
- 西班牙语
- 日语
- 格鲁吉亚语
- 韩语
- 俄语
- 粤语
- 简体中文
- 繁体中文

> [!TIP]
> **申请新增语言**
>
> 如果你认为 Tuist 应该支持某种新语言，请在[社区论坛中创建一个主题](https://community.tuist.io/c/general/4)，与社区成员共同讨论。


## 如何提供帮助 {#how-to-translate}

Tuist 的语言支持由代码仓库驱动。贡献者更新英文源内容和翻译上下文，我们的翻译流水线会自动生成对应的本地化文件。

工作流程如下：

1. 更新英文源内容。
2. 如果译者需要更多指引，请更新相关的 `L10N.md` 上下文。
3. 提交包含上述源内容变更的拉取请求。
4. 变更合并到 `main` 后，翻译工作流会重新生成目标 `.po` 文件，并发起一个包含已翻译更新的后续拉取请求。

> [!WARNING]
> **不要修改生成的本地化内容**
>
> 请勿直接编辑生成的本地化内容。应改为更新英文源内容和语言上下文。


## L10N.md 结构 {#l10n-md-structure}

`L10N.md` 文件定义了发送给翻译模型的上下文。最简单的理解方式是将其视为可在不同目录层级中生效的作用域化语言指令。

例如：

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## 目录上下文 {#directory-context}

翻译脚本会从仓库根目录向下遍历至待翻译的目录，并合并该路径上找到的所有 `L10N.md` 文件。

在上述示例中：

- `L10N.md` 全局生效。
- `server/L10N.md` 添加服务器特定的上下文。
- `server/L10N/es.md` 为该区域添加仅限西班牙语的覆盖配置。

这意味着你可以将上下文放置在合适的位置：

- 在根目录放置适用于整个仓库的指导
- 在子目录中放置特定区域的指导
- 在 `L10N/<locale>.md` 中放置特定语言的指导
