# ლოგირება {#logging}

CLI იყენებს [swift-log](https://github.com/apple/swift-log) ინტერფეისს ლოგირებისთვის. პაკეტი მალავს ლოგირების რეალიზაციის დეტალებს, რაც CLI-ს საშუალებას აძლევს იყოს დამოუკიდებელი ლოგირების ბექენდისგან. ლოგერი ინჟექტირდება დამოკიდებულების სახით task locals-ის გამოყენებით და მისი წვდომა ნებისმიერი ადგილიდან შესაძლებელია შემდეგნაირად:

```bash
Logger.current
```

> [!NOTE]
> Task locals არ ავრცელებს მნიშვნელობას `Dispatch`-ის ან detached tasks-ის გამოყენებისას, ამიტომ თუ მათ იყენებთ, მოგიწევთ მნიშვნელობის მიღება და ასინქრონულ ოპერაციაში გადაცემა.


## რა უნდა ჩაიწეროს ლოგში {#what-to-log}

ლოგები არ არის CLI-ს ინტერფეისი. ისინი ინსტრუმენტია პრობლემების დიაგნოსტიკისთვის, როდესაც ისინი ჩნდება. ამიტომ, რაც უფრო მეტ ინფორმაციას მოგვაწვდით, მით უკეთესი. ახალი ფუნქციების შექმნისას ჩაუდექით იმ დეველოპერის ადგილას, რომელიც შეუჩვეველ ქცევას ხვდება, და იფიქრეთ, თუ რა ინფორმაცია იქნებოდა მისთვის სასარგებლო. დარწმუნდით, რომ იყენებთ სწორ [ლოგის დონეს](https://www.swift.org/documentation/server/guides/libraries/log-levels.html). წინააღმდეგ შემთხვევაში, დეველოპერები ვერ შეძლებენ ხმაურის გაფილტვრას.
