# დოკუმენტაცია {#docs}

წყარო: [github.com/tuist/tuist/tree/main/server/priv/docs](https://github.com/tuist/tuist/tree/main/server/priv/docs)

## რისთვისაა განკუთვნილი {#what-it-is-for}

დოკუმენტაციის საიტი შეიცავს Tuist-ის პროდუქტისა და კონტრიბუტორების დოკუმენტაციას. ის არის Tuist სერვერის ნაწილი, რომელიც წარმოადგენს Phoenix აპლიკაციას და რენდერს Markdown გვერდებს `server/priv/docs/en` ქვეშ მისამართზე `/docs`.

## როგორ მივიღოთ მონაწილეობა {#how-to-contribute}

ჩაასწორეთ ინგლისური გვერდები `server/priv/docs/en` ქვეშ. თარგმანები ცალკე იმართება, ამიტომ არ ჩაასწოროთ სხვა ენების დირექტორიები. გვერდითი პანელი განისაზღვრება ფაილში `server/lib/tuist/docs_sidebar.ex`; დაამატეთ ახალი გვერდები იქ, რათა მკითხველებმა შეძლონ მათი პოვნა.

როდესაც რამდენიმე გვერდი იზიარებს ერთსა და იმავე ტექსტს, მაგალითად, ერთსა და იმავე სექციას სხვადასხვა ბილდის სისტემებში, მოათავსეთ ის ფაილში, რომლის სახელი იწყება `_`-ით და მდებარეობს ამ გვერდების გვერდით, ხოლო ჩართეთ ის `@snippet:` HTML კომენტარით, რომელიც მიუთითებს ფაილზე, როგორც ეს არასტაბილური ტესტების გვერდებზეა გაკეთებული. ფაილები, რომელთა სახელი იწყება `_`-ით, არ ქვეყნდება როგორც დამოუკიდებელი გვერდები.

### ლოკალურად მოწყობა {#set-up-locally}

გაუშვით სერვერი `server` დირექტორიიდან, მიჰყევით მის [მოწყობის ინსტრუქციებს](https://github.com/tuist/tuist/blob/main/server/AGENTS.md):

```bash
cd server
mise install
mise run dev
```

შემდეგ გახსენით [http://localhost:8080/en/docs](http://localhost:8080/en/docs).

### გენერირებული შინაარსი {#generated-content}

CLI-ის ცნობარი გენერირდება CLI-ის უახლესი ვერსიის ბრძანებების სპეციფიკაციიდან, ამიტომ მისი ლოკალურად აწყობა არ არის საჭირო.

ProjectDescription API-ის ცნობარი ცალკეა განთავსებული როგორც DocC საიტი მისამართზე [projectdescription.tuist.dev](https://projectdescription.tuist.dev). მისი ლოკალურად ასაწყობად, გაუშვით `mise run docs:project-description` რეპოზიტორიის ძირიდან.
