# დოკუმენტაცია {#docs}

წყარო: [github.com/tuist/tuist/tree/main/server/priv/docs](https://github.com/tuist/tuist/tree/main/server/priv/docs)

## რისთვისაა განკუთვნილი {#what-it-is-for}

დოკუმენტაციის საიტი შეიცავს Tuist-ის პროდუქტისა და კონტრიბუტორების დოკუმენტაციას. ის არის Tuist სერვერის ნაწილი, რომელიც წარმოადგენს Phoenix აპლიკაციას და რენდერს Markdown გვერდებს `server/priv/docs/en` მისამართზე `/docs`.

## როგორ მივუძღვნათ წვლილი {#how-to-contribute}

ჩაასწორეთ ინგლისური გვერდები `server/priv/docs/en` საქაღალდეში. თარგმანები ცალკე იმართება, ამიტომ არ ჩაასწოროთ სხვა ენების დირექტორიები. გვერდითი პანელი განსაზღვრულია `server/lib/tuist/docs_sidebar.ex` ფაილში; დაამატეთ ახალი გვერდები იქ, რათა მკითხველებმა შეძლონ მათი პოვნა.

როდესაც რამდენიმე გვერდი იყენებს ერთსა და იმავე ტექსტს, მაგალითად, ერთსა და იმავე სექციას სხვადასხვა ბილდის სისტემებში, მოათავსეთ ის ფაილში, რომლის სახელი იწყება `_`-ით და მდებარეობს ამ გვერდების გვერდით, შემდეგ კი ჩართეთ ის `@snippet:` HTML კომენტარის საშუალებით, რომელიც მიუთითებს ამ ფაილზე, როგორც ეს გაკეთებულია არასტაბილური ტესტების გვერდებზე. ფაილები, რომელთა სახელი იწყება `_`-ით, არ ქვეყნდება როგორც დამოუკიდებელი გვერდები.

### ლოკალურად გამართვა {#set-up-locally}

გაუშვით სერვერი `server` დირექტორიიდან, მისი [ინსტრუქციების](https://github.com/tuist/tuist/blob/main/server/AGENTS.md) მიხედვით:

```bash
cd server
mise install
mise run dev
```

შემდეგ გახსენით [http://localhost:8080/en/docs](http://localhost:8080/en/docs).

### გენერირებული შინაარსი {#generated-content}

CLI-ის ცნობარი გენერირდება უახლესი CLI ვერსიის ბრძანებების სპეციფიკაციიდან, ამიტომ მისი ლოკალურად აწყობა არ არის საჭირო.

ProjectDescription API-ის ცნობარი ცალკეა განთავსებული DocC საიტზე მისამართით [projectdescription.tuist.dev](https://projectdescription.tuist.dev). მისი ლოკალურად ასაწყობად, გაუშვით `mise run docs:project-description` რეპოზიტორიის ძირიდან.
