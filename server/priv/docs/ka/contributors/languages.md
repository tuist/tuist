# ენები {#translate}

ენებმა შეიძლება ხელი შეუშალონ გაგებას. ჩვენ გვინდა, რომ Tuist იყოს ხელმისაწვდომი რაც შეიძლება მეტი ადამიანისთვის. თუ საუბრობთ ენაზე, რომელსაც Tuist ჯერ არ უჭერს მხარს, შეგიძლიათ დაეხმაროთ Tuist-ს ამ ენაზე „ლაპარაკში“ ინგლისური წყაროს გაუმჯობესებით და ლოკალიზაციის კონტექსტის განვითარებით, რაც მართავს ჩვენს თარგმნის პაიპლაინს.

რადგან ენების მხარდაჭერა უწყვეტი პროცესია, ჩვენ ვამატებთ ენებს მაშინ, როდესაც ჩნდებიან მოხალისეები, რომლებიც მზად არიან დაგვეხმარონ მათ შენარჩუნებაში. ამჟამად მხარდაჭერილია შემდეგი ენები:

- ინგლისური
- ესპანური
- იაპონური
- ქართული
- კორეული
- რუსული
- კანტონური
- გამარტივებული ჩინური
- ტრადიციული ჩინური

> [!TIP]
> **მოითხოვეთ ახალი ენა**
>
> თუ ფიქრობთ, რომ Tuist-ს სარგებლობას მოუტანს ახალი ენის მხარდაჭერა, გთხოვთ, შექმნათ ახალი [თემა საზოგადოების ფორუმზე](https://community.tuist.io/c/general/4) და განიხილოთ ის საზოგადოებასთან ერთად.


## როგორ დაგვეხმაროთ {#how-to-translate}

Tuist-ის ენების მხარდაჭერა რეპოზიტორიიდან იმართება. კონტრიბუტორები ანახლებენ ინგლისურ წყაროს და თარგმნის კონტექსტს, ხოლო ჩვენი თარგმნის პაიპლაინი ავტომატურად ქმნის ლოკალიზებულ ფაილებს.

სამუშაო პროცედურა ასეთია:

1. განაახლეთ ინგლისური წყაროს შინაარსი.
2. განაახლეთ შესაბამისი `L10N.md` კონტექსტი, თუ თარგმნებს დამატებითი მითითებები სჭირდებათ.
3. გახსენით pull request აღნიშნული ცვლილებებით.
4. მას შემდეგ, რაც ცვლილებები `main`-ზე განთავსდება, თარგმნის სამუშაო პროცესი ხელახლა შექმნის სამიზნე `.po` ფაილებს და გახსნის მომდევნო pull request-ს თარგმნილი განახლებებით.

> [!WARNING]
> **არ შეცვალოთ გენერირებული ლოკალიზებული შინაარსი**
>
> არ ჩაასწოროთ გენერირებული ლოკალიზებული შინაარსი პირდაპირ. ნაცვლად ამისა, განაახლეთ ინგლისური წყარო და ენის კონტექსტი.


## L10N.md-ის სტრუქტურა {#l10n-md-structure}

`L10N.md` ფაილები განსაზღვრავენ კონტექსტს, რომელიც ეგზავნება თარგმნის მოდელს. მათზე ფიქრის ყველაზე მარტივი გზაა — როგორც ენის ინსტრუქციები, რომლებიც შეიძლება სხვადასხვა დირექტორიის დონეზე იყოს განთავსებული.

მაგალითად:

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## დირექტორიის კონტექსტი {#directory-context}

თარგმნის სკრიპტი გადადის რეპოზიტორიის ფესვიდან იმ დირექტორიამდე, რომელიც ითარგმნება, და აერთიანებს ყველა `L10N.md` ფაილს, რომელსაც ამ გზაზე პოულობს.

ზემოთ მოყვანილ მაგალითში:

- `L10N.md` მოქმედებს გლობალურად.
- `server/L10N.md` ამატებს სერვერის სპეციფიკურ კონტექსტს.
- `server/L10N/es.md` ამატებს მხოლოდ ესპანურად შესწორებებს იმავე არეალისთვის.

ეს ნიშნავს, რომ შეგიძლიათ განათავსოთ კონტექსტი იქ, სადაც მისი ადგილია:

- რეპოზიტორიის მასშტაბით მითითებები ფესვში
- არეალის სპეციფიკური მითითებები ქვედირექტორიაში
- ენის სპეციფიკური მითითებები `L10N/<locale>.md`-ში
