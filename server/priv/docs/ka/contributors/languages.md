# ენები {#translate}

ენებმა შეიძლება გაგების პროცესი შეაფერხონ. ჩვენ გვსურს, რომ Tuist-ით სარგებლობა რაც შეიძლება მეტ ადამიანს შეეძლოს. თუ საუბრობთ ენაზე, რომელსაც Tuist ჯერ არ უჭერს მხარს, შეგიძლიათ დაეხმაროთ Tuist-ს ამ ენის ათვისებაში ინგლისური წყაროს გაუმჯობესებით და ლოკალიზაციის კონტექსტის განახლებით, რომელსაც [Glossia](https://glossia.ai) იყენებს გადასათარგმნად.

რადგან ენების მხარდაჭერა უწყვეტი პროცესია, ახალ ენებს ვამატებთ მაშინ, როცა ჩნდებიან მოხალისეები, რომლებიც მათ შენარჩუნებაში დაგვეხმარებიან. ამჟამად მხარდაჭერილია შემდეგი ენები:

- ინგლისური
- არაბული
- ესპანური
- იაპონური
- ქართული
- კორეული
- რუსული
- კანტონური
- გამარტივებული ჩინური
- ტრადიციული ჩინური

> [!TIP]
> **მოითხოვეთ ახალი ენა**
>
> თუ ფიქრობთ, რომ Tuist-ს ახალი ენის მხარდაჭერა გამოადგება, გთხოვთ, შექმნათ ახალი [თემა საზოგადოების ფორუმზე](https://community.tuist.io/c/general/4) და განიხილოთ ის საზოგადოებასთან ერთად.


## როგორ დაგვეხმაროთ {#how-to-translate}

Tuist-ის ენების მხარდაჭერა რეპოზიტორიიდან იმართება. კონტრიბუტორები ანახლებენ ინგლისურ წყაროს და თარგმანის კონტექსტს, ხოლო [Glossia](https://glossia.ai) ავტომატურად ქმნის ლოკალიზებულ ფაილებს.

სამუშაო პროცესი ასეთია:

1. განაახლეთ ინგლისური წყაროს შინაარსი.
2. განაახლეთ შესაბამისი `L10N.md` კონტექსტი, თუ მთარგმნელებს დამატებითი მითითებები სჭირდებათ.
3. შექმენით pull request აღნიშნული ცვლილებებით.
4. ცვლილებების `main`-ზე შერწყმის შემდეგ, Glossia თარგმნის შეცვლილ ნაწილებს და ტოვებს ღია translation pull request-ს განახლებული ლოკალიზებული ფაილებით.

> [!WARNING]
> **არ შეცვალოთ გენერირებული ლოკალიზებული შინაარსი**
>
> არ ჩაასწოროთ პირდაპირ გენერირებული ლოკალიზებული შინაარსი. ნაცვლად ამისა, განაახლეთ ინგლისური წყარო და ენის კონტექსტი.


## L10N.md-ის სტრუქტურა {#l10n-md-structure}

`L10N.md` ფაილები განსაზღვრავენ კონტექსტს, რომელსაც Glossia იყენებს თარგმნისას. მათზე ფიქრის ყველაზე მარტივი გზაა, განვიხილოთ როგორც ენის მითითებები, რომლებიც შეიძლება სხვადასხვა დირექტორიის დონეზე იყოს განთავსებული.

მაგალითად:

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## დირექტორიის კონტექსტი {#directory-context}

Glossia მიემართება რეპოზიტორიის ძირიდან იმ დირექტორიამდე, რომელიც ითარგმნება, და აერთიანებს ყველა `L10N.md` ფაილს, რომელსაც ამ გზაზე პოულობს.

ზემოთ მოყვანილ მაგალითში:

- `L10N.md` მოქმედებს გლობალურად.
- `server/L10N.md` ამატებს სერვერისთვის სპეციფიკურ კონტექსტს.
- `server/L10N/es.md` ამატებს მხოლოდ ესპანური ენისთვის განკუთვნილ გადაფარვებს იმავე არეალისთვის.

ეს ნიშნავს, რომ კონტექსტი შეგიძლიათ განათავსოთ იქ, სადაც მას ადგილი აქვს:

- რეპოზიტორიის მასშტაბით მითითებები ძირითად დირექტორიაში
- არეალისთვის სპეციფიკური მითითებები ქვედირექტორიაში
- ენისთვის სპეციფიკური მითითებები `L10N/<locale>.md`-ში
