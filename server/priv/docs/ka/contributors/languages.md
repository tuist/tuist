# ენები {#translate}

ენებმა შეიძლება გაართულონ ურთიერთგაგება. ჩვენ გვსურს, Tuist იყოს ხელმისაწვდომი რაც შეიძლება მეტი ადამიანისთვის. თუ საუბრობთ ენაზე, რომელსაც Tuist ჯერ არ უჭერს მხარს, შეგიძლიათ დაეხმაროთ Tuist-ს ამ ენაზე „ლაპარაკში“ ინგლისური წყაროს გაუმჯობესებით და ლოკალიზაციის კონტექსტის განახლებით, რაც მართავს ჩვენს თარგმნის პროცესს.

ვინაიდან ენების მხარდაჭერა უწყვეტი პროცესია, ჩვენ ვამატებთ ახალ ენებს მაშინ, როდესაც ჩნდებიან მოხალისეები, რომლებიც მზად არიან დაგვეხმარონ მათ შენარჩუნებაში. ამჟამად მხარდაჭერილია შემდეგი ენები:

- ინგლისური
- ესპანური
- იაპონური
- ქართული
- კორეული
- რუსული
- კანტონური
- ჩინური (გამარტივებული)
- ჩინური (ტრადიციული)

> [!TIP]
> **მოითხოვეთ ახალი ენა**
>
> თუ მიიჩნევთ, რომ Tuist-ს სარგებლობას მოუტანს ახალი ენის მხარდაჭერა, გთხოვთ, შექმნათ ახალი [თემა საზოგადოების ფორუმზე](https://community.tuist.io/c/general/4) და განიხილოთ ეს საკითხი საზოგადოებასთან ერთად.


## როგორ დაეხმაროთ {#how-to-translate}

Tuist-ის ენების მხარდაჭერა იმართება რეპოზიტორიიდან. კონტრიბუტორები ანახლებენ ინგლისურ წყაროს და თარგმნის კონტექსტს, ხოლო ჩვენი თარგმნის პროცესი ავტომატურად ქმნის ლოკალიზებულ ფაილებს.

სამუშაო პროცესი ასეთია:

1. განაახლეთ ინგლისური წყაროს შინაარსი.
2. განაახლეთ შესაბამისი `L10N.md` კონტექსტი, თუ თარგმნელებს დამატებითი მითითებები სჭირდებათ.
3. გახსენით pull request ამ ცვლილებებით წყაროში.
4. მას შემდეგ, რაც ცვლილებები შევა `main`-ში, თარგმნის პროცესი ხელახლა შექმნის სამიზნე `.po` ფაილებს და გახსნის მომდევნო pull request-ს თარგმნილი განახლებებით.

> [!WARNING]
> **ნუ შეცვლით ავტომატურად შექმნილ ლოკალიზებულ შინაარსს**
>
> პირდაპირ ნუ ჩაასწორებთ ავტომატურად შექმნილ ლოკალიზებულ შინაარსს. ამის ნაცვლად, განაახლეთ ინგლისური წყარო და ენის კონტექსტი.


## L10N.md სტრუქტურა {#l10n-md-structure}

`L10N.md` ფაილები განსაზღვრავენ კონტექსტს, რომელიც ეგზავნება თარგმნის მოდელს. მათზე ფიქრის ყველაზე მარტივი გზაა, წარმოიდგინოთ ისინი როგორც ენობრივი ინსტრუქციები, რომლებიც შეიძლება განთავსდეს სხვადასხვა დირექტორიის დონეზე.

მაგალითად:

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## დირექტორიის კონტექსტი {#directory-context}

თარგმნის სკრიპტი გადადის რეპოზიტორიის ფესვიდან იმ დირექტორიამდე, რომელიც ითარგმნება, და აერთიანებს ყოველ `L10N.md` ფაილს, რომელსაც ამ გზაზე პოულობს.

ზემოთ მოყვანილ მაგალითში:

- `L10N.md` მოქმედებს გლობალურად.
- `server/L10N.md` ამატებს სერვერისთვის სპეციფიკურ კონტექსტს.
- `server/L10N/es.md` ამატებს მხოლოდ ესპანური ენის გადაფარვებს იმავე არეალისთვის.

ეს ნიშნავს, რომ შეგიძლიათ განათავსოთ კონტექსტი იქ, სადაც მას ადგილი აქვს:

- რეპოზიტორიის მასშტაბით მითითებები ფესვში
- არეალისთვის სპეციფიკური მითითებები ქვედირექტორიაში
- ენისთვის სპეციფიკური მითითებები `L10N/<locale>.md`-ში
