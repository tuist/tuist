# ენები {#translate}

ენებმა შეიძლება გაართულონ გაგება. ჩვენ გვსურს, რომ Tuist იყოს ხელმისაწვდომი რაც შეიძლება მეტი ადამიანისთვის. თუ საუბრობთ ენაზე, რომელსაც Tuist ჯერ არ უჭერს მხარს, შეგიძლიათ დაეხმაროთ Tuist-ს ამ ენაზე საუბარში ინგლისური წყაროს გაუმჯობესებით და ლოკალიზაციის კონტექსტის განვითარებით, რომელსაც [Glossia](https://glossia.ai) იყენებს თარგმნისას.

რადგან ენების მხარდაჭერა უწყვეტი პროცესია, ჩვენ ვამატებთ ენებს მაშინ, როდესაც გამოჩნდებიან კონტრიბუტორები, რომლებიც მზად არიან დაგვეხმარონ მათ შენარჩუნებაში. ამჟამად მხარდაჭერილია შემდეგი ენები:

- ინგლისური
- ესპანური
- იაპონური
- ქართული
- კორეული
- რუსული
- კანტონური
- გამარტივებული ჩინური
- ტრადიციული ჩინური

> [!TIP]
> **მოითხოვეთ ახალი ენა**
>
> თუ ფიქრობთ, რომ Tuist-ს სარგებლობა მოუტანს ახალი ენის მხარდაჭერას, გთხოვთ, შექმნათ ახალი [თემა საზოგადოების ფორუმზე](https://community.tuist.io/c/general/4) ამ საკითხის საზოგადოებასთან განსახილველად.


## როგორ დაეხმაროთ {#how-to-translate}

Tuist-ის ენების მხარდაჭერა რეპოზიტორიიდან ხორციელდება. კონტრიბუტორები ანახლებენ ინგლისურ წყაროს და თარგმნის კონტექსტს, ხოლო [Glossia](https://glossia.ai) ავტომატურად ქმნის ლოკალიზებულ ფაილებს.

სამუშაო პროცესი ასეთია:

1. განაახლეთ ინგლისური წყაროს შინაარსი.
2. განაახლეთ შესაბამისი `L10N.md` კონტექსტი, თუ თარგმნებს დამატებითი მითითებები სჭირდებათ.
3. გახსენით pull request აღნიშნული ცვლილებებით წყაროში.
4. მას შემდეგ, რაც ცვლილებები `main`-ზე განთავსდება, Glossia თარგმნის შეცვლილ ნაწილებს და ღია ტოვებს თარგმნის pull request-ს განახლებული ლოკალიზებული ფაილებით.

> [!WARNING]
> **არ შეცვალოთ გენერირებული ლოკალიზებული შინაარსი**
>
> არ ჩაასწოროთ პირდაპირ გენერირებული ლოკალიზებული შინაარსი. ამის ნაცვლად, განაახლეთ ინგლისური წყარო და ენის კონტექსტი.


## L10N.md სტრუქტურა {#l10n-md-structure}

`L10N.md` ფაილები განსაზღვრავენ კონტექსტს, რომელსაც Glossia იყენებს თარგმნისას. მათზე ფიქრის ყველაზე მარტივი გზაა, განიხილოთ ისინი როგორც ენის ინსტრუქციები, რომლებიც შეიძლება განთავსდეს დირექტორიების სხვადასხვა დონეზე.

მაგალითად:

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## დირექტორიის კონტექსტი {#directory-context}

Glossia გადადის რეპოზიტორიის ძირიდან იმ დირექტორიამდე, რომელიც თარგმნილია, და აერთიანებს ყველა `L10N.md` ფაილს, რომელსაც ამ გზაზე პოულობს.

ზემოთ მოცემულ მაგალითში:

- `L10N.md` მოქმედებს გლობალურად.
- `server/L10N.md` ამატებს სერვერისთვის სპეციფიკურ კონტექსტს.
- `server/L10N/es.md` ამატებს მხოლოდ ესპანურენოვან გადაფარვებს იმავე არეალისთვის.

ეს ნიშნავს, რომ შეგიძლიათ განათავსოთ კონტექსტი იქ, სადაც მას ადგილი აქვს:

- რეპოზიტორიის მასშტაბის მითითებები ძირში
- არეალისთვის სპეციფიკური მითითებები ქვედირექტორიაში
- ენისთვის სპეციფიკური მითითებები `L10N/<locale>.md`-ში
