# ენები {#translate}

ენები შეიძლება იყოს გაგების ბარიერი. ჩვენ გვსურს, რომ Tuist იყოს ხელმისაწვდომი რაც შეიძლება მეტი ადამიანისთვის. თუ საუბრობთ ენაზე, რომელსაც Tuist ჯერ არ უჭერს მხარს, შეგიძლიათ დაეხმაროთ Tuist-ს ამ ენაზე „ლაპარაკში“ ინგლისური წყაროს გაუმჯობესებით და ლოკალიზაციის კონტექსტის განვითარებით, რომელსაც [Glossia](https://glossia.ai) იყენებს თარგმნისთვის.

რადგან ენების მხარდაჭერა უწყვეტი პროცესია, ჩვენ ვამატებთ ენებს მაშინ, როდესაც ჩნდებიან მოხალისეები, რომლებიც მზად არიან დაგვეხმარონ მათ შენარჩუნებაში. ამჟამად მხარდაჭერილია შემდეგი ენები:

- ინგლისური
- არაბული
- ესპანური
- იაპონური
- ქართული
- კორეული
- რუსული
- კანტონური
- ჩინური (გამარტივებული)
- ჩინური (ტრადიციული)

> [!TIP]
> **მოითხოვეთ ახალი ენა**
>
> თუ ფიქრობთ, რომ Tuist-ს სარგებლობას მოუტანდა ახალი ენის მხარდაჭერა, გთხოვთ, შექმნათ ახალი [თემა საზოგადოების ფორუმზე](https://community.tuist.io/c/general/4) ამ საკითხის საზოგადოებასთან განსახილველად.


## როგორ დაეხმაროთ {#how-to-translate}

Tuist-ის ენების მხარდაჭერა რეპოზიტორიიდან იმართება. კონტრიბუტორები ანახლებენ ინგლისურ წყაროს და თარგმნის კონტექსტს, ხოლო [Glossia](https://glossia.ai) ავტომატურად ქმნის ლოკალიზებულ ფაილებს.

სამუშაო პროცესი ასეთია:

1. განაახლეთ ინგლისური წყაროს შინაარსი.
2. განაახლეთ შესაბამისი `L10N.md` კონტექსტი, თუ თარგმნებს დამატებითი მითითებები სჭირდებათ.
3. შექმენით pull request აღნიშნული ცვლილებებით.
4. მას შემდეგ, რაც ცვლილებები `main`-ზე აისახება, Glossia თარგმნის შეცვლილ ნაწილებს და ტოვებს ღია თარგმნის pull request-ს განახლებული ლოკალიზებული ფაილებით.

> [!WARNING]
> **არ შეცვალოთ გენერირებული ლოკალიზებული შინაარსი**
>
> არ ჩაასწოროთ პირდაპირ გენერირებული ლოკალიზებული შინაარსი. ამის ნაცვლად, განაახლეთ ინგლისური წყარო და ენის კონტექსტი.


## L10N.md-ის სტრუქტურა {#l10n-md-structure}

`L10N.md` ფაილები განსაზღვრავენ კონტექსტს, რომელსაც Glossia იყენებს თარგმნისას. მათზე ფიქრის ყველაზე მარტივი გზაა, როგორც ენის სკოპირებული ინსტრუქციებისა, რომლებიც შეიძლება სხვადასხვა დირექტორიის დონეზე იყოს განთავსებული.

მაგალითად:

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## დირექტორიის კონტექსტი {#directory-context}

Glossia გადაადგილდება რეპოზიტორიის ფესვიდან თარგმნილი დირექტორიისკენ და აერთიანებს ყველა `L10N.md` ფაილს, რომელსაც ამ გზაზე პოულობს.

ზემოთ მოყვანილ მაგალითში:

- `L10N.md` მოქმედებს გლობალურად.
- `server/L10N.md` ამატებს სერვერისთვის სპეციფიკურ კონტექსტს.
- `server/L10N/es.md` ამატებს მხოლოდ ესპანური ენისთვის განკუთვნილ გადაფარვებს იმავე არეალისთვის.

ეს ნიშნავს, რომ შეგიძლიათ კონტექსტი იქ მოათავსოთ, სადაც ის ეკუთვნის:

- რეპოზიტორიის მასშტაბის მითითებები ფესვში
- არეალის სპეციფიკური მითითებები ქვედირექტორიაში
- ენის სპეციფიკური მითითებები `L10N/<locale>.md`-ში
