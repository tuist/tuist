# ენები {#translate}

ენებმა შეიძლება ხელი შეუშალონ გაგებას. ჩვენ გვინდა, Tuist იყოს ხელმისაწვდომი რაც შეიძლება ბევრი ადამიანისთვის. თუ საუბრობთ ენაზე, რომელსაც Tuist ჯერ არ უჭერს მხარს, შეგიძლიათ დაეხმაროთ Tuist-ს ამ ენაზე საუბარში ინგლისური წყაროს და ლოკალიზაციის კონტექსტის გაუმჯობესებით, რომელსაც [Glossia](https://glossia.ai) იყენებს თარგმნისას.

რადგან ენების მხარდაჭერა უწყვეტი პროცესია, ჩვენ ვამატებთ ენებს, როგორც კი გამოჩნდებიან კონტრიბუტორები, რომლებიც მზად არიან დაგვეხმარონ მათ შენარჩუნებაში. ამჟამად მხარდაჭერილია შემდეგი ენები:

- ინგლისური
- არაბული
- ესპანური
- იაპონური
- ქართული
- კორეული
- რუსული
- კანტონური
- გამარტივებული ჩინური
- ტრადიციული ჩინური

> [!TIP]
> **ახალი ენის მოთხოვნა**
>
> თუ მიიჩნევთ, რომ Tuist-ს სარგებლობა მოუტანდა ახალი ენის მხარდაჭერა, გთხოვთ, შექმნათ ახალი [თემა საზოგადოების ფორუმზე](https://community.tuist.io/c/general/4), რათა განიხილოთ ის საზოგადოებასთან ერთად.


## როგორ დაგვეხმაროთ {#how-to-translate}

Tuist-ის ენების მხარდაჭერა რეპოზიტორიიდან მოდის. კონტრიბუტორები ანახლებენ ინგლისურ წყაროს და თარგმნის კონტექსტს, ხოლო [Glossia](https://glossia.ai) ავტომატურად ქმნის ლოკალიზებულ ფაილებს.

სამუშაო პროცესი ასეთია:

1. განაახლეთ ინგლისური წყაროს შინაარსი.
2. განაახლეთ შესაბამისი `L10N.md` კონტექსტი, თუ თარგმნელებს დამატებითი მითითებები სჭირდებათ.
3. გახსენით pull request ამ წყაროს ცვლილებებით.
4. მას შემდეგ, რაც ცვლილებები `main`-ზე აისახება, Glossia თარგმნის შეცვლილ ნაწილებს და ტოვებს თარგმნის pull request-ს ღიად განახლებული ლოკალიზებული ფაილებით.

> [!WARNING]
> **არ შეცვალოთ გენერირებული ლოკალიზებული შინაარსი**
>
> არ ჩაასწოროთ გენერირებული ლოკალიზებული შინაარსი პირდაპირ. ამის ნაცვლად, განაახლეთ ინგლისური წყარო და ენის კონტექსტი.


## L10N.md სტრუქტურა {#l10n-md-structure}

`L10N.md` ფაილები განსაზღვრავენ კონტექსტს, რომელსაც Glossia იყენებს თარგმნისას. მათზე ფიქრის ყველაზე მარტივი გზაა, როგორც შეზღუდული ენის ინსტრუქციებისა, რომლებიც შეიძლება სხვადასხვა დირექტორიის დონეზე იყოს.

მაგალითად:

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## დირექტორიის კონტექსტი {#directory-context}

Glossia გადადის რეპოზიტორიის ძირიდან იმ დირექტორიამდე, რომელიც თარგმნილია, და აერთიანებს ყველა `L10N.md` ფაილს, რომელსაც ამ გზაზე პოულობს.

ზემოთ მოცემულ მაგალითში:

- `L10N.md` მოქმედებს გლობალურად.
- `server/L10N.md` ამატებს სერვერისთვის სპეციფიკურ კონტექსტს.
- `server/L10N/es.md` ამატებს მხოლოდ ესპანური ენის გადაწერებს იმავე არეალისთვის.

ეს ნიშნავს, რომ შეგიძლიათ განათავსოთ კონტექსტი იქ, სადაც მას ადგილი აქვს:

- რეპოზიტორიის მასშტაბის მითითებები ძირში
- არეალის სპეციფიკური მითითებები ქვედირექტორიაში
- ენის სპეციფიკური მითითებები `L10N/<locale>.md`-ში
