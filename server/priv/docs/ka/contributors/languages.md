# ენები {#translate}

ენები შეიძლება იყოს გაგების ბარიერი. გვინდა, Tuist რაც შეიძლება მეტი ადამიანისთვის იყოს ხელმისაწვდომი. თუ საუბრობთ ენაზე, რომელსაც Tuist ჯერ არ უჭერს მხარს, შეგიძლიათ დაეხმაროთ Tuist-ს ამ ენაზე „ლაპარაკში“ ინგლისური წყაროს და ლოკალიზაციის კონტექსტის გაუმჯობესებით, რომელსაც [Glossia](https://glossia.ai) იყენებს თარგმნისთვის.

რადგან ენების მხარდაჭერა უწყვეტი პროცესია, ვამატებთ ენებს მაშინ, როდესაც ჩნდებიან კონტრიბუტორები, რომლებიც მზად არიან დაგვეხმარონ მათ შენარჩუნებაში. ამჟამად მხარდაჭერილია შემდეგი ენები:

- ინგლისური
- არაბული
- ესპანური
- იაპონური
- ქართული
- კორეული
- რუსული
- კანტონური
- გამარტივებული ჩინური
- ტრადიციული ჩინური

> [!TIP]
> **მოითხოვეთ ახალი ენა**
>
> თუ მიიჩნევთ, რომ Tuist-ს სარგებლობას მოუტანს ახალი ენის მხარდაჭერა, გთხოვთ, შექმნათ ახალი [თემა საზოგადოების ფორუმზე](https://community.tuist.io/c/general/4) მის განსახილველად.


## როგორ დაეხმაროთ {#how-to-translate}

Tuist-ის ენების მხარდაჭერა რეპოზიტორიიდან იმართება. კონტრიბუტორები ანახლებენ ინგლისურ წყაროს და თარგმნის კონტექსტს, ხოლო [Glossia](https://glossia.ai) ავტომატურად ქმნის ლოკალიზებულ ფაილებს.

სამუშაო პროცესი ასეთია:

1. განაახლეთ ინგლისური წყაროს შინაარსი.
2. განაახლეთ შესაბამისი `L10N.md` კონტექსტი, თუ თარგმნებს დამატებითი მითითებები სჭირდებათ.
3. გახსენით pull request აღნიშნული ცვლილებებით.
4. ცვლილებების `main`-ზე მოხვედრის შემდეგ, Glossia თარგმნის შეცვლილ ნაწილებს და ტოვებს ღია თარგმნის pull request-ს განახლებული ლოკალიზებული ფაილებით.

> [!WARNING]
> **არ შეცვალოთ გენერირებული ლოკალიზებული შინაარსი**
>
> არ ჩაასწოროთ პირდაპირ გენერირებული ლოკალიზებული შინაარსი. ამის ნაცვლად, განაახლეთ ინგლისური წყარო და ენის კონტექსტი.


## L10N.md სტრუქტურა {#l10n-md-structure}

`L10N.md` ფაილები განსაზღვრავენ კონტექსტს, რომელსაც Glossia იყენებს თარგმნისას. მათზე ფიქრის ყველაზე მარტივი გზაა, როგორც შეზღუდული ენობრივი ინსტრუქციებისა, რომლებიც შეიძლება სხვადასხვა დირექტორიის დონეზე იყოს განთავსებული.

მაგალითად:

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## დირექტორიის კონტექსტი {#directory-context}

Glossia გადაადგილდება რეპოზიტორიის ფესვიდან თარგმნადი დირექტორიისკენ და აერთიანებს ყველა `L10N.md` ფაილს, რომელსაც ამ გზაზე პოულობს.

ზემოთ მოცემულ მაგალითში:

- `L10N.md` მოქმედებს გლობალურად.
- `server/L10N.md` ამატებს სერვერისთვის სპეციფიკურ კონტექსტს.
- `server/L10N/es.md` ამატებს მხოლოდ ესპანურისთვის განკუთვნილ გადაფარვებს იმავე არეალისთვის.

ეს ნიშნავს, რომ შეგიძლიათ განათავსოთ კონტექსტი იქ, სადაც ის ეკუთვნის:

- რეპოზიტორიის მასშტაბის მითითებები ფესვში
- არეალისთვის სპეციფიკური მითითებები ქვედირექტორიაში
- ენისთვის სპეციფიკური მითითებები `L10N/<locale>.md`-ში
