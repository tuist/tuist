# ბილდ-პლატფორმა გუნდებისა და მათი კოდირების აგენტებისთვის

**Tuist არის ბილდ-პლატფორმა საინჟინრო გუნდებისა და მათი კოდირების აგენტებისთვის.** ის უზრუნველყოფს ბილდისა და ტესტირების სამუშაო პროცესებს Xcode-ში, Gradle-ში, Bazel-ში, Elixir-სა და Rust-ში; Once-ის მხარდაჭერა ხელმისაწვდომია canary ვერსიაში. ის მუშაობს თქვენს მიერ უკვე გამოყენებულ ბილდ-სისტემებთან მათი ჩანაცვლების ნაცვლად. ხელმისაწვდომი ფუნქციები დამოკიდებულია თქვენს ინსტრუმენტთა ნაკრებზე: Rust პროექტები იღებენ Cargo ბილდისა და ტესტირების ანალიტიკას, მათ შორის doctests-ებს, არასტაბილური ტესტების აღმოჩენას და ექსპერიმენტულ კომპილაციურ ქეშირებას. Once პირდაპირ უკავშირდება გაზიარებული ქეშირების, ბილდისა და ტესტირების ანალიტიკის, შარდინგისა და მხარდაჭერილი აპლიკაციის პრევიუებისთვის.

მიჰყევით ერთ-ერთ <.localized_link href="/guides/get-started">დაწყების გზას</.localized_link> თქვენი ბილდ-სისტემისთვის. Once პირდაპირ უკავშირდება Tuist CLI-ს გარეშე; სხვა გზები ხსნიან, თუ რომელი Tuist ინსტრუმენტები უნდა დააინსტალიროთ.
