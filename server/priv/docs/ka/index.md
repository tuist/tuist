# ბილდის პლატფორმა გუნდებისა და მათი კოდირების აგენტებისთვის

**Tuist არის ბილდის პლატფორმა საინჟინრო გუნდებისა და მათი კოდირების აგენტებისთვის.** ის უზრუნველყოფს ბილდისა და ტესტირების სამუშაო პროცესებს Xcode-ში, Gradle-ში, Bazel-ში, Elixir-სა და Rust-ში; Once-ის მხარდაჭერა ხელმისაწვდომია canary ვერსიაში. ის მუშაობს თქვენს მიერ უკვე გამოყენებულ ბილდის სისტემებთან მათი ჩანაცვლების ნაცვლად. ხელმისაწვდომი ფუნქციები დამოკიდებულია თქვენს ინსტრუმენტებზე: Rust პროექტები იღებენ Cargo ბილდისა და ტესტების ანალიტიკას, რაც მოიცავს doctests-ებს, ცვალებადი ტესტების აღმოჩენას და ექსპერიმენტულ კომპილაციის ქეშირებას. Once პირდაპირ უკავშირდება საერთო ქეშირების, ბილდისა და ტესტების ანალიტიკის, შარდინგისა და მხარდაჭერილი აპლიკაციის პრევიუებისთვის.

მიჰყევით ერთ-ერთ <.localized_link href="/guides/get-started">დაწყების გზას</.localized_link> თქვენი ბილდის სისტემისთვის. Once პირდაპირ უკავშირდება Tuist CLI-ს გარეშე; სხვა გზები ხსნიან, თუ რომელი Tuist ინსტრუმენტები უნდა დააინსტალიროთ.
