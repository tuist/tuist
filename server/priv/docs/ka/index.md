# ბილდის პლატფორმა გუნდებისა და მათი კოდირების აგენტებისთვის

**Tuist არის ბილდის პლატფორმა საინჟინრო გუნდებისა და მათი კოდირების აგენტებისთვის.** ის უზრუნველყოფს ბილდისა და ტესტირების სამუშაო პროცესებს Xcode-ში, Gradle-ში, Bazel-ში, Elixir-სა და Rust-ში; Struo-ს მხარდაჭერა ხელმისაწვდომია canary ვერსიაში. ის მუშაობს თქვენს მიერ უკვე გამოყენებულ ბილდის სისტემებთან მათი ჩანაცვლების ნაცვლად. ხელმისაწვდომი ფუნქციები დამოკიდებულია თქვენს ინსტრუმენტებზე: Rust პროექტები იღებენ Cargo ბილდისა და ტესტირების ანალიტიკას, მათ შორის doctests-ს, არასტაბილური ტესტების აღმოჩენას და ექსპერიმენტულ კომპილაციურ ქეშირებას. Struo უკავშირდება ნატიურად საერთო ქეშირების, ბილდისა და ტესტირების ანალიტიკის, შარდინგისა და მხარდაჭერილი აპლიკაციის პრევიუებისთვის.

მიჰყევით ერთ-ერთ <.localized_link href="/guides/get-started">დაწყების გზას</.localized_link> თქვენი ბილდის სისტემისთვის. Struo უკავშირდება პირდაპირ Tuist CLI-ს გარეშე; სხვა გზები ხსნიან, თუ რომელი Tuist ინსტრუმენტები უნდა დააინსტალიროთ.
