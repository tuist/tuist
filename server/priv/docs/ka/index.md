# ვირტუალური პლატფორმის გუნდი დეველოპერებისთვის, რომლებიც პროდუქტს უშვებენ

**Tuist ეხმარება გუნდებს აპლიკაციების განვითარების მასშტაბირებაში და სწრაფად გამოშვებაში**, რთული კოდბაზების სირთულეს პროდუქტიულ გამოცდილებად აქცევს, რომელიც თქვენს გუნდთან ერთად იზრდება. ის მუშაობს თქვენს მიერ უკვე გამოყენებულ ბილდ სისტემებთან Xcode-ის, Gradle-ის, Bazel-ის, Elixir-ის, Rust-ის და Once პროექტებში. ხელმისაწვდომი ფუნქციები დამოკიდებულია თქვენს ინსტრუმენტებზე: Rust პროექტები იღებენ Cargo ბილდისა და ტესტების ანალიტიკას, მათ შორის doctests-ს, არასტაბილური ტესტების აღმოჩენას და ექსპერიმენტულ კომპილაციის ქეშირებას. Once ნატიურად უკავშირდება საერთო ქეშირების, ბილდისა და ტესტების ანალიტიკის, შარდინგისა და მხარდაჭერილი აპლიკაციის პრივიუებისთვის.

მიჰყევით ერთ-ერთ <.localized_link href="/guides/get-started">დაწყების გზას</.localized_link> თქვენი ბილდ სისტემისთვის. Once პირდაპირ უკავშირდება Tuist CLI-ის გარეშე; სხვა გზები ხსნიან, თუ რომელი Tuist ინსტრუმენტები უნდა დააინსტალიროთ.
