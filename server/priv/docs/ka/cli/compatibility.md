# თავსებადობა {#compatibility}

Tuist CLI უკავშირდება Tuist სერვერს ისეთი ფუნქციებისთვის, როგორიცაა კეში, ბილდისა და ტესტების ანალიტიკა, პრივიუები და რეესტრი. სერვერი განახლებადია უწყვეტად და დამოუკიდებლად იმისგან, თუ როდის ახდენთ CLI-ის განახლებას, ამიტომ სერვერის ცვლილებამ არ უნდა გააფუჭოს თქვენ მიერ გამოყენებული CLI ვერსია. ამის გარანტირებისთვის, სერვერი თავსებადია ბოლოდროინდელ CLI გამოცემებთან განსაზღვრული პერიოდის განმავლობაში.

## მხარდაჭერის პერიოდი {#support-window}

Tuist სერვერი მხარს უჭერს CLI გამოცემებს **ბოლო 3 თვის** განმავლობაში. ამ პერიოდის განმავლობაში სერვერი ინარჩუნებს უკუთავსებადობას: ნებისმიერი CLI, რომელიც გამოიცა ბოლო 3 თვის განმავლობაში, აგრძელებს ბილდს, ქეშირებას და ტესტების გაშვებას სერვერზე, ხოლო თქვენ შეგიძლიათ განაახლოთ CLI საკუთარი გრაფიკით ისე, რომ სერვერის ცვლილებამ პრობლემა არ შეგიქმნათ.

CLI ემორჩილება [სემანტიკურ ვერსიირებას](https://semver.org). მხარდაჭერილია ნებისმიერი გამოცემა, რომელიც გამოქვეყნდა ბოლო 3 თვის განმავლობაში.

## პერიოდის გარეთ {#outside-the-window}

მხარდაჭერის პერიოდზე უფრო ძველი CLI გამოცემები ჩაითვლება მოძველებულად. სერვერი მაინც პასუხობს, მაგრამ:

- სერვერის ახალმა ფუნქციებმა შესაძლოა არ იმუშაონ ამ ვერსიასთან.
- სერვერზე დაფუძნებულმა ბრძანებებმა შესაძლოა გამოსცენ გაფრთხილება განახლების თხოვნით.

მოძველებულ ვერსიებზე ქცევა გარანტირებული არ არის. თუ ასეთ ვერსიას იყენებთ, გადადით მხარდაჭერის პერიოდში მყოფ გამოცემაზე.

## როგორ ვასრულებთ პირობას {#how-we-keep-the-promise}

უკუთავსებადობა მოწმდება და არა ვარაუდობენ. სერვერის ყოველი განლაგება ავტომატურად ამოწმებს მიღების ტესტს **მხარდაჭერის პერიოდში მყოფ ყველაზე ძველ CLI გამოცემასთან**, რომელიც ამჟამად არის `{{minimum_supported_cli_version}}`, და ამოწმებს ქეშის წამოღების გზას ბოლომდე. თუ ცვლილება გააფუჭებს ამ ვერსიას, განლაგება იბლოკება პროდაქშენში მოხვედრამდე. ეს პროცესი მიმდინარეობს უახლეს CLI-ზე ჩატარებულ ტესტებთან ერთად, რათა ძველი კლიენტების რეგრესია აღმოჩენილი იქნას იმავე გზით, როგორც უახლესის შემთხვევაში.

## რეკომენდაცია {#recommendation}

განაახლეთ CLI სულ მცირე 3 თვეში ერთხელ, რათა დარჩეთ მხარდაჭერილ პერიოდში. CLI ვერსიის ფიქსაცია CI-ში და მისი რეგულარული განახლება უზრუნველყოფს, რომ თქვენი გუნდი იყოს თანმიმდევრულ, მხარდაჭერილ გამოცემაზე.
