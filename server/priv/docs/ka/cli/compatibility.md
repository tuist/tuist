# თავსებადობა {#compatibility}

Tuist CLI უკავშირდება Tuist სერვერს ისეთი ფუნქციებისთვის, როგორიცაა კეში, ბილდისა და ტესტების ანალიტიკა, პრივიუები და რეესტრი. სერვერი განახლებებს მუდმივად და დამოუკიდებლად იმისგან, თუ როდის ახდენთ CLI-ის განახლებას, ამიტომ სერვერის ცვლილებამ არ უნდა გაფუჭოს თქვენ მიერ გამოყენებული CLI-ის ვერსია. ამის გარანტიისთვის, სერვერი ინარჩუნებს თავსებადობას ბოლოდროინდელ CLI-ის გამოშვებებთან განსაზღვრული პერიოდის განმავლობაში.

## მხარდაჭერის პერიოდი {#support-window}

Tuist სერვერი მხარს უჭერს CLI-ის გამოშვებებს **ბოლო 3 თვის** განმავლობაში. ამ პერიოდში სერვერი ინარჩუნებს უკუთავსებადობას: ნებისმიერი CLI, რომელიც გამოიცა ბოლო 3 თვის განმავლობაში, აგრძელებს ბილდის შექმნას, კეშირებას და ტესტების გაშვებას სერვერზე, ხოლო თქვენ შეგიძლიათ განაახლოთ CLI საკუთარი გრაფიკით ისე, რომ სერვერის ცვლილებამ პრობლემა არ შეგიქმნათ.

CLI ემორჩილება [სემანტიკურ ვერსირებას](https://semver.org). მხარდაჭერილია ნებისმიერი გამოშვება, რომელიც გამოქვეყნდა ბოლო 3 თვის განმავლობაში.

## პერიოდის გარეთ {#outside-the-window}

მხარდაჭერის პერიოდზე უფრო ძველი CLI-ის გამოშვებები ჩაითვლება მოძველებულად. სერვერი კვლავ პასუხობს, მაგრამ:

- სერვერის ახალმა ფუნქციებმა შეიძლება არ იმუშაოს ამ ვერსიასთან.
- სერვერზე დამყარებულმა ბრძანებებმა შეიძლება გამოსცენ გაფრთხილება განახლების შესახებ.

მოძველებულ ვერსიებზე ქცევა გარანტირებული არ არის. თუ ასეთ ვერსიას იყენებთ, გადადით მხარდაჭერის პერიოდში მყოფ გამოშვებაზე.

## როგორ ვასრულებთ დაპირებას {#how-we-keep-the-promise}

უკუთავსებადობა მოწმდება და არ არის ვარაუდი. ყოველი სერვერის განლაგება ავტომატურად ატარებს მიღების ტესტს **მხარდაჭერის პერიოდში მყოფ ყველაზე ძველ CLI-ის გამოშვებაზე**, რომელიც ამჟამად არის `{{minimum_supported_cli_version}}`, რაც სრულად ამოწმებს კეშის წამოღების გზას. თუ ცვლილება დააზიანებდა ამ ვერსიას, განლაგება დაიბლოკება პროდაქშენში მოხვედრამდე. ეს პროცესი მიმდინარეობს უახლეს CLI-ზე ჩატარებულ ტესტებთან ერთად, რათა ძველი კლიენტების რეგრესია იგივე გზით აღმოჩნდეს, როგორც უახლესის.

## რეკომენდაცია {#recommendation}

განაახლეთ CLI სულ მცირე 3 თვეში ერთხელ, რათა დარჩეთ მხარდაჭერილ პერიოდში. CI-ში CLI-ის ვერსიის ფიქსაცია და მისი რეგულარული განახლება უზრუნველყოფს, რომ თქვენი გუნდი იყოს თანმიმდევრულ, მხარდაჭერილ გამოშვებაზე.
