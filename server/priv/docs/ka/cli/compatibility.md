# თავსებადობა {#compatibility}

Tuist CLI უკავშირდება Tuist სერვერს ისეთი ფუნქციებისთვის, როგორიცაა ქეში, ბილდისა და ტესტების ანალიტიკა, პრივიუები და რეესტრი. სერვერი განახლდება მუდმივად და დამოუკიდებლად იმისგან, თუ როდის ახდენთ CLI-ის განახლებას, ამიტომ სერვერის ცვლილება არ უნდა არღვევდეს თქვენს მიერ გამოყენებულ CLI ვერსიას. ამის გარანტირებისთვის სერვერი ინარჩუნებს თავსებადობას CLI-ის ბოლო გამოცემებთან განსაზღვრული პერიოდის განმავლობაში.

## მხარდაჭერის პერიოდი {#support-window}

Tuist სერვერი მხარს უჭერს CLI-ის იმ გამოცემებს, რომლებიც გამოქვეყნდა **ბოლო 3 თვის** განმავლობაში. ამ პერიოდის ფარგლებში სერვერი ინარჩუნებს უკუთავსებადობას: ნებისმიერი CLI, რომელიც გამოქვეყნდა ბოლო 3 თვის განმავლობაში, აგრძელებს ბილდების შესრულებას, ქეშირებას და ტესტების გაშვებას სერვერთან ერთად, ხოლო თქვენ შეგიძლიათ განაახლოთ CLI თქვენი გრაფიკის მიხედვით ისე, რომ სერვერის ცვლილებამ არ შეგიშალოთ ხელი.

CLI ემორჩილება [სემანტიკურ ვერსირებას](https://semver.org). მხარდაჭერილია ნებისმიერი გამოცემა, რომელიც გამოქვეყნდა ბოლო 3 თვის განმავლობაში.

## პერიოდის გარეთ {#outside-the-window}

CLI-ის ის გამოცემები, რომლებიც ძველია მხარდაჭერის პერიოდზე, განიხილება როგორც მოძველებული. სერვერი კვლავ პასუხობს, მაგრამ:

- სერვერის ახალმა ფუნქციებმა შეიძლება არ იმუშაოს ამ ვერსიასთან.
- სერვერზე დამყარებულმა ბრძანებებმა შეიძლება გამოსცენ გაფრთხილება განახლების შესახებ.

მოძველებულ ვერსიებზე ქცევა გარანტირებული არ არის. თუ იყენებთ ასეთ ვერსიას, განაახლეთ ის მხარდაჭერის პერიოდში მყოფ გამოცემამდე.

## როგორ ვასრულებთ დაპირებას {#how-we-keep-the-promise}

უკუთავსებადობა მოწმდება და არ არის ვარაუდი. სერვერის ყოველი განთავსება ავტომატურად ასრულებს მიღების ტესტს **მხარდაჭერის პერიოდში დარჩენილ უძველეს CLI გამოცემასთან**, რომელიც ამჟამად არის `{{minimum_supported_cli_version}}`, რითაც სრულად მოწმდება ქეშის ჩამოტვირთვის გზა. თუ ცვლილება დაარღვევდა ამ ვერსიას, განთავსება იბლოკება პროდაქშენში მოხვედრამდე. ეს პროცესი მიმდინარეობს უახლეს CLI-თან ტესტირების პარალელურად, რათა ძველი კლიენტების რეგრესია აღმოჩენილ იქნას ისევე, როგორც უახლესის.

## რეკომენდაცია {#recommendation}

განაახლეთ CLI მინიმუმ 3 თვეში ერთხელ, რათა დარჩეთ მხარდაჭერილ პერიოდში. CLI ვერსიის CI-ში ფიქსაცია და მისი რეგულარული განახლება უზრუნველყოფს, რომ თქვენი გუნდი იყოს თანმიმდევრულ, მხარდაჭერილ გამოცემაზე.
