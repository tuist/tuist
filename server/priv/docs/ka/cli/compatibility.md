# თავსებადობა {#compatibility}

Tuist CLI უკავშირდება Tuist სერვერს ისეთი ფუნქციებისთვის, როგორიცაა კეში, ბილდისა და ტესტების ანალიტიკა, პრივიუები და რეესტრი. სერვერი მუდმივად განახლებადია და დამოუკიდებელია იმისგან, თუ როდის ახდენთ CLI-ის განახლებას, ამიტომ სერვერის ცვლილება არ უნდა არღვევდეს თქვენს მიერ გამოყენებულ CLI ვერსიას. ამის გარანტირებისთვის, სერვერი ინარჩუნებს თავსებადობას ბოლო CLI გამოცემებთან განსაზღვრული პერიოდის განმავლობაში.

## მხარდაჭერის პერიოდი {#support-window}

Tuist სერვერი მხარს უჭერს CLI-ის იმ გამოცემებს, რომლებიც გამოქვეყნდა **ბოლო 3 თვის** განმავლობაში. ამ პერიოდის ფარგლებში სერვერი ინარჩუნებს უკუთავსებადობას: ნებისმიერი CLI, რომელიც ბოლო 3 თვეში გამოქვეყნდა, აგრძელებს ბილდის შესრულებას, კეშირებას და ტესტების გაშვებას სერვერთან მიმართებაში, ხოლო თქვენ შეგიძლიათ განაახლოთ CLI თქვენი გრაფიკის მიხედვით ისე, რომ სერვერის ცვლილებამ პრობლემა არ შეგიქმნათ.

CLI ემორჩილება [სემანტიკურ ვერსირებას](https://semver.org). მხარდაჭერილია ნებისმიერი გამოცემა, რომელიც ბოლო 3 თვის განმავლობაში გამოქვეყნდა.

## პერიოდის გარეთ {#outside-the-window}

მხარდაჭერის პერიოდზე ძველი CLI გამოცემები ჩაითვლება მოძველებულად. სერვერი კვლავ პასუხობს, მაგრამ:

- სერვერის ახალი ფუნქციები შეიძლება არ მუშაობდეს ამ ვერსიასთან.
- სერვერზე დამოკიდებული ბრძანებები შეიძლება გამოიტანონ გაფრთხილებას განახლების მოთხოვნით.

მოძველებულ ვერსიებზე ქცევა გარანტირებული არ არის. თუ ასეთ ვერსიას იყენებთ, გადადით მხარდაჭერის პერიოდში მყოფ გამოცემაზე.

## როგორ ვასრულებთ დაპირებას {#how-we-keep-the-promise}

უკუთავსებადობა მოწმდება და არ იგულისხმება. სერვერის ყოველი განთავსება ავტომატურად ამოწმებს მიღების ტესტს **მხარდაჭერის პერიოდში მყოფ უძველეს CLI გამოცემასთან**, რომელიც ამჟამად არის `{{minimum_supported_cli_version}}`, და ამოწმებს კეშიდან მონაცემების ამოღების სრულ ციკლს. თუ ცვლილება დაარღვევდა ამ ვერსიას, განთავსება იბლოკება პროდაქშენში მოხვედრამდე. ეს პროცესი მიმდინარეობს უახლეს CLI-თან ტესტირების პარალელურად, რათა ძველი კლიენტების რეგრესია იგივე გზით აღმოჩნდეს, როგორც უახლესის შემთხვევაში.

## რეკომენდაცია {#recommendation}

განაახლეთ CLI სულ მცირე 3 თვეში ერთხელ, რათა დარჩეთ მხარდაჭერილ პერიოდში. CI-ში CLI ვერსიის ფიქსაცია და მისი რეგულარული განახლება უზრუნველყოფს, რომ თქვენი გუნდი მუშაობდეს თანმიმდევრულ, მხარდაჭერილ გამოცემაზე.
