# თავსებადობა {#compatibility}

Tuist CLI უკავშირდება Tuist სერვერს ისეთი ფუნქციებისთვის, როგორიცაა კეში, ბილდისა და ტესტების ანალიტიკა, პრივიუები და რეესტრი. სერვერი განახლებებს იღებს მუდმივად და დამოუკიდებლად იმისგან, თუ როდის ახდენთ CLI-ის განახლებას, ამიტომ სერვერის ცვლილებამ არ უნდა დაარღვიოს თქვენ მიერ გამოყენებული CLI-ის ვერსია. ამის გარანტიისთვის, სერვერი თავსებადია CLI-ის ბოლო რელიზებთან განსაზღვრული პერიოდის განმავლობაში.

## მხარდაჭერის პერიოდი {#support-window}

Tuist სერვერი მხარს უჭერს CLI-ის რელიზებს **ბოლო 3 თვის** განმავლობაში. ამ პერიოდში სერვერი ინარჩუნებს უკუთავსებადობას: ნებისმიერი CLI, რომელიც გამოქვეყნდა ბოლო 3 თვის განმავლობაში, აგრძელებს ბილდის შექმნას, კეშირებას და ტესტების გაშვებას სერვერზე, ხოლო თქვენ შეგიძლიათ განაახლოთ CLI თქვენი გრაფიკის მიხედვით ისე, რომ სერვერის ცვლილებამ პრობლემა არ შეგიქმნათ.

CLI ემორჩილება [სემანტიკურ ვერსირებას](https://semver.org). მხარდაჭერილია ნებისმიერი რელიზი, რომელიც გამოქვეყნდა ბოლო 3 თვის განმავლობაში.

## პერიოდის გარეთ {#outside-the-window}

CLI-ის რელიზები, რომლებიც ძველია მხარდაჭერის პერიოდზე, ჩაითვლება მოძველებულად. სერვერი კვლავ პასუხობს, მაგრამ:

- სერვერის ახალი ფუნქციები შესაძლოა არ იმუშაოს ამ ვერსიასთან.
- სერვერზე დაფუძნებულმა ბრძანებებმა შესაძლოა გამოიტანონ გაფრთხილება განახლების მოთხოვნით.

მოძველებულ ვერსიებზე ქცევა გარანტირებული არ არის. თუ ასეთ ვერსიას იყენებთ, განაახლეთ რელიზამდე, რომელიც მხარდაჭერის პერიოდშია.

## როგორ ვასრულებთ დაპირებას {#how-we-keep-the-promise}

უკუთავსებადობა მოწმდება და არ არის ვარაუდობითი. სერვერის ყოველი განლაგება ავტომატურად ამოწმებს მიღების ტესტს **უძველეს CLI რელიზთან, რომელიც კვლავ მხარდაჭერის პერიოდშია**, რაც ამჟამად არის `{{minimum_supported_cli_version}}`, და ამოწმებს კეშის წამოღების გზას ბოლომდე. თუ ცვლილება დაარღვევდა ამ ვერსიას, განლაგება იბლოკება წარმოებაში გადასვლამდე. ეს პროცესი მიმდინარეობს უახლეს CLI-თან ტესტირების პარალელურად, ამიტომ ძველი კლიენტების რეგრესია აღმოიჩინება ისევე, როგორც უახლესის.

## რეკომენდაცია {#recommendation}

განაახლეთ CLI მინიმუმ ერთხელ ყოველ 3 თვეში, რათა დარჩეთ მხარდაჭერილ პერიოდში. CLI-ის ვერსიის ფიქსაცია CI-ში და მისი რეგულარული განახლება უზრუნველყოფს, რომ თქვენი გუნდი იყოს თანმიმდევრულ, მხარდაჭერილ რელიზზე.
