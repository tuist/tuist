# CLI {#cli}

Tuist CLI არის Tuist-თან ურთიერთქმედების ერთ-ერთი ინტერფეისი და ყველაზე ხშირად გამოყენებადი, თუ იყენებთ <.localized_link href="/guides/features/projects">გენერირებულ პროექტებს</.localized_link>. ის გთავაზობთ ბრძანებებს პროექტების გენერაციისთვის, ბინარული ფაილების ქეშირებისთვის, ტესტების გაშვებისთვის, პრივიუების გაზიარებისთვის და სხვა.

## დაწყება {#getting-started}

თუ ჯერ არ დაგიყენებიათ Tuist, მიჰყევით <.localized_link href="/guides/install-tuist">ინსტალაციის სახელმძღვანელოს</.localized_link> დასაწყებად.

ინსტალაციის შემდეგ, შეგიძლიათ გაუშვათ `tuist` თქვენს ტერმინალში, რათა ნახოთ ხელმისაწვდომი ბრძანებების სია:

```bash
tuist --help
```

## კონფიგურაცია {#configuration}

CLI-ის ქცევის კონფიგურაცია შესაძლებელია `tuist.toml` ფაილის მეშვეობით. ყველა ხელმისაწვდომი პარამეტრის სანახავად იხილეთ <.localized_link href="/references/tuist-toml">tuist.toml-ის ცნობარი</.localized_link>.

## პრობლემების აღმოფხვრა {#troubleshooting}

თუ პრობლემები შეგექმნათ, იხილეთ <.localized_link href="/cli/debugging">გამართვის სახელმძღვანელო</.localized_link> პრობლემების დიაგნოსტიკის ინსტრუმენტებისთვის, მათ შორის სესიის ლოგებისა და ქსელური ჩანაწერებისთვის.
