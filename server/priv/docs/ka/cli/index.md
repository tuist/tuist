# CLI {#cli}

Tuist CLI არის Tuist-თან ურთიერთობის ერთ-ერთი ინტერფეისი და ყველაზე გავრცელებული, თუ იყენებთ <.localized_link href="/guides/features/projects">გენერირებულ პროექტებს</.localized_link>. ის გთავაზობთ ბრძანებებს პროექტების გენერაციისთვის, ბინარული ფაილების ქეშირებისთვის, ტესტების გაშვებისთვის, პრივიუსების გაზიარებისთვის და სხვა.

## დაწყება {#getting-started}

თუ ჯერ არ დაგიყენებიათ Tuist, მიჰყევით <.localized_link href="/guides/install-tuist">დაყენების სახელმძღვანელოს</.localized_link> დასაწყებად.

დაყენების შემდეგ, შეგიძლიათ გაუშვათ `tuist` თქვენს ტერმინალში ხელმისაწვდომი ბრძანებების სიის სანახავად:

```bash
tuist --help
```

## კონფიგურაცია {#configuration}

CLI-ის ქცევის კონფიგურირება შესაძლებელია `tuist.toml` ფაილის მეშვეობით. ყველა ხელმისაწვდომი პარამეტრის სანახავად იხილეთ <.localized_link href="/references/tuist-toml">tuist.toml-ის ცნობარი</.localized_link>.

## პრობლემების აღმოფხვრა {#troubleshooting}

თუ პრობლემებს წააწყდებით, შეამოწმეთ <.localized_link href="/cli/debugging">დებაგინგის სახელმძღვანელო</.localized_link> პრობლემების დიაგნოსტიკის ინსტრუმენტებისთვის, მათ შორის სესიის ლოგებისა და ქსელური ჩანაწერების.
