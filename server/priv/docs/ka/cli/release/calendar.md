# გამოშვების კალენდარი {#release-calendar}

მიჰყევით CLI-ის მიმდინარე ვერსიებს, ბოლო გამოშვებებს და მომავალი გამოშვების ფანჯრებს. არხის გარანტიების, ვერსიის დამაგრების და უკუპორტის პოლიტიკის შესახებ იხილეთ <.localized_link href="/cli/release/channels">გამოშვების არხები</.localized_link>.

სტაბილურად გადაყვანა დაგეგმილია ორშაბათობით 06:00 UTC-ზე. წარმატებული დაგეგმილი გადაყვანის შემდეგ, შემდეგი რელიზის კანდიდატი იჭრება `main`-დან, ხოლო მომდევნო კანარეულები გადადიან შემდეგ მინორულ ვერსიაზე. შეცდომებმა შეიძლება შეანელონ პროცესი, ხოლო მეინთეინერებმა შეიძლება გამოაქვეყნონ განრიგის მიღმა. მომავალი ფანჯრები არის გეგმები და არა დაპირებული გამოქვეყნების დრო.

პეტჩის გამოშვებები და უკუპორტები გამოიცემა მოთხოვნის საფუძველზე და არა ყოველკვირეული განრიგით. ქვემოთ მოცემულ ისტორიაში გამოქვეყნებული გამოშვებები ბმულია მათ შენიშვნებთან და ფაქტიურ გამოქვეყნების თარიღებთან.
