# გამოშვების კალენდარი {#release-calendar}

მიჰყევით CLI-ის მიმდინარე ვერსიებს, ბოლო გამოშვებებს და მომავალი გამოშვების ფანჯრებს. არხების გარანტიების, ვერსიის ფიქსაციისა და უკან გადატანის პოლიტიკის შესახებ იხილეთ <.localized_link href="/cli/release/channels">გამოშვების არხები</.localized_link>.

სტაბილურ ვერსიაზე გადაყვანა დაგეგმილია ორშაბათობით 06:00 UTC-ზე. წარმატებული დაგეგმილი გადაყვანის შემდეგ, შემდეგი რელიზ-კანდიდატი იჭრება `main`-დან, ხოლო მომდევნო კანარეულები გადადიან შემდეგ მცირე ვერსიაზე. შეფერხებებმა შეიძლება შეაყოვნონ პროცესი, ხოლო მეინტეინერებმა შეიძლება გამოაქვეყნონ განრიგის გარეთ. მომავალი ფანჯრები არის გეგმები და არა დაპირებული გამოქვეყნების დრო.

პატჩ-გამოშვებები და უკან გადატანილი ცვლილებები ქვეყნდება საჭიროებისამებრ და არა ყოველკვირეული განრიგით. ქვემოთ მოცემულ ისტორიაში გამოქვეყნებული გამოშვებები დაკავშირებულია მათ შენიშვნებთან და რეალურ გამოქვეყნების თარიღებთან.
