# გამოშვების კალენდარი {#release-calendar}

აქციეთ თვალი CLI-ის მიმდინარე ვერსიებს, ბოლო გამოშვებებს და მომავალი გამოშვების ფანჯრებს. არხების გარანტიების, ვერსიის მიბმისა და უკან გადატანის პოლიტიკის შესახებ იხილეთ <.localized_link href="/cli/release/channels">გამოშვების არხები</.localized_link>.

სტაბილური ვერსიის წარმოჩენა დაგეგმილია ორშაბათობით 06:00 UTC-ზე. წარმატებული დაგეგმილი წარმოჩენის შემდეგ, შემდეგი რელიზის კანდიდატი იჭრება `main`-დან, ხოლო მომდევნო კანარები გადადიან შემდეგ მინორულ ვერსიაზე. შეცდომებმა შეიძლება შეანელონ პროცესი, ხოლო მეინთეინერებს შეუძლიათ გამოაქვეყნონ განრიგის მიღმა. მომავალი ფანჯრები არის გეგმები და არა დაპირებული გამოქვეყნების დრო.

პატჩ-გამოშვებები და უკან გადატანილი ცვლილებები ქვეყნდება საჭიროებისამებრ და არა ყოველკვირეული განრიგით. ქვემოთ მოცემული ისტორია აკავშირებს გამოქვეყნებულ გამოშვებებს მათ შენიშვნებთან და რეალურ გამოქვეყნების თარიღებთან.
