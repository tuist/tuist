# მაგალითები

ამ განყოფილებაში იხილავთ <.localized_link href="/guides/features/projects">გენერირებული პროექტების</.localized_link> მაგალითებს, რომლებსაც ვიყენებთ როგორც [მაგალითებს](https://github.com/tuist/tuist/tree/main/examples/xcode) მიღების ტესტების შესასრულებლად. ისინი შეიძლება სასარგებლო აღმოჩნდეს ახალი გენერირებული პროექტის შექმნისას, ან არსებული Xcode-ის პროექტის Tuist-ით გენერირებაზე გადატანისას.
