ამ სექციაში ნახავთ <.localized_link href="/guides/features/projects">გენერირებული პროექტების</.localized_link> მაგალითებს, რომლებსაც ვიყენებთ როგორც [მაგალითებს](https://github.com/tuist/tuist/tree/main/examples/xcode) მიღების ტესტების ჩასატარებლად. ისინი შეიძლება სასარგებლო აღმოჩნდეთ ახალი გენერირებული პროექტის შექმნისას, ან არსებული Xcode-პროექტის Tuist-ით გენერირებაზე გადაყვანისას.
