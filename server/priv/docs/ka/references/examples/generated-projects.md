# გენერირებული პროექტების მაგალითები

ამ განყოფილებაში ნახავთ <.localized_link href="/guides/features/projects">გენერირებული პროექტების</.localized_link> მაგალითებს, რომლებსაც ვიყენებთ [მაგალითებად](https://github.com/tuist/tuist/tree/main/examples/xcode) მიღების ტესტების ჩასატარებლად. ისინი შეიძლება სასარგებლო აღმოჩნდეს ახალი გენერირებული პროექტის შექმნისას, ან არსებული Xcode-ის პროექტის Tuist-ით გენერირებაზე გადაყვანისას.
