ამ სექციაში იხილავთ <.localized_link href="/guides/features/projects">გენერირებული პროექტების</.localized_link> მაგალითებს, რომლებსაც ვიყენებთ [მაგალითებად](https://github.com/tuist/tuist/tree/main/examples/xcode) მიღების ტესტების ჩასატარებლად. ისინი სასარგებლო შეიძლება აღმოჩნდეს ახალი გენერირებული პროექტის შექმნისას, ან არსებული Xcode-ის პროექტის Tuist-ით გენერირებაზე გადატანისას.
