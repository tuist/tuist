# Origin-ის ინტეგრაცია {#origin}

Tuist-ს შეუძლია ბილდების, ტესტების, პრევიუების და ბანდლების ანგარიშების გამოქვეყნება pull request-ებში ნატიურ [Cursor Origin](https://cursor.com/docs/api/origin) რეპოზიტორიებში. ის აახლებს არსებულ Tuist Run Report-ს ახალი კომენტარის დამატების ნაცვლად ყოველი ატვირთვისას.

აპლიკაციის ინსტალაცია არ ასრულებს ბილდებს ან ტესტებს. თქვენი არსებული სამუშაო პროცესები განაგრძობენ შედეგების ატვირთვას Tuist-ზე, ხოლო ინტეგრაცია ამ შედეგებს თქვენს pull request-ებში აჩვენებს.

## მოწყობა {#setup}

Tuist-ის ანგარიშის ადმინისტრატორმა უნდა გახსნას **Settings → Integrations**, აირჩიოს **Install Origin App** Origin-ის ბარათში და დაადასტუროს წვდომა Cursor-ში. აირჩიეთ Origin-ის ანგარიში ან სივრცე და რეპოზიტორიები, რომლებსაც Tuist უნდა მიუწვდებოდეს, შემდეგ დაუბრუნდით Tuist-ს. კავშირი ეკუთვნის Tuist-ის ანგარიშს და არა ცალკეულ პროექტს.

აპლიკაციის ინსტალაცია შესაძლებელია პირდაპირ Origin-იდან. წვდომის დადასტურების შემდეგ, საჭიროების შემთხვევაში შედით Tuist-ში და აირჩიეთ ორგანიზაცია დასაკავშირებლად. ხელმისაწვდომია მხოლოდ თქვენ მიერ ადმინისტრირებადი ორგანიზაციები და თქვენი პირადი ანგარიში. თუ მხოლოდ ერთი ანგარიშია ხელმისაწვდომი, Tuist მას ავტომატურად დააკავშირებს არჩევნის ფანჯრის ჩვენების გარეშე. თუ Tuist-დან იწყებთ, ორგანიზაცია უკვე შერჩეულია და ეს ნაბიჯი გამოტოვებულია.

აირჩიეთ **Add new project connection** რეპოზიტორიის შერჩევის მოდალის გასახსნელად. აირჩიეთ დაუკავშირებელი Tuist-ის პროექტი და ერთ-ერთი რეპოზიტორია, რომელიც აღმოჩენილია დაკავშირებული Origin-ის ანგარიშიდან, შემდეგ აირჩიეთ **Create Connection**. თუ რამდენიმე Origin-ის ანგარიშია დაკავშირებული, ჯერ აირჩიეთ ანგარიში. დასაკავშირებლად ხელმისაწვდომია მხოლოდ ნატიური Origin-ის რეპოზიტორიები. Tuist კიდევ ერთხელ ამოწმებს pull-request-ზე წვდომას პროექტის დაკავშირებამდე და იღებს რეპოზიტორიის ნაგულისხმებ შტოს.

გამოიყენეთ **Manage integration** Cursor-ის ნებართვის ნაკადის ახალ ჩანართში გასახსნელად და რეპოზიტორიის წვდომის შესაცვლელად ან სხვა Origin-ის ანგარიშის დასაკავშირებლად. რეპოზიტორიების ჩატვირთვის შეცდომები აჩვენებს **Retry**-ს, რაც განცალკევებულია რეპოზიტორიების ცარიელი, მაგრამ წარმატებული სიისგან.

გამოიყენეთ <.localized_link href="/guides/server/authentication#account-tokens">ანგარიშის ტოკენი</.localized_link> შედეგების ატვირთვის ავთენტიკაციისთვის.

## ანგარიშები და ნებართვები {#reports-and-permissions}

აპლიკაციის დადასტურებისას, თქვენ ანიჭებთ ნებართვებს, რომლებიც საჭიროა რეპოზიტორიების დასაკავშირებლად და ანგარიშების გამოსაქვეყნებლად:

| ნებართვა | გამოიყენება |
| --- | --- |
| Pull requests: წაკითხვა | მოძებნეთ გახსნილი pull request მოხსენებული კომიტისთვის. |
| Pull request reviews: წაკითხვა და ჩაწერა | წაიკითხეთ, გამოაქვეყნეთ და განაახლეთ Tuist Run Report-ის კომენტარი. |
| რეპოზიტორიის მეტამონაცემები: წაკითხვა | აღმოაჩინეთ რეპოზიტორიები და მათი ნაგულისხმები შტოები. ავტომატურად შედის Origin-ის მიერ. |

Tuist-ს არ სჭირდება წვდომა თქვენს საწყის კოდზე ან ნებართვა pull request-ების გაერთიანებისთვის.

შედეგების pull request-თან დასაკავშირებლად, ატვირთვებმა უნდა შეიცავდნენ რეპოზიტორიის Origin-ის კლონის URL-ს, Git ref-ს და სრულ კომიტ SHA-ს. Tuist აქვეყნებს ანგარიშს მხოლოდ მაშინ, როცა ეს მონაცემები მიუთითებენ ერთ გახსნილ pull request-ზე მის მიმდინარე head კომიტზე. ჩანაცვლებული კომიტების შედეგები არ ცვლიან მიმდინარე ანგარიშს.

Origin-ის ბარათი ჩამოთვლის პროექტ-რეპოზიტორიის კავშირებს. აირჩიეთ **Manage → Remove connection** პროექტის კავშირზე მისი ანგარიშგების შესაჩერებლად აპლიკაციის წაშლის გარეშე. წაშალეთ აპლიკაცია Cursor-ში მისი წვდომის გაუქმებისთვის; Tuist წაშლის ინსტალაციას და მის პროექტულ კავშირებს ინსტალაციის შეტყობინების დამუშავებისას.

## თვითმასპინძელი სერვერები {#server-configuration}

თუ თქვენ მასპინძლობთ საკუთარ Tuist სერვერს, ჯერ დარეგისტრირეთ და დააკონფიგურირეთ Origin აპლიკაცია თქვენი განლაგებისთვის. მიჰყევით <.localized_link href="/guides/server/self-host/server#platform-origin">Origin-ის თვითმასპინძლობის ინსტრუქციებს</.localized_link>, შემდეგ დაუბრუნდით ზემოთ მოცემულ მოწყობის ნაბიჯებს ანგარიშებისა და პროექტების დასაკავშირებლად.
