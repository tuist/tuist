# Origin ინტეგრაცია {#origin}

Tuist-ს შეუძლია ატვირთოს ბილდის, ტესტების, პრივიუს და ბანდლის ანგარიშები pull request-ებზე ნატიურ [Cursor Origin](https://cursor.com/docs/api/origin) რეპოზიტორიებში. ის აახლებს არსებულ Tuist Run Report-ს იმის ნაცვლად, რომ ყოველი ატვირთვისთვის ახალი კომენტარი დაწეროს.

აპლიკაციის ინსტალაცია არ ასრულებს ბილდებს ან ტესტებს. თქვენი არსებული სამუშაო პროცესები განაგრძობენ შედეგების ატვირთვას Tuist-ში, ხოლო ინტეგრაცია ამ შედეგებს თქვენს pull request-ებში აჩენს.

## მოწყობა {#setup}

Tuist ანგარიშის ადმინისტრატორმა უნდა გახსნას **Settings → Integrations**, აირჩიოს **Install Origin App** Origin ბარათში და დაადასტუროს წვდომა Cursor-ში. აირჩიეთ Origin ანგარიში ან სივრცე და რეპოზიტორიები, რომლებზეც Tuist-ს უნდა ჰქონდეს წვდომა, შემდეგ დაბრუნდით Tuist-ში. კავშირი ეკუთვნის Tuist ანგარიშს და არა ცალკეულ პროექტს.

აპლიკაციის ინსტალაცია შესაძლებელია პირდაპირ Origin-დან. წვდომის დადასტურების შემდეგ, საჭიროების შემთხვევაში, შედით Tuist-ში და აირჩიეთ ორგანიზაცია დასაკავშირებლად. ხელმისაწვდომია მხოლოდ ის ორგანიზაციები, რომლებსაც თქვენ ადმინისტრირებთ და თქვენი პირადი ანგარიში. Tuist ყოველთვის ითხოვს არჩევანს, მაშინაც კი, თუ თქვენი პირადი ანგარიში ერთადერთი ვარიანტია. თუ თქვენი გუნდის Tuist ორგანიზაცია სიაში არ ჩანს, აირჩიეთ **Create an organization**, ან სთხოვეთ მის ერთ-ერთ ადმინისტრატორს, რომ გახდეთ ადმინი. სია განახლდება, სანამ გვერდი გახსნილია, ამიტომ ორგანიზაცია გამოჩნდება თავიდან დაწყების გარეშე, იმ პირობით, რომ Tuist-ში დაბრუნებიდან ათი წუთის განმავლობაში აირჩევთ მას. თუ Tuist-დან იწყებთ, ორგანიზაცია უკვე შერჩეულია და ეს ნაბიჯი გამოტოვებულია.

აირჩიეთ **Add new project connection** რეპოზიტორიის შერჩევის ფანჯრის გასახსნელად. აირჩიეთ დაუკავშირებელი Tuist პროექტი და ერთ-ერთი რეპოზიტორია, რომელიც აღმოჩენილია დაკავშირებული Origin ანგარიშიდან, შემდეგ აირჩიეთ **Create Connection**. თუ რამდენიმე Origin ანგარიშია დაკავშირებული, ჯერ აირჩიეთ ანგარიში. კავშირისთვის ხელმისაწვდომია მხოლოდ ნატიური Origin რეპოზიტორიები. Tuist ხელახლა ამოწმებს pull-request წვდომას პროექტთან დაკავშირებამდე და იღებს რეპოზიტორიის ნაგულისხმევ შტოს.

გამოიყენეთ **Manage integration** Cursor-ის თანხმობის ნაკადის ახალ ჩანართში გასახსნელად და რეპოზიტორიის წვდომის შესაცვლელად ან სხვა Origin ანგარიშის დასაკავშირებლად. რეპოზიტორიის ჩატვირთვის შეცდომები აჩვენებს **Retry**-ს, რაც განსხვავდება წარმატებული ცარიელი რეპოზიტორიების სიისგან.

შედეგების ატვირთვის ავთენტიკაციისთვის გამოიყენეთ <.localized_link href="/guides/server/authentication#account-tokens">account token</.localized_link>.

## ანგარიშები და ნებართვები {#reports-and-permissions}

აპლიკაციის დამტკიცებისას, თქვენ ანიჭებთ ნებართვებს, რომლებიც საჭიროა რეპოზიტორიების დასაკავშირებლად და ანგარიშების გამოსაქვეყნებლად:

| ნებართვა | გამოიყენება |
| --- | --- |
| Pull requests: read | მოძებნეთ გახსნილი pull request მოხსენებული კომიტისთვის. |
| Pull request reviews: read and write | წაიკითხეთ, გამოაქვეყნეთ და განაახლეთ Tuist Run Report კომენტარი. |
| Repository metadata: read | აღმოაჩინეთ რეპოზიტორიები და მათი ნაგულისხმევი შტოები. ავტომატურად შედის Origin-ის მიერ. |

Tuist-ს არ სჭირდება წვდომა თქვენს საწყის კოდზე ან ნებართვა pull request-ების გაერთიანებისთვის.

შედეგების pull request-თან ასოცირებისთვის, ატვირთვებმა უნდა შეიცავდნენ რეპოზიტორიის Origin clone URL-ს, Git ref-ს და სრულ კომიტ SHA-ს. Tuist აქვეყნებს ანგარიშს მხოლოდ მაშინ, როდესაც ეს მონაცემები მიუთითებს ერთ გახსნილ pull request-ზე მის მიმდინარე head კომიტზე. ჩანაცვლებული კომიტების შედეგები არ ცვლის მიმდინარე ანგარიშს.

Origin ბარათი ჩამოთვლის პროექტ-რეპოზიტორიის კავშირებს. აირჩიეთ **Manage → Remove connection** პროექტის კავშირზე, რათა შეწყვიტოთ მისი ანგარიშგება აპლიკაციის წაშლის გარეშე. წაშალეთ აპლიკაცია Cursor-ში მისი წვდომის გაუქმებისთვის; Tuist წაშლის ინსტალაციას და მის პროექტულ კავშირებს, როდესაც დაამუშავებს ინსტალაციის შეტყობინებას.

## თვითმასპინძელი სერვერები {#server-configuration}

თუ თქვენ მასპინძლობთ საკუთარ Tuist სერვერს, ჯერ დაარეგისტრირეთ და მოაწყვეთ Origin აპლიკაცია თქვენი განლაგებისთვის. მიჰყევით <.localized_link href="/guides/server/self-host/server#platform-origin">Origin self-hosting instructions</.localized_link>-ს, შემდეგ დაბრუნდით ზემოთ მოცემულ მოწყობის ნაბიჯებზე ანგარიშებისა და პროექტების დასაკავშირებლად.
