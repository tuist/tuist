# Origin ინტეგრაცია {#origin}

Tuist-ს შეუძლია გამოაქვეყნოს კომპილაციის, ტესტების, პრივიუს და ბანდლის ანგარიშები pull request-ებში ნატიურ [Cursor Origin](https://cursor.com/docs/api/origin) რეპოზიტორიებში. ის აახლებს არსებულ Tuist Run Report-ს იმის ნაცვლად, რომ ყოველი ატვირთვისთვის ახალი კომენტარი დაწეროს.

აპლიკაციის ინსტალაცია არ ასრულებს კომპილაციას ან ტესტებს. თქვენი არსებული სამუშაო პროცესები განაგრძობენ შედეგების ატვირთვას Tuist-ზე, ხოლო ინტეგრაცია ამ შედეგებს თქვენს pull request-ებში აერთიანებს.

## მოწყობა {#setup}

Tuist ანგარიშის ადმინისტრატორმა უნდა გახსნას **Settings → Integrations**, აირჩიოს **Install Origin App** Origin ბარათში და დაადასტუროს წვდომა Cursor-ში. აირჩიეთ Origin ანგარიში ან სივრცე და რეპოზიტორიები, რომლებსაც Tuist უნდა მიუწვდებოდეს, შემდეგ დაუბრუნდით Tuist-ს. კავშირი ეკუთვნის Tuist ანგარიშს და არა ცალკეულ პროექტს.

აპლიკაციის ინსტალაცია შესაძლებელია პირდაპირ Origin-დანაც. წვდომის დადასტურების შემდეგ, საჭიროების შემთხვევაში, შედით Tuist-ში და აირჩიეთ ორგანიზაცია დასაკავშირებლად. ხელმისაწვდომია მხოლოდ ის ორგანიზაციები, რომლებსაც თქვენ მართავთ და თქვენი პირადი ანგარიში. თუ მხოლოდ ერთი ანგარიშია ხელმისაწვდომი, Tuist მას ავტომატურად დააკავშირებს შერჩევის ფანჯრის ჩვენების გარეშე. თუ Tuist-დან იწყებთ, ორგანიზაცია უკვე შერჩეულია და ეს ნაბიჯი გამოტოვებული იქნება.

აირჩიეთ **Add new project connection** რეპოზიტორიის შერჩევის მოდალური ფანჯრის გასახსნელად. აირჩიეთ დაუკავშირებელი Tuist პროექტი და ერთ-ერთი რეპოზიტორია, რომელიც აღმოჩენილია დაკავშირებული Origin ანგარიშიდან, შემდეგ აირჩიეთ **Create Connection**. თუ რამდენიმე Origin ანგარიშია დაკავშირებული, ჯერ აირჩიეთ ანგარიში. კავშირისთვის ხელმისაწვდომია მხოლოდ ნატიური Origin რეპოზიტორიები. Tuist კიდევ ერთხელ ამოწმებს pull-request წვდომას პროექტის დაკავშირებამდე და იღებს რეპოზიტორიის ნაგულისხმებ ბრენჩს.

გამოიყენეთ **Manage integration** Cursor-ის თანხმობის ნაკადის ახალ ჩანართში გასახსნელად და რეპოზიტორიის წვდომის შესაცვლელად ან სხვა Origin ანგარიშის დასაკავშირებლად. რეპოზიტორიის ჩატვირთვის შეცდომები აჩვენებს **Retry**-ს, რაც განსხვავდება წარმატებული, მაგრამ ცარიელი რეპოზიტორიების სიისგან.

შედეგების ატვირთვის ავთენტიკაციისთვის გამოიყენეთ <.localized_link href="/guides/server/authentication#account-tokens">account token</.localized_link>.

## ანგარიშები და ნებართვები {#reports-and-permissions}

აპლიკაციის დამტკიცებისას თქვენ ანიჭებთ ნებართვებს, რომლებიც საჭიროა რეპოზიტორიების დასაკავშირებლად და ანგარიშების გამოსაქვეყნებლად:

| ნებართვა | გამოიყენება |
| --- | --- |
| Pull requests: read | მოძებნეთ ღია pull request მოხსენებული კომიტისთვის. |
| Pull request reviews: read and write | წაიკითხეთ, გამოაქვეყნეთ და განაახლეთ Tuist Run Report კომენტარი. |
| Repository metadata: read | აღმოაჩინეთ რეპოზიტორიები და მათი ნაგულისხმები ბრენჩები. ავტომატურად შედის Origin-ის მიერ. |

Tuist-ს არ სჭირდება წვდომა თქვენს საწყის კოდთან ან ნებართვა pull request-ების შერწყმისთვის.

შედეგების pull request-თან დასაკავშირებლად, ატვირთვებმა უნდა შეიცავდნენ რეპოზიტორიის Origin clone URL-ს, Git ref-ს და სრულ კომიტ SHA-ს. Tuist აქვეყნებს ანგარიშს მხოლოდ მაშინ, როდესაც ეს მონაცემები მიუთითებენ ერთ ღია pull request-ზე მის მიმდინარე head კომიტზე. ჩანაცვლებული კომიტების შედეგები არ ცვლის მიმდინარე ანგარიშს.

Origin ბარათი ჩამოთვლის პროექტ-რეპოზიტორიის კავშირებს. აირჩიეთ **Manage → Remove connection** პროექტის კავშირზე, რათა შეწყვიტოთ მისი ანგარიშგება აპლიკაციის წაშლის გარეშე. წაშალეთ აპლიკაცია Cursor-ში მისი წვდომის გაუქმებისთვის; Tuist წაშლის ინსტალაციას და მის პროექტის კავშირებს ინსტალაციის შეტყობინების დამუშავებისას.

## თვითმასპინძელი სერვერები {#server-configuration}

თუ თქვენ მასპინძლობთ საკუთარ Tuist სერვერს, ჯერ დაარეგისტრირეთ და დააკონფიგურირეთ Origin აპლიკაცია თქვენი განლაგებისთვის. მიჰყევით <.localized_link href="/guides/server/self-host/server#platform-origin">Origin self-hosting instructions</.localized_link>-ს, შემდეგ დაუბრუნდით ზემოთ მოცემულ მოწყობის ნაბიჯებს ანგარიშებისა და პროექტების დასაკავშირებლად.
