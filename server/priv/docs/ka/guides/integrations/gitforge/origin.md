# Origin-ის ინტეგრაცია {#origin}

Tuist-ს შეუძლია აგების, ტესტირების, პრივიუს და ბანდლის ანგარიშები განათავსოს pull request-ებზე ნატიურ [Cursor Origin](https://cursor.com/docs/api/origin) რეპოზიტორიებში. ის აახლებს არსებულ Tuist Run Report-ს იმის ნაცვლად, რომ ყოველი ატვირთვისთვის ახალი კომენტარი დაწეროს.

აპლიკაციის ინსტალაცია არ ასრულებს აგებას ან ტესტებს. თქვენი არსებული სამუშაო პროცესები შედეგების Tuist-ზე ატვირთვას აგრძელებენ, ხოლო ინტეგრაცია ამ შედეგებს თქვენს pull request-ებში აერთიანებს.

## მოწყობა {#setup}

Tuist ანგარიშის ადმინისტრატორმა უნდა გახსნას **Settings → Integrations**, აირჩიოს **Install Origin App** Origin-ის ბარათში და დაამტკიცოს წვდომა Cursor-ში. აირჩიეთ Origin ანგარიში ან სივრცის სახელი (namespace) და რეპოზიტორიები, რომლებზეც Tuist-ს უნდა ჰქონდეს წვდომა, შემდეგ კი დაუბრუნდით Tuist-ს. კავშირი ეკუთვნის Tuist ანგარიშს და არა ცალკეულ პროექტს.

აპლიკაციის ინსტალაცია პირდაპირ Origin-დანაც შეგიძლიათ. წვდომის დამტკიცების შემდეგ, საჭიროების შემთხვევაში, შედით Tuist-ში და აირჩიეთ ორგანიზაცია დასაკავშირებლად. ხელმისაწვდომია მხოლოდ თქვენ მიერ ადმინისტრირებადი ორგანიზაციები და თქვენი პირადი ანგარიში. Tuist ყოველთვის ითხოვს არჩევანს, მაშინაც კი, თუ ერთადერთი ვარიანტი თქვენი პირადი ანგარიშია. თუ თქვენი გუნდის Tuist ორგანიზაცია სიაში არ ჩანს, აირჩიეთ **Create an organization** ან სთხოვეთ მის ერთ-ერთ ადმინისტრატორს, რომ ადმინისტრატორად დაგნიშნოთ. სია გვერდის გახსნილობისას ახლდება, ამიტომ ორგანიზაცია გამოჩნდება თავიდან დაწყების გარეშე, იმ პირობით, რომ Tuist-ზე დაბრუნებიდან ათი წუთის განმავლობაში აირჩევთ მას. თუ Tuist-დან იწყებთ, ორგანიზაცია უკვე შერჩეულია და ეს ნაბიჯი გამოტოვებულია.

აირჩიეთ **Add new project connection** რეპოზიტორიის შერჩევის ფანჯრის გასახსნელად. აირჩიეთ დაუკავშირებელი Tuist პროექტი და დაკავშირებული Origin ანგარიშიდან აღმოჩენილი რეპოზიტორიებიდან ერთ-ერთი, შემდეგ კი აირჩიეთ **Create Connection**. თუ რამდენიმე Origin ანგარიშია დაკავშირებული, ჯერ აირჩიეთ ანგარიში. დასაკავშირებლად ხელმისაწვდომია მხოლოდ ნატიური Origin რეპოზიტორიები. Tuist პროექტთან დაკავშირებამდე კიდევ ერთხელ ამოწმებს pull-request-ზე წვდომას და იღებს რეპოზიტორიის ნაგულისხმებ შტოს (default branch).

გამოიყენეთ **Manage integration** ახალ ჩანართში Cursor-ის თანხმობის პროცესის გასახსნელად და რეპოზიტორიის წვდომის შესაცვლელად ან სხვა Origin ანგარიშის დასაკავშირებლად. რეპოზიტორიების ჩატვირთვის შეცდომები აჩვენებს **Retry**-ს, რაც ცალკეა წარმატებული, მაგრამ ცარიელი რეპოზიტორიების სიისგან.

შედეგების ატვირთვის ავთენტიკაციისთვის გამოიყენეთ <.localized_link href="/guides/server/authentication#account-tokens">account token</.localized_link>.

## ანგარიშები და ნებართვები {#reports-and-permissions}

აპლიკაციის დამტკიცებისას თქვენ ანიჭებთ ნებართვებს, რომლებიც საჭიროა რეპოზიტორიების დასაკავშირებლად და ანგარიშების გამოსაქვეყნებლად:

| ნებართვა | გამოიყენება |
| --- | --- |
| Pull requests: read | მოძებნეთ გახსნილი pull request მოხსენებული კომიტისთვის. |
| Pull request reviews: read and write | წაიკითხეთ, გამოაქვეყნეთ და განაახლეთ Tuist Run Report კომენტარი. |
| Repository metadata: read | აღმოაჩინეთ რეპოზიტორიები და მათი ნაგულისხმები შტოები. ავტომატურად შედის Origin-ის მიერ. |

Tuist-ს არ სჭირდება წვდომა თქვენს საწყის კოდზე ან ნებართვა pull request-ების შერწყმისთვის (merge).

შედეგების pull request-თან ასოცირებისთვის, ატვირთვებმა უნდა შეიცავდნენ რეპოზიტორიის Origin clone URL-ს, Git ref-ს და სრულ კომიტ SHA-ს. Tuist ანგარიშს აქვეყნებს მხოლოდ მაშინ, როცა ეს მონაცემები მიუთითებს ერთ გახსნილ pull request-ზე მის მიმდინარე head კომიტზე. ჩანაცვლებული კომიტების შედეგები არ ცვლის მიმდინარე ანგარიშს.

Origin ბარათი ჩამოთვლის პროექტ-რეპოზიტორი კავშირებს. აირჩიეთ **Manage → Remove connection** პროექტის კავშირზე, რათა შეწყვიტოთ მისი ანგარიშგება აპლიკაციის წაშლის გარეშე. წაშალეთ აპლიკაცია Cursor-ში მისი წვდომის გაუქმებისთვის; Tuist წაშლის ინსტალაციას და მის პროექტ კავშირებს, როცა ინსტალაციის შეტყობინებას დაამუშავებს.

## თვითმასპინძელი სერვერები {#server-configuration}

თუ საკუთარ Tuist სერვერს მასპინძლობთ, ჯერ დაარეგისტრირეთ და მოაწყვეთ Origin აპლიკაცია თქვენი განლაგებისთვის. მიჰყევით <.localized_link href="/guides/server/self-host/server#platform-origin">Origin self-hosting instructions</.localized_link>-ს, შემდეგ კი დაუბრუნდით ზემოთ მოცემულ მოწყობის ნაბიჯებს ანგარიშებისა და პროექტების დასაკავშირებლად.
