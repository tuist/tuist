# Origin-ის ინტეგრაცია {#origin}

Tuist-ს შეუძლია ატვირთოს ბილდების, ტესტების, პრივიუების და ბანდლების ანგარიშები pull request-ებში ნატიურ [Cursor Origin](https://cursor.com/docs/api/origin) რეპოზიტორიებში. ის აახლებს არსებულ Tuist Run Report-ს ახალი კომენტარის დამატების ნაცვლად ყოველი ატვირთვისას.

აპლიკაციის ინსტალაცია არ ასრულებს ბილდებს ან ტესტებს. თქვენი არსებული სამუშაო პროცესები განაგრძობენ შედეგების ატვირთვას Tuist-ში, ხოლო ინტეგრაცია ამ შედეგებს თქვენს pull request-ებში აჩვენებს.

## მოწყობა {#setup}

Tuist-ის ანგარიშის ადმინისტრატორმა უნდა გახსნას **Settings → Integrations**, აირჩიოს **Install Origin App** Origin-ის ბარათზე და დაადასტუროს წვდომა Cursor-ში. აირჩიეთ Origin-ის ანგარიში ან namespace და რეპოზიტორიები, რომლებზეც Tuist-ს უნდა ჰქონდეს წვდომა, შემდეგ კი დაბრუნდით Tuist-ში. კავშირი ეკუთვნის Tuist-ის ანგარიშს და არა ცალკეულ პროექტს.

აპლიკაციის ინსტალაცია შესაძლებელია პირდაპირ Origin-დანაც. წვდომის დადასტურების შემდეგ, საჭიროების შემთხვევაში, შედით Tuist-ში და აირჩიეთ ორგანიზაცია დასაკავშირებლად. ხელმისაწვდომია მხოლოდ ის ორგანიზაციები, რომლებსაც თქვენ ადმინისტრირებთ და თქვენი პირადი ანგარიში. თუ მხოლოდ ერთი ანგარიშია ხელმისაწვდომი, Tuist მას ავტომატურად დააკავშირებს არჩევანის ჩვენების გარეშე. თუ Tuist-დან იწყებთ, ორგანიზაცია უკვე შერჩეულია და ეს ნაბიჯი გამოტოვებულია.

აირჩიეთ **Add new project connection** რეპოზიტორიის შერჩევის მოდალის გასახსნელად. აირჩიეთ დაუკავშირებელი Tuist-ის პროექტი და ერთ-ერთი რეპოზიტორია, რომელიც აღმოჩენილია დაკავშირებული Origin-ის ანგარიშიდან, შემდეგ კი აირჩიეთ **Create Connection**. თუ რამდენიმე Origin-ის ანგარიშია დაკავშირებული, ჯერ აირჩიეთ ანგარიში. კავშირისთვის ხელმისაწვდომია მხოლოდ ნატიური Origin-ის რეპოზიტორიები. Tuist კიდევ ერთხელ ამოწმებს pull-request-ზე წვდომას პროექტის დაკავშირებამდე და იღებს რეპოზიტორიის ნაგულისხმებ branch-ს.

გამოიყენეთ **Manage integration** Cursor-ის თანხმობის ნაკადის ახალ ტაბში გასახსნელად და რეპოზიტორიის წვდომის შესაცვლელად ან სხვა Origin-ის ანგარიშის დასაკავშირებლად. რეპოზიტორიის ჩატვირთვის შეცდომები აჩვენებს **Retry**-ს, რაც განსხვავდება წარმატებული, მაგრამ ცარიელი რეპოზიტორიების სიისგან.

გამოიყენეთ <.localized_link href="/guides/server/authentication#account-tokens">ანგარიშის ტოკენი</.localized_link> შედეგების ატვირთვის ავთენტიკაციისთვის.

## ანგარიშები და ნებართვები {#reports-and-permissions}

აპლიკაციის დადასტურებისას თქვენ ანიჭებთ ნებართვებს, რომლებიც საჭიროა რეპოზიტორიების დასაკავშირებლად და ანგარიშების გამოსაქვეყნებლად:

| ნებართვა | გამოიყენება |
| --- | --- |
| Pull requests: read | მოძებნეთ ღია pull request მოხსენებული commit-ისთვის. |
| Pull request reviews: read and write | წაიკითხეთ, გამოაქვეყნეთ და განაახლეთ Tuist Run Report-ის კომენტარი. |
| Repository metadata: read | აღმოაჩინეთ რეპოზიტორიები და მათი ნაგულისხმები branches. ავტომატურად არის ჩართული Origin-ის მიერ. |

Tuist-ს არ სჭირდება წვდომა თქვენს საწყის კოდზე ან ნებართვა pull request-ების merge-ისთვის.

შედეგების pull request-თან დასაკავშირებლად, ატვირთვებმა უნდა შეიცავდნენ რეპოზიტორიის Origin clone URL-ს, Git ref-ს და სრულ commit SHA-ს. Tuist აქვეყნებს ანგარიშს მხოლოდ მაშინ, როდესაც ეს მონაცემები მიუთითებენ ერთ ღია pull request-ზე მის მიმდინარე head commit-ზე. შეცვლილი commit-ების შედეგები არ ცვლიან მიმდინარე ანგარიშს.

Origin-ის ბარათი ჩამოთვლის პროექტ-რეპოზიტორიის კავშირებს. აირჩიეთ **Manage → Remove connection** პროექტის კავშირზე მისი ანგარიშგების შეწყვეტისთვის აპლიკაციის წაშლის გარეშე. წაშალეთ აპლიკაცია Cursor-ში მისი წვდომის გაუქმებისთვის; Tuist წაშლის ინსტალაციას და მის პროექტულ კავშირებს ინსტალაციის შეტყობინების დამუშავებისას.

## თვითმასპინძელი სერვერები {#server-configuration}

თუ თქვენ მასპინძლობთ საკუთარ Tuist სერვერს, ჯერ დარეგისტრირეთ და დააკონფიგურირეთ Origin აპლიკაცია თქვენი განლაგებისთვის. მიჰყევით <.localized_link href="/guides/server/self-host/server#platform-origin">Origin-ის თვითმასპინძლობის ინსტრუქციებს</.localized_link>, შემდეგ კი დაბრუნდით ზემოთ მოცემულ მოწყობის ნაბიჯებზე ანგარიშებისა და პროექტების დასაკავშირებლად.
