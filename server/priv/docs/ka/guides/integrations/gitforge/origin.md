# Origin-ის ინტეგრაცია {#origin}

Tuist-ს შეუძლია ანგარიშების, ტესტების, პრივიუსების და ბანდლების შესახებ ანგარიშების გამოქვეყნება პულ-რეკვესტებზე ნატიურ [Cursor Origin](https://cursor.com/docs/api/origin) რეპოზიტორიებში. ის ანახლებს არსებულ Tuist Run Report-ს ყოველი ატვირთვისთვის ახალი კომენტარის დამატების ნაცვლად.

აპლიკაციის დაინსტალირება არ ასრულებს ბილდებს ან ტესტებს. თქვენი არსებული სამუშაო პროცესები აგრძელებენ შედეგების ატვირთვას Tuist-ზე, ხოლო ინტეგრაცია ამ შედეგებს თქვენს პულ-რეკვესტებში აჩვენებს.

## მოწყობა {#setup}

Tuist-ის ანგარიშის ადმინისტრატორმა უნდა გახსნას **Settings → Integrations**, აირჩიოს **Install Origin App** Origin-ის ბარათში და დაუჭიროს წვდომას Cursor-ში. აირჩიეთ Origin-ის ანგარიში ან სივრცე (namespace) და რეპოზიტორიები, რომლებზეც Tuist-ს უნდა ჰქონდეს წვდომა, შემდეგ კი დაუბრუნდით Tuist-ს. კავშირი ეკუთვნის Tuist-ის ანგარიშს და არა ცალკეულ პროექტს.

აპლიკაციის დაინსტალირება პირდაპირ Origin-დანაც შეგიძლიათ. წვდომის დადასტურების შემდეგ, საჭიროების შემთხვევაში, შედით Tuist-ში და აირჩიეთ ორგანიზაცია დასაკავშირებლად. ხელმისაწვდომია მხოლოდ თქვენ მიერ ადმინისტრირებადი ორგანიზაციები და თქვენი პირადი ანგარიში. Tuist ყოველთვის ითხოვს დადასტურებას, მაშინაც კი, თუ თქვენი პირადი ანგარიში ერთადერთი ვარიანტია. თუ თქვენი გუნდის Tuist-ის ორგანიზაცია სიაში არ ჩანს, აირჩიეთ **Create an organization** ან სთხოვეთ მის ერთ-ერთ ადმინისტრატორს, რომ გახდეთ ადმინისტრატორი. სია განახლდება გვერდის გახსნილობისას, ამიტომ ორგანიზაცია გამოჩნდება თავიდან დაწყების გარეშე, თუ მას Tuist-ზე დაბრუნებიდან ათი წუთის განმავლობაში აირჩევთ. თუ Tuist-დან იწყებთ, ორგანიზაცია უკვე შერჩეულია და ეს ნაბიჯი გამოტოვებულია.

აირჩიეთ **Add new project connection** რეპოზიტორიის შერჩევის მოდალის გასახსნელად. აირჩიეთ დაუკავშირებელი Tuist-ის პროექტი და ერთ-ერთი რეპოზიტორია, რომელიც აღმოჩენილია დაკავშირებული Origin-ის ანგარიშიდან, შემდეგ კი აირჩიეთ **Create Connection**. თუ რამდენიმე Origin-ის ანგარიშია დაკავშირებული, ჯერ აირჩიეთ ანგარიში. დასაკავშირებლად ხელმისაწვდომია მხოლოდ ნატიური Origin-ის რეპოზიტორიები. Tuist კიდევ ერთხელ ამოწმებს პულ-რეკვესტზე წვდომას პროექტთან დაკავშირებამდე და იღებს რეპოზიტორიის ნაგულისხმებ ბრენჩს.

გამოიყენეთ **Manage integration** Cursor-ის თანხმობის ნაკადის ახალ ტაბში გასახსნელად და რეპოზიტორიის წვდომის შესაცვლელად ან სხვა Origin-ის ანგარიშის დასაკავშირებლად. რეპოზიტორიების ჩატვირთვის შეცდომები აჩვენებს **Retry**-ს, რაც განსხვავდება წარმატებული ცარიელი რეპოზიტორიების სიისგან.

შედეგების ატვირთვის ავთენტიკაციისთვის გამოიყენეთ <.localized_link href="/guides/server/authentication#account-tokens">account token</.localized_link>.

## ანგარიშები და ნებართვები {#reports-and-permissions}

აპლიკაციის დადასტურებისას თქვენ ანიჭებთ ნებართვებს, რომლებიც საჭიროა რეპოზიტორიების დასაკავშირებლად და ანგარიშების გამოსაქვეყნებლად:

| ნებართვა | გამოიყენება |
| --- | --- |
| Pull requests: read | მოძებნეთ გახსნილი პულ-რეკვესტი მოხსენებული კომიტისთვის. |
| Pull request reviews: read and write | წაიკითხეთ, გამოაქვეყნეთ და განაახლეთ Tuist Run Report-ის კომენტარი. |
| Repository metadata: read | აღმოაჩინეთ რეპოზიტორიები და მათი ნაგულისხმები ბრენჩები. ავტომატურად შედის Origin-ის მიერ. |

Tuist-ს არ სჭირდება თქვენს საწყის კოდზე წვდომა ან პულ-რეკვესტების შერწყმის ნებართვა.

შედეგების პულ-რეკვესტთან ასოცირებისთვის, ატვირთვებმა უნდა შეიცავდეს რეპოზიტორიის Origin-ის კლონის URL-ს, Git ref-ს და სრულ კომიტ SHA-ს. Tuist აქვეყნებს ანგარიშს მხოლოდ მაშინ, როდესაც ეს მონაცემები მიუთითებს ერთ გახსნილ პულ-რეკვესტზე მის მიმდინარე head კომიტზე. ჩანაცვლებული კომიტების შედეგები არ ცვლის მიმდინარე ანგარიშს.

Origin-ის ბარათი ჩამოთვლის პროექტ-რეპოზიტორიის კავშირებს. აირჩიეთ **Manage → Remove connection** პროექტის კავშირზე მისი ანგარიშგების შესაჩერებლად აპლიკაციის წაშლის გარეშე. წაშალეთ აპლიკაცია Cursor-ში მისი წვდომის გაუქმებისთვის; Tuist წაშლის ინსტალაციას და მის პროექტულ კავშირებს ინსტალაციის შეტყობინების დამუშავებისას.

## თვითმასპინძელი სერვერები {#server-configuration}

თუ თქვენ მასპინძლობთ თქვენს საკუთარ Tuist სერვერს, ჯერ დარეგისტრირეთ და დააკონფიგურირეთ Origin აპლიკაცია თქვენი განლაგებისთვის. მიჰყევით <.localized_link href="/guides/server/self-host/server#platform-origin">Origin self-hosting instructions</.localized_link>-ს, შემდეგ კი დაუბრუნდით ზემოთ მოცემულ მოწყობის ნაბიჯებს ანგარიშებისა და პროექტების დასაკავშირებლად.
