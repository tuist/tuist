# ანგარიშები და პროექტები {#accounts-and-projects}

ზოგიერთი Tuist-ის ფუნქციას სჭირდება სერვერი, რომელიც უზრუნველყოფს მონაცემთა შენახვას და შეუძლია ურთიერთქმედება სხვა სერვისებთან. სერვერთან ურთიერთქმედებისთვის გჭირდებათ ანგარიში და პროექტი, რომელსაც თქვენს ლოკალურ პროექტთან დააკავშირებთ.

## ანგარიშები {#accounts}

სერვერის გამოყენებისთვის დაგჭირდებათ ანგარიში. არსებობს ანგარიშების ორი ტიპი:

- **პირადი ანგარიში:** ეს ანგარიშები ავტომატურად იქმნება რეგისტრაციისას და იდენტიფიცირდება სახელით (handle), რომელიც მიიღება იდენტობის პროვაიდერიდან (მაგ., GitHub) ან ელფოსტის მისამართის პირველი ნაწილიდან.
- **ორგანიზაციის ანგარიში:** ეს ანგარიშები იქმნება ხელით და იდენტიფიცირდება სახელით (handle), რომელსაც დეველოპერი განსაზღვრავს. ორგანიზაციები საშუალებას გაძლევენ მოიწვიოთ სხვა წევრები პროექტებზე ერთობლივი მუშაობისთვის.

თუ გაქვთ გამოცდილება [GitHub](https://github.com)-თან, კონცეფცია მსგავსია: შეგიძლიათ გქონდეთ პირადი და ორგანიზაციის ანგარიშები, რომლებიც იდენტიფიცირდება *სახელით*, რომელიც გამოიყენება URL-ების აგებისას.

> [!NOTE]
> **CLI-პრიორიტეტული**
>
> ანგარიშებისა და პროექტების მართვის უმეტესი ოპერაცია ხორციელდება CLI-ით. ვმუშაობთ ვებინტერფეისზე, რომელიც გაამარტივებს ანგარიშებისა და პროექტების მართვას.


ორგანიზაციის მართვა შესაძლებელია <.localized_link href="/cli/organization">`tuist organization`</.localized_link> ქვებრძანებებით. ახალი ორგანიზაციის ანგარიშის შესაქმნელად, გაუშვით:
```bash
tuist organization create {account-handle}
```

### ორგანიზაციის წევრობა {#organization-membership}

მომხმარებლებს შეუძლიათ გახდნენ ორგანიზაციის წევრები მიწვევის, ავტომატური SSO-რეგისტრაციის ან <.localized_link href="/guides/integrations/authentication/scim">System for Cross-domain Identity Management provisioning</.localized_link>-ის მეშვეობით.

ორგანიზაციის იდენტობის პროვაიდერით ავტორიზაცია თავისთავად არ იძლევა წევრობას. ორგანიზაციის <.localized_link href="/guides/integrations/authentication/sso#choose-an-enrollment-policy">single sign-on enrollment policy</.localized_link> განსაზღვრავს, სჭირდება თუ არა მისი სანდო დომენის მომხმარებელს მიწვევა, თუ შეუძლია ავტომატურად შემოერთება.

ადმინისტრატორებს შეუძლიათ მოიწვიონ წევრი დაფიდან ან <.localized_link href="/cli/organization/invite">`tuist organization invite`</.localized_link>-ის მეშვეობით. გადასცეთ `--role admin` ან `--role viewer`, რათა მიწვეულს მიანიჭოთ როლი `user`-ისგან განსხვავებული, როდესაც ის მიიღებს მიწვევას.

### როლები {#roles}

ორგანიზაციის ყოველ წევრს აქვს ერთ-ერთი სამი როლიდან:

| როლი | რა უფლებებს იძლევა |
| --- | --- |
| **ადმინისტრატორი** | ყველაფერი, რაც მომხმარებელს შეუძლია, პლუს ორგანიზაციის მართვა: წევრები და მიწვევები, პროექტები, გადახდები, ტოკენები, ვებჰუკები და პარამეტრები. |
| **მომხმარებელი** | კითხულობს და ასრულებს ორგანიზაციის სამუშაოებს: ბილდებისა და ტესტების გაშვება, ქეშში ჩაწერა, პრივიუების შექმნა და წაშლა, სატესტო შემთხვევის სტატუსის ცვლილება. |
| **დამკვირვებელი** | კითხულობს ორგანიზაციის სამუშაოებს და არაფერს ცვლის. დაფები, ბილდები, ტესტების გაშვებები, არასტაბილური და კარანტინში მყოფი ტესტები, პრივიუები, ბანდლები და რანერების აქტივობა — ყველაფერი ხელმისაწვდომია წაკითხვისთვის. ინტერაქტიული შელის ან VNC სესიის მიმაგრება რანერზე არ არის შესაძლებელი, რადგან ის ბრძანებებს ასრულებს მანქანაზე. |

აირჩიეთ როლი მიწვევისას და მოგვიანებით შეცვალეთ ის დაფაზე **Members**-დან. ამ გზით დაყენებული როლი არასდროს გადაიწერება შემდგომი შესვლისას.

## პროექტები {#projects}

თქვენი პროექტები უნდა იყოს ინტეგრირებული თქვენს ანგარიშთან remote პროექტის მეშვეობით. GitHub-თან შედარების გაგრძელებით, ეს ჰგავს ლოკალურ და remote რეპოზიტორიებს, სადაც თქვენ აგზავნით ცვლილებებს. პროექტების შესაქმნელად და სამართავად შეგიძლიათ გამოიყენოთ <.localized_link href="/cli/project">`tuist project`</.localized_link>.

პროექტები იდენტიფიცირდება სრული სახელით (full handle), რომელიც მიიღება ორგანიზაციის სახელისა და პროექტის სახელის შეერთებით. მაგალითად, თუ გაქვთ ორგანიზაცია სახელით `tuist` და პროექტი სახელით `tuist`, სრული სახელი იქნება `tuist/tuist`.

ლოკალურ და remote პროექტს შორის კავშირი ხორციელდება კონფიგურაციის ფაილის მეშვეობით. თუ არ გაქვთ, შექმენით ის `Tuist.swift`-ში და დაამატეთ შემდეგი შინაარსი:

```swift
let tuist = Tuist(fullHandle: "{account-handle}/{project-handle}") // e.g. tuist/tuist
```

> [!WARNING]
> **Tuist Project-only Features**
>
> გაითვალისწინეთ, რომ ზოგიერთ ფუნქციას, როგორიცაა <.localized_link href="/guides/features/cache/module-cache">module caching</.localized_link>, სჭირდება Tuist-ით მართული პროექტი. თუ Tuist-ს არ იყენებთ თქვენი პროექტის მართვისთვის, ვერ შეძლებთ ამ ფუნქციების გამოყენებას.


თქვენი პროექტის URL იქმნება სრული სახელის გამოყენებით. მაგალითად, Tuist-ის საჯარო დაფა ხელმისაწვდომია მისამართზე [tuist.dev/tuist/tuist](https://tuist.dev/tuist/tuist), სადაც `tuist/tuist` არის პროექტის სრული სახელი.
