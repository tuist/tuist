# გამოშვების კალენდარი {#release-calendar}

ადევნეთ თვალყურს სერვერისა და Kura-ს მიმდინარე ვერსიებს, ბოლო გამოშვებებსა და მომავალი გამოშვების ფანჯრებს. არხების გარანტიების, გამოსახულებების მიმაგრებისა და უკან გადატანის პოლიტიკის შესახებ იხილეთ <.localized_link href="/guides/server/self-host/release/channels">გამოშვების არხები</.localized_link>.

სტაბილური განახლებები დაგეგმილია ორშაბათობით 06:00 UTC-ზე, <.localized_link href="/cli/release/calendar">CLI-ის გამოშვების ციკლის</.localized_link> პარალელურად. შემდეგი რელიზ-კანდიდატი მზადდება მხოლოდ წარმატებული დაგეგმილი განახლების შემდეგ. შეცდომებმა შეიძლება დამოუკიდებლად შეაფერხონ რომელიმე კომპონენტი, ხოლო მეინტეინერებმა შეიძლება გამოაქვეყნონ განახლებები გრაფიკის გარეთ. მომავალი ფანჯრები არის გეგმები და არა გამოქვეყნების გარანტირებული დრო.

პეტჩ-გამოშვებები და უკან გადატანილი განახლებები ქვეყნდება საჭიროებისამებრ და არა ყოველკვირეული გრაფიკით. ქვემოთ მოცემულ ისტორიაში ნაჩვენებია გამოქვეყნებული გამოშვებები, მათი შენიშვნები და რეალური გამოქვეყნების თარიღები.
