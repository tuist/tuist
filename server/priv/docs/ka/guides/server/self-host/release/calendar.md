# გამოშვების კალენდარი {#release-calendar}

აქტიურად მიჰყევით სერვერის და Kura-ს მიმდინარე ვერსიებს, ბოლო გამოშვებებს და მომავალი გამოშვების ფანჯრებს. არხების გარანტიების, იმიჯების პინინგისა და ბექპორტის პოლიტიკის შესახებ იხილეთ <.localized_link href="/guides/server/self-host/release/channels">გამოშვების არხები</.localized_link>.

სტაბილური პრომოუშენები დაგეგმილია ორშაბათობით 06:00 UTC-ზე, <.localized_link href="/cli/release/calendar">CLI-ის გამოშვების მატარებელთან</.localized_link> ერთად. შემდეგი რელიზ კანდიდატი მხოლოდ წარმატებული დაგეგმილი პრომოუშენის შემდეგ იჭრება. შეცდომებმა შეიძლება დამოუკიდებლად შეაფერხონ რომელიმე კომპონენტი, ხოლო მეინტეინერებმა შეიძლება გამოაქვეყნონ განრიგის მიღმა. მომავალი ფანჯრები არის გეგმები და არა დაპირებული გამოქვეყნების დრო.

პეტჩ-გამოშვებები და ბექპორტები გაიცემა მოთხოვნისას და არა ყოველკვირეული განრიგით. ქვემოთ მოცემულ ისტორიაში გამოქვეყნებული გამოშვებები დაკავშირებულია მათ აღწერებთან და რეალურ გამოქვეყნების თარიღებთან.
