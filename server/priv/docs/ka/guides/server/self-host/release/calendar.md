# რელიზების კალენდარი {#release-calendar}

აქციე მიმდინარე სერვერისა და Kura-ს ვერსიებს, ბოლო რელიზებსა და მომავალ რელიზების ფანჯრებს. არხების გარანტიების, იმიჯების პინინგისა და ბექპორტის პოლიტიკის შესახებ იხილეთ <.localized_link href="/guides/server/self-host/release/channels">რელიზის არხები</.localized_link>.

სტაბილური პრომოუშენები დაგეგმილია ორშაბათობით 06:00 UTC-ზე, <.localized_link href="/cli/release/calendar">CLI-ის რელიზის მატარებელთან</.localized_link> ერთად. შემდეგი რელიზის კანდიდატი გამოიყოფა მხოლოდ წარმატებული დაგეგმილი პრომოუშენის შემდეგ. შეცდომებმა შეიძლება დამოუკიდებლად შეაფერხოს ნებისმიერი კომპონენტი, ხოლო მეინთეინერებს შეუძლიათ გამოაქვეყნონ გრაფიკის მიღმა. მომავალი ფანჯრები არის გეგმები და არა დაპირებული გამოქვეყნების დრო.

პეტჩ-რელიზები და ბექპორტები გამოიცემა მოთხოვნისამებრ და არა ყოველკვირეული გრაფიკით. ქვემოთ მოცემულ ისტორიაში გამოქვეყნებულ რელიზებს მიბმული აქვთ თავიანთი შენიშვნები და რეალური გამოქვეყნების თარიღები.
