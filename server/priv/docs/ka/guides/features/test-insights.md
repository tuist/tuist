# ტესტების ანალიტიკა {#test-insights}

გამოიყენეთ ტესტების ანალიტიკა თქვენი ტესტების ნაკრების ჯანმრთელობის მონიტორინგისთვის: აღმოაჩინეთ ნელი ტესტები, დააკვირდით არასტაბილურ ტესტებს და სწრაფად გაარკვიეთ CI-ს წარუმატებელი გაშვებების მიზეზები. ამჟამად მხარდაჭერილია Xcode, Gradle, Bazel, Elixir, Rust და Struo. ხელმისაწვდომი შედეგები და დროებითი მონაცემები დამოკიდებულია თქვენს გამშვებ აგენტზე. იმისათვის, რომ დაადგინოთ, თუ რომელ კოდს ასრულებენ თქვენი ტესტები მხარდაჭერილ ბილდ-სისტემებში, იხილეთ <.localized_link href="/guides/features/test-code-coverage">კოდის დაფარვა</.localized_link>. რჩევებისთვის [ნელი ტესტების](https://tuist.dev/solutions/slow-tests) და [არასტაბილური ტესტების](https://tuist.dev/solutions/flaky-tests) შესახებ, იხილეთ გადაწყვეტის სახელმძღვანელოები.
