# ტესტების ანალიტიკა {#test-insights}

გამოიყენეთ ტესტების ანალიტიკა თქვენი ტესტების ნაკრების ჯანმრთელობის მონიტორინგისთვის: გამოავლინეთ ნელი ტესტები, დააკვირდით არასტაბილურ ტესტებს და სწრაფად გაარკვიეთ CI-ს წარუმატებელი გაშვებების მიზეზები. ამჟამად მხარდაჭერილია Xcode, Gradle, Bazel, Elixir, Rust და Once. ხელმისაწვდომი შედეგები და დროის მაჩვენებლები დამოკიდებულია თქვენს რანერზე. იმისათვის, რომ დააკვირდეთ, თუ რომელ კოდს ასრულებენ თქვენი ტესტები მხარდაჭერილ ბილდის სისტემებში, იხილეთ <.localized_link href="/guides/features/test-code-coverage">კოდის დაფარვა</.localized_link>. [ნელი ტესტების](https://tuist.dev/solutions/slow-tests) და [არასტაბილური ტესტების](https://tuist.dev/solutions/flaky-tests) შესახებ რჩევებისთვის იხილეთ გადაწყვეტის გზამკვლევები.
