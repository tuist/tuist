# ტესტების ანალიტიკა {#test-insights}

გამოიყენეთ ტესტების ანალიტიკა თქვენი ტესტების ნაკრების ჯანმრთელობის მონიტორინგისთვის: გამოავლინეთ ნელი ტესტები, დააკვირდით არასტაბილურ ტესტებს და სწრაფად გაერკვეთ CI-ს წარუმატებელ გაშვებებში. ამჟამად მხარდაჭერილია Xcode, Gradle, Bazel, Elixir, Rust და Struo. ხელმისაწვდომი შედეგები და დროებითი მაჩვენებლები დამოკიდებულია თქვენს runner-ზე. იმისათვის, რომ დააკვირდეთ, თუ რომელ კოდს ასრულებენ თქვენი ტესტები მხარდაჭერილ ბილდის სისტემებში, იხილეთ <.localized_link href="/guides/features/test-code-coverage">კოდის დაფარვა</.localized_link>. რჩევებისთვის [ნელი ტესტების](https://tuist.dev/solutions/slow-tests) და [არასტაბილური ტესტების](https://tuist.dev/solutions/flaky-tests) შესახებ, იხილეთ გადაწყვეტის გზამკვლევები.
