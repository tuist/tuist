# ტესტების ანალიტიკა {#test-insights}

გამოიყენეთ ტესტების ანალიტიკა თქვენი ტესტების ნაკრების ჯანმრთელობის მონიტორინგისთვის: გამოავლინეთ ნელი ტესტები, დააკვირდით არასტაბილურ ტესტებს და სწრაფად გაერკვეთ CI-ს წარუმატებელ გაშვებებში. ამჟამად ის მხარდაჭერილია Xcode-ის, Gradle-ის, Bazel-ის, Elixir-ისა და Rust-ისთვის. იმისთვის, რომ დააკვირდეთ, თუ რომელ კოდს ასრულებენ თქვენი ტესტები, იხილეთ <.localized_link href="/guides/features/test-code-coverage">კოდის დაფარვა</.localized_link>.
