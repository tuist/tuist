# Xcode-ის პროექტი {#xcode-project}

იმისათვის, რომ დაამატოთ პაკეტები რეესტრის გამოყენებით თქვენს Xcode-ის პროექტში, გამოიყენეთ Xcode-ის სტანდარტული ინტერფეისი. შეგიძლიათ მოძებნოთ პაკეტები რეესტრში `+` ღილაკზე დაჭერით Xcode-ის `Package Dependencies` ჩანართში. თუ პაკეტი ხელმისაწვდომია რეესტრში, მარჯვენა ზედა კუთხეში დაინახავთ `tuist.dev` რეესტრს:

![პაკეტის დამოკიდებულებების დამატება](/images/guides/features/build/registry/registry-add-package.png)

## წყაროს კონტროლის პაკეტების ამოცნობა {#resolving-source-control-packages}

პაკეტები, რომლებიც განსაზღვრულია წყაროს კონტროლის URL-ით, როგორიცაა თქვენს მიერ დამატებული პაკეტების ტრანზიტული დამოკიდებულებები, ნაგულისხმევად იხსნება წყაროს კონტროლიდან. `tuist registry setup` აკონფიგურირებს Xcode-ს, რომ ისინი ამოიცნოს რეესტრიდან შემდეგი მომხმარებლის პარამეტრის ჩაწერით:

```bash
defaults write com.apple.dt.Xcode IDEPackageDependencySCMToRegistryTransformation useRegistryIdentityAndSources
```

შემდეგ Xcode ამოიცნობს წყაროს კონტროლის პაკეტს რეესტრიდან, როდესაც არსებობს რეესტრის ეკვივალენტი, და ბრუნდება წყაროს კონტროლზე, როდესაც ასეთი არ არის.

> [!NOTE]
> ეს არის Xcode-ის პარამეტრი თითოეული კომპიუტერისთვის და არა პროექტის პარამეტრი, ამიტომ რეესტრის კონფიგურაციის ფაილის დაკომიტვა არ გაუზიარებს მას თქვენი გუნდის დანარჩენ წევრებს. ყოველმა დეველოპერმა უნდა გაუშვას `tuist registry setup` ერთხელ საკუთარ კომპიუტერზე. ეს პარამეტრი შემდეგ ვრცელდება ამ კომპიუტერზე არსებულ ყველა Xcode-ის პროექტზე.
