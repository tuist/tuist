# Xcode-ის პროექტი {#xcode-project}

Xcode-ის პროექტში რეესტრის გამოყენებით პაკეტების დასამატებლად, გამოიყენეთ Xcode-ის სტანდარტული ინტერფეისი. რეესტრში პაკეტების მოსაძებნად, Xcode-ში დააჭირეთ `+` ღილაკს `Package Dependencies` ჩანართში. თუ პაკეტი ხელმისაწვდომია რეესტრში, ზედა მარჯვენა კუთხეში ნახავთ `tuist.dev` რეესტრს:

![პაკეტის დამოკიდებულებების დამატება](/images/guides/features/build/registry/registry-add-package.png)

## წყაროს კონტროლის პაკეტების გარჩევა {#resolving-source-control-packages}

პაკეტები, რომლებიც განაცხადებულია წყაროს კონტროლის URL-ით, როგორიცაა თქვენს მიერ დამატებული პაკეტების ტრანზიტული დამოკიდებულებები, ნაგულისხმევად იგარჩევა წყაროს კონტროლიდან. `tuist registry setup` აკონფიგურირებს Xcode-ს, რომ ისინი რეესტრიდან გაარჩიოს შემდეგი მომხმარებლის პარამეტრის ჩაწერით:

```bash
defaults write com.apple.dt.Xcode IDEPackageDependencySCMToRegistryTransformation useRegistryIdentityAndSources
```

Xcode შემდეგ რეესტრიდან არჩევს წყაროს კონტროლის პაკეტს, როცა არსებობს რეესტრის ეკვივალენტი, და ბრუნდება წყაროს კონტროლზე, როცა ის არ არსებობს.

> [!NOTE]
> ეს არის Xcode-ის ერთ კომპიუტერზე მოქმედი პარამეტრი და არა პროექტის კონფიგურაცია, ამიტომ რეესტრის კონფიგურაციის ფაილის დაკომიტვა არ გაუზიარებს მას თქვენს გუნდს. ყოველმა დეველოპერმა უნდა გაუშვას `tuist registry setup` ერთხელ საკუთარ კომპიუტერზე. პარამეტრი შემდეგ ვრცელდება ამ კომპიუტერზე არსებულ ყველა Xcode-ის პროექტზე.
