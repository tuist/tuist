# Xcode-ის პროექტი {#xcode-project}

იმისათვის, რომ Xcode-ის პროექტში რეესტრის გამოყენებით პაკეტები დაამატოთ, გამოიყენეთ Xcode-ის სტანდარტული ინტერფეისი. რეესტრში პაკეტების ძებნა შეგიძლიათ Xcode-ში `Package Dependencies` ჩანართში `+` ღილაკზე დაჭერით. თუ პაკეტი რეესტრში ხელმისაწვდომია, ზედა მარჯვენა კუთხეში ნახავთ `tuist.dev` რეესტრს:

![პაკეტის დამოკიდებულებების დამატება](/images/guides/features/build/registry/registry-add-package.png)

## წყაროს კონტროლის პაკეტების გარჩევა {#resolving-source-control-packages}

პაკეტები, რომლებიც წყაროს კონტროლის URL-ით არის განცხადებული, მაგალითად, თქვენს მიერ დამატებული პაკეტების ტრანზიტული დამოკიდებულებები, ნაგულისხმევად წყაროს კონტროლიდან იგარჩევა. `tuist registry setup` აკონფიგურირებს Xcode-ს, რომ ისინი რეესტრიდან გაარჩიოს შემდეგი მომხმარებლის პარამეტრის ჩაწერით:

```bash
defaults write com.apple.dt.Xcode IDEPackageDependencySCMToRegistryTransformation useRegistryIdentityAndSources
```

შემდეგ Xcode წყაროს კონტროლის პაკეტს რეესტრიდან გაარჩევს ყოველთვის, როცა რეესტრში ექვივალენტი არსებობს, და გადადის წყაროს კონტროლზე, როცა ასეთი არ არის.

> [!NOTE]
> ეს არის თითოეულ კომპიუტერზე Xcode-ის პარამეტრი და არა პროექტის კონფიგურაცია, ამიტომ რეესტრის კონფიგურაციის ფაილის კომიტში შეტანა მას თქვენს გუნდთან არ გააზიარებს. ყოველმა დეველოპერმა თავის კომპიუტერზე ერთხელ უნდა გაუშვას `tuist registry setup`. პარამეტრი შემდეგ ვრცელდება ამ კომპიუტერზე არსებულ ყველა Xcode-ის პროექტზე.
