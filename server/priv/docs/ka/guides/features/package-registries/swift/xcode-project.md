# Xcode-ის პროექტი {#xcode-project}

იმისათვის, რომ Xcode-ის პროექტში რეგისტრის გამოყენებით პაკეტები დაამატოთ, გამოიყენეთ Xcode-ის სტანდარტული ინტერფეისი. რეგისტრში პაკეტების ძებნა შეგიძლიათ Xcode-ში `Package Dependencies` ჩანართში `+` ღილაკზე დაწკაპუნებით. თუ პაკეტი რეგისტრში ხელმისაწვდომია, ზედა მარჯვენა კუთხეში ნახავთ `tuist.dev` რეგისტრს:

![პაკეტის დამოკიდებულებების დამატება](/images/guides/features/build/registry/registry-add-package.png)

## წყაროს კონტროლის პაკეტების ამოცნობა {#resolving-source-control-packages}

პაკეტები, რომლებიც წყაროს კონტროლის URL-ით არის განსაზღვრული (მაგალითად, თქვენს მიერ დამატებული პაკეტების ტრანზიტული დამოკიდებულებები), ნაგულისხმევად წყაროს კონტროლიდან ამოიცნობა. `tuist registry setup` აკონფიგურირებს Xcode-ს, რომ ისინი რეგისტრიდან ამოიცნოს შემდეგი მომხმარებლის პარამეტრის ჩაწერით:

```bash
defaults write com.apple.dt.Xcode IDEPackageDependencySCMToRegistryTransformation useRegistryIdentityAndSources
```

შემდეგ Xcode წყაროს კონტროლის პაკეტს რეგისტრიდან ამოიცნობს, როდესაც არსებობს რეგისტრის ეკვივალენტი, და ბრუნდება წყაროს კონტროლზე, როდესაც ასეთი არ არსებობს.

> [!NOTE]
> ეს არის Xcode-ის თითოეულ კომპიუტერზე მოქმედი პარამეტრი და არა პროექტის კონფიგურაცია, ამიტომ რეგისტრის კონფიგურაციის ფაილის კომიტში შეტანა მას თქვენს გუნდთან არ გააზიარებს. ყველა დეველოპერმა ერთხელ უნდა გაუშვას `tuist registry setup` თავის კომპიუტერზე. ეს პარამეტრი შემდეგ ვრცელდება ამ კომპიუტერზე არსებულ ყველა Xcode-ის პროექტზე.
