# Xcode-ის პროექტი {#xcode-project}

იმისათვის, რომ დაამატოთ პაკეტები რეესტრის გამოყენებით თქვენს Xcode-ის პროექტში, გამოიყენეთ Xcode-ის სტანდარტული ინტერფეისი. შეგიძლიათ მოძებნოთ პაკეტები რეესტრში `+` ღილაკზე დაჭერით Xcode-ის `Package Dependencies` ჩანართში. თუ პაკეტი ხელმისაწვდომია რეესტრში, მარჯვენა ზედა კუთხეში ნახავთ `tuist.dev` რეესტრს:

![პაკეტის დამოკიდებულებების დამატება](/images/guides/features/build/registry/registry-add-package.png)

## წყაროს კონტროლის პაკეტების გარჩევა {#resolving-source-control-packages}

პაკეტები, რომლებიც განსაზღვრულია წყაროს კონტროლის URL-ით, მაგალითად, თქვენ მიერ დამატებული პაკეტების ტრანზიტული დამოკიდებულებები, ნაგულისხმევად იგარჩევა წყაროს კონტროლიდან. `tuist registry setup` აკონფიგურირებს Xcode-ს, რომ ისინი რეესტრიდან გაარჩიოს შემდეგი მომხმარებლის პარამეტრის ჩაწერით:

```bash
defaults write com.apple.dt.Xcode IDEPackageDependencySCMToRegistryTransformation useRegistryIdentityAndSources
```

შემდეგ Xcode რეესტრიდან არჩევს წყაროს კონტროლის პაკეტს, როცა არსებობს რეესტრის ეკვივალენტი, და ბრუნდება წყაროს კონტროლზე, როცა ასეთი არ არის.

> [!NOTE]
> ეს არის თითოეული მანქანისთვის Xcode-ის პარამეტრი და არა პროექტის კონფიგურაცია, ამიტომ რეესტრის კონფიგურაციის ფაილის კომიტში შეტანა არ გაუზიარებს მას თქვენი გუნდის დანარჩენ წევრებს. ყოველმა დეველოპერმა უნდა გაუშვას `tuist registry setup` ერთხელ თავის მანქანაზე. პარამეტრი შემდეგ ვრცელდება იმ მანქანაზე არსებულ ყველა Xcode-ის პროექტზე.
