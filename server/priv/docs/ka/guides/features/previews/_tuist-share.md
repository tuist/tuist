## ტრეკები tuist share-ით {#share-tracks}

ნაკადებისთვის, რომლებიც აქვეყნებენ `tuist share`-ით, გამოიყენეთ `--track` ტრეკის არჩევას:

```bash
tuist share App --track beta
tuist share App --track nightly
```

## გამოშვების შენიშვნები {#release-notes}

გამოიყენეთ ტრეკები გარემოს ჯგუფებისთვის და გამოშვების შენიშვნები ცალკეული ბილდის მიზნით:

```bash
tuist share App --track QA --release-notes "Fix sign-in and improve the checkout flow"
```

ჩაანაცვლეთ `App` თქვენი აპლიკაციის სახელით, ფაილის გზით ან შესრულებადი დისტრიბუციით და მისი `--executable` ოფციით. გამოშვების შენიშვნები არის არასავალდებულო ჩვეულებრივი ტექსტი, 10,000 სიმბოლომდე. პირველი არაცარიელი ხაზი ჩნდება ერთხაზიან ფრაგმენტად წინასწარი ნახვის სიაში, ასე რომ ბილდის ნომრები და სხვა იდენტიფიცირების ინფორმაცია ერთი შეხედვით ჩანს. გრძელი ხაზები იკვეცება; სრული შენიშვნები ჩნდება დეტალურ გვერდებზე. ძიების შედეგები ემთხვევა საჩვენებელ სახელებს და სრულ გამოშვების შენიშვნებს, მათ შორის იმ ხაზებს, რომლებიც ფრაგმენტში არ ჩანს. მრავალხაზიანი შენიშვნები მხარდაჭერილია, მაგალითად `--release-notes "$(< release-notes.txt)"`. ისინი არ ცვლიან აპლიკაციის საჩვენებელ სახელს ან მის ტრეკს.

### თავსებადობა {#preview-metadata-compatibility}

გამოშვების შენიშვნები არ ცვლიან, რომელ წინასწარ ნახვას ეკუთვნის ბილდი. პირველი შენიშვნები, რომელსაც წინასწარი ნახვა იღებს, რჩება: მოგვიანებითი ატვირთვა შეუძლია დაამატოს შენიშვნები წინასწარ ნახვას, რომელსაც არ აქვს, მაგრამ ვერ გადაწერს ან გაასუფთავებს არსებულს. წინასწარი ნახვები, რომლებიც აიტვირთა გამოშვების შენიშვნების არსებობამდე, რჩება ვალიდური მათ გარეშე.

თვითმასპინძელ განლაგებებს სჭირდებათ სერვერის ვერსია, რომელიც მხარს უჭერს გამოშვების შენიშვნებს და ტრეკის ფილტრაციას, განახლებულ კლიენტთან ერთად. ძველი სერვერები იგნორირებენ შენიშვნებს. სიის ბოლოწერტილების ტრეკისა და ძიების ფილტრებისთვის, იხილეთ [API-ის ცნობარი](https://tuist.dev/api/docs).

## ავტომატიზაციები {#automations}

გამოიყენეთ `--json` JSON გამოსავლის მისაღებად `tuist share`-დან:

```bash
tuist share --json
```

გამოიყენეთ შედეგი მორგებული ავტომატიზაციებისთვის, როგორიცაა Slack-ის შეტყობინების გამოქვეყნება CI-დან. `url` გასაღები შეიცავს სრულ წინასწარი ნახვის ბმულს; `qrCodeURL` მიუთითებს QR კოდის სურათზე მოწყობილობაზე წინასწარი ნახვის გასახსნელად:

```json
{
  "id": 1234567890,
  "url": "https://tuist.dev/preview/1234567890",
  "qrCodeURL": "https://tuist.dev/preview/1234567890/qr-code.svg"
}
```
