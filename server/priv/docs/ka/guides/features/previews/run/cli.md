# პრივიუსების გაშვება CLI-ით

დააინსტალირეთ <.localized_link href="/guides/install-tuist">Tuist CLI</.localized_link>, შემდეგ კი გაუშვით გაზიარებული პრივიუსის ბმული. თქვენ არ გჭირდებათ ის აწყობის სისტემა, რომელმაც შექმნა პრივიუ:

```bash
tuist run {url}
```

Tuist ირჩევს თავსებად აწყობას თქვენი ოპერაციული სისტემის, CPU არქიტექტურისა და დანიშნულებისთვის. კერძო პრივიუები მოითხოვს ავთენტიკაციასა და პროექტზე წვდომას.

## მობილური აპლიკაციები {#mobile-applications}

აირჩიეთ მიერთებული მოწყობილობა ან სიმულატორი:

```bash
tuist run --device "My device" {url}
```

Android მოწყობილობები და ემულატორები უნდა იყოს მიერთებული ADB-ის საშუალებით. ასევე შეგიძლიათ ჩამოტვირთოთ APK პრივიუსის გვერდიდან და დააინსტალიროთ ის Android მოწყობილობაზე, რომელიც იძლევა ინსტალაციას ამ წყაროდან. Apple-ის აწყობები უნდა შეესაბამებოდეს დანიშნულების პლატფორმას და აკმაყოფილებდნენ მათ ხელმოწერის მოთხოვნებს. IPA-სთვის, გახსენით პრივიუსის ბმული დანიშნულების მოწყობილობაზე მის დასაინსტალირებლად.

## ბრძანების სტრიქონის პრივიუები {#command-line-previews}

გადაეცით არგუმენტები `--`-ის შემდეგ:

```bash
tuist run {url} -- --help
tuist run {url} -- build --configuration Release
```

ყველაფერი `--`-ის შემდეგ გადაიცემა ზუსტად ისე, როგორც არის, მათ შორის `--verbose`, `--quiet` და `--path`. შვილობილი არგუმენტები არ შედის Tuist-ის ბრძანებების ანალიტიკაში.

პრივიუ გაშვებულია თქვენი სამუშაო დირექტორიით, გარემოთი და ტერმინალის შეტანა/გამოტანით, და აბრუნებს შესრულებადი ფაილის გამოსვლის სტატუსს. ის არ ცვლის დაინსტალირებულ CLI-ს და არ ამატებს მას `PATH`-ში. CLI დისტრიბუციები რჩებიან Tuist-ის ლოკალურ `previews` ქეშში შესრულების შემდეგ, რათა გენერირებულმა პროექტებმა შეძლონ მათზე მითითება; ამ ქეშის წაშლა ასევე შლის ამ მითითებების სამიზნეებს.

დესკტოპისა და CLI პრივიუები გაშვებულია მიმდინარე მომხმარებლის სახელით, არა სენდბოქსში. გაუშვით მხოლოდ ის აწყობები, რომელთა ავტორებსა და pull request-ებს ენდობით.

## აირჩიეთ ვერსია {#select-a-version}

`tuist run` ასევე იღებს აპის სახელს `latest`-თან ერთად, ბრენჩის სახელს ან კომიტის ჰეშს:

```bash
tuist run App@latest # Latest App preview associated with the project's default branch
tuist run App@my-feature-branch # Latest App preview associated with a branch
tuist run App@00dde7f56b1b8795a26b8085a781fb3715e834be # Preview associated with a commit
```

ამ სელექტორებს სჭირდებათ შესაბამისი Git მეტამონაცემების გამოქვეყნება. სამუშაო ნაკადებისთვის, რომლებიც ტოვებენ Git მეტამონაცემებს, გამოიყენეთ კონკრეტული პრივიუსის URL.

წვდომისა და ორგანიზაციისთვის, იხილეთ <.localized_link href="/guides/features/previews#visibility">ხილვადობა და ტრეკები</.localized_link>.
