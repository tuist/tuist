# პრევიუების გაშვება CLI-ით

დააინსტალირეთ <.localized_link href="/guides/install-tuist">Tuist CLI</.localized_link>, შემდეგ გაუშვით გაზიარებული პრევიუს ბმული. თქვენ არ გჭირდებათ ის აგების სისტემა, რომელმაც შექმნა პრევიუ:

```bash
tuist run {url}
```

Tuist ირჩევს თავსებად აგებას თქვენი ოპერაციული სისტემის, პროცესორის არქიტექტურისა და დანიშნულების მიხედვით. კერძო პრევიუები მოითხოვს ავთენტიკაციასა და პროექტზე წვდომას.

## მობილური აპლიკაციები {#mobile-applications}

აირჩიეთ მიერთებული მოწყობილობა ან სიმულატორი:

```bash
tuist run --device "My device" {url}
```

Android მოწყობილობები და ემულატორები უნდა იყოს ADB-ის საშუალებით მიერთებული. ასევე შეგიძლიათ ჩამოტვირთოთ APK პრევიუს გვერდიდან და დააინსტალიროთ იმ Android მოწყობილობაზე, რომელიც იძლევა ამ წყაროდან ინსტალაციის ნებართვას. Apple-ის აგებები უნდა შეესაბამებოდეს დანიშნულების პლატფორმას და აკმაყოფილებდეს ხელმოწერის მოთხოვნებს. IPA-სთვის, გახსენით პრევიუს ბმული დანიშნულების მოწყობილობაზე მის დასაინსტალირებლად.

## კომანდური ხაზის პრევიუები {#command-line-previews}

გადაეცით არგუმენტები `--`-ის შემდეგ:

```bash
tuist run {url} -- --help
tuist run {url} -- build --configuration Release
```

ყველაფერი `--`-ის შემდეგ გადაეცევა უცვლელად, მათ შორის `--verbose`, `--quiet` და `--path`. შვილობილი არგუმენტები არ შედის Tuist-ის ბრძანებების ანალიტიკაში.

პრევიუ ეშვება თქვენი სამუშაო დირექტორიით, გარემოთი და ტერმინალის შეტანა/გამოტანით, და აბრუნებს შესრულებადი ფაილის გასვლის სტატუსს. ის არ ცვლის დაინსტალირებულ CLI-ს და არ ამატებს მას `PATH`-ში. CLI-ის დისტრიბუციები რჩება Tuist-ის ლოკალურ `previews` ქეშში შესრულების შემდეგ, რათა გენერირებულმა პროექტებმა შეძლონ მათზე მითითება; ამ ქეშის წაშლა ასევე შლის ამ მითითებების მიზნებს.

დესკტოპისა და CLI პრევიუები ეშვება მიმდინარე მომხმარებლის სახელით, არა სენდბოქსში. გაუშვით მხოლოდ იმ ავტორებისა და pull request-ების აგებები, რომლებსაც ენდობით.

## ვერსიის არჩევა {#select-a-version}

`tuist run` ასევე იღებს აპლიკაციის სახელს `latest`-თან ერთად, ბრენჩის სახელს ან კომიტის ჰეშს:

```bash
tuist run App@latest # Latest App preview associated with the project's default branch
tuist run App@my-feature-branch # Latest App preview associated with a branch
tuist run App@00dde7f56b1b8795a26b8085a781fb3715e834be # Preview associated with a commit
```

ამ სელექტორებს სჭირდებათ შესაბამისი Git მეტამონაცემების გამოქვეყნება. იმ სამუშაო პროცესებისთვის, რომლებიც ტოვებენ Git მეტამონაცემებს, გამოიყენეთ კონკრეტული პრევიუს URL.

წვდომისა და ორგანიზაციისთვის, იხილეთ <.localized_link href="/guides/features/previews#visibility">ხილვადობა და ტრეკები</.localized_link>.
