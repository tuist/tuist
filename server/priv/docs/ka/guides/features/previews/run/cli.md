# პრივიუსების გაშვება CLI-ით

დააინსტალირეთ <.localized_link href="/guides/install-tuist">Tuist CLI</.localized_link>, შემდეგ კი გაუშვით გაზიარებული პრივიუსის ბმული. თქვენ არ გჭირდებათ ბილდის სისტემა, რომელმაც შექმნა პრივიუ:

```bash
tuist run {url}
```

Tuist ირჩევს თავსებად ბილდს თქვენი ოპერაციული სისტემის, CPU არქიტექტურისა და დანიშნულების მიხედვით. კერძო პრივიუსები მოითხოვს ავტორიზაციასა და პროექტზე წვდომას.

## მობილური აპლიკაციები {#mobile-applications}

აირჩიეთ მიერთებული მოწყობილობა ან სიმულატორი:

```bash
tuist run --device "My device" {url}
```

Android მოწყობილობები და ემულატორები უნდა იყოს მიერთებული ADB-ის საშუალებით. ასევე შეგიძლიათ ჩამოტვირთოთ APK პრივიუსის გვერდიდან და დააინსტალიროთ ის Android მოწყობილობაზე, რომელიც ნებართვას იძლევა ინსტალაციისთვის ამ წყაროდან. Apple ბილდები უნდა შეესაბამებოდეს დანიშნულების პლატფორმას და აკმაყოფილებდნენ ხელმოწერის მოთხოვნებს. IPA-სთვის, გახსენით პრივიუსის ბმული დანიშნულების მოწყობილობაზე მის დასაინსტალირებლად.

## კომანდური ხაზის პრივიუსები {#command-line-previews}

გადაეცით არგუმენტები `--`-ის შემდეგ:

```bash
tuist run {url} -- --help
tuist run {url} -- build --configuration Release
```

ყველაფერი `--`-ის შემდეგ გადაეცევა უცვლელად, მათ შორის `--verbose`, `--quiet` და `--path`. შვილობილი არგუმენტები არ შედის Tuist-ის კომანდების ანალიტიკაში.

პრივიუ იწყება თქვენი სამუშაო დირექტორიით, გარემოთი და ტერმინალის შეყვანა/გამოტანით, და აბრუნებს შესრულებადი ფაილის გამოსვლის სტატუსს. ის არ ცვლის დაინსტალირებულ CLI-ს ან არ ამატებს მას `PATH`-ში. CLI დისტრიბუციები რჩება Tuist-ის ლოკალურ `previews` ქეშში შესრულების შემდეგ, რათა გენერირებულმა პროექტებმა შეძლონ მათზე მითითება; ამ ქეშის წაშლა ასევე შლის ამ მითითებების სამიზნეებს.

დესკტოპისა და CLI პრივიუსები იწყება მიმდინარე მომხმარებლის სახელით, არა სენდბოქსში. გაუშვით მხოლოდ ისეთი ბილდები, რომელთა ავტორებსა და pull request-ებს ენდობით.

## აირჩიეთ ვერსია {#select-a-version}

`tuist run` ასევე იღებს აპლიკაციის სახელს `latest`-თან ერთად, ბრენჩის სახელს ან კომიტის ჰეშს:

```bash
tuist run App@latest # Latest App preview associated with the project's default branch
tuist run App@my-feature-branch # Latest App preview associated with a branch
tuist run App@00dde7f56b1b8795a26b8085a781fb3715e834be # Preview associated with a commit
```

ამ სელექტორებს სჭირდებათ შესაბამისი Git მეტამონაცემების გამოქვეყნება. სამუშაო პროცესებისთვის, რომლებიც ტოვებენ Git მეტამონაცემებს, გამოიყენეთ კონკრეტული პრივიუსის URL.

წვდომისა და ორგანიზაციისთვის, იხილეთ <.localized_link href="/guides/features/previews#visibility">ხილვადობა და ტრეკები</.localized_link>.
