# პრივიუების გაშვება CLI-ით

დააინსტალირეთ <.localized_link href="/guides/install-tuist">Tuist CLI</.localized_link>, შემდეგ კი გაუშვით გაზიარებული პრივიუს ბმული. თქვენ არ გჭირდებათ ის აწყობის სისტემა, რომელმაც შექმნა პრივიუ:

```bash
tuist run {url}
```

Tuist ირჩევს თავსებად აწყობას თქვენი ოპერაციული სისტემის, CPU არქიტექტურისა და დანიშნულების მიხედვით. კერძო პრივიუები მოითხოვს ავთენტიფიკაციას და პროექტზე წვდომას.

## მობილური აპლიკაციები {#mobile-applications}

აირჩიეთ მიერთებული მოწყობილობა ან სიმულატორი:

```bash
tuist run --device "My device" {url}
```

Android მოწყობილობები და ემულატორები უნდა იყოს მიერთებული ADB-ის საშუალებით. ასევე შეგიძლიათ ჩამოტვირთოთ APK პრივიუს გვერდიდან და დააინსტალიროთ იმ Android მოწყობილობაზე, რომელიც ნებას რთავს ინსტალაციას ამ წყაროდან. Apple-ის აწყობები უნდა შეესაბამებოდეს დანიშნულების პლატფორმას და აკმაყოფილებდნენ მათ ხელმოწერის მოთხოვნებს. IPA-სთვის, გახსენით პრივიუს ბმული დანიშნულების მოწყობილობაზე მის დასაინსტალირებლად.

## ბრძანების სტრიქონის პრივიუები {#command-line-previews}

გადაეცით არგუმენტები `--`-ის შემდეგ:

```bash
tuist run {url} -- --help
tuist run {url} -- build --configuration Release
```

ყველაფერი `--`-ის შემდეგ გადაეცევა უცვლელად, მათ შორის `--verbose`, `--quiet` და `--path`. შვილობილი არგუმენტები გამოირიცხება Tuist-ის ბრძანებების ანალიტიკიდან.

პრივიუ იწყება თქვენი სამუშაო დირექტორიით, გარემოთი და ტერმინალის შეყვანა/გამოყვანით და აბრუნებს შესრულებადი ფაილის გასვლის სტატუსს. ის არ ცვლის დაინსტალირებულ CLI-ს და არ ამატებს მას `PATH`-ში. CLI დისტრიბუციები რჩება Tuist-ის ლოკალურ `previews` ქეშში შესრულების შემდეგ, რათა გენერირებულ პროექტებს შეეძლოთ მათზე მითითება; ამ ქეშის წაშლა ასევე შლის ამ მითითებების სამიზნეებს.

დესკტოპისა და CLI პრივიუები იწყება მიმდინარე მომხმარებლის სახელით, არა სენდბოქსში. გაუშვით მხოლოდ ის აწყობები, რომელთა ავტორებსა და pull request-ებს ენდობით.

## ვერსიის არჩევა {#select-a-version}

`tuist run` ასევე იღებს აპლიკაციის სახელს `latest`-თან ერთად, ბრენჩის სახელს ან კომიტის ჰეშს:

```bash
tuist run App@latest # Latest App preview associated with the project's default branch
tuist run App@my-feature-branch # Latest App preview associated with a branch
tuist run App@00dde7f56b1b8795a26b8085a781fb3715e834be # Preview associated with a commit
```

ამ სელექტორებს სჭირდებათ შესაბამისი Git მეტამონაცემების გამოქვეყნება. იმ სამუშაო ნაკადებისთვის, რომლებიც ტოვებენ Git მეტამონაცემებს, გამოიყენეთ კონკრეტული პრივიუს URL.

წვდომისა და ორგანიზაციისთვის, იხილეთ <.localized_link href="/guides/features/previews#visibility">ხილვადობა და ტრეკები</.localized_link>.
