## ატვირთვების შეზღუდვა CI-სთვის {#restrict-uploads-to-ci}

ანგარიშის ადმინისტრატორებს შეუძლიათ დეველოპერებს მხოლოდ წაკითხვის უფლება მიანიჭონ, ხოლო CI-ს ნება დართონ ქეშის არტეფაქტების ატვირთვა. გახსენით ანგარიშის **Cache** პარამეტრები Tuist-ში და დააყენეთ **Cache upload access** მნიშვნელობად **CI and account tokens only**. ამის შემდეგ, შესვლის სესიებით ავთენტიკირებულ წევრებს კვლავ შეეძლებათ ქეშიდან ჩამოტვირთვა, მაგრამ ატვირთვებისთვის საჭიროა CI OIDC ავთენტიკაცია ან ანგარიშის ტოკენი ქეშის ჩაწერის სკოპებით, როგორიცაა `project:cache:write` ან `ci`.

გამოიყენეთ ეს, როდესაც CI არის სანდო ქეშის წყარო და ლოკალურმა მანქანებმა მხოლოდ უნდა მიიღონ ქეში. პარამეტრი მოქმედებს მხოლოდ ქეშზე ატვირთვის ავტორიზაციაზე.
