# კეში {#cache}

## ატვირთვების შეზღუდვა CI-სთვის {#restrict-uploads-to-ci}

ანგარიშის ადმინისტრატორებს შეუძლიათ დეველოპერებს მხოლოდ წაკითხვის უფლება მისცენ, ხოლო CI-ს ნება დართონ ქეშის არტეფაქტების ატვირთვა. გახსენით ანგარიშის **Cache** პარამეტრები Tuist-ში და დააყენეთ **Cache upload access** მნიშვნელობად **CI and account tokens only**. ამის შემდეგ, შესვლის სესიებით ავტორიზებულ წევრებს შეუძლიათ ქეშიდან ჩამოტვირთვა, მაგრამ ატვირთვები საჭიროებენ CI OIDC ავტორიზაციას ან ანგარიშის ტოკენს ქეშის ჩაწერის სკოპებით, როგორიცაა `project:cache:write` ან `ci`.

გამოიყენეთ ეს, როდესაც CI არის სანდო კეშის პროდიუსერი და ლოკალურმა მანქანებმა უნდა მიიღონ კეში მხოლოდ. პარამეტრი მოქმედებს მხოლოდ კეშის ატვირთვის ავტორიზაციაზე.
