## ატვირთვების შეზღუდვა მხოლოდ CI-სთვის {#restrict-uploads-to-ci}

ანგარიშის ადმინისტრატორებს შეუძლიათ დეველოპერებისთვის მხოლოდ წაკითხვის უფლება მიანიჭონ, ხოლო CI-ს ატვირთვის უფლება დაუტოვონ. გახსენით ანგარიშის **ქეშის** პარამეტრები Tuist-ში და დააყენეთ **ქეშის ატვირთვის წვდომა** მნიშვნელობაზე **მხოლოდ CI და ანგარიშის ტოკენები**. ამის შემდეგ, შესვლის სესიებით ავტორიზებულ წევრებს კვლავ შეეძლებათ ქეშიდან ჩამოტვირთვა, მაგრამ ატვირთვები მოითხოვს CI OIDC ავტორიზაციას ან ანგარიშის ტოკენს ქეშის ჩაწერის სკოპებით, როგორიცაა `project:cache:write` ან `ci`.

გამოიყენეთ ეს, როდესაც CI არის სანდო ქეშის მწარმოებელი და ლოკალურმა მანქანებმა მხოლოდ ქეში უნდა მოიხმარონ. პარამეტრი მოქმედებს მხოლოდ ქეშის ატვირთვის ავტორიზაციაზე.
