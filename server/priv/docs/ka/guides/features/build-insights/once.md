# Once-ის ბილდების ინსაიტები {#once-build-insights}

Once ასრულებს გაშვებებს Tuist-ზე მათი შესრულებისას, რაც საშუალებას გაძლევთ თვალი ადევნოთ პროგრესს საბოლოო CI ლოგის მოლოდინის გარეშე. გახსენით დაფის ბმული, რომელიც იბეჭდება გაშვების დასაწყისში, რათა შეამოწმოთ მისი გრაფიკი, ქმედებების სტატუსი და კეშის გადაწყვეტილებები.

> [!IMPORTANT]
> **მოთხოვნები**
>
> - დაასრულეთ <.localized_link href="/guides/get-started/once-project">Once-ის დაწყება</.localized_link> და გაიარეთ ავთენტიკაცია იმ მანქანაზე, სადაც Once მუშაობს.

## ბილდების ანგარიშგება {#report-your-builds}

განაგრძეთ Once-ის ბრძანებების გამოყენება:

```bash
once build MyApplication
```

პირდაპირი ანგარიშგება ხორციელდება მაქსიმალური ძალისხმევით. მიუწვდომელი ანგარიშგების წერტილი ან ვადამოწურული სესია არ აჩერებს ბილდს. ხელახლა შედით სისტემაში `once auth login --provider tuist`-ით, თუ სესია ამოიწურა.

## რა ჩანს დაფაზე {#what-the-dashboard-shows}

გამოიყენეთ **ბილდები** და **ბილდების გაშვებები**, რათა შეადაროთ გაშვებები დროის, შტოებისა და ლოკალური ან CI გარემოების მიხედვით. თითოეული გაშვება შეიძლება შეიცავდეს:

- მოთხოვნილ ბრძანებას, სტატუსს, დაწყების დროსა და ხანგრძლივობას.
- Once-ის ვერსიასა და მოხსენებულ ჰოსტის ინფორმაციას.
- ქმედებებსა და მათ დამოკიდებულებებს, სტატუსს, ხანგრძლივობასა და კეშის შედეგებს.
- მოხსენებულ ქმედების შეცდომებს.
- Git შტოს, კომიტსა და CI კონტექსტს, როდესაც ისინი მოხსენებულია კლიენტის მიერ.

მოძებნეთ და გაფილტრეთ ქმედებები, რათა იპოვოთ შეცდომები ან ნელი სამუშაო. მოხსენებული ქმედებების სახელები და საწყისი ფაილები ეხმარება სამუშაოს კოდთან დაკავშირებას; უფრო ძველმა კლიენტებმა შეიძლება ნაკლები დეტალი მოგაწოდონ. კეშირებული ან გამოტოვებული ქმედებები არ არის შესრულებული სამუშაო, ხოლო დროის არარსებობა არ ნიშნავს ნულოვანი ხანგრძლივობის შესრულებას.

Tuist ამჟამად არ იღებს Once-ის უმიზნო ქმედების ლოგის ნაკადს. შეინახეთ CI ლოგები პროცესის სრული გამომავალი მონაცემებისთვის; გაშვების შეჯამებები და სტრუქტურირებული შეცდომები არ ცვლის ამ ლოგებს.

**კეშის** ხედი ყოფს ქმედებების გადაწყვეტილებებს შინაარსის ობიექტების გადაცემისგან. იხილეთ <.localized_link href="/guides/features/cache/once">Once კეში</.localized_link> კეშის აქტივობის ინტერპრეტაციისთვის.

## ტესტები {#tests}

ტესტების ბრძანებები ასევე ქმნიან Once-ის გაშვებებს. მათი მოხსენებული სუიტები და ტესტები ჩანს **ტესტების** ქვეშ; ჰოსტინგზე განთავსებული შარდები ასევე აქვეყნებენ გაერთიანებულ ტესტების გაშვებას. იხილეთ <.localized_link href="/guides/features/test-insights/once">Once ტესტების ინსაიტები</.localized_link>.

## კოდირების აგენტები და Grafana {#coding-agents-and-grafana}

<.localized_link href="/guides/features/agentic-coding/mcp#once-runs">Model Context Protocol ინსტრუმენტები</.localized_link> საშუალებას აძლევს აგენტს ჩამოთვალოს Once-ის გაშვებები და წაიკითხოს გაშვების ქმედებებისა და კეშის ჯამური მაჩვენებლები. იგივე წაკითხვები ხელმისაწვდომია HTTP API-ის მეშვეობით.

გამოიყენეთ <.localized_link href="/guides/integrations/grafana">Grafana ინტეგრაცია</.localized_link> Once-ის საბოლოო ბილდის ჯანმრთელობის მეტრიკებისთვის. Once ამჟამად არ ანგარიშგებს კეშის დროის დაზოგვას, ამიტომ ეს გაზომვა რჩება მიუწვდომლად და არა ნულოვნად.
