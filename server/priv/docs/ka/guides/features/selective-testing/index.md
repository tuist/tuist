# შერჩევითი ტესტირება {#selective-testing}

როგორც პროექტები იზრდება, ყოველ პუშზე ყველა ტესტის გაშვება აღარ არის მიზანშეწონილი. Tuist Selective Testing მკვეთრად ამცირებს ტესტირების დროს მხოლოდ იმ ტესტების გაშვებით, რომლებზეც გავლენა მოახდინა ბოლო წარმატებული გაშვების შემდეგ მომხდარმა ცვლილებებმა, ჩვენი <.localized_link href="/guides/features/projects/hashing">ჰეშირების ალგორითმის</.localized_link> გამოყენებით.
