# შერჩევითი ტესტირება {#selective-testing}

როგორც კი პროექტები იზრდება, ყოველ push-ზე ყველა ტესტის გაშვება აღარ არის რეალისტური. Tuist Selective Testing მკვეთრად ამცირებს ტესტირების დროს, აწარმოებს მხოლოდ იმ ტესტებს, რომლებზეც გავლენა მოახდინა ბოლო წარმატებული გაშვების შემდეგ განხორციელებულმა ცვლილებებმა, ჩვენი <.localized_link href="/guides/features/projects/hashing">ჰეშირების ალგორითმის</.localized_link> გამოყენებით.
