# რედაქტირება {#editing}

განსხვავებით ტრადიციული Xcode პროექტებისა ან Swift პაკეტებისგან, სადაც ცვლილებები ხდება Xcode-ის UI-ის მეშვეობით, Tuist-ით მართული პროექტები განისაზღვრება Swift კოდით, რომელიც შეიცავს **მანიფესტ ფაილებში**. თუ გაქვთ გამოცდილება Swift პაკეტებთან და `Package.swift` ფაილთან, მიდგომა ძალიან მსგავსია.

ამ ფაილების რედაქტირება ნებისმიერი ტექსტური რედაქტორით შეგიძლიათ, მაგრამ ჩვენ გირჩევთ გამოიყენოთ Tuist-ის მიერ მოწოდებული სამუშაო ნაკადი ამისთვის, `tuist edit`. ეს ნაკადი ქმნის Xcode პროექტს, რომელიც შეიცავს ყველა მანიფესტ ფაილს და გაძლევთ საშუალებას დაარედაქტიროთ და დააკომპილიროთ ისინი. Xcode-ის გამოყენების წყალობით, იღებთ ყველა უპირატესობას: **კოდის ავტოშევსება, სინტაქსის გამოყოფა და შეცდომების შემოწმება**.

## პროექტის რედაქტირება {#edit-the-project}

პროექტის რედაქტირებისთვის, შეგიძლიათ გაუშვათ შემდეგი ბრძანება Tuist პროექტის დირექტორიაში ან ქვედირექტორიაში:

```bash
tuist edit
```

ბრძანება ქმნის Xcode პროექტს გლობალურ დირექტორიაში და ხსნის მას Xcode-ში. პროექტი შეიცავს `Manifests` დირექტორიას, რომლის აგებაც შეგიძლიათ, რათა დარწმუნდეთ, რომ ყველა თქვენი მანიფესტი ვალიდურია.

> [!NOTE]
> **Glob-ით ამოცნობილი მანიფესტები**
>
> `tuist edit` ადგენს შესატან მანიფესტებს glob შაბლონის `**/{Manifest}.swift` გამოყენებით პროექტის ფესვის დირექტორიიდან (ის, რომელიც შეიცავს `Tuist.swift` ფაილს). დარწმუნდით, რომ პროექტის ფესვში არის ვალიდური `Tuist.swift`.


### მანიფესტ ფაილების იგნორირება {#ignoring-manifest-files}

თუ თქვენს პროექტში არის Swift ფაილები იგივე სახელით, როგორც მანიფესტ ფაილებს (მაგ., `Project.swift`), ქვედირექტორიებში, რომლებიც არ არის რეალური Tuist მანიფესტები, შეგიძლიათ შექმნათ `.tuistignore` ფაილი თქვენი პროექტის ფესვში, რათა გამორიცხოთ ისინი რედაქტირების პროექტიდან.

`.tuistignore` ფაილი იყენებს glob შაბლონებს იმის დასადგენად, თუ რომელი ფაილები უნდა იყოს იგნორირებული:

```gitignore
# Ignore all Project.swift files in the Sources directory
Sources/**/Project.swift

# Ignore specific subdirectories
Tests/Fixtures/**/Workspace.swift
```

ეს განსაკუთრებით სასარგებლოა, როცა გაქვთ ტესტების ფიქსტურები ან მაგალითი კოდი, რომელიც შემთხვევით იყენებს იგივე სახელდების კონვენციას, რასაც Tuist მანიფესტ ფაილები.

## რედაქტირებისა და გენერაციის სამუშაო ნაკადი {#edit-and-generate-workflow}

როგორც შეამჩნიეთ, რედაქტირება არ შეიძლება გენერირებული Xcode პროექტიდან. ეს განზრახვაა, რათა გენერირებულ პროექტს არ ჰქონდეს დამოკიდებულება Tuist-ზე, რაც უზრუნველყოფს, რომ მომავალში Tuist-დან გადასვლა მინიმალური ძალისხმევით შეძლოთ.

პროექტზე მუშაობისას, გირჩევთ გაუშვათ `tuist edit` ტერმინალის სესიაში, რათა მიიღოთ Xcode პროექტი პროექტის რედაქტირებისთვის, და გამოიყენოთ სხვა ტერმინალის სესია `tuist generate`-ის გასაშვებად.
