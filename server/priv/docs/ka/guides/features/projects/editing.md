# რედაქტირება {#editing}

ტრადიციული Xcode პროექტებისგან ან Swift პაკეტებისგან განსხვავებით, სადაც ცვლილებები ხდება Xcode-ის ინტერფეისის მეშვეობით, Tuist-ით მართული პროექტები განისაზღვრება Swift კოდით, რომელიც მოთავსებულია **მანიფესტ ფაილებში**. თუ გაქვთ გამოცდილება Swift პაკეტებთან და `Package.swift` ფაილთან, მიდგომა ძალიან მსგავსია.

ამ ფაილების რედაქტირება ნებისმიერი ტექსტური რედაქტორით შეგიძლიათ, მაგრამ ჩვენ გირჩევთ გამოიყენოთ Tuist-ის მიერ შემოთავაზებული სამუშაო პროცესი ამისთვის — `tuist edit`. ეს პროცესი ქმნის Xcode პროექტს, რომელიც შეიცავს ყველა მანიფესტ ფაილს და გაძლევთ მათი რედაქტირებისა და კომპილაციის საშუალებას. Xcode-ის გამოყენების წყალობით, იღებთ ყველა უპირატესობას: **კოდის ავტოშევსება, სინტაქსის გამოყოფა და შეცდომების შემოწმება**.

## პროექტის რედაქტირება {#edit-the-project}

თქვენი პროექტის რედაქტირებისთვის, შეგიძლიათ გაუშვათ შემდეგი ბრძანება Tuist პროექტის დირექტორიაში ან ქვედირექტორიაში:

```bash
tuist edit
```

ბრძანება ქმნის Xcode პროექტს გლობალურ დირექტორიაში და ხსნის მას Xcode-ში. პროექტი შეიცავს `Manifests` დირექტორიას, რომლის აწყობაც შეგიძლიათ, რათა დარწმუნდეთ, რომ ყველა თქვენი მანიფესტი ვალიდურია.

> [!NOTE]
> **Glob-ით განსაზღვრული მანიფესტები**
>
> `tuist edit` განსაზღვრავს ჩასართავ მანიფესტებს glob შაბლონის `**/{Manifest}.swift` გამოყენებით პროექტის ფესვის დირექტორიიდან (ის, რომელიც შეიცავს `Tuist.swift` ფაილს). დარწმუნდით, რომ პროექტის ფესვში არსებობს ვალიდური `Tuist.swift`.


### მანიფესტ ფაილების იგნორირება {#ignoring-manifest-files}

თუ თქვენს პროექტში არის Swift ფაილები იგივე სახელით, რაც მანიფესტ ფაილებს (მაგ., `Project.swift`), ქვედირექტორიებში, რომლებიც რეალურად Tuist მანიფესტები არ არის, შეგიძლიათ შექმნათ `.tuistignore` ფაილი თქვენი პროექტის ფესვში, რათა გამორიცხოთ ისინი რედაქტირების პროექტიდან.

`.tuistignore` ფაილი იყენებს glob შაბლონებს, რათა მიუთითოს, რომელი ფაილები უნდა იგნორირდეს:

```gitignore
# Ignore all Project.swift files in the Sources directory
Sources/**/Project.swift

# Ignore specific subdirectories
Tests/Fixtures/**/Workspace.swift
```

ეს განსაკუთრებით სასარგებლოა, როდესაც გაქვთ ტესტის ფიქსტურები ან მაგალითის კოდი, რომელიც შემთხვევით იყენებს იგივე სახელდების კონვენციას, რასაც Tuist მანიფესტ ფაილები.

## რედაქტირებისა და გენერაციის სამუშაო პროცესი {#edit-and-generate-workflow}

როგორც შეამჩნიეთ, რედაქტირება შეუძლებელია გენერირებული Xcode პროექტიდან. ეს განზრახვით არის გაკეთებული, რათა თავიდან ავიცილოთ გენერირებულ პროექტში დამოკიდებულება Tuist-ზე, რაც უზრუნველყოფს, რომ მომავალში Tuist-დან გადასვლა მინიმალური ძალისხმევით შეძლოთ.

პროექტზე მუშაობისას, გირჩევთ გაუშვათ `tuist edit` ტერმინალის სესიაში, რათა მიიღოთ Xcode პროექტი პროექტის რედაქტირებისთვის, და გამოიყენოთ სხვა ტერმინალის სესია `tuist generate`-ის გასაშვებად.
