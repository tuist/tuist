# რედაქტირება {#editing}

ტრადიციული Xcode პროექტებისგან ან Swift პაკეტებისგან განსხვავებით, სადაც ცვლილებები ხდება Xcode-ის ინტერფეისის მეშვეობით, Tuist-ით მართული პროექტები განისაზღვრება Swift კოდით, რომელიც შეიცავს **მანიფესტ ფაილებში**. თუ გაქვთ გამოცდილება Swift პაკეტებთან და `Package.swift` ფაილთან, მიდგომა ძალიან მსგავსია.

ამ ფაილების რედაქტირება ნებისმიერი ტექსტური რედაქტორით შეგიძლიათ, მაგრამ ჩვენ გირჩევთ გამოიყენოთ Tuist-ის მიერ მოწოდებული სამუშაო ნაკადი ამისთვის — `tuist edit`. ეს ნაკადი ქმნის Xcode პროექტს, რომელიც შეიცავს ყველა მანიფესტ ფაილს და გაძლევთ საშუალებას, დაარედაქტიროთ და აკომპილიროთ ისინი. Xcode-ის გამოყენების წყალობით, იღებთ ყველა უპირატესობას: **კოდის ავტოშევსება, სინტაქსის გამოყოფა და შეცდომების შემოწმება**.

## პროექტის რედაქტირება {#edit-the-project}

პროექტის რედაქტირებისთვის, შეგიძლიათ გაუშვათ შემდეგი ბრძანება Tuist პროექტის დირექტორიაში ან ქვედირექტორიაში:

```bash
tuist edit
```

ბრძანება ქმნის Xcode პროექტს გლობალურ დირექტორიაში და ხსნის მას Xcode-ში. პროექტი შეიცავს `Manifests` დირექტორიას, რომლის აგებაც შეგიძლიათ, რათა დარწმუნდეთ, რომ ყველა თქვენი მანიფესტი ვალიდურია.

> [!NOTE]
> **Glob-ით ამოცნობილი მანიფესტები**
>
> `tuist edit` ამოცნობს შესატან მანიფესტებს პროექტის ფესვის დირექტორიიდან (რომელიც შეიცავს `Tuist.swift` ფაილს) `**/{Manifest}.swift` glob-ის გამოყენებით. დარწმუნდით, რომ პროექტის ფესვში არსებობს ვალიდური `Tuist.swift`.


### მანიფესტ ფაილების იგნორირება {#ignoring-manifest-files}

თუ თქვენს პროექტში არის Swift ფაილები იგივე სახელით, რაც მანიფესტ ფაილებს აქვთ (მაგ., `Project.swift`), ქვედირექტორიებში, რომლებიც რეალური Tuist მანიფესტები არ არის, შეგიძლიათ შექმნათ `.tuistignore` ფაილი პროექტის ფესვში, რათა გამორიცხოთ ისინი რედაქტირების პროექტიდან.

`.tuistignore` ფაილი იყენებს glob შაბლონებს, რათა მიუთითოს, რომელი ფაილები უნდა იყოს იგნორირებული:

```gitignore
# Ignore all Project.swift files in the Sources directory
Sources/**/Project.swift

# Ignore specific subdirectories
Tests/Fixtures/**/Workspace.swift
```

ეს განსაკუთრებით სასარგებლოა, როცა გაქვთ ტესტის ფიქსტურები ან მაგალითის კოდი, რომელიც შემთხვევით იყენებს იგივე სახელდების კონვენციას, რასაც Tuist მანიფესტ ფაილები.

## რედაქტირებისა და გენერაციის სამუშაო ნაკადი {#edit-and-generate-workflow}

როგორც შეამჩნიეთ, რედაქტირება ვერ ხდება გენერირებული Xcode პროექტიდან. ეს განზრახვითაა გაკეთებული, რათა გენერირებულ პროექტს არ ჰქონდეს დამოკიდებულება Tuist-ზე, რაც უზრუნველყოფს, რომ მომავალში Tuist-დან გადასვლა მინიმალური ძალისხმევით შეძლოთ.

პროექტზე მუშაობისას, გირჩევთ გაუშვათ `tuist edit` ტერმინალის სესიაში, რათა მიიღოთ Xcode პროექტი პროექტის რედაქტირებისთვის, და გამოიყენოთ სხვა ტერმინალის სესია `tuist generate`-ის გასაშვებად.
