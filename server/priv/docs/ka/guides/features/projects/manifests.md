# მანიფესტები {#manifests}

Tuist-ის ნაგულისხმევი მიდგომა პროექტებისა და სამუშაო სივრცეების აღწერისა და გენერაციის პროცესის კონფიგურირებისთვის არის Swift ფაილების გამოყენება. დოკუმენტაციაში ამ ფაილებს მოიხსენიებენ როგორც **მანიფესტის ფაილები**.

Swift-ის გამოყენების გადაწყვეტილება შთაგონებული იყო [Swift Package Manager](https://www.swift.org/documentation/package-manager/)-ით, რომელიც ასევე იყენებს Swift ფაილებს პაკეტების აღსაწერად. Swift-ის გამოყენების წყალობით, შეგვიძლია გამოვიყენოთ კომპილატორი შინაარსის სისწორის ვალიდაციისა და კოდის ხელახლა გამოყენებისთვის სხვადასხვა მანიფესტის ფაილში, ხოლო Xcode უზრუნველყოფს რედაქტირების მაღალი ხარისხის გამოცდილებას სინტაქსის გამოკვეთის, ავტომატური შევსებისა და ვალიდაციის მეშვეობით.

> [!NOTE]
> **ქეშირება**
>
> ვინაიდან მანიფესტის ფაილები არის Swift ფაილები, რომლებიც საჭიროებენ კომპილაციას, Tuist აქეშირებს კომპილაციის შედეგებს პარსინგის პროცესის დასაჩქარებლად. შესაბამისად, შენიშნავთ, რომ Tuist-ის პირველად გაშვებისას პროექტის გენერაციას ოდნავ მეტი დრო დასჭირდება. მომდევნო გაშვებები უფრო სწრაფი იქნება.


## Project.swift {#projectswift}

[`Project.swift`](https://projectdescription.tuist.dev/documentation/projectdescription/project) მანიფესტი აღწერს Xcode პროექტს. პროექტი გენერირდება იმავე საქაღალდეში, სადაც მანიფესტის ფაილია განთავსებული, `name` თვისებაში მითითებული სახელით.

```swift
// Project.swift
let project = Project(
    name: "App",
    targets: [
        // ....
    ]
)
```


> [!WARNING]
> **ფესვური ცვლადები**
>
> ერთადერთი ცვლადი, რომელიც უნდა იყოს მანიფესტის ფესვურ დონეზე, არის `let project = Project(...)`. თუ გჭირდებათ კოდის ხელახლა გამოყენება მანიფესტის სხვადასხვა ნაწილში, შეგიძლიათ გამოიყენოთ Swift ფუნქციები.


## Workspace.swift {#workspaceswift}

ნაგულისხმევად, Tuist ქმნის [Xcode Workspace](https://developer.apple.com/documentation/xcode/projects-and-workspaces)-ს, რომელიც შეიცავს გენერირებად პროექტს და მისი დამოკიდებულებების პროექტებს. თუ რაიმე მიზეზით გსურთ სამუშაო სივრცის მორგება დამატებითი პროექტების დასამატებლად ან ფაილებისა და ჯგუფების ჩასართავად, ეს შეგიძლიათ გააკეთოთ [`Workspace.swift`](https://projectdescription.tuist.dev/documentation/projectdescription/workspace) მანიფესტის განსაზღვრით.

```swift
// Workspace.swift
import ProjectDescription

let workspace = Workspace(
    name: "App-Workspace",
    projects: [
        "./App", // Path to directory containing the Project.swift file
    ]
)
```

> [!NOTE]
> Tuist გადაწყვეტს დამოკიდებულებების გრაფს და ჩართავს დამოკიდებულებების პროექტებს სამუშაო სივრცეში. მათი ხელით ჩართვა არ არის საჭირო. ეს აუცილებელია, რათა ბილდის სისტემამ სწორად გადაწყვიტოს დამოკიდებულებები.


### მრავალ- ან ერთპროექტიანი {#multi-or-monoproject}

ხშირად ისმის კითხვა, უნდა გამოვიყენოთ თუ არა ერთი პროექტი ან რამდენიმე პროექტი სამუშაო სივრცეში. Tuist-ის გარეშე სამყაროში, სადაც ერთპროექტიანი მიდგომა ხშირ Git კონფლიქტებს გამოიწვევდა, სამუშაო სივრცეების გამოყენება რეკომენდებულია. თუმცა, ვინაიდან არ ვუშვებთ Tuist-ით გენერირებული Xcode პროექტების Git რეპოზიტორიაში ჩართვას, Git კონფლიქტები პრობლემა არ არის. შესაბამისად, ერთი ან რამდენიმე პროექტის გამოყენების გადაწყვეტილება სამუშაო სივრცეში თქვენზეა დამოკიდებული.

Tuist-ის პროექტში ვეყრდნობით ერთპროექტიან მიდგომას, რადგან ცივი გენერაციის დრო უფრო სწრაფია (ნაკლები მანიფესტის ფაილია კომპილირებადი) და <.localized_link href="/guides/features/projects/code-sharing">პროექტის აღწერის დამხმარე საშუალებებს</.localized_link> ვიყენებთ როგორც ინკაფსულაციის ერთეულს. თუმცა, შესაძლოა გსურთ Xcode პროექტების გამოყენება ინკაფსულაციის ერთეულად თქვენი აპლიკაციის სხვადასხვა დომენის წარმოსადგენად, რაც უფრო ახლოსაა Xcode-ის რეკომენდებულ პროექტის სტრუქტურასთან.

## Tuist.swift {#tuistswift}

Tuist უზრუნველყოფს <.localized_link href="/contributors/principles#default-to-conventions">გონივრულ ნაგულისხმევ მნიშვნელობებს</.localized_link> პროექტის კონფიგურაციის გასამარტივებლად. თუმცა, შეგიძლიათ მორგოთ კონფიგურაცია პროექტის ფესვურ დონეზე [`Tuist.swift`](https://projectdescription.tuist.dev/documentation/projectdescription/tuist)-ის განსაზღვრით, რომელსაც Tuist იყენებს პროექტის ფესვის დასადგენად.

```swift
import ProjectDescription

let tuist = Tuist(
    project: .tuist(generationOptions: .options(registryEnabled: true))
)
```
