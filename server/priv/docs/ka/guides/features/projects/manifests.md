# მანიფესტები {#manifests}

Tuist პროექტებისა და სამუშაო სივრცეების განსაზღვრისა და გენერაციის პროცესის კონფიგურაციისთვის ძირითადად Swift ფაილებს იყენებს. დოკუმენტაციაში ამ ფაილებს **მანიფესტ ფაილებად** მოიხსენიებენ.

Swift-ის გამოყენების გადაწყვეტილება შთაგონებული იყო [Swift Package Manager](https://www.swift.org/documentation/package-manager/)-ით, რომელიც ასევე Swift ფაილებს იყენებს პაკეტების განსაზღვრისთვის. Swift-ის გამოყენების წყალობით შეგვიძლია გამოვიყენოთ კომპილატორი შინაარსის სისწორის ვალიდაციისა და კოდის ხელახლა გამოყენებისთვის სხვადასხვა მანიფესტ ფაილებში, ხოლო Xcode — სინტაქსის გამოკვეთის, ავტომატური დასრულებისა და ვალიდაციის წყალობით უმაღლესი დონის რედაქტირების გამოცდილების უზრუნველსაყოფად.

> [!NOTE]
> **ქეშირება**
>
> ვინაიდან მანიფესტ ფაილები არის Swift ფაილები, რომლებიც კომპილაციას საჭიროებენ, Tuist ინახავს კომპილაციის შედეგებს ქეშში პარსინგის პროცესის დასაჩქარებლად. შესაბამისად, შეამჩნევთ, რომ Tuist-ის პირველად გაშვებისას პროექტის გენერაცია ოდნავ მეტ დროს შეიძლება წაიღოს. მომდევნო გაშვებები უფრო სწრაფი იქნება.


## Project.swift {#projectswift}

[`Project.swift`](https://projectdescription.tuist.dev/documentation/projectdescription/project) მანიფესტი აღწერს Xcode პროექტს. პროექტი გენერირდება იმავე დირექტორიაში, სადაც მანიფესტ ფაილი მდებარეობს, `name` თვისებაში მითითებული სახელით.

```swift
// Project.swift
let project = Project(
    name: "App",
    targets: [
        // ....
    ]
)
```


> [!WARNING]
> **ძირითადი ცვლადები**
>
> მანიფესტის ძირში ერთადერთი ცვლადი, რომელიც უნდა იყოს, არის `let project = Project(...)`. თუ გჭირდებათ კოდის ხელახლა გამოყენება მანიფესტის სხვადასხვა ნაწილში, შეგიძლიათ გამოიყენოთ Swift ფუნქციები.


## Workspace.swift {#workspaceswift}

ნაგულისხმევად, Tuist ქმნის [Xcode Workspace](https://developer.apple.com/documentation/xcode/projects-and-workspaces)-ს, რომელიც შეიცავს გენერირებად პროექტსა და მისი დამოკიდებულებების პროექტებს. თუ რაიმე მიზეზით გსურთ სამუშაო სივრცის მორგება დამატებითი პროექტების დასამატებლად ან ფაილებისა და ჯგუფების ჩასართავად, ეს შეგიძლიათ [`Workspace.swift`](https://projectdescription.tuist.dev/documentation/projectdescription/workspace) მანიფესტის განსაზღვრით.

```swift
// Workspace.swift
import ProjectDescription

let workspace = Workspace(
    name: "App-Workspace",
    projects: [
        "./App", // Path to directory containing the Project.swift file
    ]
)
```

> [!NOTE]
> Tuist გადაწყვეტს დამოკიდებულებების გრაფს და სამუშაო სივრცეში ჩართავს დამოკიდებულებების პროექტებს. მათი ხელით ჩართვა არ არის საჭირო. ეს აუცილებელია ბილდის სისტემისთვის დამოკიდებულებების სწორად გადასაწყვეტად.


### მრავალპროექტიანი ან ერთპროექტიანი {#multi-or-monoproject}

ხშირად ისმება კითხვა, გამოვიყენოთ თუ არა ერთი პროექტი ან რამდენიმე პროექტი სამუშაო სივრცეში. Tuist-ის გარეშე სამყაროში, სადაც ერთპროექტიანი სეტაპი ხშირ Git კონფლიქტებს გამოიწვევდა, სამუშაო სივრცეების გამოყენება რეკომენდებულია. თუმცა, ვინაიდან ჩვენ არ ვუკეთებთ რეკომენდაციას Tuist-ით გენერირებული Xcode პროექტების Git რეპოზიტორიაში ჩართვის შესახებ, Git კონფლიქტები პრობლემა არ არის. შესაბამისად, გადაწყვეტილება ერთი პროექტის ან რამდენიმე პროექტის გამოყენების შესახებ სამუშაო სივრცეში თქვენზეა.

Tuist პროექტში ჩვენ ერთპროექტიან მიდგომას ვანიჭებთ უპირატესობას, რადგან ცივი გენერაციის დრო უფრო სწრაფია (ნაკლები მანიფესტ ფაილია კომპილირებადი) და <.localized_link href="/guides/features/projects/code-sharing">პროექტის აღწერის დამხმარე საშუალებებს</.localized_link> ვიყენებთ როგორც ინკაფსულაციის ერთეულს. თუმცა, შესაძლოა გსურდეთ Xcode პროექტების გამოყენება ინკაფსულაციის ერთეულად თქვენი აპლიკაციის სხვადასხვა დომენების წარმოსადგენად, რაც უფრო მეტად ემთხვევა Xcode-ის რეკომენდებულ პროექტის სტრუქტურას.

## Tuist.swift {#tuistswift}

Tuist უზრუნველყოფს <.localized_link href="/contributors/principles#default-to-conventions">გონივრულ ნაგულისხმევ მნიშვნელობებს</.localized_link> პროექტის კონფიგურაციის გასამარტივებლად. თუმცა, შეგიძლიათ კონფიგურაციის მორგება პროექტის ძირში [`Tuist.swift`](https://projectdescription.tuist.dev/documentation/projectdescription/tuist)-ის განსაზღვრით, რომელსაც Tuist იყენებს პროექტის ძირის დასადგენად.

```swift
import ProjectDescription

let tuist = Tuist(
    project: .tuist(generationOptions: .options(enforceExplicitDependencies: true))
)
```
