# მანიფესტები {#manifests}

Tuist პროექტებისა და სამუშაო სივრცეების აღსაწერად და გენერაციის პროცესის კონფიგურაციისთვის ძირითადად Swift ფაილებს იყენებს. დოკუმენტაციაში ამ ფაილებს **მანიფესტ ფაილებს** უწოდებენ.

Swift-ის გამოყენების გადაწყვეტილება შთაგონებული იყო [Swift Package Manager](https://www.swift.org/documentation/package-manager/)-ით, რომელიც ასევე Swift ფაილებს იყენებს პაკეტების აღსაწერად. Swift-ის გამოყენების წყალობით შეგვიძლია გამოვიყენოთ კომპილატორი შინაარსის სისწორის ვალიდაციისთვის და კოდის ხელახლა გამოყენებისთვის სხვადასხვა მანიფესტ ფაილში, ხოლო Xcode — სინტაქსის გამოკვეთის, ავტომატური შევსებისა და ვალიდაციის წყალობით რედაქტირების მაღალი ხარისხის გამოცდილების უზრუნველსაყოფად.

> [!NOTE]
> **ქეშირება**
>
> ვინაიდან მანიფესტ ფაილები არის Swift ფაილები, რომლებიც კომპილაციას საჭიროებენ, Tuist აქეშირებს კომპილაციის შედეგებს პარსინგის პროცესის დასაჩქარებლად. შესაბამისად, შეამჩნევთ, რომ Tuist-ის პირველად გაშვებისას პროექტის გენერაციას ოდნავ მეტი დრო დასჭირდება. მომდევნო გაშვებები უფრო სწრაფი იქნება.


## Project.swift {#projectswift}

[`Project.swift`](https://projectdescription.tuist.dev/documentation/projectdescription/project) მანიფესტი აღწერს Xcode პროექტს. პროექტი გენერირდება იმავე საქაღალდეში, სადაც მანიფესტ ფაილი მდებარეობს, `name` თვისებაში მითითებული სახელით.

```swift
// Project.swift
let project = Project(
    name: "App",
    targets: [
        // ....
    ]
)
```


> [!WARNING]
> **ფესვითი ცვლადები**
>
> ერთადერთი ცვლადი, რომელიც მანიფესტის ფესვში უნდა იყოს, არის `let project = Project(...)`. თუ მანიფესტის სხვადასხვა ნაწილში კოდის ხელახლა გამოყენება გჭირდებათ, შეგიძლიათ გამოიყენოთ Swift ფუნქციები.


## Workspace.swift {#workspaceswift}

ნაგულისხმევად, Tuist ქმნის [Xcode Workspace](https://developer.apple.com/documentation/xcode/projects-and-workspaces)-ს, რომელიც შეიცავს გენერირებად პროექტს და მისი დამოკიდებულებების პროექტებს. თუ რაიმე მიზეზით გსურთ სამუშაო სივრცის მორგება დამატებითი პროექტების დასამატებლად ან ფაილებისა და ჯგუფების ჩასართავად, ეს შეგიძლიათ [`Workspace.swift`](https://projectdescription.tuist.dev/documentation/projectdescription/workspace) მანიფესტის განსაზღვრით.

```swift
// Workspace.swift
import ProjectDescription

let workspace = Workspace(
    name: "App-Workspace",
    projects: [
        "./App", // Path to directory containing the Project.swift file
    ]
)
```

> [!NOTE]
> Tuist გადაწყვეტს დამოკიდებულებების გრაფს და სამუშაო სივრცეში ჩართავს დამოკიდებულებების პროექტებს. მათი ხელით ჩართვა არ არის საჭირო. ეს აუცილებელია ბილდის სისტემისთვის დამოკიდებულებების სწორად გადასაწყვეტად.


### მრავალპროექტიანი ან ერთპროექტიანი {#multi-or-monoproject}

ხშირად ისმის კითხვა, სამუშაო სივრცეში ერთი პროექტი გამოვიყენოთ თუ რამდენიმე. Tuist-ის გარეშე, სადაც ერთპროექტიანი მიდგომა ხშირ Git კონფლიქტებს გამოიწვევდა, სამუშაო სივრცეების გამოყენება რეკომენდებულია. თუმცა, ვინაიდან ჩვენ არ ვუწევთ რეკომენდაციას Tuist-ით გენერირებული Xcode პროექტების Git რეპოზიტორიაში ჩართვას, Git კონფლიქტები პრობლემა არ არის. შესაბამისად, ერთი ან რამდენიმე პროექტის გამოყენების გადაწყვეტილება თქვენზეა.

Tuist-ის პროექტში ჩვენ ერთპროექტიან მიდგომას ვანიჭებთ უპირატესობას, რადგან ცივი გენერაციის დრო უფრო სწრაფია (ნაკლები მანიფესტ ფაილი კომპილაციისთვის) და <.localized_link href="/guides/features/projects/code-sharing">პროექტის აღწერის დამხმარეებს</.localized_link> ვიყენებთ როგორც ინკაფსულაციის ერთეულს. თუმცა, შეიძლება გსურდეთ Xcode პროექტების გამოყენება როგორც ინკაფსულაციის ერთეულის თქვენი აპლიკაციის სხვადასხვა დომენის წარმოსადგენად, რაც უფრო ახლოსაა Xcode-ის რეკომენდებულ პროექტის სტრუქტურასთან.

## Tuist.swift {#tuistswift}

Tuist უზრუნველყოფს <.localized_link href="/contributors/principles#default-to-conventions">გონივრულ ნაგულისხმევ მნიშვნელობებს</.localized_link> პროექტის კონფიგურაციის გასამარტივებლად. თუმცა, შეგიძლიათ კონფიგურაცია მოარგოთ პროექტის ფესვში [`Tuist.swift`](https://projectdescription.tuist.dev/documentation/projectdescription/tuist)-ის განსაზღვრით, რომელსაც Tuist იყენებს პროექტის ფესვის დასადგენად.

```swift
import ProjectDescription

let tuist = Tuist(
    project: .tuist(generationOptions: .options(registryEnabled: true))
)
```
