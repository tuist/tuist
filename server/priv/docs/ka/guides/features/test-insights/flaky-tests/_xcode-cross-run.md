### გაშვებებს შორის აღმოჩენა {#cross-run-detection}

ტესტების ხელახალი გაშვების გარეშეც, Tuist-ს შეუძლია არასტაბილური ტესტების აღმოჩენა იმავე კომიტზე, სქემასა და მითითებულ დანიშნულებაზე (მოწყობილობის სახელი, პლატფორმა და OS ვერსია) შესრულებული სხვადასხვა CI გაშვების შედეგების შედარებით. თუ ტესტი ერთ შესაბამის CI გაშვებაში წარმატებულია, მაგრამ მეორეში — ჩავარდნილი, ჩავარდნილი შესრულება მონიშნულია როგორც არასტაბილური. ეს მუშაობს მიუხედავად იმისა, რომელი შედეგი მოვიდა პირველად.

იგივე ტესტს შეიძლება ჰქონდეს თანმიმდევრულად განსხვავებული ქცევა სხვადასხვა სქემასა თუ დანიშნულებაში. მაგალითად, iOS 26-ზე წარმატება და iOS 27-ზე ჩავარდნა არასტაბილურობას არ ადგენს. სხვადასხვა სქემებიდან, მოწყობილობებიდან, პლატფორმებიდან ან OS ვერსიებიდან მიღებული შედეგები ერთმანეთს არასტაბილურად არ ნიშნავენ.

გაშვებები დანიშნულების მეტამონაცემების გარეშე, ან რამდენიმე დანიშნულებას მოიცავს, შედარდება მხოლოდ ერთმანეთთან, ამიტომ მათ შორის გარემოს განსხვავებები მაინც შეიძლება არასტაბილურად იყოს მოხსენებული. ხელახალ გაშვებაზე დაფუძნებული აღმოჩენა კვლავ მოქმედებს.

ეს განსაკუთრებით სასარგებლოა ისეთი არასტაბილური ტესტების აღმოსაჩენად, რომლებიც საკმარისად თანმიმდევრულად არ ჩავარდებიან, რათა ხელახალი გაშვებით აღმოჩენილ იქნან, მაგრამ მაინც იწვევენ პერიოდულ CI ჩავარდნებს.
