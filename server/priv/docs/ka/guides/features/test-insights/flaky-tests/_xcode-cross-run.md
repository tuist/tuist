### გაშვებებს შორის დეტექცია {#cross-run-detection}

ტესტების ხელახალი გაშვების გარეშეც, Tuist-ს შეუძლია არასტაბილური ტესტების აღმოჩენა იმავე კომიტზე, სქიმასა და მითითებულ დანიშნულებაზე (მოწყობილობის სახელი, პლატფორმა და ოპერაციული სისტემის ვერსია) შესრულებული სხვადასხვა CI გაშვების შედეგების შედარებით. თუ ტესტი ერთ შესაბამის CI გაშვებაში წარმატებით სრულდება, ხოლო მეორეში — ვერა, მაშინ ვერშესრულებული გაშვება მონიშნული იქნება როგორც არასტაბილური. ეს მუშაობს მიუხედავად იმისა, რომელი შედეგი მოვა პირველი.

იგივე ტესტს შეიძლება ჰქონდეს თანმიმდევრულად განსხვავებული ქცევა სხვადასხვა სქიმასა თუ დანიშნულებაში. მაგალითად, წარმატება iOS 26-ზე და ვერშესრულება iOS 27-ზე არ ნიშნავს არასტაბილურობას. სხვადასხვა სქემებიდან, მოწყობილობებიდან, პლატფორმებიდან ან OS ვერსიებიდან მიღებული შედეგები ერთმანეთს არასტაბილურად არ მონიშნავენ.

გაშვებები, რომლებსაც არ აქვთ დანიშნულების მეტამონაცემები ან რამდენიმე დანიშნულებას ფარავენ, შედარებულია მხოლოდ ერთმანეთთან, ამიტომ მათ შორის გარემოს განსხვავებები მაინც შეიძლება მონიშნული იყოს როგორც არასტაბილური. ხელახალი გაშვებაზე დაფუძნებული დეტექცია კვლავ მოქმედებს.

ეს განსაკუთრებით სასარგებლოა ისეთი არასტაბილური ტესტების დასაჭერად, რომლებიც არ ვერდებიან საკმარისად თანმიმდევრულად, რომ ხელახალი გაშვებით დაიჭირონ, მაგრამ მაინც იწვევენ პერიოდულ CI შეცდომებს.
