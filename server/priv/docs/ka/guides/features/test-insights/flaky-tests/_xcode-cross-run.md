### გაშვებებს შორის გამოვლენა {#cross-run-detection}

ტესტების ხელახალი გაშვების გარეშეც, Tuist-ს შეუძლია არასტაბილური ტესტების გამოვლენა ერთი და იმავე კომიტზე, სქიმასა და მითითებულ დანიშნულებაზე (მოწყობილობის სახელი, პლატფორმა და OS-ის ვერსია) შესრულებული სხვადასხვა CI გაშვების შედეგების შედარებით. თუ ტესტი ერთ შესაბამის CI გაშვებაში წარმატებით სრულდება, ხოლო მეორეში — ვერ, მაშინ ვერშესრულებული გაშვება მონიშნულია როგორც არასტაბილური. ეს მუშაობს მიუხედავად იმისა, რომელი შედეგი მოვიდა პირველი.

ერთი და იგივე ტესტს შეიძლება ჰქონდეს თანმიმდევრულად განსხვავებული ქცევა სხვადასხვა სქემასა ან დანიშნულებაში. მაგალითად, წარმატება iOS 26-ზე და წარუმატებლობა iOS 27-ზე არ ნიშნავს არასტაბილურობას. სხვადასხვა სქემებიდან, მოწყობილობებიდან, პლატფორმებიდან ან OS-ის ვერსიებიდან მიღებული შედეგები ერთმანეთს არასტაბილურად არ მონიშნავენ.

გაშვებები, რომლებსაც არ აქვთ დანიშნულების მეტამონაცემები ან რამდენიმე დანიშნულებას ფარავენ, შედარებულია მხოლოდ ერთმანეთთან, ამიტომ მათ შორის გარემოს განსხვავებები მაინც შეიძლება მონიშნულ იყოს როგორც არასტაბილური. ხელახალი გაშვებაზე დაფუძნებული გამოვლენა კვლავ მოქმედებს.

ეს განსაკუთრებით სასარგებლოა ისეთი არასტაბილური ტესტების დასაჭერად, რომლებიც საკმარისად თანმიმდევრულად არ ვერხებიან, რათა ხელახალი გაშვებებით გამოვლინდნენ, მაგრამ მაინც იწვევენ პერიოდულ CI შეცდომებს.
