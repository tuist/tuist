კარანტინი იზოლირებს არასტაბილურ სატესტო შემთხვევას, რათა მან არ დაბლოკოს CI, სანამ პრობლემას აღმოფხვრით. ნაგულისხმევად ეს **ხელით შესრულებული მოქმედებაა**: თქვენ აყენებთ ტესტს კარანტინში, ათავისუფლებთ მას და ცვლით რეჟიმებს დაშბორდზე სატესტო შემთხვევის დეტალური გვერდიდან. ასევე შეგიძლიათ ის დააკავშიროთ **ავტომატიზაციის გაფრთხილებასთან** განყოფილებაში **პარამეტრები → ავტომატიზაციები**, რათა ტესტი ავტომატურად დადუმდეს (ან გამოიტოვოს), როცა გადააჭარბებს არასტაბილურობის ზღვარს, და გათავისუფლდეს, როცა გამოჯანმრთელდება. ყოველი გადასვლა, ხელით თუ ავტომატურად, ფიქსირდება სატესტო შემთხვევის აუდიტის ჟურნალში.

ნაგულისხმევად, გამოჯანმრთელება ელოდება, სანამ გამომწვევი პირობა ძალაში აღარ იქნება, ამიტომ ტესტი რჩება კარანტინში, სანამ მისი ძველი არასტაბილური გაშვებები არ დატოვებენ გამომწვევ ფანჯარას. უფრო სწრაფად აღდგენისთვის, დააყენეთ **აღდგენა, როცა** მნიშვნელობაზე **ახალი არასტაბილური გაშვებები არ არის**: ტესტი აღდგება, როცა აღდგენის ფანჯარა (დღეები ან გაშვებები) გავა ახალი არასტაბილური გაშვების გარეშე, ყოველი ახალი არასტაბილური გაშვება თავიდან იწყებს ამ ლოდინს და აღდგენის შემდეგ მხოლოდ ახალი არასტაბილური გაშვება კვლავ აყენებს მას კარანტინში.
