### როდესაც გეიტი არ გაეშვება {#when-the-gate-does-not-run}

- პირველი გაშვება უკვე ჩავარდა. ჯერ ეს ტესტები გამოასწორეთ.
- პროექტს არ აქვს ნაგულისხმები ბრენჩი, ან მასზე CI-ში ჯერ არაფერი გაშვებულა.
- პროექტის ტესტების 30%-ზე მეტი ახალი ჩანს. ამდენის ხელახლა გაშვება იმაზე მეტ დროს წაიღებს, ვიდრე საჭიროა. ეს მოსალოდნელია პროექტზე, რომელიც ახლახან დაიწყე Tuist-თან რეპორტინგს, ან სახელის შეცვლის შემდეგ, როცა ერთბაშად ბევრი ტესტი გადაიტანეს.
