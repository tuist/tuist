### როდესაც გეიტი არ მუშაობს {#when-the-gate-does-not-run}

- პირველი გაშვება უკვე ჩავარდა. ჯერ ეს ტესტები გამოასწორეთ.
- პროექტს არ აქვს ნაგულისხმები ბრენჩი, ან CI-ზე მისთვის ჯერ არაფერი გაშვებულა.
- პროექტის ტესტების 30%-ზე მეტი ახალი ჩანს. ამ რაოდენობის ხელახლა გაშვება იმაზე მეტ დროს წაიღებს, ვიდრე საჭიროა. ეს მოსალოდნელია პროექტში, რომელიც ახლახან დაიწყო Tuist-თან მონაცემების გაგზავნას, ან სახელის შეცვლის შემდეგ, როცა ბევრი ტესტი ერთდროულად გადაადგილდება.
