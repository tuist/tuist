### როდესაც გეიტი არ მუშაობს {#when-the-gate-does-not-run}

- პირველი გაშვება უკვე ჩავარდა. ჯერ ეს ტესტები შეასწორეთ.
- პროექტს არ აქვს ნაგულისხმები ბრენჩი, ან მასზე CI-ში ჯერ არაფერი გაშვებულა.
- პროექტის ტესტების 30%-ზე მეტი ახალი ჩანს. ამ რაოდენობის ხელახლა გაშვება იმაზე მეტ დროს წაიღებს, ვიდრე სასარგებლოა. ეს მოსალოდნელია პროექტზე, რომელიც ახლახანს დაიწყო Tuist-თან რეპორტინგს, ან სახელის ცვლილების შემდეგ, როცა ერთდროულად ბევრი ტესტი გადაადგილდება.
