### მისი ჩართვა {#enabling-stress-testing}

კარიბჭე ნაგულისხმევად გამორთულია. დააყენეთ რეჟიმი:

- **`report`**: აფრთხილებს თითოეულ არამდგრად სატესტო შემთხვევაზე. გაშვება მაინც სრულდება საკუთარი შედეგის მიხედვით.
- **`enforce`**: არამდგრადი სატესტო შემთხვევა აცდენს გაშვებას, იგივე გასვლის კოდით, რაც წარუმატებელ ტესტს.

დაიწყეთ `report`-ით რამდენიმე კვირის განმავლობაში, რათა ნახოთ, რას დაბლოკავდა `enforce`.
