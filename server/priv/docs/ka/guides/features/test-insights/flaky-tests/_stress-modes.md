### მისი ჩართვა {#enabling-stress-testing}

კარიბჭე ნაგულისხმევად გამორთულია. აირჩიეთ რეჟიმი:

- **`report`**: აფრთხილებს თითოეულ არამდგრად სატესტო შემთხვევაზე. გაშვება მაინც სრულდება საკუთარი შედეგის მიხედვით.
- **`enforce`**: არამდგრადი სატესტო შემთხვევა აცდენს გაშვებას, იმავე გასვლის კოდით, რაც ჩავარდნილ ტესტს.

დაიწყეთ `report`-ით რამდენიმე კვირის განმავლობაში, რომ ნახოთ, რას დაბლოკავდა `enforce`.
