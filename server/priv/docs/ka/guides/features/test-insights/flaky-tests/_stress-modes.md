### მისი ჩართვა {#enabling-stress-testing}

კარიბჭე ნაგულისხმევად გამორთულია. დააყენეთ რეჟიმი:

- **`report`**: აფრთხილებს თითოეულ არასტაბილურ სატესტო შემთხვევაზე. გაშვება მაინც სრულდება თავისი შედეგის მიხედვით.
- **`enforce`**: არასტაბილური სატესტო შემთხვევა აწარუმატებს გაშვებას, იგივე გასვლის კოდით, რაც წარუმატებელ ტესტს.

დაიწყეთ `report`-ით რამდენიმე კვირის განმავლობაში, რომ ნახოთ, რას დაბლოკავდა `enforce`.
