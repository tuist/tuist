### რატომ შეიძლება კარანტინში მყოფი ტესტები წარმატებულად გამოისახოს {#quarantined-passing}

- **ჩუმად დატოვებული ტესტები** მაინც სრულდება. ჩუმად დატოვებული ტესტი, რომელიც ვერ გადის, ფიქსირდება როგორც **ვერ გაიარა** სატესტო შემთხვევის გაშვებისას და მონიშნულია როგორც არამყარი; ცალკეული ტესტის სტატუსი არ იცვლება. რაც გადაიწერება, არის **ტესტების გაშვების საერთო სტატუსი**: თუ გაშვებაში ყველა ვერ გასული სატესტო შემთხვევა ჩუმად არის დატოვებული, მთლიანი გაშვება აღირიცხება როგორც წარმატებული, ამიტომ ჩუმად დატოვებული ვერ გასვლები არ არღვევენ CI-ს.
- **გამოტოვებული ტესტები** საერთოდ არ სრულდება, ამიტომ დაშბორდი აგრძელებს ბოლო რეალური შესრულების სტატუსის ჩვენებას. ეს სნეპშოტი შეიძლება კვირების ძველი იყოს.
