### რატომ შეიძლება კარანტინში მყოფი ტესტები წარმატებულად გამოჩნდნენ {#quarantined-passing}

- **ჩუმად დატოვებული ტესტები** მაინც სრულდება. ჩუმად დატოვებული ტესტი, რომელიც ვერ გადის, ფიქსირდება როგორც **ვერ გაიარა** სატესტო შემთხვევის გაშვებისას და მონიშნულია როგორც არასტაბილური; თითოეული ტესტის სტატუსი არ იცვლება. ის, რაც იცვლება, არის **მთლიანი ტესტების გაშვება**: თუ გაშვებისას ყველა ვერ გავლილი სატესტო შემთხვევა ჩუმად არის დატოვებული, მთლიანი გაშვება მოიხსენიება როგორც წარმატებული, ამიტომ ჩუმად დატოვებული ვერ გავლებები არ არღვევენ CI-ს.
- **გამოტოვებული ტესტები** საერთოდ არ სრულდება, ამიტომ დაშბორდი აგრძელებს ბოლო რეალური გაშვების სტატუსის ჩვენებას. ეს სნეპშოტი შეიძლება რამდენიმე კვირის იყოს.
