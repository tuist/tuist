### რატომ შეიძლება კარანტინში მოქცეული ტესტები წარმატებულად გამოჩნდეს {#quarantined-passing}

- **დახშული ტესტები** მაინც სრულდება. დახშული ტესტი, რომელიც ვერ გადის, ფიქსირდება როგორც **ვერ გავიდა** სატესტო შემთხვევის გაშვებისას და მონიშნულია როგორც არამდგრადი; თითოეული ტესტის სტატუსი არ იცვლება. რაც გადაიწერება, არის **ტესტების საერთო გაშვება**: თუ გაშვებაში ყველა ვერ გამავალი სატესტო შემთხვევა დახშულია, მთლიანი გაშვება აღირიცხება როგორც წარმატებული, ამიტომ დახშული ვერ გასვლები არ არღვევენ CI-ს.
- **გამოტოვებული ტესტები** საერთოდ არ სრულდება, ამიტომ დაფაზე კვლავ ჩანს ტესტის ბოლო რეალური შესრულების სტატუსი. ეს სნეპშოტი შეიძლება რამდენიმე კვირის სიძველის იყოს.
