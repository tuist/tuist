### რამდენჯერ გადაირბენს თითოეული ტესტი {#stress-reruns}

ეს დამოკიდებულია იმაზე, თუ რამდენი ხანი დასჭირდა სატესტო შემთხვევას პირველ გაშვებაზე:

| პირველი გაშვება | განმეორებითი გაშვებები |
| --- | --- |
| 5 წმ-მდე | 10 |
| 10 წმ-მდე | 5 |
| 30 წმ-მდე | 3 |
| 5 წთ-მდე | 2 |
| 5 წთ-ზე მეტი | არ განმეორდება |

გაშვება ჩერდება 200 სატესტო შემთხვევის ან 10 წუთის შემდეგ, იმის მიხედვით, რომელიც უფრო ადრე დადგება, და მიუთითებს, რომელი ზღვარი მიიღწია.
