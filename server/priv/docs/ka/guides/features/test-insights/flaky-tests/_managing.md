## არასტაბილური ტესტების მართვა {#managing-flaky-tests}

### ავტომატური გასუფთავება {#automatic-clearing}

აღმოჩენა და გასუფთავება ხდება პროექტზე **ავტომატიზაციის შეტყობინების** მეშვეობით. ყოველ პროექტს აქვს ნაგულისხმევი „არასტაბილური ტესტების აღმოჩენის“ ავტომატიზაცია, რომლის *ტრიგერი* ტესტს არასტაბილურად ნიშნავს, ხოლო *აღდგენა* ხსნის ამ ნიშანს, როცა ტესტი კონფიგურირებული აღდგენის ფანჯრის განმავლობაში (ნაგულისხმევი **14 დღე**) ხელახლა არ გააქტიურებს ტრიგერს. შეცვალეთ ის **პარამეტრები → ავტომატიზაციები**-ში, რათა შეცვალოთ აღდგენის ფანჯარა, აღდგენის ქმედებები (მაგალითად, ასევე გამოიყვანოთ ტესტი კარანტინიდან) ან სრულად გათიშოთ აღდგენა, რათა ტესტები დარჩეს არასტაბილურად მონიშნული, სანამ ხელით არ გაასუფთავებთ.

### ხელით მართვა {#manual-management}

ასევე შეგიძლიათ ხელით მონიშნოთ ან მოხსნათ ტესტები არასტაბილურად სატესტო შემთხვევის დეტალური გვერდიდან. ეს სასარგებლოა, როცა:
- გსურთ აღიაროთ ცნობილი არასტაბილური ტესტი შესწორებაზე მუშაობისას
- ტესტი არასწორად იყო მონიშნული ინფრასტრუქტურის პრობლემების გამო
