## არასტაბილური ტესტების მართვა {#managing-flaky-tests}

### ავტომატური გასუფთავება {#automatic-clearing}

აღმოჩენა და გასუფთავება ხდება პროექტზე არსებული **ავტომატიზაციის შეტყობინების** მეშვეობით. ყოველ პროექტს აქვს ნაგულისხმევი „არასტაბილური ტესტის აღმოჩენის“ ავტომატიზაცია, რომლის *გამშვები* ტესტს არასტაბილურად ნიშნავს, ხოლო *აღდგენა* ხსნის ამ ნიშანს, როცა ტესტი კონფიგურირებულ აღდგენის ფანჯარაში (ნაგულისხმევი **14 დღე**) ხელახლა არ გაააქტიურებს შეტყობინებას. ჩაასწორეთ ის **პარამეტრები → ავტომატიზაციები** განყოფილებაში, რათა შეცვალოთ აღდგენის ფანჯარა, შეცვალოთ აღდგენის ქმედებები (მაგალითად, ასევე მოხსნათ ტესტი კარანტინიდან) ან სრულად გამორთოთ აღდგენა, რათა ტესტები დარჩეს არასტაბილურად მონიშნული, სანამ ხელით არ გაასუფთავებთ.

### ხელით მართვა {#manual-management}

ასევე შეგიძლიათ ხელით მონიშნოთ ან მოხსნათ ტესტების არასტაბილურობა სატესტო შემთხვევის დეტალურ გვერდზე. ეს სასარგებლოა, როცა:
- გსურთ აღიაროთ ცნობილი არასტაბილური ტესტი, სანამ მუშაობთ შესწორებაზე
- ტესტი არასწორად იქნა მონიშნული ინფრასტრუქტურული პრობლემების გამო
