## არასტაბილური ტესტების მართვა {#managing-flaky-tests}

### ავტომატური გასუფთავება {#automatic-clearing}

აღმოჩენა და გასუფთავება ხორციელდება პროექტზე არსებული **ავტომატიზაციის შეტყობინების** მეშვეობით. ყოველ პროექტს აქვს ნაგულისხმევი „არასტაბილური ტესტების აღმოჩენის“ ავტომატიზაცია, რომლის *ტრიგერი* ტესტს არასტაბილურად ნიშნავს, ხოლო *აღდგენა* ხსნის ამ ნიშანს, როცა ტესტი კონფიგურირებულ აღდგენის ფანჯარაში (ნაგულისხმევი **14 დღე**) ხელახლა არ გააქტიურებს ტრიგერს. შეცვალეთ ის **პარამეტრები → ავტომატიზაციები** განყოფილებაში, რათა შეცვალოთ აღდგენის ფანჯარა, აღდგენის ქმედებები (მაგალითად, ასევე მოხსნათ ტესტი კარანტინიდან) ან სრულიად გამორთოთ აღდგენა, რათა ტესტები დარჩეს არასტაბილურად მონიშნული, სანამ ხელით არ გაასუფთავებთ.

### ხელით მართვა {#manual-management}

ტესტების არასტაბილურად მონიშვნა ან ნიშნის მოხსნა შესაძლებელია სატესტო შემთხვევის დეტალური გვერდიდან. ეს სასარგებლოა, როცა:
- გსურთ აღიაროთ ცნობილი არასტაბილური ტესტი, სანამ მის გამოსწორებაზე მუშაობთ
- ტესტი ინფრასტრუქტურული პრობლემების გამო შეცდომით იყო მონიშნული
