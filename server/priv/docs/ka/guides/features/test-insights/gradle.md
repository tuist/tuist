# Gradle ტესტების ანალიტიკა {#gradle-test-insights}

Tuist-ის Gradle პლაგინი ავტომატურად ატვირთავს ტესტების შედეგებს ყოველი სატესტო ამოცანის შესრულების შემდეგ, რაც Tuist-ის დაფზე პირდაპირ გაძლევთ ხილვადობას ტესტების წარმადობასა და არასტაბილურ ტესტებზე.

ტესტების ანალიტიკა ავტომატურად იკრიბება Tuist Gradle პლაგინის გამოყენებისას — დამატებითი კონფიგურაცია არ არის საჭირო პლაგინის საწყისი მოწყობის გარდა.

შეგიძლიათ მიუწვდეთ თქვენს ტესტების ანალიტიკას Tuist-ის დაფზე და ნახოთ, როგორ იცვლება ის დროთა განმავლობაში:

![დაფა ტესტების ანალიტიკით](/images/guides/features/build-insights/tests-dashboard.png)

## რა ფიქსირდება {#what-is-tracked}

პლაგინი აგროვებს შედეგებს ყველა Gradle `Test` ამოცანიდან, მათ შორის:
- ინდივიდუალური სატესტო შემთხვევის წარმატებული/ჩავარდნილი სტატუსი და ხანგრძლივობა
- ტესტების ნაკრებისა და კლასის სტრუქტურა
- არასტაბილური ტესტების აღმოჩენა გაშვებებს შორის

## ატვირთვის ქცევის კონფიგურაცია {#configure-upload-behavior}

ნაგულისხმევად:
- ტესტების შედეგები აიტვირთება ფონურად ლოკალური ბილდებისთვის.
- ტესტების შედეგები აიტვირთება წინა პლანზე CI გაშვებებისთვის, რათა თავიდან იქნას აცილებული ტელემეტრიის დაკარგვა მოკლე სიცოცხლის მქონე აგენტებზე.

შეგიძლიათ გადაწეროთ ეს ქცევა `uploadInBackground`-ის გამოყენებით `tuist` ბლოკში თქვენს `settings.gradle.kts`-ში:

```kotlin
tuist {
    uploadInBackground = false // always upload in the foreground
}
```

### Git-ის ისტორია {#git-history}

CI-ზე პლაგინი ასევე ატვირთავს ჩექაუთის კომიტების ისტორიას, როდესაც იტყობინება ტესტების გაშვების შესახებ: კომიტების SHA-ები, მათი მშობლები, კომიტების თარიღები და დარგი, რომელზეც იყო გაშვება და მისი პულ-რეკვესტის საბაზისო დარგი. არ აიტვირთება ფაილების შინაარსი, კომიტების შეტყობინებები ან ავტორები. ეს არის ის, რაც ეუბნება Tuist-ს, რომელი კომიტები მოხვდა თქვენს ნაგულისხმევ დარგზე, მაგალითად ისინი, რომლებიც მერჯის რიგმა შეამოწმა. პლაგინი კითხულობს ისტორიას, რომელიც ჩექაუთს უკვე აქვს, და როდესაც ჩექაუთს არ აქვს საბაზისო დარგი, ითხოვს უახლეს კომიტს რიმოტისგან (`git ls-remote`). ის არ იწერს ისტორიას.

| ცვლადი | ეფექტი |
| --- | --- |
| `TUIST_GIT_UPLOAD_ENABLED=false` | არ კითხულობს და არ ატვირთავს Git-ის ისტორიას. |
| `TUIST_GIT_UNSHALLOW_ENABLED=false` | კითხულობს მხოლოდ ჩექაუთს, რიმოტთან დაკავშირების გარეშე. |
