# Gradle ტესტების ანალიტიკა {#gradle-test-insights}

Tuist-ის Gradle პლაგინი ავტომატურად ატვირთავს ტესტების შედეგებს ყოველი სატესტო ამოცანის შესრულების შემდეგ, რაც საშუალებას გაძლევთ პირდაპირ Tuist-ის დაფზე ნახოთ ტესტების წარმადობა და არასტაბილური ტესტები.

ტესტების ანალიტიკა ავტომატურად იკრიბება Tuist Gradle პლაგინის ჩართვისას — დამატებითი კონფიგურაცია არ არის საჭირო პლაგინის საწყისი მორგების გარდა.

ტესტების ანალიტიკაზე წვდომა შეგიძლიათ Tuist-ის დაფზე და ნახოთ, როგორ იცვლება ისინი დროთა განმავლობაში:

![დაფა ტესტების ანალიტიკით](/images/guides/features/build-insights/tests-dashboard.png)

## რა ფიქსირდება {#what-is-tracked}

პლაგინი აგროვებს შედეგებს ყველა Gradle `Test` ამოცანიდან, მათ შორის:
- ცალკეული სატესტო შემთხვევის წარმატებული/წარუმატებელი სტატუსი და ხანგრძლივობა
- ტესტების სიუიტისა და კლასის სტრუქტურა
- არასტაბილური ტესტების გამოვლენა გაშვებებს შორის

## ატვირთვის ქცევის კონფიგურაცია {#configure-upload-behavior}

ნაგულისხმევად:
- ლოკალური ბილდებისთვის ტესტების შედეგები ფონურ რეჟიმში იტვირთება.
- CI გაშვებებისთვის ტესტების შედეგები წინა პლანზე იტვირთება, რათა თავიდან იქნას აცილებული ტელემეტრიის დაკარგვა მოკლე სიცოცხლის მქონე აგენტებზე.

ამ ქცევის გადაწერა შეგიძლიათ `uploadInBackground`-ის გამოყენებით `tuist` ბლოკში თქვენს `settings.gradle.kts`-ში:

```kotlin
tuist {
    uploadInBackground = false // always upload in the foreground
}
```

### Git-ის ისტორია {#git-history}

CI-ზე პლაგინი ასევე ატვირთავს checkout-ის კომიტების ისტორიას, როდესაც იუწყება ტესტების გაშვებას: კომიტების SHA, მათი მშობლები, კომიტების თარიღები და დარჩი, რომელზეც იყო გაშვება და მისი pull request-ის საბაზო დარჩი. ფაილების შინაარსი, კომიტების შეტყობინებები ან ავტორები არ იტვირთება. ეს არის ინფორმაცია, რომელიც ეუბნება Tuist-ს, რომელი კომიტები მოხვდა თქვენს საბაზო დარჩზე, მაგალითად ისინი, რომლებიც merge queue-მ შეამოწმა. პლაგინი კითხულობს ისტორიას, რომელიც checkout-ს უკვე აქვს, და როდესაც checkout-ს არ აქვს საბაზო დარჩი, სთხოვს remote-ს მის უახლეს კომიტს (`git ls-remote`). ისტორიას არ იწერს.

| ცვლადი | ეფექტი |
| --- | --- |
| `TUIST_GIT_UPLOAD_ENABLED=false` | არ კითხულობს და არ ატვირთავს Git-ის ისტორიას. |
| `TUIST_GIT_UNSHALLOW_ENABLED=false` | კითხულობს მხოლოდ checkout-ს, remote-თან დაკავშირების გარეშე. |
