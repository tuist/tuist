# არასტაბილური ტესტები {#flaky-tests}

არასტაბილური ტესტები არის ტესტები, რომლებიც ერთი და იგივე კოდის რამდენჯერმე გაშვებისას სხვადასხვა შედეგს (წარმატებას ან ჩავარდნას) აჩვენებენ. ისინი ამცირებენ ნდობას თქვენი ტესტების ნაკრადის მიმართ და ფლანგავენ დეველოპერების დროს ყალბი ჩავარდნების გამოკვლევაში. Tuist ავტომატურად ავლენს არასტაბილურ ტესტებს და გეხმარებათ მათი თვალყურის დევნაში დროთა განმავლობაში.
