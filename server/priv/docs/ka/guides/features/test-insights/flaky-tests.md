# არასტაბილური ტესტები {#flaky-tests}

არასტაბილური ტესტებია ისეთი ტესტები, რომლებიც ერთი და იმავე კოდის რამდენჯერმე გაშვებისას სხვადასხვა შედეგს (წარმატება ან შეცდომა) იძლევა. ისინი არღვევენ ნდობას თქვენი ტესტების ნაკრადის მიმართ და ფუჭად ხარჯავენ დეველოპერების დროს ცრუ შეცდომების გამოკვლევაში. Tuist ავტომატურად აღმოაჩენს არასტაბილურ ტესტებს და გეხმარებათ მათი თვალყურის დევნაში დროთა განმავლობაში.
