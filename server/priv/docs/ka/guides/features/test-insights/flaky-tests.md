# არასტაბილური ტესტები {#flaky-tests}

არასტაბილური ტესტები არის ტესტები, რომლებიც ერთი და იმავე კოდის რამდენჯერმე გაშვებისას განსხვავებულ შედეგებს (წარმატება ან ჩავარდნა) იძლევა. ისინი ამცირებენ ნდობას თქვენს ტესტების ნაკრებში და ფლანგავენ დეველოპერების დროს ყალბი ჩავარდნების გამოკვლევაზე. Tuist ავტომატურად აღმოაჩენს არასტაბილურ ტესტებს და გეხმარებათ მათ თვალყურის დევნაში დროთა განმავლობაში.
