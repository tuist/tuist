# Struo-ს დისტანციური შესრულება {#struo-remote-execution}

<a id="once-remote-execution"></a>

გაზიარებული ქეშირება თავიდან აცილებს იმ სამუშაოს გამეორებას, რომელიც სხვა კომპიუტერმა უკვე შეასრულა. დისტანციური შესრულება ასევე გადაიტანს შესაბამის ქეშ-გამოტოვებებს თქვენი კომპიუტერიდან: Struo გრაფის ბრძანების მოქმედებებს განრიგებს Tuist-ის ერთჯერად Linux-მუშაკებზე და მათ შედეგებს იღებს იმავე პროექტის ქეშის მეშვეობით.

> [!NOTE]
> დისტანციური შესრულება ამჟამად მხოლოდ მიწვევითაა ხელმისაწვდომი. [დაგვიკავშირდით](mailto:contact@tuist.dev), რათა მოითხოვოთ წვდომა თქვენი ანგარიშისთვის.

> [!IMPORTANT]
> **მოთხოვნები**
>
> - Tuist-ის ანგარიში ჩართული დისტანციური შესრულებით და ხელმისაწვდომი შესრულების ტევადობით.
> - Struo-ს ვერსია Tuist-ის დისტანციური შესრულების მხარდაჭერით.
> - თავსებადი სერვერი, რომელიც აცხადებს მუშაკის იმიჯს, ქეშის საბოლოო წერტილს, პარალელურობას და შესრულების აბსოლუტურ დირექტორიას. სერვერები, რომლებიც გამოტოვებენ დირექტორიას, არ არიან თავსებადები მიმდინარე Struo-ს კლიენტთან; Struo წყვეტს მუშაობას მუშაობის ატვირთვამდე.
> - ბრძანებები და ინსტრუმენტთა ჯაჭვები, რომლებსაც შეუძლიათ გაშვება `linux/amd64`-ზე რეკლამირებულ მუშაკის იმიჯში.

ეს ასრულებს გრაფის მოქმედებებს და არა მთლიან CI-ს სამუშაოს. Struo-ს კონფიგურაცია არ აყენებს GitHub-ის ან GitLab-ის სამუშაო ნაკადების ორკესტრაციას.

## მოწყობა {#setup}

დაასრულეთ <.localized_link href="/guides/get-started/struo-project">Struo-ს გამოყენების დაწყება</.localized_link>. აირჩიეთ იგივე Tuist-ის პროვაიდერი ქეშირებისა და შესრულებისთვის და დააფიქსირეთ სერვისის მიერ რეკლამირებული მუშაკის იმიჯი:

```toml
[infrastructures.tuist]
kind = "tuist"
account = "acme"
project = "app"
execution_image = "sha-REPLACE_WITH_THE_IMAGE_TAG"

[infrastructure.cache]
provider = "tuist"

[infrastructure.execution]
provider = "tuist"
```

გაიარეთ ავთენტიკაცია ისეთი სერთიფიკატებით, რომლებსაც შეუძლიათ წაიკითხონ და ჩაწერონ პროექტის ქეში, შემდეგ კი მოითხოვეთ დისტანციური შესრულება:

```bash
struo build --remote MyTarget
```

ჩაანაცვლეთ სამიზნე და იმიჯის თეგი თქვენით. Struo ამოწმებს რეკლამირებულ იმიჯს, შესრულების დირექტორიას, ქეშის დანიშნულების ადგილს და ანგარიშის ტევადობას მუშაობის ატვირთვამდე. ქეში და შესრულება უნდა მიუთითებდნენ ერთსა და იმავე პროექტზე.

## მუშაკებისთვის მოქმედებების მომზადება {#prepare-actions-for-workers}

- განაცხადეთ შეყვანები და გამოტანები. გამოტანები უნდა დარჩეს მოქმედების სამუშაო დირექტორიის ქვეშ.
- ინსტრუმენტების ამოცნობა მოახდინეთ მუშაკის იმიჯის შიგნით, არა ინიციატორ კომპიუტერზე აბსოლუტური გზებით.
- გამოიყენეთ მოქმედებები, რომელთა გამეორებაც უსაფრთხოა: მუშაკის შეცდომა ან სერვისის გადატვირთვა შეიძლება გამოიწვიოს კიდევ ერთი შესრულება.
- შეინარჩუნეთ დროის ამოწურვა სერვისის ათწუთიანი მოქმედების ლიმიტის ფარგლებში. მხარდაუჭერელი მოთხოვნები, მათ შორის ქსელის უარყოფა, იწვევენ შეცდომას და არა ჩუმად ადგილობრივად გაშვებას.

Struo ითვალისწინებს ანგარიშის რეკლამირებულ მოქმედების პარალელურობას და ამცირებს დატვირთვას, როდესაც სერვისის რიგი სავსეა. იმიჯის შეცვლა ყოფს აგების კონფიგურაციასა და ქეშირებულ შედეგებს, რაც ხელს უშლის თავსებად არა მუშაკის იმიჯებში ხელახლა გამოყენებას.

## დისტანციური შესრულების ინსპექტირება {#inspect-remote-execution}

პროექტის გვერდით პანელს აქვს **დისტანციური შესრულება** გვერდი. მისი **ანალიტიკა** ბარათი აჩვენებს შესრულებებსა და შესრულების ჯამურ დროს შერჩეული პერიოდისთვის, როგორც აღწერილია <.localized_link href="/guides/features/cache/bazel-cache#running-actions-and-usage">მოქმედებების გაშვება და გამოყენება</.localized_link>-ში. Struo-ს გაშვების ტელემეტრია ჯერჯერობით არ არჩევს დისტანციურ შესრულებას ადგილობრივი მოქმედებებისგან, ამიტომ გვერდზე არ არის თითოეული გაშვების დისტანციური დროები ან მიმდინარე გაშვებები. ის ხსნის ამ სხვაობას და ბმავს **აგების გაშვებებთან** ჩაწერილი მოქმედების დეტალებისთვის. მიმდინარედ გაშვებული და რიგში მყოფი დისტანციური მოქმედებები ხელმისაწვდომია `get_remote_execution_activity` MCP ინსტრუმენტიდან და მისი REST საბოლოო წერტილიდან. ორივე მოდის შესრულების სერვისიდან, არა მუშაკის არხებიდან.

იხილეთ [Struo-ს დისტანციური შესრულების სახელმძღვანელო](https://struo.run/docs/guide/infrastructure/tuist#run-actions-on-tuist-workers) რიგში დაყენების, ავთენტიკაციის განახლებისა და ქეშის საბოლოო წერტილის გადაფარვისთვის. მიჰყევით <.localized_link href="/guides/features/build-insights/struo">Struo-ს აგების ინსაიტებს</.localized_link>, რათა შეისწავლოთ მიღებული გაშვებები.
