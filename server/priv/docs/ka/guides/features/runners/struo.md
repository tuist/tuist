# Struo-ს დისტანციური შესრულება {#struo-remote-execution}

<a id="once-remote-execution"></a>

გაზიარებული ქეში თავიდან აცილებს იმ სამუშაოს განმეორებას, რომელიც სხვა მანქანამ უკვე შეასრულა. დისტანციური შესრულება ასევე გადაიტანს დასაშვებ ქეშის გამოტოვებებს თქვენი კომპიუტერიდან: Struo გრაფის ბრძანების მოქმედებებს გეგმავს Tuist-ის ერთჯერად Linux მუშაკებზე და იღებს მათ გამომავალ მონაცემებს იმავე პროექტის ქეშის მეშვეობით.

> [!NOTE]
> დისტანციური შესრულება ამჟამად მხოლოდ მიწვევით არის ხელმისაწვდომი. [დაგვიკავშირდით](mailto:contact@tuist.dev) თქვენი ანგარიშისთვის წვდომის მოსათხოვნად.

> [!IMPORTANT]
> **მოთხოვნები**
>
> - Tuist-ის ანგარიში ჩართული დისტანციური შესრულებით და ხელმისაწვდომი შესრულების სიმძლავრით.
> - Struo-ს ვერსია Tuist-ის დისტანციური შესრულების მხარდაჭერით.
> - თავსებადი სერვერი, რომელიც აცხადებს მუშაკის იმიჯს, ქეშის ბოლოწერტილს, კონკურენტულობას და აბსოლუტურ შესრულების დირექტორიას. სერვერები, რომლებიც ტოვებენ დირექტორიას, არ არიან თავსებადი მიმდინარე Struo კლიენტთან; Struo ჩერდება სამუშაოს ატვირთვამდე.
> - ბრძანებები და ინსტრუმენტების ჯაჭვები, რომლებსაც შეუძლიათ გაშვება `linux/amd64` რეკლამირებულ მუშაკის იმიჯში.

ეს ასრულებს გრაფის მოქმედებებს და არა მთლიან CI დავალებას. Struo-ს კონფიგურაცია არ აყენებს GitHub ან GitLab სამუშაო ნაკადის ორკესტრაციას.

## მორგება {#setup}

შეასრულეთ <.localized_link href="/guides/get-started/struo-project">დაწყება Struo-სთან</.localized_link>. აირჩიეთ იგივე Tuist პროვაიდერი ქეშინგისა და შესრულებისთვის და დააფიქსირეთ სერვისის მიერ რეკლამირებული მუშაკის იმიჯი:

```toml
[infrastructures.tuist]
kind = "tuist"
account = "acme"
project = "app"
execution_image = "sha-REPLACE_WITH_THE_IMAGE_TAG"

[infrastructure.cache]
provider = "tuist"

[infrastructure.execution]
provider = "tuist"
```

გაიარეთ ავთენტიფიკაცია ისეთი მონაცემებით, რომლებსაც შეუძლიათ წაიკითხონ და ჩაწერონ პროექტის ქეში, შემდეგ მოითხოვეთ დისტანციური შესრულება:

```bash
struo build --remote MyTarget
```

ჩაანაცვლეთ სამიზნე და იმიჯის თეგი თქვენით. Struo ამოწმებს რეკლამირებულ იმიჯს, შესრულების დირექტორიას, ქეშის დანიშნულების ადგილს და ანგარიშის სიმძლავრეს სამუშაოს ატვირთვამდე. ქეში და შესრულება უნდა მიუთითებდეს ერთსა და იმავე პროექტზე.

## მუშაკებისთვის მოქმედებების მომზადება {#prepare-actions-for-workers}

- განაცხადეთ შემავალი და გამომავალი მონაცემები. გამომავალი მონაცემები უნდა დარჩეს მოქმედების სამუშაო დირექტორიის ქვეშ.
- გააგვარეთ ინსტრუმენტები მუშაკის იმიჯის შიგნით, არა საწყის კომპიუტერზე აბსოლუტური გზებით.
- გამოიყენეთ მოქმედებები, რომლებიც უსაფრთხოა განმეორებისთვის: მუშაკის შეცდომა ან სერვისის გადატვირთვა შეიძლება გამოიწვიოს კიდევ ერთი შესრულება.
- დაიცავით დროის ამოწურვა სერვისის ათწუთიანი მოქმედების ლიმიტის ფარგლებში. არამხარდაჭერილი მოთხოვნები, მათ შორის ქსელის აკრძალვა, ვერ ასრულებენ და არა ჩუმად ადგილობრივად გაშვებას.

Struo პატივს სცემს ანგარიშის რეკლამირებულ მოქმედების კონკურენტულობას და ელოდება, როდესაც სერვისის რიგი სავსეა. იმიჯის შეცვლა ყოფს აგების კონფიგურაციას და ქეშირებულ შედეგებს, რაც ხელს უშლის თავსებად არა მუშაკის იმიჯებში ხელახლა გამოყენებას.

## დისტანციური შესრულების ინსპექტირება {#inspect-remote-execution}

პროექტის გვერდითა პანელს აქვს **დისტანციური შესრულება** გვერდი. მისი **ანალიტიკა** ბარათი აჩვენებს შესრულებებს და საერთო შესრულების დროს შერჩეული პერიოდისთვის, როგორც აღწერილია <.localized_link href="/guides/features/cache/bazel-cache#running-actions-and-usage">მოქმედებების გაშვება და გამოყენება</.localized_link>-ში. Struo გაშვების ტელემეტრია ჯერ არ არჩევს დისტანციურ შესრულებას ადგილობრივი მოქმედებებისგან, ამიტომ გვერდს არ აქვს თითოეული გაშვების დისტანციური დროები ან მიმდინარე გაშვებები. ის ხსნის ამ ნაკლს და აკავშირებს **აგების გაშვებებთან** ჩაწერილი მოქმედების დეტალებისთვის. მიმდინარედ გაშვებული და რიგში მყოფი დისტანციური მოქმედებები ხელმისაწვდომია `get_remote_execution_activity` MCP ინსტრუმენტისა და მისი REST ბოლოწერტილის მეშვეობით. ორივე მოდის შესრულების სერვისიდან, არა მუშაკის ზოლებიდან.

იხილეთ [Struo-ს დისტანციური შესრულების სახელმძღვანელო](https://struo.run/docs/guide/infrastructure/tuist#run-actions-on-tuist-workers) რიგში ჩადგომის, ავთენტიფიკაციის განახლებისა და ქეშის ბოლოწერტილის გადაფარვისთვის. მიჰყევით <.localized_link href="/guides/features/build-insights/struo">Struo აგების ინსაიტებს</.localized_link> შედეგად მიღებული გაშვებების ინსპექტირებისთვის.
