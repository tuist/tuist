# პროფილები {#profiles}

**პროფილი** არის ანგარიშის ფარგლებში განსაზღვრული, სახელდართი მანქანის კონფიგურაცია. თქვენ მიუთითებთ მას სამუშაო პროცესის `runs-on`-ში და Tuist საქმეს გაუშვებს შესაბამის რანერზე. პროფილები ინფრასტრუქტურის არჩევანს (პლატფორმა, ზომა, Xcode-ის ვერსია) ერთ ადგილას ინახავს, ნაცვლად იმისა, რომ ის ყველა სამუშაო პროცესის ფაილში იყოს გაფანტული, და გაძლევთ სტაბილურ იარლიყს CI-სთვის.

```yaml
jobs:
  build:
    runs-on: tuist-macos
```

იარლიყი არის პროფილის სახელი `tuist-` პრეფიქსით. პროფილი სახელით `macos` არის `runs-on: tuist-macos`; პროფილი სახელით `linux-large` არის `runs-on: tuist-linux-large`. შედარება არ არის დამოკიდებული ასოების რეგისტრზე.

## ნაგულისხმევი პროფილები {#default-profiles}

ყველა ანგარიში, რომელიც ჩართულია რანერებისთვის, იწყება ორი პროფილით, რათა შეძლოთ ფლოტის გამოყენება რაიმეს კონფიგურაციის გარეშე:

{{runner_default_profiles_table}}

ორივე მიუთითებს თავისი პლატფორმის ნაგულისხმევ <.localized_link href="/guides/features/runners/profiles#machine-shapes">კონფიგურაციაზე</.localized_link>. ისინი არიან **დაცული**, ამიტომ მათი წაშლა შეუძლებელია და იარლიყები, რომლებზეც თქვენი სამუშაო პროცესებია დამოკიდებული, ყოველთვის მუშაობს. მაინც შეგიძლიათ შეცვალოთ მათი კონფიგურაცია ან Xcode-ის ვერსია და შექმნათ დამატებითი პროფილები სხვა ზომების ან Xcode-ის ვერსიებისთვის.

## მანქანის კონფიგურაციები {#machine-shapes}

რანერები ხელმისაწვდომია macOS-ზე (Apple silicon, ვირტუალიზებული Mac-ის ფლოტზე) და Linux-ზე. თითოეული პროფილი აფიქსირებს ერთ მანქანის კონფიგურაციას, `(vCPUs, memory)` წყვილს, ქვემოთ მოცემული კატალოგიდან.

### Linux {#linux}

{{runner_linux_shapes_table}}

ყოველი Linux პროფილი მხარს უჭერს <.localized_link href="/guides/features/runners#android-emulators">აპარატურულად აჩქარებულ Android ემულატორებს</.localized_link> `/dev/kvm`-ის მეშვეობით. ცალკე KVM პროფილი არ არის საჭირო.

### macOS {#macos}

{{runner_macos_shapes_table}}

უფრო დიდი macOS კონფიგურაციები ნაკლებ მანქანაზე მუშაობს ფლოტში, ამიტომ საქმემ, რომელიც მათ ითხოვს, შეიძლება უფრო დიდხანს დაელოდოს გაშვებას, ვიდრე იგივე საქმემ უფრო მცირე კონფიგურაციაზე. გამოიყენეთ უფრო დიდი კონფიგურაცია, როცა საქმე CPU-ით არის შეზღუდული, და დატოვეთ ნაგულისხმევი კონფიგურაცია ყველაფერი დანარჩენისთვის. თუ არ ხართ დარწმუნებული, გაუშვით საქმე ორივეზე და შეადარეთ ხანგრძლივობები დაშბორდზე.

macOS პროფილები ასევე აფიქსირებენ **Xcode-ის ვერსიას**. ვერსია ირჩევს რანერის იმიჯს წინასწარ ინსტალირებული Xcode-ით, ასე რომ საქმეები იწყება უკვე არსებული ინსტრუმენტების ნაკრებით. მხარდაჭერილი ვერსიები დღეს:

{{runner_macos_xcode_versions}}

> [!NOTE]
> კატალოგი იცვლება, როგორც ვამატებთ ახალ აპარატურას და Xcode-ის გამოშვებებს. დაშბორდზე **ახალი პროფილის** ფორმა და `tuist runner profile catalog` ყოველთვის აჩვენებს კონფიგურაციებს და Xcode-ის ვერსიებს, რომლებიც ამჟამად ხელმისაწვდომია თქვენი ანგარიშისთვის, ამიტომ მიიჩნიეთ ისინი ჭეშმარიტების წყაროდ.

macOS რანერის სახელი აჩვენებს macOS-ის ვერსიას, რომელზეც ის მუშაობს, პროფილის Xcode-ის ვერსიას და მის კონფიგურაციას, მაგალითად `tuist-macos-26.6-xcode-27.0-6vcpu-14gb-1a2b3c4d5e6f`. სახელი ჩანს GitHub-ზე საქმის **საქმის მომზადების** ეტაპზე და Tuist-ის დაშბორდზე საქმის დეტალებში.

## პროფილის შექმნა {#creating-a-profile}

1. გახსენით თქვენი ანგარიშის დაშბორდის **რანერები → პროფილები** სექცია.
2. აირჩიეთ **ახალი პროფილი**.
3. მიეცით სახელი, აირჩიეთ პლატფორმა და აირჩიეთ კონფიგურაცია. macOS-ისთვის ასევე აირჩიეთ Xcode-ის ვერსია.
4. შეინახეთ, შემდეგ მიუთითეთ ის სამუშაო პროცესიდან `runs-on: tuist-<name>`-ით.

პროფილების მართვა ასევე შეგიძლიათ ბრძანების სტრიქონიდან. პროფილების შექმნა, შეცვლა და წაშლა მოითხოვს ანგარიშის ადმინისტრირებას, როგორც დაშბორდზე, ან ანგარიშის ტოკენს `account:runners:write` სკოუპით:

```bash
tuist runner profile catalog
tuist runner profile create linux-large --platform linux --vcpus 8 --memory-gb 32
tuist runner profile update linux-large --vcpus 16 --memory-gb 32
tuist runner profile delete linux-large --yes
```

აგენტებს იგივეს გაკეთება შეუძლიათ <.localized_link href="/guides/features/agentic-coding/mcp">MCP სერვერის</.localized_link> მეშვეობით.

მაგალითად, პროფილი სახელით `linux-large` 8 vCPU / 32 GB კონფიგურაციაზე:

```yaml
jobs:
  integration-tests:
    runs-on: tuist-linux-large
```

ან macOS პროფილი სახელით `xcode-26-4`, მიბმული Xcode `26.4.1`-ზე, რათა საქმემ შეძლოს ძველ ინსტრუმენტების ნაკრებზე მუშაობა, სანამ თქვენი ნაგულისხმევი `macos` პროფილი უახლესს მიჰყვება:

```yaml
jobs:
  build-legacy:
    runs-on: tuist-xcode-26-4
```
