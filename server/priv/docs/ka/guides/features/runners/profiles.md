# პროფილები {#profiles}

**პროფილი** არის ანგარიშის ფარგლებში განსაზღვრული, სახელდარქმეული მანქანის კონფიგურაცია. თქვენ მიუთითებთ მას სამუშაო პროცესის `runs-on`-ში და Tuist ამუშავებს დავალებას შესაბამის გამშვებზე (runner). პროფილები ინფრასტრუქტურის არჩევანს (პლატფორმა, ზომა, Ubuntu-ის ვერსია ან Xcode-ის ვერსია) ერთ ადგილას ინახავს, ნაცვლად იმისა, რომ ის გაფანტული იყოს ყველა სამუშაო პროცესის ფაილში, და გაძლევთ სტაბილურ ლეიბლს CI-სთვის.

```yaml
jobs:
  build:
    runs-on: tuist-macos
```

ლეიბლი არის პროფილის სახელი `tuist-` პრეფიქსით. პროფილი სახელით `macos` არის `runs-on: tuist-macos`; პროფილი სახელით `linux-large` არის `runs-on: tuist-linux-large`. შედარება რეგისტრის მიმართ უგრძნობელია.

## ნაგულისხმევი პროფილები {#default-profiles}

ყველა ანგარიში, რომლისთვისაც ჩართულია Runners, იწყება ორი პროფილით, რათა შეძლოთ ფლოტის გამოყენება ყოველგვარი კონფიგურაციის გარეშე:

{{runner_default_profiles_table}}

ორივე მიუთითებს თავისი პლატფორმის ნაგულისხმევ <.localized_link href="/guides/features/runners/profiles#machine-shapes">კონფიგურაციაზე</.localized_link>. ისინი **დაცულია**, ამიტომ მათი წაშლა შეუძლებელია და ლეიბლები, რომლებზეც თქვენი სამუშაო პროცესებია დამოკიდებული, ყოველთვის წარმატებით ამოიცნობა. თქვენ მაინც შეგიძლიათ შეცვალოთ მათი კონფიგურაცია ან Xcode-ის ვერსია, ასევე შეგიძლიათ შექმნათ დამატებითი პროფილები სხვა ზომების ან Xcode-ის ვერსიებისთვის.

## მანქანის კონფიგურაციები {#machine-shapes}

გამშვები ხელმისაწვდომია macOS-ზე (Apple silicon, ვირტუალიზებული Mac-ების ფლოტზე) და Linux-ზე. ყოველი პროფილი აფიქსირებს ერთ მანქანის კონფიგურაციას, `(vCPUs, memory)` წყვილს, ქვემოთ მოცემული კატალოგიდან.

### Linux {#linux}

{{runner_linux_shapes_table}}

Linux-ის პროფილები ასევე ირჩევენ **Ubuntu-ის ვერსიას**, ისევე როგორც macOS-ის პროფილები ირჩევენ Xcode-ის ვერსიას:

- **Ubuntu 24.04** (`ubuntu-24.04`), ახალი პროფილების ნაგულისხმევი ვერსია.
- **Ubuntu 22.04** (`ubuntu-22.04`), იმ სამუშაო პროცესებისთვის, რომლებსაც ის ჯერ კიდევ სჭირდებათ. GitHub-მა თავისი 22.04 ჰოსტინგის გამოსახულება მოძველებულად აღიარა და წაშლის 2027 წლის 17 აპრილს; დაგეგმეთ მისგან გადასვლა ამ დროისთვის.

პროფილი რჩება თქვენს მიერ არჩეულ ვერსიაზე მანამ, სანამ მას არ შეცვლით, ამიტომ უფრო ახალი ნაგულისხმევი ვერსია თავისთავად არ გადაიტანს თქვენს დავალებებს სხვა ოპერაციულ სისტემაზე. 24.04-ზე აგებულ ბინარებს სჭირდებათ მისი უფრო ახალი glibc (2.39) და შეიძლება არ იმუშაონ ძველ სისტემებზე, ხოლო მისი სისტემური Python უარს ამბობს `pip install`-ზე ვირტუალური გარემოს გარეთ (PEP 668). გამშვები აყენებს `ImageOS`-ს (`ubuntu24` ან `ubuntu22`), როგორც ეს GitHub-ის ჰოსტინგის გამშვები აკეთებს, რათა დაყენების ექშენებმა აირჩიონ შესაბამისი ვერსიის აგებულებები.

ყოველი Linux-ის პროფილი მხარს უჭერს <.localized_link href="/guides/features/runners#android-emulators">აპარატულად აჩქარებულ Android ემულატორებს</.localized_link> `/dev/kvm`-ის მეშვეობით. ცალკე KVM პროფილი არ არის საჭირო.

### macOS {#macos}

{{runner_macos_shapes_table}}

უფრო დიდი macOS კონფიგურაციები ნაკლებ მანქანაზე მუშაობენ ფლოტში, ამიტომ დავალებამ, რომელიც მათ ითხოვს, შეიძლება უფრო დიდხანს ილოდოს გაშვება, ვიდრე იმავე დავალებამ უფრო მცირე კონფიგურაციაზე. გამოიყენეთ უფრო დიდი კონფიგურაცია, როცა დავალება CPU-ით არის შეზღუდული, და დატოვეთ ნაგულისხმევი კონფიგურაცია ყველაფერი სხვისთვის. თუ არ ხართ დარწმუნებული, გაუშვით დავალება ორივეზე და შეადარეთ ხანგრძლივობები დაშბორდზე.

macOS-ის პროფილები ასევე აფიქსირებენ **Xcode-ის ვერსიას**. ვერსია ირჩევს გამშვების გამოსახულებას წინასწარ დაინსტალირებული Xcode-ით, რათა დავალებები დაიწყოს უკვე არსებული ინსტრუმენტების ნაკრებით. მხარდაჭერილი ვერსიები ამჟამად:

{{runner_macos_xcode_versions}}

> [!NOTE]
> კატალოგი ვითარდება, როცა ვამატებთ ახალ აღჭურვილობას და Xcode-ის ვერსიებს. დაშბორდის **ახალი პროფილი** ფორმა და `tuist runner profile catalog` ყოველთვის აჩვენებს კონფიგურაციებს, Xcode-ის ვერსიებს და Ubuntu-ის ვერსიებს, რომლებიც ამჟამად ხელმისაწვდომია თქვენი ანგარიშისთვის, ამიტომ მიიჩნიეთ ისინი სანდო წყაროდ.

macOS გამშვების სახელი აჩვენებს macOS-ის ვერსიას, რომელზეც ის მუშაობს, პროფილის Xcode-ის ვერსიას და მის კონფიგურაციას, მაგალითად `tuist-macos-26.6-xcode-27.0-8vcpu-24gb-1a2b3c4d5e6f`. სახელი ჩანს დავალების **დავალების დაყენება** ეტაპზე GitHub-ზე და დავალების დეტალებში Tuist-ის დაშბორდზე.

## პროფილის შექმნა {#creating-a-profile}

1. გახსენით თქვენი ანგარიშის დაშბორდის **გამშვები → პროფილები** სექცია.
2. აირჩიეთ **ახალი პროფილი**.
3. მიანიჭეთ სახელი, აირჩიეთ პლატფორმა და შეარჩიეთ კონფიგურაცია. Linux-ისთვის ასევე აირჩიეთ Ubuntu-ის ვერსია; macOS-ისთვის — Xcode-ის ვერსია.
4. შეინახეთ, შემდეგ მიუთითეთ ის სამუშაო პროცესიდან `runs-on: tuist-<name>`-ით.

პროფილების მართვა შეგიძლიათ ასევე ბრძანების სტრიქონიდან. პროფილების შექმნა, ცვლილება და წაშლა მოითხოვს ანგარიშის ადმინისტრირებას, როგორც დაშბორდზე, ან ანგარიშის ტოკენს `account:runners:write` უფლებით:

```bash
tuist runner profile catalog
tuist runner profile create linux-large --platform linux --vcpus 8 --memory-gb 32
tuist runner profile update linux-large --vcpus 16 --memory-gb 32
tuist runner profile delete linux-large --yes
```

აგენტებს შეუძლიათ იგივეს გაკეთება <.localized_link href="/guides/features/agentic-coding/mcp">MCP სერვერის</.localized_link> მეშვეობით.

მაგალითად, პროფილი სახელით `linux-large` 8 vCPU / 32 GB კონფიგურაციაზე:

```yaml
jobs:
  integration-tests:
    runs-on: tuist-linux-large
```

ან macOS პროფილი სახელით `xcode-26-4`, მიბმული Xcode `26.4.1`-ზე, რათა დავალებამ შეძლოს მუშაობა უფრო ძველ ინსტრუმენტების ნაკრებზე, მაშინ როცა თქვენი ნაგულისხმევი `macos` პროფილი მიჰყვება უახლესს:

```yaml
jobs:
  build-legacy:
    runs-on: tuist-xcode-26-4
```
