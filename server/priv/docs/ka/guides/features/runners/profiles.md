# პროფილები {#profiles}

**პროფილი** არის ანგარიშის ფარგლებში განსაზღვრული, სახელდართული მანქანის კონფიგურაცია. თქვენ მას მიუთითებთ სამუშაო ნაკადის `runs-on`-ში და Tuist ამუშავებს დავალებას შესაბამის გამშვებზე. პროფილები ინფრასტრუქტურის არჩევანს (პლატფორმა, ზომა, Xcode-ის ვერსია) ერთ ადგილას ინახავს, ნაცვლად იმისა, რომ ის ყველა სამუშაო ნაკადის ფაილში იყოს გაფანტული, და გაძლევთ სტაბილურ ლეიბლს CI-სთვის.

```yaml
jobs:
  build:
    runs-on: tuist-macos
```

ლეიბლი არის პროფილის სახელი `tuist-` პრეფიქსით. პროფილი სახელით `macos` არის `runs-on: tuist-macos`; პროფილი სახელით `linux-large` არის `runs-on: tuist-linux-large`. შედარება არ არის დამოკიდებული ასოების რეგისტრზე.

## ნაგულისხმევი პროფილები {#default-profiles}

ყველა ანგარიში, რომელიც გამშვებებისთვის არის აქტიური, იწყება ორი პროფილით, რათა შეძლოთ ფლოტის გამოყენება რაიმეს კონფიგურაციის გარეშე:

{{runner_default_profiles_table}}

ორივე მიუთითებს თავისი პლატფორმისთვის ნაგულისხმევ <.localized_link href="/guides/features/runners/profiles#machine-shapes">კონფიგურაციაზე</.localized_link>. ისინი **დაცულია**, ამიტომ მათი წაშლა შეუძლებელია და თქვენი სამუშაო პროცესების მიერ გამოყენებული ლეიბლები ყოველთვის სწორად განისაზღვრება. მაინც შეგიძლიათ შეცვალოთ მათი კონფიგურაცია ან Xcode-ის ვერსია, ასევე შეგიძლიათ შექმნათ დამატებითი პროფილები სხვა ზომების ან Xcode-ის ვერსიებისთვის.

## მანქანის კონფიგურაციები {#machine-shapes}

გამშვებები ხელმისაწვდომია macOS-ზე (Apple silicon, ვირტუალიზებული Mac-ების ფლოტზე) და Linux-ზე. თითოეული პროფილი აფიქსირებს ერთ მანქანის კონფიგურაციას, `(vCPUs, memory)` წყვილს, ქვემოთ მოცემული კატალოგიდან.

### Linux {#linux}

{{runner_linux_shapes_table}}

ყოველი Linux-ის პროფილი მხარდაჭერას უწევს <.localized_link href="/guides/features/runners#android-emulators">აპარატულად აჩქარებულ Android ემულატორებს</.localized_link> `/dev/kvm`-ის საშუალებით. ცალკე KVM პროფილი არ არის საჭირო.

### macOS {#macos}

{{runner_macos_shapes_table}}

უფრო დიდი macOS კონფიგურაციები ნაკლებ მანქანაზე მუშაობენ ფლოტში, ამიტომ დავალება, რომელიც მათ ითხოვს, შეიძლება უფრო დიდხანს ელოდებოდეს გაშვებას, ვიდრე იგივე დავალება უფრო მცირე კონფიგურაციაზე. გამოიყენეთ უფრო დიდი კონფიგურაცია, როდესაც დავალება CPU-ით არის შეზღუდული, და დარჩით ნაგულისხმევ კონფიგურაციაზე ყველაფერი სხვისთვის. თუ არ ხართ დარწმუნებული, გაუშვით დავალება ორივეზე და შეადარეთ ხანგრძლივობები დაშბორდზე.

macOS პროფილები ასევე აფიქსირებენ **Xcode-ის ვერსიას**. ვერსია ირჩევს გამშვების იმიჯს წინასწარ დაინსტალირებული Xcode-ით, ამიტომ დავალებები იწყება ინსტრუმენტების ჯაჭვის უკვე არსებობით. მხარდაჭერილი ვერსიები ამჟამად:

{{runner_macos_xcode_versions}}

> [!NOTE]
> კატალოგი იცვლება, როგორც კი ვამატებთ ახალ აპარატურას და Xcode-ის გამოშვებებს. დაშბორდზე **ახალი პროფილის** ფორმა და `tuist runner profile catalog` ყოველთვის აჩვენებენ კონფიგურაციებს და Xcode-ის ვერსიებს, რომლებიც ამჟამად ხელმისაწვდომია თქვენი ანგარიშისთვის, ამიტომ მიიჩნიეთ ისინი ჭეშმარიტ წყაროდ.

macOS გამშვების სახელი აჩვენებს macOS-ის ვერსიას, რომელზეც ის მუშაობს, პროფილის Xcode-ის ვერსიას და მის კონფიგურაციას, მაგალითად `tuist-macos-26.6-xcode-27.0-6vcpu-14gb-1a2b3c4d5e6f`. სახელი ჩანს დავალების **დავალების მომზადება** ნაბიჯში GitHub-ზე და დავალების დეტალებში Tuist-ის დაშბორდზე.

## პროფილის შექმნა {#creating-a-profile}

1. გახსენით თქვენი ანგარიშის დაშბორდის **გამშვებები → პროფილები** სექცია.
2. აირჩიეთ **ახალი პროფილი**.
3. მიანიჭეთ სახელი, აირჩიეთ პლატფორმა და აირჩიეთ კონფიგურაცია. macOS-ისთვის ასევე აირჩიეთ Xcode-ის ვერსია.
4. შეინახეთ, შემდეგ მიუთითეთ ის სამუშაო ნაკადიდან `runs-on: tuist-<name>`-ის მეშვეობით.

ასევე შეგიძლიათ პროფილების მართვა ბრძანების ხაზიდან. პროფილების შექმნა, ცვლილება და წაშლა მოითხოვს ანგარიშის ადმინისტრაციას, როგორც დაშბორდზე, ან ანგარიშის ტოკენს `account:runners:write` უფლებით:

```bash
tuist runner profile catalog
tuist runner profile create linux-large --platform linux --vcpus 8 --memory-gb 32
tuist runner profile update linux-large --vcpus 16 --memory-gb 32
tuist runner profile delete linux-large --yes
```

აგენტებს იგივეს გაკეთება <.localized_link href="/guides/features/agentic-coding/mcp">MCP სერვერის</.localized_link> საშუალებითაც შეუძლიათ.

მაგალითად, პროფილი სახელით `linux-large` 8 vCPU / 32 GB კონფიგურაციაზე:

```yaml
jobs:
  integration-tests:
    runs-on: tuist-linux-large
```

ან macOS პროფილი სახელით `xcode-26-4`, მიბმული Xcode `26.4.1`-ზე, რათა დავალებამ შეძლოს ძველ ინსტრუმენტების ჯაჭვზე მუშაობა, მაშინ როცა თქვენი ნაგულისხმევი `macos` პროფილი უახლესს მიჰყვება:

```yaml
jobs:
  build-legacy:
    runs-on: tuist-xcode-26-4
```
