# პროფილები {#profiles}

**პროფილი** არის ანგარიშის მასშტაბის, სახელით მონიშნული მანქანის კონფიგურაცია. თქვენ მიუთითებთ მას სამუშაო ნაკადის `runs-on`-ში და Tuist აგზავნის დავალებას შესაბამის გამშვებზე (runner). პროფილები ინფრასტრუქტურის არჩევანს (პლატფორმა, ზომა, Xcode-ის ვერსია) ერთ ადგილას ინახავს, ნაცვლად იმისა, რომ ის ყველა სამუშაო ნაკადის ფაილში იყოს გაფანტული, და გაძლევთ სტაბილურ იარლიყს CI-სთვის.

```yaml
jobs:
  build:
    runs-on: tuist-macos
```

იარლიყი არის პროფილის სახელი `tuist-` პრეფიქსით. პროფილი სახელით `macos` არის `runs-on: tuist-macos`; პროფილი სახელით `linux-large` არის `runs-on: tuist-linux-large`. შესაბამისობა არ არის დამოკიდებული რეგისტრზე.

## ნაგულისხმები პროფილები {#default-profiles}

ყველა ანგარიში, რომელიც ჩართულია გამშვებებისთვის (Runners), იწყება ორი პროფილით, რათა შეძლოთ ფლოტის გამოყენება ყოველგვარი კონფიგურაციის გარეშე:

{{runner_default_profiles_table}}

ორივე მიუთითებს თავისი პლატფორმის ნაგულისხმევ <.localized_link href="/guides/features/runners/profiles#machine-shapes">კონფიგურაციაზე</.localized_link>. ისინი არიან **დაცული**, ამიტომ მათი წაშლა შეუძლებელია და იარლიყები, რომლებზეც თქვენი სამუშაო ნაკადებია დამოკიდებული, ყოველთვის მოქმედებს. თქვენ მაინც შეგიძლიათ შეცვალოთ მათი კონფიგურაცია ან Xcode-ის ვერსია, ასევე შეგიძლიათ შექმნათ დამატებითი პროფილები სხვა ზომების ან Xcode-ის ვერსიებისთვის.

## მანქანის კონფიგურაციები {#machine-shapes}

გამშვებები ხელმისაწვდომია macOS-ზე (Apple silicon, ვირტუალიზებული Mac-ის ფლოტზე) და Linux-ზე. ყოველი პროფილი აფიქსირებს ერთ მანქანის კონფიგურაციას, `(vCPUs, memory)` წყვილს, ქვემოთ მოცემული კატალოგიდან.

### Linux {#linux}

{{runner_linux_shapes_table}}

ყოველი Linux პროფილი უზრუნველყოფს <.localized_link href="/guides/features/runners#android-emulators">აპარატულად აჩქარებულ Android ემულატორებს</.localized_link> `/dev/kvm`-ის მეშვეობით. ცალკე KVM პროფილი არ არის საჭირო.

### macOS {#macos}

{{runner_macos_shapes_table}}

უფრო დიდი macOS კონფიგურაციები ნაკლებ მანქანაზე მუშაობენ ფლოტში, ამიტომ დავალებას, რომელიც მათ ითხოვს, შეიძლება უფრო დიდი ლოდინი ჰქონდეს დაწყებამდე, ვიდრე იმავე დავალებას უფრო მცირე კონფიგურაციაზე. გამოიყენეთ უფრო დიდი კონფიგურაცია, როდესაც დავალება CPU-ით არის შეზღუდული, და დარჩეთ ნაგულისხმევ კონფიგურაციაზე ყველაფერი სხვისთვის. თუ არ ხართ დარწმუნებული, გაუშვით დავალება ორივეზე და შეადარეთ ხანგრძლივობები დაფაზე (dashboard).

macOS პროფილები ასევე აფიქსირებენ **Xcode-ის ვერსიას**. ვერსია ირჩევს გამშვების იმიჯს წინასწარ ინსტალირებული Xcode-ით, ასე რომ დავალებები იწყებიან უკვე არსებული ინსტრუმენტების ნაკრებით. დღეს მხარდაჭერილი ვერსიებია:

{{runner_macos_xcode_versions}}

> [!NOTE]
> კატალოგი ვითარდება, როგორც კი ვამატებთ ახალ აღჭურვილობას და Xcode-ის გამოშვებებს. დაფაზე (dashboard) არსებული **ახალი პროფილის** ფორმა და `tuist runner profile catalog` ყოველთვის აჩვენებს თქვენს ანგარიშზე ამჟამად ხელმისაწვდომ კონფიგურაციებს და Xcode-ის ვერსიებს, ამიტომ მიიჩნიეთ ისინი ჭეშმარიტობის წყაროდ.

macOS გამშვების სახელი აჩვენებს macOS-ის ვერსიას, რომელზეც ის მუშაობს, პროფილის Xcode-ის ვერსიას და მის კონფიგურაციას, მაგალითად `tuist-macos-26.6-xcode-27.0-6vcpu-14gb-1a2b3c4d5e6f`. სახელი ჩანს დავალების **დავალების დაყენება** ეტაპზე GitHub-ზე და დავალების დეტალებში Tuist-ის დაფაზე (dashboard).

## პროფილის შექმნა {#creating-a-profile}

1. გახსენით თქვენი ანგარიშის დაფის (dashboard) **გამშვებები → პროფილები** სექცია.
2. აირჩიეთ **ახალი პროფილი**.
3. მიეცით სახელი, აირჩიეთ პლატფორმა და აირჩიეთ კონფიგურაცია. macOS-ისთვის ასევე აირჩიეთ Xcode-ის ვერსია.
4. შეინახეთ, შემდეგ მიუთითეთ ის სამუშაო ნაკადიდან `runs-on: tuist-<name>`-ის მეშვეობით.

ასევე შეგიძლიათ მართოთ პროფილები ბრძანების სტრიქონიდან. პროფილების შექმნა, შეცვლა და წაშლა მოითხოვს ანგარიშის ადმინისტრირებას, როგორც დაფაზე (dashboard), ან ანგარიშის ტოკენს `account:runners:write` წვდომით:

```bash
tuist runner profile catalog
tuist runner profile create linux-large --platform linux --vcpus 8 --memory-gb 32
tuist runner profile update linux-large --vcpus 16 --memory-gb 32
tuist runner profile delete linux-large --yes
```

აგენტებს შეუძლიათ იგივეს გაკეთება <.localized_link href="/guides/features/agentic-coding/mcp">MCP სერვერის</.localized_link> მეშვეობით.

მაგალითად, პროფილი სახელით `linux-large` 8 vCPU / 32 GB კონფიგურაციაზე:

```yaml
jobs:
  integration-tests:
    runs-on: tuist-linux-large
```

ან macOS პროფილი სახელით `xcode-26-4`, მიბმული Xcode `26.4.1`-ზე, რათა დავალებამ შეძლოს ძველ ინსტრუმენტების ნაკრებზე მუშაობა, მაშინ როცა თქვენი ნაგულისხმევი `macos` პროფილი უახლესს ეთანხმება:

```yaml
jobs:
  build-legacy:
    runs-on: tuist-xcode-26-4
```
