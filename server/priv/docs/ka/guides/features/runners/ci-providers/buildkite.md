# Buildkite {#buildkite}

Tuist აკვირდება თქვენს Buildkite კლასტერში განთავსებულ თვითმასპინძელ რიგებს და ამ რიგებში ნაპოვნ სამუშაოებს ასრულებს ფლოტზე. თქვენი პაიპლაინები Buildkite-ზე გრძელდება; იცვლება მხოლოდ გამოთვლითი რესურსები. ფლოტზე სამუშაოს გასაშვებად საჭიროა სამი ცვლილება: დააკავშირეთ თქვენი კლასტერი, მიანიჭეთ რიგს Tuist-ის <.localized_link href="/guides/features/runners/profiles">პროფილის</.localized_link> სახელი და მიმართეთ ის ნაბიჯიდან.

1. **დააკავშირეთ თქვენი კლასტერი.** Buildkite-ში გახსენით თქვენი კლასტერი, გადადით **Agent Tokens**-ზე და შექმენით ტოკენი; ის იწყება `bkct_`-ით. თქვენს Tuist დაფაზე გადადით **Settings → Integrations**-ზე, Buildkite-ის ბარათზე აირჩიეთ **Connect** და შეიყვანეთ თქვენი ორგანიზაციის slug და ტოკენი. ტოკენი ინახება დაშიფრული და აღარასდროს ჩანს. ორგანიზაციის შესაცვლელად ან ტოკენის როტაციისთვის მოგვიანებით, შეცვალეთ ველები ბარათზე და აირჩიეთ **Save changes**. Tuist კლასტერის მონიტორინგს ერთ წუთში იწყებს.
2. **მიანიჭეთ რიგს Tuist-ის პროფილის სახელი.** ყოველი აქტიური ანგარიში იწყება ორი გამოსაყენებლად მზა <.localized_link href="/guides/features/runners/profiles">პროფილით</.localized_link>: `linux` და `macos`. სამუშაო აღიქმება მაშინ, როცა მისი რიგის გასაღები ემთხვევა პროფილის ლეიბლს. შექმენით თვითმასპინძელი რიგები თქვენს კლასტერში გასაღებებით `tuist-linux` და `tuist-macos`, შემდეგ მიმართეთ ერთ-ერთი მათგანი ნაბიჯიდან:

   ```yaml
   # .buildkite/pipeline.yml
   steps:
     - label: "Test"
       command: tuist test
       agents:
         queue: tuist-macos # or tuist-linux
   ```

3. **გაუშვით და დააკვირდით.** სამუშაო დგება რიგში, მას იღებს ერთ-ერთი რანერი და ნაკადი ბრუნდება თქვენი Tuist დაფის **Runners** სექციაში, სადაც შეგიძლიათ თვალი ადევნოთ ლოგებს, ნაბიჯებს და მანქანის მეტრიკებს. რანერი აგზავნის ლოგს სამუშაოს შიგნიდან იმ ერთი სამუშაოსთვის განკუთვნილი კრედენშალით, ამიტომ Buildkite API ტოკენი არ არის საჭირო.

## შეჩერება და გათიშვა {#pausing-and-disconnecting}

Buildkite-ის რიგზე გაგზავნის შეჩერება ხელს უშლის Tuist-ს ახალი სამუშაოების აღებაში. უკვე გაშვებული სამუშაოები არ იცვლება.

კლასტერის გათიშვა Buildkite-ის ბარათზე **Settings → Integrations** ქვეშ სრულად აჩერებს Tuist-ის მონიტორინგს.

## ქეშის ტომები {#cache-volumes}

შეინახეთ Xcode-ის, მოდულების და Gradle-ის ქეშები და სხვა დირექტორიები სამუშაოებს შორის <.localized_link href="/guides/features/runners/cache-volumes">ქეშის ტომების</.localized_link> საშუალებით. დაამატეთ ისინი checkout-ის შემდეგ და იმ ბრძანებებამდე, რომლებიც მათ იყენებენ.
