# Buildkite {#buildkite}

Tuist აკვირდება თქვენს Buildkite კლასტერში განთავსებულ თვითმასპინძელ რიგებს და ამ რიგებში ნაპოვნ სამუშაოებს ასრულებს ფლოტზე. თქვენი პაიპლაინები Buildkite-ზე გრძელდება; იცვლება მხოლოდ გამოთვლითი რესურსები. ფლოტზე სამუშაოს გასაშვებად საჭიროა სამი ცვლილება: დააკავშირეთ თქვენი კლასტერი, მიანიჭეთ რიგს Tuist <.localized_link href="/guides/features/runners/profiles">პროფილის</.localized_link> სახელი და მიმართეთ ის ნაბიჯიდან.

1. **დააკავშირეთ თქვენი კლასტერი.** Buildkite-ში გახსენით თქვენი კლასტერი, გადადით **Agent Tokens**-ზე და შექმენით ტოკენი; ის იწყება `bkct_`-ით. თქვენს Tuist დაფაზე გადადით **Settings → Integrations**-ზე, აირჩიეთ **Connect** Buildkite ბარათზე და შეიყვანეთ თქვენი ორგანიზაციის slug და ტოკენი. ტოკენი ინახება დაშიფრული და აღარასდროს ჩანს. ორგანიზაციის შესაცვლელად ან ტოკენის მოგვიანებით როტაციისთვის, შეცვალეთ ველები ბარათზე და აირჩიეთ **Save changes**. Tuist კლასტერის მონიტორინგს ერთ წუთში იწყებს.
2. **მიანიჭეთ რიგს Tuist პროფილის სახელი.** ყოველი აქტიური ანგარიში იწყება ორი გამოსაყენებლად მზად <.localized_link href="/guides/features/runners/profiles">პროფილით</.localized_link>, `linux` და `macos`, და სამუშაო აღიქმება მაშინ, როცა მისი რიგის გასაღები ემთხვევა პროფილის ლეიბლს. შექმენით თვითმასპინძელი რიგები თქვენს კლასტერში გასაღებებით `tuist-linux` და `tuist-macos`, შემდეგ მიმართეთ ერთ-ერთი მათგანი ნაბიჯიდან:

   ```yaml
   # .buildkite/pipeline.yml
   steps:
     - label: "Test"
       command: tuist test
       agents:
         queue: tuist-macos # or tuist-linux
   ```

3. **გაუშვით და დააკვირდით.** სამუშაო დგება რიგში, იღებს მას რანერი და აბრუნებს ნაკადს თქვენი Tuist დაფის **Runners** სექციაში, სადაც შეგიძლიათ მიჰყვეთ მის ლოგებს, ნაბიჯებს და მანქანის მეტრიკებს. რანერი აგზავნის ლოგს სამუშაოს შიგნიდან იმ ერთი სამუშაოსთვის განკუთვნილი კრედენტიალით, ამიტომ Buildkite API ტოკენი არ არის საჭირო.

## შეჩერება და გათიშვა {#pausing-and-disconnecting}

Buildkite რიგზე გაგზავნის შეჩერება აჩერებს Tuist-ს ახალი სამუშაოების აღებაში. უკვე გაშვებული სამუშაოები უცვლელი რჩება.

კლასტერის გათიშვა Buildkite ბარათზე **Settings → Integrations**-ის ქვეშ სრულად აჩერებს Tuist-ის მონიტორინგს.

## ქეშის ტომები {#cache-volumes}

შეინარჩუნეთ Xcode-ის, მოდულის და Gradle-ის ქეშები და სხვა დირექტორიები სამუშაოებს შორის <.localized_link href="/guides/features/runners/cache-volumes">ქეშის ტომების</.localized_link> საშუალებით. დაამატეთ ისინი checkout-ის შემდეგ და იმ ბრძანებებამდე, რომლებიც მათ იყენებენ.
