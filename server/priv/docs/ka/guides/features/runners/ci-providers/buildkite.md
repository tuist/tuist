# Buildkite {#buildkite}

> [!IMPORTANT]
> **მხოლოდ მოწვევით**
>
> Tuist Runners ამჟამად მხოლოდ მოწვევითაა ხელმისაწვდომი. [დაგვიკავშირდით](mailto:contact@tuist.dev) ან მოგვწერეთ [საზოგადოების Slack-ზე](https://slack.tuist.dev), რათა თქვენს ანგარიშზე წვდომა მოითხოვოთ.

Tuist აკვირდება თქვენს Buildkite კლასტერში განთავსებულ self-hosted რიგებს და აღმოჩენილ სამუშაოებს ასრულებს ფლიტზე. თქვენი პაიპლაინები Buildkite-ზე გრძელდება; იცვლება მხოლოდ გამოთვლითი რესურსები. ფლიტზე სამუშაოს გასაშვებად საჭიროა სამი ცვლილება: დააკავშირეთ თქვენი კლასტერი, მიანიჭეთ რიგს Tuist <.localized_link href="/guides/features/runners/profiles">პროფილის</.localized_link> სახელი და მიმართეთ მას ნაბიჯიდან.

1. **მოითხოვეთ წვდომა.** ბეტა პერიოდში Runners მხოლოდ მოწვევითაა ხელმისაწვდომი. [დაგვიკავშირდით](mailto:contact@tuist.dev) იმ ანგარიშის მითითებით, რომლის გააქტიურებაც გსურთ.
2. **დააკავშირეთ თქვენი კლასტერი.** Buildkite-ში გახსენით თქვენი კლასტერი, გადადით **Agent Tokens**-ზე და შექმენით ტოკენი; ის იწყება `bkct_`-ით. თქვენს Tuist დაშბორდზე გადადით **Settings → Integrations**-ზე, აირჩიეთ **Connect** Buildkite ბარათზე და შეიყვანეთ თქვენი ორგანიზაციის slug და ტოკენი. ტოკენი ინახება დაშიფრული და შემდგომში არ ჩანს. ორგანიზაციის შესაცვლელად ან ტოკენის როტაციისთვის მოგვიანებით, შეცვალეთ ველები ბარათზე და აირჩიეთ **Save changes**. Tuist კლასტერის თვალთვალებას ერთი წუთის განმავლობაში იწყებს.
3. **მიანიჭეთ რიგს Tuist პროფილის სახელი.** ყოველი გააქტიურებული ანგარიში იწყება ორი გამოსაყენებლად მზა <.localized_link href="/guides/features/runners/profiles">პროფილით</.localized_link>, `linux` და `macos`, და სამუშაო აღიქმება მაშინ, როცა მისი რიგის გასაღები ემთხვევა პროფილის ლეიბლს. შექმენით self-hosted რიგები თქვენს კლასტერში გასაღებებით `tuist-linux` და `tuist-macos`, შემდეგ მიმართეთ ერთ-ერთს ნაბიჯიდან:

   ```yaml
   # .buildkite/pipeline.yml
   steps:
     - label: "Test"
       command: tuist test
       agents:
         queue: tuist-macos # or tuist-linux
   ```

4. **გაგზავნეთ და დააკვირდით.** სამუშაო დგება რიგში, იღებს მას runner და გადასცემს ნაკადს თქვენი Tuist დაშბორდის **Runners** სექციაში, სადაც შეგიძლიათ თვალყური ადევნოთ მის ლოგებს, ნაბიჯებს და მანქანის მეტრიკებს. Runner აგზავნის ლოგს სამუშაოს შიგნიდან იმ ერთი სამუშაოსთვის შეზღუდული კრედენციალით, ამიტომ Buildkite API ტოკენი არ არის საჭირო.

## შეჩერება და გათიშვა {#pausing-and-disconnecting}

Buildkite რიგზე დისპეტჩერიზაციის შეჩერება ხელს უშლის Tuist-ს ახალი სამუშაოების აღებაში მისგან. უკვე გაშვებულ სამუშაოებზე ეს არ მოქმედებს.

კლასტერის გათიშვა Buildkite ბარათზე **Settings → Integrations**-ის ქვეშ სრულად აჩერებს Tuist-ის მიერ მის თვალთვალებას.

## ქეშის ტომები {#cache-volumes}

შეინარჩუნეთ Xcode, მოდულის და Gradle ქეშები და სხვა დირექტორიები სამუშაოებს შორის <.localized_link href="/guides/features/runners/cache-volumes">ქეშის ტომების</.localized_link> გამოყენებით. დაამატეთ ისინი checkout-ის შემდეგ და იმ ბრძანებებამდე, რომლებიც მათ იყენებენ.
