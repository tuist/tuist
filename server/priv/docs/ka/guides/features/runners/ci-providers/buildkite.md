# Buildkite {#buildkite}

<!-- @snippet: ./_invite-only -->

Tuist აკვირდება თქვენს Buildkite კლასტერში განთავსებულ თვითმასპინძელ რიგებს და ამ რიგებში ნაპოვნ სამუშაოებს ასრულებს საკუთარ ფლოტზე. თქვენი პაიპლაინები Buildkite-ზე გრძელდება; იცვლება მხოლოდ გამოთვლითი რესურსები. ფლოტზე სამუშაოს გასაშვებად სამი ცვლილებაა საჭირო: დააკავშირეთ თქვენი კლასტერი, მიანიჭეთ რიგს Tuist-ის <.localized_link href="/guides/features/runners/profiles">პროფილის</.localized_link> სახელი და მიმართეთ ის ნაბიჯიდან.

1. **დააკავშირეთ თქვენი კლასტერი.** Buildkite-ში გახსენით თქვენი კლასტერი, გადადით **Agent Tokens**-ზე და შექმენით ტოკენი; ის იწყება `bkct_`-ით. თქვენს Tuist დაშბორდზე გადადით **Settings → Integrations**-ზე, აირჩიეთ **Connect** Buildkite ბარათზე და შეიყვანეთ თქვენი ორგანიზაციის slug და ტოკენი. ტოკენი ინახება დაშიფრული და აღარასდროს ჩანს. ორგანიზაციის შესაცვლელად ან ტოკენის მოგვიანებით როტაციისთვის, შეცვალეთ ველები ბარათზე და აირჩიეთ **Save changes**. Tuist ერთ წუთში იწყებს კლასტერის მონიტორინგს.
2. **მიანიჭეთ რიგს Tuist პროფილის სახელი.** ყოველი აქტიური ანგარიში იწყება ორი გამოსაყენებლად მზა <.localized_link href="/guides/features/runners/profiles">პროფილით</.localized_link>: `linux` და `macos`, და სამუშაო აღიქმება მაშინ, როცა მისი რიგის გასაღები ემთხვევა პროფილის ლეიბლს. შექმენით თვითმასპინძელი რიგები თქვენს კლასტერში გასაღებებით `tuist-linux` და `tuist-macos`, შემდეგ მიმართეთ ერთ-ერთი მათგანი ნაბიჯიდან:

   ```yaml
   # .buildkite/pipeline.yml
   steps:
     - label: "Test"
       command: tuist test
       agents:
         queue: tuist-macos # or tuist-linux
   ```

3. **გაგზავნეთ და დააკვირდით.** სამუშაო დგება რიგში, იბრუნებს გამშვები (runner) და ნაკადი ბრუნდება თქვენი Tuist დაშბორდის **Runners** სექციაში, სადაც შეგიძლიათ მიჰყვეთ მის ლოგებს, ნაბიჯებს და მანქანის მეტრიკებს. გამშვები აგზავნის ლოგს სამუშაოს შიგნიდან იმ ერთი სამუშაოსთვის შეზღუდული კრედენციალით, ამიტომ Buildkite API ტოკენი არ არის საჭირო.

## შეჩერება და გათიშვა {#pausing-and-disconnecting}

Buildkite რიგზე გაგზავნის შეჩერება ხელს უშლის Tuist-ს ახალი სამუშაოების აღებას მისგან. უკვე გაშვებულ სამუშაოებზე ეს გავლენას არ ახდენს.

კლასტერის გათიშვა Buildkite ბარათზე **Settings → Integrations** ქვეშ სრულად აჩერებს Tuist-ის მონიტორინგს.

## ქეშის ტომები {#cache-volumes}

შეინარჩუნეთ Xcode, მოდულის და Gradle ქეშები და სხვა დირექტორიები სამუშაოებს შორის <.localized_link href="/guides/features/runners/cache-volumes">ქეშის ტომების</.localized_link> საშუალებით. დაამატეთ ისინი checkout-ის შემდეგ და იმ ბრძანებებამდე, რომლებიც მათ იყენებენ.
