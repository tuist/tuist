# Bitrise {#bitrise}

<!-- @snippet: ./_invite-only -->

> [!WARNING]
> **მხოლოდ კერძო რეპოზიტორიები**
>
> Tuist ენდობა ყველა Bitrise ბილდს: ბილდები იზიარებენ თქვენი ანგარიშის ქეშს და შეუძლიათ მასში ჩაწერა. არ დააკავშიროთ პული, რომლის სამუშაო ნაკადებიც აწყობენ პულ-რეკვესტებს საჯარო რეპოზიტორიის ფორკებიდან.

Tuist უზრუნველყოფს თქვენი Bitrise სამუშაო სივრცის თვითმასპინძელ რანერების პულებს. ბილდი, რომელიც ირჩევს ერთ-ერთ ასეთ პულს, გაეშვება Tuist მანქანაზე, <.localized_link href="/guides/features/runners/profiles">პროფილის</.localized_link> შესაბამისად, რომელსაც პულთან აკავშირებთ. თქვენი სამუშაო ნაკადები, ტრიგერები და ლოგები რჩება Bitrise-ზე; იცვლება მხოლოდ მანქანები.

1. **დააკავშირეთ თქვენი სამუშაო სივრცე.** Bitrise-ში გახსენით **Workspace settings → Security → Workspace API tokens** და შექმენით ტოკენი **Viewer** სამუშაო სივრცის როლით და **Tester/QA** წვდომით Bitrise CI-ზე ყველა პროექტისთვის. თქვენს Tuist დაშბორდზე გადადით **Settings → Integrations**-ზე, აირჩიეთ **Connect** Bitrise ბარათზე და ჩასვით ტოკენი. Tuist კითხულობს სამუშაო სივრცეს ტოკენიდან, ინახავს ტოკენს დაშიფრულად და აღარასდროს აჩვენებს მას.
2. **შექმენით რანერების პული.** Bitrise-ში გახსენით **Workspace settings → Infrastructure**, აირჩიეთ **Add Runner pool** და მიანიჭეთ სახელი იმ მანქანის მიხედვით, რომელსაც ის წარმოადგენს, მაგალითად `tuist-macos`. დააკოპირეთ პულის ტოკენი: Bitrise აჩვენებს მას მხოლოდ ერთხელ.
3. **დააკავშირეთ პული Tuist პროფილთან.** Tuist-ის Bitrise ბარათზე, **Runner pools** განყოფილებაში, აირჩიეთ პული, Tuist პროფილი, რომელზეც მისმა ბილდებმა უნდა გაეშვას, ჩასვით პულის ტოკენი და აირჩიეთ **Add pool**. ყოველი აქტიური ანგარიში იწყება ორი პროფილით: `tuist-linux` და `tuist-macos`. დაამატეთ ერთი პული თითოეული პროფილისთვის, რომლის გამოყენებაც გსურთ.
4. **აირჩიეთ პული თქვენს სამუშაო ნაკადში.** Bitrise-ის Workflow Editor-ში გახსენით **Stacks & Machines** და აირჩიეთ **Self-Hosted Runner: tuist-macos**. `bitrise.yml`-ში დააყენეთ პულის სტეკი, რომელსაც Tuist აჩვენებს პულის სახელის ქვეშ:

   ```yaml
   meta:
     bitrise.io:
       stack: agent-pool-a0c641c0-142f-427d-a326-07f0f6c2a1be
   ```

5. **გაუშვით ბილდი.** რამდენიმე წამის განმავლობაში Tuist მანქანა უკავშირდება პულს, იღებს ბილდს და წყვეტს კავშირს მისი დასრულების შემდეგ. ბილდი ჩნდება თქვენი Tuist დაშბორდის **Runners** განყოფილებაში მანქანის მეტრიკებით და ბმულით Bitrise-ზე, სადაც მისი ლოგები რჩება.

## გამოყოფილი პულები {#dedicated-pools}

გამოიყენეთ პულები, რომლებსაც Tuist-თან აკავშირებთ, მხოლოდ Tuist-ისთვის. თუ თქვენი ერთ-ერთი მანქანაც უკავშირდება დაკავშირებულ პულს, ის ეჯიბრება Tuist-ს ამ პულის ბილდებისთვის.

## რანერების ლიმიტი {#runner-limit}

ყოველი Tuist მანქანა ითვლება ერთ Bitrise რანერად, სანამ ის ბილდს ასრულებს, და წყვეტს თვლას კავშირის გაწყვეტისას. თქვენი Bitrise გეგმის რანერების ლიმიტი, შესაბამისად, ზღუდავს იმ ბილდების რაოდენობას, რომლებიც ერთდროულად გაეშვება Tuist-ზე, თქვენს Tuist კონკურენტულობის ლიმიტთან ერთად.

## კავშირის გაწყვეტა {#disconnecting}

პულის წაშლა Bitrise ბარათიდან აჩერებს Tuist-ს იმ პულის ბილდების აღებაში. უკვე გაშვებულ ბილდებს ეს არ ეხება.

**Disconnect**-ის არჩევა Bitrise ბარათზე შლის სამუშაო სივრცეს და მის ყველა პულს.
