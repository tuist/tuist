# Bitrise {#bitrise}

> [!WARNING]
> **მხოლოდ კერძო რეპოზიტორიებისთვის**
>
> Tuist ენდობა ყველა Bitrise ბილდს: ბილდები იზიარებენ თქვენი ანგარიშის ქეშს და შეუძლიათ ჩაწერონ მასში. არ დააკავშიროთ პული, რომლის სამუშაო პროცესებიც აწყობენ pull request-ებს საჯარო რეპოზიტორიის ფორკებიდან.

Tuist უზრუნველყოფს თქვენი Bitrise სამუშაო სივრცის თვითდაყენებული გამშვები პულებს. ბილდი, რომელიც ირჩევს ერთ-ერთ ამ პულს, გაეშვება Tuist მანქანაზე <.localized_link href="/guides/features/runners/profiles">პროფილის</.localized_link> მიხედვით, რომელსაც თქვენ დააკავშირებთ პულთან. თქვენი სამუშაო პროცესები, ტრიგერები და ლოგები რჩება Bitrise-ზე; იცვლება მხოლოდ მანქანები.

1. **დააკავშირეთ თქვენი სამუშაო სივრცე.** Bitrise-ში გახსენით **Workspace settings → Security → Workspace API tokens** და შექმენით ტოკენი **Viewer** სამუშაო სივრცის როლითა და **Tester/QA** წვდომით Bitrise CI-ზე ყველა პროექტისთვის. თქვენს Tuist დაფაზე გადადით **Settings → Integrations**-ზე, აირჩიეთ **Connect** Bitrise ბარათზე და ჩასვით ტოკენი. Tuist კითხულობს სამუშაო სივრცეს ტოკენიდან, ინახავს ტოკენს დაშიფრულად და აღარასდროს აჩვენებს მას.
2. **შექმენით გამშვები პული.** Bitrise-ში გახსენით **Workspace settings → Infrastructure**, აირჩიეთ **Add Runner pool** და მიანიჭეთ სახელი იმ მანქანის მიხედვით, რომელსაც ის წარმოადგენს, მაგალითად `tuist-macos`. დააკოპირეთ პულის ტოკენი: Bitrise აჩვენებს მას მხოლოდ ერთხელ.
3. **დააკავშირეთ პული Tuist პროფილთან.** Tuist-ში Bitrise ბარათზე, **Runner pools** განყოფილებაში, აირჩიეთ პული, Tuist პროფილი, რომელზეც მისმა ბილდებმა უნდა გაეშვას, ჩასვით პულის ტოკენი და აირჩიეთ **Add pool**. ყოველი აქტიური ანგარიში იწყება ორი პროფილით: `tuist-linux` და `tuist-macos`. დაამატეთ ერთი პული ყოველი პროფილისთვის, რომლის გამოყენებაც გსურთ.
4. **აირჩიეთ პული თქვენს სამუშაო პროცესში.** Bitrise-ის Workflow Editor-ში გახსენით **Stacks & Machines** და აირჩიეთ **Self-Hosted Runner: tuist-macos**. `bitrise.yml`-ში მიუთითეთ პულის სტეკი, რომელსაც Tuist აჩვენებს პულის სახელის ქვეშ:

   ```yaml
   meta:
     bitrise.io:
       stack: agent-pool-a0c641c0-142f-427d-a326-07f0f6c2a1be
   ```

5. **გაუშვით ბილდი.** რამდენიმე წამში Tuist მანქანა უკავშირდება პულს, იღებს ბილდს და წყვეტს კავშირს დასრულების შემდეგ. ბილდი ჩნდება თქვენი Tuist დაფის **Runners** განყოფილებაში მანქანის მეტრიკებითა და Bitrise-ზე დამბრუნებელი ბმულით, სადაც მისი ლოგები რჩება.

## გამოყოფილი პულები {#dedicated-pools}

გამოიყენეთ Tuist-თან დაკავშირებული პულები მხოლოდ Tuist-ისთვის. თუ თქვენი ერთ-ერთი საკუთარი მანქანაც უკავშირდება დაკავშირებულ პულს, ის ეცილება Tuist-ს ამ პულის ბილდებისთვის.

## გამშვების ლიმიტი {#runner-limit}

ყოველი Tuist მანქანა ითვლება ერთ Bitrise გამშვებად, სანამ ის ასრულებს ბილდს, და წყვეტს დათვლას კავშირის გაწყვეტისას. შესაბამისად, თქვენი Bitrise გეგმის გამშვების ლიმიტი ზღუდავს, თუ რამდენი თქვენი ბილდი შეიძლება გაეშვას Tuist-ზე ერთდროულად, თქვენს Tuist პარალელურობის ლიმიტთან ერთად.

## გათიშვა {#disconnecting}

პულის წაშლა Bitrise ბარათიდან აჩერებს Tuist-ს ამ პულის ბილდების აღებაში. უკვე გაშვებულ ბილდებს ეს არ ეხება.

Bitrise ბარათზე **Disconnect**-ის არჩევა შლის სამუშაო სივრცეს და მის ყველა პულს.
