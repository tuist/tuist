# Once-ის დისტანციური შესრულება {#once-remote-execution}

გაზიარებული ქეში თავს არიდებს იმ სამუშაოს გამეორებას, რომელიც სხვა მანქანამ უკვე შეასრულა. დისტანციური შესრულება ასევე გადაიტანს შესაბამის ქეშ-ჩავარდნებს თქვენი კომპიუტერიდან: Once გრაფის ბრძანებების მოქმედებებს განრიგებს Tuist-ის ერთჯერად Linux-ვორკერებზე და იღებს მათ შედეგებს იმავე პროექტის ქეშის მეშვეობით.

> [!NOTE]
> დისტანციური შესრულება ამჟამად მხოლოდ მიწვევითაა ხელმისაწვდომი. [დაგვიკავშირდით](mailto:contact@tuist.dev) თქვენი ანგარიშისთვის წვდომის მოსათხოვნად.

> [!IMPORTANT]
> **მოთხოვნები**
>
> - Tuist-ის ანგარიში ჩართული დისტანციური შესრულებით და ხელმისაწვდომი შესრულების ტევადობით.
> - Once-ის ვერსია Tuist-ის დისტანციური შესრულების მხარდაჭერით.
> - თავსებადი სერვერი, რომელიც აცხადებს ვორკერის იმიჯს, ქეშის endpoint-ს, პარალელურობას და შესრულების აბსოლუტურ დირექტორიას. სერვერები, რომლებიც გამოტოვებენ დირექტორიას, არ არიან თავსებადები მიმდინარე Once კლიენტთან; Once წყვეტს მუშაობას სამუშაოს ატვირთვამდე.
> - ბრძანებები და ინსტრუმენტთა ჯაჭვები, რომლებსაც შეუძლიათ გაშვება `linux/amd64`-ზე რეკლამირებულ ვორკერის იმიჯში.

ეს ასრულებს გრაფის მოქმედებებს და არა მთლიან CI სამუშაოს. Once-ის კონფიგურაცია არ აყენებს GitHub ან GitLab workflow ორკესტრაციას.

## მოწყობა {#setup}

დაასრულეთ <.localized_link href="/guides/get-started/once-project">Once-ით დაწყება</.localized_link>. აირჩიეთ იგივე Tuist პროვაიდერი ქეშინგისა და შესრულებისთვის და მიამაგრეთ სერვისის მიერ რეკლამირებული ვორკერის იმიჯი:

```toml
[infrastructures.tuist]
kind = "tuist"
account = "acme"
project = "app"
execution_image = "sha-REPLACE_WITH_THE_IMAGE_TAG"

[infrastructure.cache]
provider = "tuist"

[infrastructure.execution]
provider = "tuist"
```

გაიარეთ ავთენტიკაცია ისეთი კრედენციალებით, რომლებსაც შეუძლიათ წაიკითხონ და ჩაწერონ პროექტის ქეში, შემდეგ მოითხოვეთ დისტანციური შესრულება:

```bash
once build --remote MyTarget
```

ჩაანაცვლეთ მიზანი და იმიჯის ტეგი თქვენი საკუთარი მნიშვნელობებით. Once ამოწმებს რეკლამირებულ იმიჯს, შესრულების დირექტორიას, ქეშის დანიშნულების ადგილს და ანგარიშის ტევადობას სამუშაოს ატვირთვამდე. ქეში და შესრულება უნდა მიუთითებდნენ იმავე პროექტზე.

## მოქმედებების მომზადება ვორკერებისთვის {#prepare-actions-for-workers}

- განაცხადეთ შემავალი და გამომავალი მონაცემები. გამომავალი მონაცემები უნდა დარჩეს მოქმედების სამუშაო დირექტორიის ქვეშ.
- გააგვარეთ ინსტრუმენტები ვორკერის იმიჯის შიგნით და არა საწყის კომპიუტერზე აბსოლუტური გზებით.
- გამოიყენეთ მოქმედებები, რომელთა გამეორებაც უსაფრთხოა: ვორკერის შეცდომა ან სერვისის გადატვირთვა შეიძლება გამოიწვიოს კიდევ ერთი შესრულება.
- დაიცავით ვადები სერვისის ათწუთიანი მოქმედების ლიმიტის ფარგლებში. მხარდაუჭერელი მოთხოვნები, მათ შორის ქსელის აკრძალვა, ვერ ასრულებენ და არა ჩუმად ადგილობრივად გაშვებას.

Once ითვალისწინებს ანგარიშის რეკლამირებულ მოქმედების პარალელურობას და ელოდება, როდესაც სერვისის რიგი სავსეა. იმიჯის შეცვლა ყოფს ბილდის კონფიგურაციას და ქეშირებულ შედეგებს, რაც ხელს უშლის თავსებად არა ვორკერის იმიჯებში ხელახლა გამოყენებას.

## დისტანციური შესრულების შემოწმება {#inspect-remote-execution}

პროექტის გვერდითა პანელს აქვს **დისტანციური შესრულება** გვერდი. მისი **ანალიტიკა** ბარათი აჩვენებს შესრულებებს და საერთო შესრულების დროს შერჩეული პერიოდისთვის, როგორც აღწერილია <.localized_link href="/guides/features/cache/bazel-cache#running-actions-and-usage">მოქმედებების გაშვება და გამოყენება</.localized_link>-ში. Once-ის გაშვების ტელემეტრია ჯერ კიდევ არ არჩევს დისტანციურ შესრულებას ადგილობრივი მოქმედებებისგან, ამიტომ გვერდს არ აქვს თითოეული გაშვების დისტანციური დროები ან მიმდინარე გაშვებები. ის ხსნის ამ ნაკლს და ბმავს **ბილდის გაშვებებზე** ჩაწერილი მოქმედებების დეტალებისთვის. მიმდინარედ გაშვებული და რიგში მყოფი დისტანციური მოქმედებები ხელმისაწვდომია `get_remote_execution_activity` MCP ინსტრუმენტიდან და მისი REST endpoint-დან. ორივე მოდის შესრულების სერვისიდან და არა ვორკერის არხებიდან.

იხილეთ [Once-ის დისტანციური შესრულების სახელმძღვანელო](https://buildonce.dev/docs/guide/infrastructure/tuist#run-actions-on-tuist-workers) რიგში დაყენების, ავთენტიკაციის განახლებისა და ქეშ-endpoint-ის გადაფარვისთვის. მიჰყევით <.localized_link href="/guides/features/build-insights/once">Once ბილდის ინსაიტებს</.localized_link> მიღებული გაშვებების შესამოწმებლად.
