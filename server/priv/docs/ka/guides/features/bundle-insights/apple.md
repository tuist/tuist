# Apple {#bundle-insights-apple}

Apple-ის ბანდლის ანალიზი შესაძლებელია `tuist inspect bundle`-ის გამოყენებით, მიუთითეთ არქივი, დასაინსტალირებელი ფაილი ან აგებული აპლიკაცია:

::: code-group
```bash [Analyze an .ipa]
tuist inspect bundle App.ipa
```
```bash [Analyze an .xcarchive]
tuist inspect bundle App.xcarchive
```
```bash [Analyze an app bundle]
tuist inspect bundle App.app
```
```bash [Analyze by app name]
tuist inspect bundle App --platforms ios --configuration Debug
```
<!-- -->
:::

როცა macOS-ზე გზის ნაცვლად გადასცემთ აპლიკაციის სახელს, Tuist პოულობს აგებულ `.app` Xcode-ის აგების პროდუქტებიდან (ითვალისწინებს `--derived-data-path`, თუ მითითებულია), ისევე როგორც `tuist share`.

ბრძანება ტვირთავს ბანდლს Tuist-ში და აბრუნებს ბმულს დეტალურ მიმოხილვაზე, რომელიც მოიცავს შიგთავსის სკანირებას და მოდულების დაშლას:

![ანალიზირებული ბანდლი](/images/guides/features/bundle-size/analyzed-bundle.png)

## App Store Connect-თან შედარება {#app-store-connect}

Tuist ზომავს ბანდლს ზუსტად ისე, როგორც თქვენ მას წარადგენთ და არ იყენებს [აპლიკაციის გამხდარებას](https://developer.apple.com/documentation/xcode/reducing-your-app-s-size). მოცემული ზომები შეესაბამება **უნივერსალურ** (გაუმხდარებელ) ვარიანტს — App Store Connect-ის აპლიკაციის ფაილების ზომების ანგარიშში „Universal“ ეტიკეტით აღნიშნულ სტრიქონს — და არა მოწყობილობაზე მორგებულ ვარიანტებს.

მოელით, რომ რიცხვები იქნება Universal სტრიქონის დიაპაზონში, მაგრამ არა იდენტური:

- **დაინსტალირების ზომა** ახლოსაა Universal დაინსტალირების ზომასთან. App Store Connect ოდნავ მეტ მნიშვნელობას აჩვენებს, რადგან ის მოიცავს მოწყობილობაზე არსებულ დამატებით ხარჯებს, როგორიცაა ფაილური სისტემის ბლოკების განაწილება და Apple-ის საკუთარი შეფასება, რასაც უბრალო ფაილის ზომის გაზომვა არ ითვალისწინებს.
- **ჩამოტვირთვის ზომა** ნაკლებია Universal ჩამოტვირთვის ზომაზე. Apple აშიფრავს აპლიკაციის ბინარულ ფაილს ატვირთვის შემდეგ, ხოლო დაშიფრული მონაცემები ნაკლებად ეფექტურად იკუმშება, ამიტომ App Store-ის შეკუმშული ჩამოტვირთვა უფრო დიდია, ვიდრე `.ipa` არქივი, რომელსაც Tuist ზომავს. ეს ხდება Apple-ის მხარეს ატვირთვის შემდეგ, ამიტომ ეს არ აისახება Tuist-ის მონაცემებში.

App Store Connect-ში მოწყობილობაზე მორგებული სტრიქონები კიდევ უფრო მცირეა, რადგან აპლიკაციის გამხდარება აშორებს CPU არქიტექტურებს და ასეტების ვარიანტებს, რომლებიც კონკრეტულ მოწყობილობას არ სჭირდება. Tuist ამჟამად არ აჩვენებს მოწყობილობაზე მორგებულ (გამხდარებულ) ზომებს.
