# Apple {#bundle-insights-apple}

Apple-ის ბანდლის ანალიზი შესაძლებელია `tuist inspect bundle`-ის მიმართვით არქივზე, დასაყენებელ ფაილზე ან აგებულ აპლიკაციაზე:

::: code-group
```bash [Analyze an .ipa]
tuist inspect bundle App.ipa
```
```bash [Analyze an .xcarchive]
tuist inspect bundle App.xcarchive
```
```bash [Analyze an app bundle]
tuist inspect bundle App.app
```
```bash [Analyze by app name]
tuist inspect bundle App --platforms ios --configuration Debug
```
<!-- -->
:::

როდესაც macOS-ზე გზის ნაცვლად გადასცემთ აპლიკაციის სახელს, Tuist პოულობს აგებულ `.app` Xcode-ის აგების პროდუქტებიდან (ითვალისწინებს `--derived-data-path`-ს, თუ მითითებულია), ისევე როგორც `tuist share`.

ბრძანება ტვირთავს ბანდლს Tuist-ში და აბრუნებს ბმულს დეტალურ მიმოხილვაზე, რომელიც მოიცავს შიგთავსის სკანირებას და მოდულების დაშლას:

![ანალიზირებული ბანდლი](/images/guides/features/bundle-size/analyzed-bundle.png)

## App Store Connect-თან შედარება {#app-store-connect}

Tuist ზომავს ბანდლს ზუსტად ისე, როგორც თქვენ აწვდით და არ იყენებს [აპლიკაციის გათხელებას](https://developer.apple.com/documentation/xcode/reducing-your-app-s-size). მოხსენებული ზომები შეესაბამება **უნივერსალურ** (გაუთხელებელ) ვარიანტს — App Store Connect-ის აპლიკაციის ფაილების ზომების ანგარიშში „უნივერსალური“ ეტიკეტით მონიშნულ სტრიქონს — და არა თითოეული მოწყობილობისთვის განკუთვნილ ვარიანტებს.

მოელით, რომ რიცხვები იქნება იმავე დიაპაზონში, რაც უნივერსალური სტრიქონი, მაგრამ არა იდენტური:

- **დაყენების ზომა** ახლოსაა უნივერსალურ დაყენების ზომასთან. App Store Connect აჩვენებს ოდნავ მაღალ მნიშვნელობას, რადგან ის მოიცავს მოწყობილობაზე არსებულ დამატებით ხარჯებს, როგორიცაა ფაილური სისტემის ბლოკების განაწილება და Apple-ის საკუთარი შეფასება, რასაც უბრალო ფაილის ზომის გაზომვა არ ითვალისწინებს.
- **ჩამოტვირთვის ზომა** ნაკლებია უნივერსალურ ჩამოტვირთვის ზომაზე. Apple აშიფრავს აპლიკაციის ბინარულ ფაილს ატვირთვის შემდეგ და დაშიფრული მონაცემები ნაკლებად ეფექტურად იკუმშება, ამიტომ App Store-ის შეკუმშული ჩამოტვირთვა საბოლოოდ უფრო დიდია, ვიდრე `.ipa` არქივი, რომელსაც Tuist ზომავს. ეს ხდება Apple-ის მხარეს ატვირთვის შემდეგ, ამიტომ ეს არ აისახება Tuist-ის მონაცემებში.

App Store Connect-ში თითოეული მოწყობილობისთვის განკუთვნილი სტრიქონები კიდევ უფრო მცირეა, რადგან აპლიკაციის გათხელება აშორებს CPU არქიტექტურებს და ასეტების ვარიანტებს, რომლებიც კონკრეტულ მოწყობილობას არ სჭირდება. Tuist ამჟამად არ აჩვენებს თითოეული მოწყობილობისთვის განკუთვნილ (გათხელებულ) ზომებს.
