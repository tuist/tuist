# ბანდლის ანალიტიკა {#bundle-insights}

როგორც კი აპლიკაციას ახალ ფუნქციებს დაამატებთ, ბანდლის ზომა იზრდება. ზრდის ნაწილი გარდაუვალია, მაგრამ დიდი ნაწილი — არა: დუბლირებული რესურსები, გამოუყენებელი სიმბოლოები და პლატფორმისთვის სპეციფიკური ზედმეტობები ჯამში მნიშვნელოვან ხარჯს ქმნიან. Tuist Bundle Insights მხარს უჭერს როგორც **Apple**-ის, ასევე **Android**-ის ბანდლებს, გაძლევთ ინსტრუმენტებსა და ანალიტიკას, რომ აპლიკაციის ზომა მცირე დარჩეს, და თვალყურს ადევნებს ტრენდს დროთა განმავლობაში.
