# ბანდლის ანალიტიკა {#bundle-insights}

როგორც კი აპლიკაციას მეტ ფუნქციას დაამატებთ, ბანდლის ზომა იზრდება. ზრდის ნაწილი თავიდან აუცილებელია, მაგრამ ბევრი მათგანი არა: დუბლირებული რესურსები, გამოუყენებელი სიმბოლოები და პლატფორმისთვის სპეციფიკური ზედმეტობა გროვდება. Tuist Bundle Insights მხარს უჭერს როგორც **Apple**, ისე **Android** ბანდლებს, გაძლევთ ინსტრუმენტებსა და ანალიტიკას, რომ აპლიკაციის ზომა მცირე დარჩეს, და თვალყურს ადევნებს ტენდენციას დროში.
