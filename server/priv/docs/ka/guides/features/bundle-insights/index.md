# ბანდლის ანალიზი {#bundle-insights}

როგორც კი აპლიკაციას ახალ ფუნქციებს დაამატებთ, ბანდლის ზომა იზრდება. ზრდის ნაწილი თავიდან ასაცილებელია, მაგრამ ბევრი მათგანი — არა: დუბლირებული რესურსები, გამოუყენებელი სიმბოლოები და პლატფორმისთვის დამახასიათებელი ზედმეტობები ჯამში მნიშვნელოვან მოცულობას ქმნიან. Tuist Bundle Insights მხარს უჭერს როგორც **Apple**, ისე **Android** ბანდლებს, გთავაზობთ ინსტრუმენტებსა და ანალიტიკას, რაც დაგეხმარებათ აპლიკაციის ზომა მცირე შეინარჩუნოთ, და თვალყურს ადევნებს ტრენდს დროთა განმავლობაში.
