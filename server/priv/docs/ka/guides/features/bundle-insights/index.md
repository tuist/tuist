# ბანდლის ანალიტიკა {#bundle-insights}

როგორც კი თქვენს აპლიკაციას ახალ ფუნქციებს დაამატებთ, ბანდლის ზომა იზრდება. ზრდის ნაწილი თავიდან ასაცილებელია, მაგრამ ბევრი მათგანი — არა: დუბლირებული რესურსები, გამოუყენებელი სიმბოლოები და პლატფორმისთვის დამახასიათებელი ზედმეტი წონა ჯამში დიდ გავლენას ახდენს. Tuist Bundle Insights მხარს უჭერს როგორც **Apple**, ისე **Android** ბანდლებს, გაძლევთ ინსტრუმენტებს და ანალიტიკას, რაც დაგეხმარებათ აპლიკაციის ზომა მცირედ შეინარჩუნოთ, და ასევე აკვირდება ტენდენციას დროთა განმავლობაში.
