# ბანდლის ანალიტიკა {#bundle-insights}

როგორც კი აპლიკაციას ახალ ფუნქციებს დაამატებთ, ბანდლის ზომა იზრდება. ზრდის ნაწილი გარდაუვალია, მაგრამ დიდი ნაწილი არა: გაორმაგებული რესურსები, გამოუყენებელი სიმბოლოები და პლატფორმისთვის სპეციფიკური ზედმეტობა ჯამში მნიშვნელოვან ხდება. Tuist Bundle Insights მხარს უჭერს როგორც **Apple**, ისე **Android** ბანდლებს, გაძლევთ ინსტრუმენტებსა და ანალიტიკას, რათა თქვენი აპლიკაციის ზომა მცირე დარჩეს, და აკვირდება ტენდენციას დროთა განმავლობაში.
