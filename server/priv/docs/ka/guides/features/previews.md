# პრივიუები {#previews}

Tuist Previews საშუალებას აძლევს გუნდის წევრებს სცადონ მობილური აპლიკაციები, დესკტოპ აპლიკაციები და კომანდური ხაზის ინსტრუმენტები მათი ლოკალურად ხელახლა აწყობის გარეშე. გამოაქვეყნეთ ბილდი თქვენს Tuist პროექტში და გაუზიარეთ მისი პრივიუს ბმული.

## რა შეგიძლიათ ნახოთ პრივიუში {#what-you-can-preview}

- **მობილური აპლიკაციები:** Android APK-ები და Apple აპლიკაციის ბანდლები ან IPA ფაილები. მხარდაჭერილი მოწყობილობები, სიმულატორები და ხელმოწერის მოთხოვნები დამოკიდებულია გამოქვეყნების სამუშაო პროცესზე.
- **დესკტოპ აპლიკაციები:** macOS აპლიკაციის ბანდლები.
- **კომანდური ხაზის ინსტრუმენტები:** macOS ან Linux შესრულებადი ფაილები, ცალკე ან დამოკიდებულებებთან ერთად შეფუთული.

შეფუთვისა და თავსებადობის მოთხოვნებისთვის იხილეთ <.localized_link href="/guides/features/previews/types">მხარდაჭერილი ტიპები</.localized_link>. არტიფაქტის ტიპი განსაზღვრავს, სად შეიძლება გაეშვას პრივიუ; ის არ კარნახობს, რომელი ბილდ სისტემა ქმნის მას.

## ხილვადობა {#visibility}

პრივიუები იყენებენ პროექტის ნაგულისხმევ ხილვადობას. პირადი პრივიუები მოითხოვს ავთენტიკაციას და პროექტზე წვდომას. გახადეთ პრივიუები საჯარო პროექტის პარამეტრებში მხოლოდ მაშინ, როცა ბილდის გაზიარება ნებისმიერთან არის შესაძლებელი. საჯარო ხილვადობა არ აუქმებს პლატფორმის ხელმოწერის ან მოწყობილობაზე ინსტალაციის მოთხოვნებს.

## ტრეკები {#tracks}

ტრეკები აჯგუფებენ პრივიუებს დასახელებულ ჯგუფებად, მაგალითად, `beta` შიდა ტესტერებისთვის ან `nightly` ავტომატური ბილდებისთვის. მიუთითეთ ტრეკი თქვენი სამუშაო პროცესის გამოქვეყნების ბრძანებაში; ტრეკები იქმნება ზარმაცად, პირველი გამოყენებისას. გამოიყენეთ ისინი პრივიუების დასაჯგუფებლად დანიშნულების მიხედვით და პრივიუების ფილტრაციისთვის Tuist დაშბორდზე.
