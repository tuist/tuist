# სენდბოქსები {#sandboxes}

> [!IMPORTANT]
> **მხოლოდ მოწვევით**
>
> Tuist Sandboxes, როგორც Linux-ის, ისე macOS-ის ვერსიები, ამჟამად ხელმისაწვდომია მხოლოდ მოწვევით, სანამ ტევადობას გავზრდით. [დაგვიკავშირდით](mailto:contact@tuist.dev) ან მოგვწერეთ [საზოგადოების Slack-ში](https://slack.tuist.dev), რათა თქვენი ანგარიშისთვის წვდომა მოითხოვოთ. ფასები გამოცხადდება, როდესაც Sandboxes ზოგად ხელმისაწვდომობაზე გადავა.

სენდბოქსი არის ვირტუალური მანქანა, სადაც კოდირების აგენტი ასრულებს ბრძანებებს და არედაქტირებს ფაილებს. თითოეულ აგენტის სესიას ენიჭება საკუთარი სენდბოქსი, რომელიც ინახავს ჩეკაუტს, ბილდის პროდუქტებს და დაინსტალირებულ ხელსაწყოებს სესიის განმავლობაში. როდესაც აგენტი უმოქმედო ხდება, სენდბოქსი იყინება; შემდეგი შეტყობინება აღადგენს მას იქიდან, სადაც გაჩერდა.

სენდბოქსები მუშაობენ იმავე ფლიტზე, რაზეც <.localized_link href="/guides/features/runners">Tuist Runners</.localized_link>, თქვენი გუნდის <.localized_link href="/guides/features/cache">ქეშის</.localized_link> გვერდით, რათა აგენტის ბილდებმა შეძლონ იმავე ქეშირებული არტეფაქტების გამოყენება, რასაც თქვენი CI და ლოკალური მანქანები იყენებენ.

სენდბოქსების გამოყენება შესაძლებელია:

- **<.localized_link href="/guides/features/sandboxes/amp">Amp</.localized_link>**: გაუშვით თქვენი Amp სამუშაო სივრცის orbs Tuist-ზე.
- **<.localized_link href="/guides/features/sandboxes/claude">Claude</.localized_link>**: გაუშვით Claude Managed Agents სესიები და Claude Code cloud სესიები (claude.ai, დესკტოპისა და მობილურის აპები და `claude --cloud`) Tuist-ზე.
- **[Tuist CLI](#cli)**: შექმენით სენდბოქსები და გაუშვით მათში ბრძანებები თქვენი ტერმინალიდან ან თქვენი საკუთარი ხელსაწყოებიდან API-ს მეშვეობით.

## CLI-ს გამოყენების დაწყება {#cli}

შექმენით სენდბოქსი და გაუშვით მასში ბრძანებები თქვენი ტერმინალიდან `tuist sandbox`-ის მეშვეობით.

### 1. შესვლა {#cli-log-in}

სენდბოქსების მართვა მოითხოვს ანგარიშის ადმინისტრატორს:

```bash
tuist auth login
```

### 2. სენდბოქსის შექმნა {#cli-create}

```bash
tuist sandbox create --platform macos
```

Linux-ისთვის გამოტოვეთ `--platform`. გადაეცით `--vcpus` `--memory-gb`-თან ერთად უფრო დიდი [კონფიგურაციისთვის](#platforms) და `--workspace-gb` უფრო დიდი დისკოსთვის. ბრძანება ბრუნდება, როდესაც სენდბოქსი გაეშვება და ბეჭდავს მის დეტალებს, მათ შორის ID-ს. ის იყენებს მიმდინარე დირექტორიაში არსებული Tuist პროექტის ანგარიშს; გადაეცით `--account` სხვის არჩევას.

### 3. ბრძანებების გაშვება {#cli-exec}

```bash
tuist sandbox exec <sandbox-id> -- xcodebuild -version
```

ბრძანება სრულდება `bash -lc`-ით სენდბოქსში, რომელიც ჯერ აღდგება, თუ გაყინულია, და `tuist` ბრუნდება ბრძანების სტატუსით.

### ჩვეულებრივი ამოცანები {#cli-tasks}

| ამოცანა | ბრძანება |
| --- | --- |
| სენდბოქსების სია | `tuist sandbox list` |
| ერთის ჩვენება | `tuist sandbox show <id>` |
| შეჩერება ან აღდგენა | `tuist sandbox pause <id>`, `tuist sandbox resume <id>` |
| წაშლა | `tuist sandbox delete <id> --yes` |
| გამოყენების ნახვა | `tuist sandbox analytics` |

დაამატეთ `--json` მანქანისთვის წაკითხვადი გამომავალი მონაცემებისთვის. ყველა პარამეტრის სანახავად იხილეთ <.localized_link href="/cli/sandbox">CLI-ს ცნობარი</.localized_link>. სენდბოქსების კოდიდან მართვისთვის, გამოიყენეთ იგივე ოპერაციები [Tuist API](https://tuist.dev/api/docs)-ს მეშვეობით `/api/accounts/{account_handle}/sandboxes`-ის ქვეშ, ან მიეცით აგენტს მათი გამოყენების საშუალება <.localized_link href="/guides/features/agentic-coding/mcp">MCP</.localized_link>-ის მეშვეობით.

## Linux და macOS {#platforms}

**Linux** სენდბოქსები მუშაობენ Ubuntu 24.04-ზე:

- 2 vCPU, 4 GiB RAM (ნაგულისხმები)
- 4 vCPU, 8 GiB RAM
- 8 vCPU, 16 GiB RAM

**macOS** სენდბოქსები მუშაობენ Apple silicon-ზე Xcode-ით:

- 8 vCPU, 8 GiB RAM (ნაგულისხმები)
- 8 vCPU, 16 GiB RAM
- 8 vCPU, 24 GiB RAM

## უსაფრთხოება {#security}

- თითოეული სენდბოქსი არის საკუთარი ვირტუალური მანქანა. სენდბოქსები არ იზიარებენ ფაილურ სისტემას, მეხსიერებას ან პროცესებს ერთმანეთთან ან CI დავალებებთან.
- სენდბოქსები ეკუთვნის ანგარიშს და მათ მართვა მხოლოდ მის ადმინისტრატორებს შეუძლიათ. ინტეგრაციიდან წამოსული სესიები მხოლოდ იმ ანგარიშის სენდბოქსებს აღწევენ, რომელთანაც ინტეგრაციაა დაკავშირებული.
- მონაცემები, რომლებსაც Tuist-ს აწვდით ინტეგრაციის დასაკავშირებლად, როგორიცაა Amp პროვაიდერის ტოკენი ან Claude გარემოს გასაღები, ინახება დაშიფრული და აღარასდროს ჩანს.
- სენდბოქსს შეუძლია ინტერნეტთან წვდომა. მოეპყარით იმას, რასაც აგენტი მისგან წვდება, ისე, როგორც CI დავალებას.
