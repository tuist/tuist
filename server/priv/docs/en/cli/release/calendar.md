# Release calendar {#release-calendar}

Follow current CLI versions, recent releases, and upcoming release windows. For channel guarantees, version pinning, and backport policy, see <.localized_link href="/cli/release/channels">Release channels</.localized_link>.

Stable promotion is scheduled for Mondays at 06:00 UTC. After a successful scheduled promotion, the next release candidate is cut from `main`, and subsequent canaries move to the following minor. Failures can delay the train, and maintainers can publish outside the schedule. Future windows are plans, not promised publication times.

Patch releases and backports ship on demand, not on a weekly schedule. The history below links published releases to their notes and actual publication dates.
