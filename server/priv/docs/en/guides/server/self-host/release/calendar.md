# Release calendar {#release-calendar}

Follow current server and Kura versions, recent releases, and upcoming release windows. For channel guarantees, image pinning, and backport policy, see <.localized_link href="/guides/server/self-host/release/channels">Release channels</.localized_link>.

Stable promotions are scheduled for Mondays at 06:00 UTC, alongside the <.localized_link href="/cli/release/calendar">CLI release train</.localized_link>. The next release candidate is cut only after a successful scheduled promotion. Failures can delay either component independently, and maintainers can publish outside the schedule. Future windows are plans, not promised publication times.

Patch releases and backports ship on demand, not on a weekly schedule. The history below links published releases to their notes and actual publication dates.
