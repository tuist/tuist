# Código {#code}

Tuist es un monorepositorio. Cada componente tiene sus propias herramientas, dependencias y pasos de ejecución local. Elige el área en la que quieres contribuir:

- <.localized_link href="/contributors/code/cli">CLI</.localized_link>
- <.localized_link href="/contributors/code/server">Server</.localized_link>
- <.localized_link href="/contributors/code/handbook">Handbook</.localized_link>
- <.localized_link href="/contributors/code/docs">Docs</.localized_link>

Todos los componentes utilizan <.localized_link href="https://mise.jdx.dev/getting-started.html">Mise</.localized_link> para la gestión de dependencias.
