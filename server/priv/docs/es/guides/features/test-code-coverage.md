# Cobertura de código {#code-coverage}

La cobertura de código te indica qué líneas de tu código ejecutaron los tests. Tuist sube la cobertura de cada ejecución de tests y consolida las ejecuciones de un commit en una única cifra, por archivo y para todo el proyecto, para que puedas seguirla en el panel commit tras commit.
