### Cuando no se ejecuta la puerta {#when-the-gate-does-not-run}

- La primera pasada ya falló. Corrige esos tests primero.
- El proyecto no tiene una rama predeterminada o aún no se ha ejecutado nada en CI para ella.
- Más del 30% de los casos de test del proyecto parecen nuevos. Volver a ejecutar tantos llevaría más tiempo del que vale la pena. Esto es esperable en un proyecto que acaba de empezar a enviar informes a Tuist, o después de un cambio de nombre que mueve muchos tests a la vez.
