# Calendario de versiones {#release-calendar}

Sigue las versiones actuales del servidor y de Kura, los lanzamientos recientes y las próximas ventanas de lanzamiento. Para conocer las garantías de canal, la fijación de imágenes y la política de retroportaciones, consulta <.localized_link href="/guides/server/self-host/release/channels">Canales de lanzamiento</.localized_link>.

Las promociones estables están programadas para los lunes a las 06:00 UTC, junto con el <.localized_link href="/cli/release/calendar">calendario de lanzamientos de la CLI</.localized_link>. La siguiente versión candidata se genera solo después de una promoción programada exitosa. Los fallos pueden retrasar cada componente de forma independiente, y los mantenedores pueden publicar fuera del horario establecido. Las futuras ventanas son planes, no tiempos de publicación prometidos.

Los lanzamientos de parches y las retroportaciones se publican bajo demanda, no según un calendario semanal. El historial a continuación enlaza los lanzamientos publicados con sus notas y fechas reales de publicación.
