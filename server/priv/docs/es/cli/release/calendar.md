# Calendario de lanzamientos {#release-calendar}

Sigue las versiones actuales de la CLI, los lanzamientos recientes y las próximas ventanas de lanzamiento. Para conocer las garantías de canal, la fijación de versión y la política de retroportación, consulta <.localized_link href="/cli/release/channels">Canales de lanzamiento</.localized_link>.

La promoción a estable está programada para los lunes a las 06:00 UTC. Tras una promoción programada exitosa, se crea el siguiente candidato a lanzamiento desde `main`, y las siguientes versiones canary pasan a la siguiente versión menor. Los fallos pueden retrasar el ciclo, y los mantenedores pueden publicar fuera del horario establecido. Las futuras ventanas son planes, no tiempos de publicación prometidos.

Los lanzamientos de parche y las retroportaciones se publican bajo demanda, no según un calendario semanal. El historial siguiente enlaza los lanzamientos publicados con sus notas y las fechas reales de publicación.
