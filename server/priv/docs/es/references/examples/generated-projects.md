# Ejemplos de proyectos generados

En esta sección encontrarás ejemplos de <.localized_link href="/guides/features/projects">proyectos generados</.localized_link> que utilizamos como [ejemplos](https://github.com/tuist/tuist/tree/main/examples/xcode) para ejecutar pruebas de aceptación.
