# ログ {#logging}

CLIは、ロギングに[swift-log](https://github.com/apple/swift-log)インターフェースを採用しています。このパッケージはロギングの実装詳細を抽象化し、CLIがロギングバックエンドに依存しないようにします。ロガーはタスクローカルを使用して依存性注入され、次の方法でどこからでもアクセスできます。

```bash
Logger.current
```

> [!NOTE]
> `Dispatch`やデタッチドタスクを使用する場合、タスクローカルは値を伝播しません。そのため、これらを使用する場合は、値を取得して非同期操作に渡す必要があります。


## 何をログに記録するか {#what-to-log}

ログはCLIのUIではありません。問題が発生した際に診断するためのツールです。したがって、提供する情報が多いほど有益です。新機能を実装する際は、予期しない動作に遭遇した開発者の立場になり、どのような情報が役立つかを考えてください。適切な[ログレベル](https://www.swift.org/documentation/server/guides/libraries/log-levels.html)を使用してください。そうしないと、開発者はノイズをフィルタリングできなくなります。
