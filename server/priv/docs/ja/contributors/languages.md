# 言語 {#translate}

言語は理解の障壁となることがあります。Tuist をできるだけ多くの人々に利用できるようにしたいと考えています。Tuist がまだサポートしていない言語を話せる場合は、英語のソースと [Glossia](https://glossia.ai) が翻訳に使用するローカライゼーションコンテキストを改善することで、その言語での Tuist のサポートに貢献できます。

言語サポートは継続的な取り組みであるため、メンテナンスを引き受けてくれるコントリビューターが見つかり次第、対応言語を追加しています。現在サポートされている言語は以下のとおりです。

- 英語
- スペイン語
- 日本語
- ジョージア語
- 韓国語
- ロシア語
- 広東語
- 簡体字中国語
- 繁体字中国語

> [!TIP]
> **新しい言語のリクエスト**
>
> Tuist に新しい言語のサポートが必要だと考える場合は、コミュニティで議論するために [コミュニティフォーラムのトピック](https://community.tuist.io/c/general/4) を新規作成してください。


## 支援方法 {#how-to-translate}

Tuist の言語サポートはリポジトリを中心に行われます。コントリビューターが英語のソースと翻訳コンテキストを更新すると、[Glossia](https://glossia.ai) が自動的にローカライズされたファイルを生成します。

ワークフローは次のとおりです。

1. 英語のソースコンテンツを更新する。
2. 翻訳者に追加のガイダンスが必要な場合は、関連する `L10N.md` コンテキストを更新する。
3. それらのソース変更を含むプルリクエストを作成する。
4. 変更が `main` にマージされると、Glossia が変更部分を翻訳し、更新されたローカライズファイルを含む翻訳用プルリクエストを開いたままにします。

> [!WARNING]
> **生成されたローカライズコンテンツを変更しない**
>
> 生成されたローカライズコンテンツを直接編集しないでください。代わりに、英語のソースと言語コンテキストを更新してください。


## L10N.md の構造 {#l10n-md-structure}

`L10N.md` ファイルは、Glossia が翻訳時に使用するコンテキストを定義します。これらは異なるディレクトリレベルに配置できる、スコープ付きの言語指示として捉えると理解しやすいでしょう。

例：

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## ディレクトリコンテキスト {#directory-context}

Glossia はリポジトリのルートから翻訳対象のディレクトリまで降りていき、そのパス上にあるすべての `L10N.md` ファイルを組み合わせて使用します。

上記の例では：

- `L10N.md` はグローバルに適用されます。
- `server/L10N.md` はサーバー固有のコンテキストを追加します。
- `server/L10N/es.md` は同じ領域に対するスペイン語専用の上書きを追加します。

つまり、コンテキストを適切な場所に配置できます。

- リポジトリ全体のガイドラインはルートに配置
- 領域固有のガイドラインはサブディレクトリに配置
- 言語固有のガイドラインは `L10N/<locale>.md` に配置
