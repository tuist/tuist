# 言語 {#translate}

言語は理解の障壁となることがあります。Tuist をできるだけ多くの人に利用できるようにしたいと考えています。Tuist がまだサポートしていない言語を話せる場合は、英語のソースと [Glossia](https://glossia.ai) が翻訳に使用するローカライゼーションコンテキストを改善することで、Tuist がその言語に対応するのを支援できます。

言語サポートは継続的な取り組みであるため、メンテナンスを手伝ってくれる貢献者が見つかり次第、新しい言語を追加しています。現在サポートされている言語は次のとおりです。

- 英語
- アラビア語
- スペイン語
- 日本語
- ジョージア語
- 韓国語
- ロシア語
- 広東語
- 簡体字中国語
- 繁体字中国語

> [!TIP]
> **新しい言語をリクエスト**
>
> Tuist が新しい言語をサポートすることで恩恵を受けると考える場合は、コミュニティで議論するためにコミュニティフォーラムの[新しいトピック](https://community.tuist.io/c/general/4)を作成してください。


## 支援方法 {#how-to-translate}

Tuist の言語サポートはリポジトリから推進されます。貢献者が英語のソースと翻訳コンテキストを更新すると、[Glossia](https://glossia.ai) が自動的にローカライズされたファイルを生成します。

ワークフローは次のとおりです。

1. 英語のソースコンテンツを更新します。
2. 翻訳者にさらなるガイダンスが必要な場合は、関連する `L10N.md` コンテキストを更新します。
3. それらのソース変更を含むプルリクエストを作成します。
4. 変更が `main` にマージされると、Glossia は変更部分を翻訳し、更新されたローカライズされたファイルを含む翻訳プルリクエストを開いたままにします。

> [!WARNING]
> **生成されたローカライズ済みコンテンツを変更しない**
>
> 生成されたローカライズ済みコンテンツを直接編集しないでください。代わりに英語のソースと言語コンテキストを更新してください。


## L10N.md の構造 {#l10n-md-structure}

`L10N.md` ファイルは、Glossia が翻訳時に使用するコンテキストを定義します。これらを異なるディレクトリレベルに配置できるスコープ付きの言語指示として考えると理解しやすいでしょう。

例：

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## ディレクトリコンテキスト {#directory-context}

Glossia はリポジトリのルートから翻訳対象のディレクトリまで降りていき、そのパス上で見つかったすべての `L10N.md` ファイルを結合します。

上記の例では：

- `L10N.md` はグローバルに適用されます。
- `server/L10N.md` はサーバー固有のコンテキストを追加します。
- `server/L10N/es.md` は同じ領域に対してスペイン語専用のオーバーライドを追加します。

つまり、コンテキストを適切な場所に配置できます。

- リポジトリ全体のガイダンスはルートに配置
- 領域固有のガイダンスはサブディレクトリに配置
- 言語固有のガイダンスは `L10N/<locale>.md` に配置
