# 言語 {#translate}

言語は理解の障壁になり得ます。私たちは、Tuist ができるだけ多くの人々に利用できるようにしたいと考えています。Tuist がまだサポートしていない言語を話せる場合、英語のソースと [Glossia](https://glossia.ai) が翻訳に使用するローカライゼーションコンテキストを改善することで、その言語での Tuist のサポートに貢献できます。

言語サポートは継続的な取り組みであるため、メンテナンスを支援してくれる貢献者が現れた時点で新しい言語を追加しています。現在サポートされている言語は次のとおりです。

- 英語
- アラビア語
- スペイン語
- 日本語
- ジョージア語
- 韓国語
- ロシア語
- 広東語
- 簡体字中国語
- 繁体字中国語

> [!TIP]
> **新しい言語のリクエスト**
>
> Tuist に新しい言語のサポートが必要だと考える場合は、コミュニティで議論するために [コミュニティフォーラムのトピック](https://community.tuist.io/c/general/4) を新規作成してください。


## 貢献方法 {#how-to-translate}

Tuist の言語サポートはリポジトリから管理されています。貢献者が英語のソースと翻訳コンテキストを更新すると、[Glossia](https://glossia.ai) が自動的にローカライズされたファイルを生成します。

ワークフローは次のとおりです。

1. 英語のソースコンテンツを更新する。
2. 翻訳者に追加のガイダンスが必要な場合は、関連する `L10N.md` コンテキストを更新する。
3. それらのソース変更を含むプルリクエストを作成する。
4. 変更が `main` にマージされると、Glossia は変更部分を翻訳し、更新されたローカライズファイルを含めた翻訳用プルリクエストをオープンな状態に保ちます。

> [!WARNING]
> **生成されたローカライズコンテンツを変更しない**
>
> 生成されたローカライズコンテンツを直接編集しないでください。代わりに英語のソースと言語コンテキストを更新してください。


## L10N.md の構造 {#l10n-md-structure}

`L10N.md` ファイルは、Glossia が翻訳時に使用するコンテキストを定義します。これらは異なるディレクトリレベルに配置できる、スコープ付きの言語指示として捉えると分かりやすいでしょう。

例:

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## ディレクトリコンテキスト {#directory-context}

Glossia はリポジトリのルートから翻訳対象のディレクトリまで走査し、そのパス上で見つかったすべての `L10N.md` ファイルを結合します。

上記の例では:

- `L10N.md` はグローバルに適用されます。
- `server/L10N.md` はサーバー固有のコンテキストを追加します。
- `server/L10N/es.md` は同じ領域に対するスペイン語専用のオーバーライドを追加します。

つまり、コンテキストを適切な場所に配置できます。

- リポジトリ全体のガイダンスはルートに配置
- 領域固有のガイダンスはサブディレクトリに配置
- 言語固有のガイダンスは `L10N/<locale>.md` に配置
