# リリースカレンダー {#release-calendar}

最新のCLIバージョン、最近のリリース、今後のリリースウィンドウを確認できます。チャンネル保証、バージョン固定、バックポートポリシーについては、<.localized_link href="/cli/release/channels">リリースチャンネル</.localized_link>をご覧ください。

安定版への昇格は、月曜日の06:00 UTCに予定されています。スケジュールされた昇格が成功すると、次のリリース候補が `main` から作成され、後続のカナリアビルドは次のマイナーバージョンへ移行します。失敗が発生するとリリースサイクルが遅れる可能性があり、メンテナーはスケジュール外で公開することもあります。将来のウィンドウは計画であり、約束された公開時刻ではありません。

パッチリリースとバックポートは、毎週のスケジュールではなく、必要に応じて提供されます。以下の履歴では、公開されたリリースをそのノートと実際の公開日にリンクしています。
