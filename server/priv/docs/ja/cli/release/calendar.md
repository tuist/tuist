# リリースカレンダー {#release-calendar}

最新のCLIバージョン、最近のリリース、今後のリリース予定を確認できます。チャネルの保証、バージョン固定、バックポートポリシーについては、<.localized_link href="/cli/release/channels">リリースチャネル</.localized_link>をご覧ください。

安定版への昇格は、毎週月曜日の06:00 UTCにスケジュールされています。スケジュールされた昇格が成功すると、次のリリース候補が `main` から切り出され、後続のカナリアビルドは次のマイナーバージョンに移行します。失敗があるとリリースが遅れることがあり、メンテナーはスケジュール外で公開することもあります。将来のリリース予定は計画であり、公開時刻の保証ではありません。

パッチリリースとバックポートは、毎週のスケジュールではなく、必要に応じて提供されます。以下の履歴では、公開されたリリースをそのリリースノートおよび実際の公開日に関連付けています。
