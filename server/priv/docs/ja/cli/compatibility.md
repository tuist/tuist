# 互換性 {#compatibility}

Tuist CLI は、キャッシュ、ビルドおよびテストのインサイト、プレビュー、レジストリなどの機能のために Tuist サーバーと通信します。サーバーは CLI のアップグレード時期とは関係なく継続的に提供されるため、サーバー側の変更によって現在実行中の CLI バージョンが壊れないようにする必要があります。これを保証するため、サーバーは定義された期間内で最新の CLI リリースとの互換性を維持します。

## サポート期間 {#support-window}

Tuist サーバーは **過去 3 か月以内** にリリースされた CLI をサポートします。この期間内ではサーバーは後方互換性を維持します。過去 3 か月以内にリリースされた任意の CLI は、サーバーに対してビルド、キャッシング、テストの実行を継続でき、サーバー側の変更による障害を気にせず独自のスケジュールで CLI をアップグレードできます。

CLI は [セマンティック バージョニング](https://semver.org) に準拠しています。過去 3 か月以内に公開されたリリースはすべてサポート対象です。

## サポート期間外 {#outside-the-window}

サポート期間より古い CLI リリースは非推奨とみなされます。サーバーは引き続き応答しますが、次の点に注意してください。

- 新しいサーバー側の機能がそのバージョンでは動作しない可能性があります。
- サーバー依存のコマンドは、アップグレードを促す警告を表示することがあります。

非推奨バージョンでの動作は保証されません。該当する場合は、サポート期間内のリリースにアップグレードしてください。

## 互換性の保証方法 {#how-we-keep-the-promise}

後方互換性は想定ではなく検証に基づいて確保されます。すべてのサーバーデプロイメントでは、**サポート期間内にある最も古い CLI リリース**（現在は `{{minimum_supported_cli_version}}`）に対して自動受け入れテストを実行し、キャッシュのプルパスをエンドツーエンドで検証します。もし変更によってそのバージョンが壊れる場合、デプロイメントは本番環境に到達する前にブロックされます。これは最新の CLI に対するテストと並行して実行されるため、古いクライアントでの回帰は最新クライアントでの回帰と同様に検出されます。

## 推奨事項 {#recommendation}

サポート対象の期間内に留まるため、CLI は少なくとも 3 か月に 1 回アップグレードしてください。CI で CLI バージョンを固定し、定期的なリズムで更新することで、チームが一貫してサポート対象のリリースを使用し続けられます。
