# バンドルインサイト {#bundle-insights}

アプリに機能を追加していくと、バンドルサイズは増大し続けます。その増加の一部は避けられませんが、重複アセット、未使用シンボル、プラットフォーム固有の無駄など、多くの要因は解消可能です。Tuist Bundle Insights は **Apple** と **Android** の両方のバンドルに対応しており、アプリサイズの縮小を支援するツールとインサイトを提供し、経時的な推移を追跡します。
