# テストインサイト {#test-insights}

Test Insights を使用して、低速なテストの特定、不安定なテストの追跡、失敗した CI 実行の迅速な理解により、テストスイートの健全性を監視します。現在、Xcode、Gradle、Bazel、Elixir、および Rust をサポートしています。
