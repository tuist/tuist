## マシンメトリクス {#machine-metrics}

ビルドインサイトには、ビルド中にキャプチャされたマシンレベルのパフォーマンスメトリクス（CPU、メモリ、ネットワーク、ディスク使用量）が含まれる場合があります。これを有効にするには、システムメトリクスを継続的にサンプリングする軽量なバックグラウンドデーモンを設定してください：

```bash
tuist setup insights
```

これにより、バックグラウンドでメトリクスをサンプリングするローカルデーモンが実行されます。データは `tuist inspect build` によって自動的に取得され、ビルドレポートと一緒にアップロードされます。

ディスクメトリクスには、読み書きアクティビティと、互換性のあるCLIおよびサーバーを使用した場合のmacOSシステムDataボリューム（`/System/Volumes/Data`）上の総容量と利用可能容量が含まれます。利用可能容量にはパージ可能な領域は含まれません。ディスク容量チャートは、アップロード時だけでなく、ビルド期間中の総容量 alongside 使用済み容量（総容量から利用可能容量を引いた値）を表示します。チェックアウトやDerivedDataに使用される個別の外部ボリュームは測定しません。

CLIをアップグレードした後、既存のサンプラーを `tuist teardown insights` で停止し、続いて `tuist setup insights` で再起動してください。サンプリングはビルド中に実行されている必要があります。古いレポートや失敗した測定にはディスク容量の値が含まれておらず、ゼロとして表示されません。ディスク容量のサンプルは、既存の90日間のマシンメトリクス保持ポリシーに従います。

> [!TIP]
> **CI**
>
> CIマシンでもマシンメトリクスをキャプチャするために、ビルド前に `tuist setup insights` を実行してください。

マシンメトリクスの収集を停止するには、次を実行してください：

```bash
tuist teardown insights
```

これにより、デーモンのLaunchAgentがアンロードされ、plistが削除され、`~/.local/state` からサンプリングされたメトリクスとデーモンログが削除されるため、バックグラウンドで実行されているものは残りません。
