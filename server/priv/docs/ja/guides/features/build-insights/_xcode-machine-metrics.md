## マシンメトリクス {#machine-metrics}

ビルドインサイトには、ビルド中に取得したマシンレベルのパフォーマンスメトリクス（CPU、メモリ、ネットワーク、ディスク使用量）を含めることができます。これを有効にするには、システムメトリクスを継続的にサンプリングする軽量なバックグラウンドデーモンを設定してください：

```bash
tuist setup insights
```

これにより、バックグラウンドでメトリクスをサンプリングするローカルデーモンが実行されます。データは `tuist inspect build` によって自動的に収集され、ビルドレポートと一緒にアップロードされます。

ディスクメトリクスには読み書きアクティビティが含まれ、互換性のあるCLIとサーバーを使用している場合は、macOSのシステムDataボリューム（`/System/Volumes/Data`）の合計容量と利用可能容量も含まれます。利用可能容量にはパージ可能な領域は含まれません。ディスク容量チャートは、アップロード時だけでなく、ビルド全体の期間における使用済み容量（合計から利用可能を引いた値）と総容量を表示します。チェックアウトやDerivedDataに使用される個別の外部ボリュームは測定しません。

CLIをアップグレードした後、既存のサンプラーを `tuist teardown insights` で停止し、続いて `tuist setup insights` で再起動してください。サンプリングはビルド中に実行されている必要があります。古いレポートや失敗した測定にはディスク容量の値が含まれておらず、ゼロとして表示されることはありません。ディスク容量のサンプルは、既存の90日間のマシンメトリクス保持ポリシーに従います。

> [!TIP]
> **CI**
>
> CIマシンでもマシンメトリクスを取得するために、ビルド前に `tuist setup insights` を実行してください。

マシンメトリクスの収集を停止するには、次を実行してください：

```bash
tuist teardown insights
```

これにより、デーモンのLaunchAgentがアンロードされ、plistが削除され、`~/.local/state` からサンプリングされたメトリクスとデーモンログが削除されるため、バックグラウンドで実行されているプロセスは残りません。
