# コードカバレッジ {#code-coverage}

コードカバレッジは、テストが実行したコードの行を示します。Tuist は各テスト実行のカバレッジをアップロードし、コミットごとの実行結果をファイル単位およびプロジェクト全体で1つの数値に集約するため、ダッシュボードでコミットごとに推移を追跡できます。
