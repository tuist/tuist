## 不安定なテストの管理 {#managing-flaky-tests}

### 自動クリア {#automatic-clearing}

検出とクリアはプロジェクト上の **自動化アラート** を介して実行されます。すべてのプロジェクトにはデフォルトで「不安定なテスト検出」自動化が設定されており、その *トリガー* はテストを不安定としてマークし、*リカバリー* はテストが再トリガーされずに設定されたリカバリー期間（デフォルト **14 日**）を経過するとフラグを解除します。**設定 → 自動化** で編集して、リカバリー期間を変更したり、リカバリーアクション（例：テストの隔離も解除する）を変更したり、リカバリーを完全に無効にしてテストを手動でクリアするまで不安定なままにしておくことができます。

### 手動管理 {#manual-management}

テストケースの詳細ページから、テストを不安定として手動でマークまたはマーク解除することもできます。これは以下のような場合に役立ちます。
- 修正作業中に既知の不安定なテストを認識したい場合
- インフラストラクチャの問題によりテストが誤ってフラグ付けされた場合
