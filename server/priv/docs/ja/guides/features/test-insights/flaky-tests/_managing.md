## 不安定なテストの管理 {#managing-flaky-tests}

### 自動クリア {#automatic-clearing}

検出とクリアは、プロジェクト上の**自動化アラート**を通じて実行されます。すべてのプロジェクトにはデフォルトで「不安定なテスト検出」自動化が用意されており、その*トリガー*はテストを不安定としてマークし、*リカバリー*はテストが再トリガーなしで設定されたリカバリー期間（デフォルトは**14日間**）を経過するとフラグを解除します。**設定 → 自動化**で編集して、リカバリー期間を変更したり、リカバリーアクション（例：テストの隔離も解除する）を変更したり、リカバリーを完全に無効にしてテストを手動でクリアするまで不安定なままにしておくことができます。

### 手動管理 {#manual-management}

テストケースの詳細ページから、テストを不安定として手動でマークまたはマーク解除することもできます。これは以下の場合に役立ちます：
- 修正作業中に既知の不安定なテストを認識しておきたい場合
- インフラストラクチャの問題によりテストが誤ってフラグ付けされた場合
