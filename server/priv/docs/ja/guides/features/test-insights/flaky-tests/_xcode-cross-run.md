### クロスラン検出 {#cross-run-detection}

テストのリトライがなくても、Tuist は同じコミット、スキーム、報告された宛先（デバイス名、プラットフォーム、OS バージョン）における異なる CI 実行の結果を比較することで、不安定なテストを検出できます。一致する CI 実行の 1 つでテストが成功し、別の実行で失敗した場合、その失敗した実行は不安定としてマークされます。この処理は、どちらの結果が先に到着しても機能します。

同じテストでも、スキームや宛先によって一貫して異なる動作をする場合があります。たとえば、iOS 26 で合格し iOS 27 で不合格になっても、それは不安定性を示すものではありません。異なるスキーム、デバイス、プラットフォーム、または OS バージョンからの結果同士は、互いを不安定としてフラグ付けしません。

宛先メタデータがない実行、または複数の宛先を対象とする実行は、互いとのみ比較されるため、それらの間での環境の違いは依然として不安定として報告される可能性があります。リトライベースの検出も引き続き適用されます。

これは、リトライで捕捉できるほど一貫して失敗しないものの、依然として断続的な CI の失敗を引き起こす不安定なテストを検出するために特に役立ちます。
