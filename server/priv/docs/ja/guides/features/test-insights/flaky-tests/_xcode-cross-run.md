### クロスラン検出 {#cross-run-detection}

テストの再試行を行わなくても、Tuist は同じコミット、スキーム、および報告された宛先（デバイス名、プラットフォーム、OS バージョン）における異なる CI ラン間の結果を比較することで、不安定なテストを検出できます。一致する CI ランのうち 1 つでテストが成功し、別のランで失敗した場合、失敗した実行は不安定としてマークされます。この処理は、どちらの結果が先に到着するかに関係なく機能します。

同じテストでも、スキームや宛先によって一貫して異なる動作をする場合があります。たとえば、iOS 26 では成功し iOS 27 では失敗しても、それは不安定性を示すものではありません。異なるスキーム、デバイス、プラットフォーム、または OS バージョンからの結果同士は、互いを不安定としてフラグ付けしません。

宛先メタデータがないラン、または複数の宛先をカバーするランは、互いとのみ比較されるため、それらの間の環境の違いは依然として不安定として報告される可能性があります。再試行に基づく検出も引き続き適用されます。

これは、再試行で捕捉できるほど一貫して失敗しないものの、依然として断続的な CI の失敗を引き起こす不安定なテストを検出するのに特に役立ちます。
