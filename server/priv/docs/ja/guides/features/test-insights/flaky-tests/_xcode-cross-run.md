### クロスラン検出 {#cross-run-detection}

テストの再試行がなくても、Tuistは同じコミット、スキーム、および報告された宛先（デバイス名、プラットフォーム、OSバージョン）に対する異なるCI実行の結果を比較することで、不安定なテストを検出できます。ある一致するCI実行ではテストが成功し、別の実行では失敗した場合、失敗した実行は不安定としてマークされます。この処理は、どちらの結果が先に届いたかに関係なく機能します。

同じテストでも、スキームや宛先によって一貫して異なる動作をする場合があります。たとえば、iOS 26では成功し、iOS 27では失敗する場合、それは不安定性を示すものではありません。異なるスキーム、デバイス、プラットフォーム、またはOSバージョンからの結果は、互いに不安定としてフラグを立てません。

宛先メタデータのない実行、または複数の宛先をカバーする実行は、互いとのみ比較されるため、それらの間の環境の違いは依然として不安定として報告される可能性があります。再試行に基づく検出も引き続き適用されます。

これは、再試行で捕捉できるほど一貫して失敗しないものの、依然として断続的なCI障害を引き起こす不安定なテストを検出するのに特に役立ちます。
