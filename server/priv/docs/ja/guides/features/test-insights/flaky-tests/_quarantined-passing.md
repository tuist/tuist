### 検疫中のテストが合格として表示される理由 {#quarantined-passing}

- **ミュートされたテスト**は依然として実行されます。失敗したミュートテストは、テストケースの実行において**失敗**として記録され、不安定なテストとしてフラグが付けられます。個々のテストのステータスは書き換えられません。上書きされるのは**テスト実行全体の結果**です。実行内のすべての失敗したテストケースがミュートされている場合、実行全体は合格として報告されるため、ミュートされた失敗によってCIが中断されることはありません。
- **スキップされたテスト**はまったく実行されないため、ダッシュボードにはそのテストの最後の実際の実行時のステータスが表示され続けます。そのスナップショットは数週間前のものかもしれません。
