### 検疫中のテストが合格として表示される理由 {#quarantined-passing}

- **ミュートされたテスト**は引き続き実行されます。失敗したミュート済みテストは、テストケースの実行で**失敗**として記録され、不安定フラグが付きます。テストごとのステータスは上書きされません。上書きされるのは**テスト実行全体**です。実行内のすべての失敗したテストケースがミュートされている場合、実行全体が合格として報告されるため、ミュートされた失敗によってCIが中断されることはありません。
- **スキップされたテスト**はまったく実行されないため、ダッシュボードにはそのテストの最後の実際の実行からのステータスが表示され続けます。そのスナップショットは数週間前のものになる可能性があります。
