# Origin の統合 {#origin}

Tuist は、ネイティブな [Cursor Origin](https://cursor.com/docs/api/origin) リポジトリのプルリクエストにビルド、テスト、プレビュー、バンドルのレポートを投稿できます。アップロードごとに新しいコメントを投稿するのではなく、アプリの既存の Tuist Run Report を更新します。

アプリをインストールしてもビルドやテストは実行されません。既存のワークフローは引き続き結果を Tuist にアップロードし、この統合によりそれらの結果がプルリクエストに表示されます。

## セットアップ {#setup}

Tuist アカウントの管理者は、**Settings → Integrations** を開き、Origin カードで **Install Origin App** を選択して、Cursor でアクセスを承認してください。Tuist がアクセスすべき Origin アカウントまたはネームスペースとリポジトリを選択し、Tuist に戻ります。接続は個別のプロジェクトではなく、Tuist アカウントに属します。

Origin から直接アプリをインストールすることもできます。アクセスを承認した後、必要に応じて Tuist にログインし、接続する組織を選択してください。管理している組織と個人アカウントのみが表示されます。利用可能なアカウントが 1 つだけの場合、Tuist は選択画面を表示せずに自動的に接続します。Tuist から開始した場合、組織はすでに選択されており、このステップはスキップされます。

**Add new project connection** を選択してリポジトリ選択モーダルを開きます。未接続の Tuist プロジェクトと、接続された Origin アカウントから検出されたリポジトリのいずれかを選択し、**Create Connection** を選択してください。複数の Origin アカウントが接続されている場合は、まずアカウントを選択してください。接続できるのはネイティブな Origin リポジトリのみです。Tuist はプロジェクトを接続する前にプルリクエストへのアクセスを再度確認し、リポジトリのデフォルトブランチを採用します。

**Manage integration** を使用して、新しいタブで Cursor の同意フローを開き、リポジトリアクセスを調整したり、別の Origin アカウントを接続したりできます。リポジトリの読み込み失敗時には **Retry** が表示され、空のリポジトリリストが正常に表示される場合とは区別されます。

結果のアップロードを認証するには、<.localized_link href="/guides/server/authentication#account-tokens">アカウントトークン</.localized_link> を使用してください。

## レポートと権限 {#reports-and-permissions}

アプリを承認すると、リポジトリの接続とレポートの公開に必要な権限が付与されます。

| 権限 | 用途 |
| --- | --- |
| プルリクエスト: 読み取り | 報告されたコミットに対応するオープンなプルリクエストを検索します。 |
| プルリクエストのレビュー: 読み取りおよび書き込み | Tuist Run Report のコメントを読み取り、投稿し、更新します。 |
| リポジトリメタデータ: 読み取り | リポジトリとそのデフォルトブランチを検出します。Origin によって自動的に含まれます。 |

Tuist はソースコードへのアクセスやプルリクエストのマージ権限を必要としません。

結果をプルリクエストに関連付けるには、アップロードにリポジトリの Origin クローン URL、Git ref、および完全なコミット SHA を含める必要があります。Tuist は、それらが現在のヘッドコミットにおける単一のオープンなプルリクエストを特定する場合にのみレポートを投稿します。置き換えられたコミットの結果は、現在のレポートを上書きしません。

Origin カードにはプロジェクトとリポジトリの接続が一覧表示されます。アプリをアンインストールせずにレポートを停止するには、プロジェクト接続で **Manage → Remove connection** を選択してください。Cursor でアプリをアンインストールしてアクセスを取り消すと、Tuist はインストール通知を処理する際にインストールとそのプロジェクト接続を削除します。

## セルフホスト型サーバー {#server-configuration}

独自の Tuist サーバーをホストしている場合は、まずデプロイメント用に Origin アプリを登録して設定してください。<.localized_link href="/guides/server/self-host/server#platform-origin">Origin のセルフホスティング手順</.localized_link> に従い、その後上記のセットアップ手順に戻ってアカウントとプロジェクトを接続してください。
