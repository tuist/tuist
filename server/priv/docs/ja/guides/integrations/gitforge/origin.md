# Origin インテグレーション {#origin}

Tuist は、ネイティブな [Cursor Origin](https://cursor.com/docs/api/origin) リポジトリのプルリクエストにビルド、テスト、プレビュー、バンドルのレポートを投稿できます。アップロードごとに新しいコメントを投稿するのではなく、アプリの既存の Tuist Run Report を更新します。

アプリをインストールしても、ビルドやテストは実行されません。既存のワークフローは引き続き結果を Tuist にアップロードし、インテグレーションによってそれらの結果がプルリクエストに取り込まれます。

## セットアップ {#setup}

Tuist アカウントの管理者は、**Settings → Integrations** を開き、Origin カードで **Install Origin App** を選択して、Cursor でアクセスを承認してください。Tuist がアクセスすべき Origin アカウントまたはネームスペースとリポジトリを選択し、Tuist に戻ってください。接続は個別のプロジェクトではなく、Tuist アカウントに属します。

Origin から直接アプリをインストールすることもできます。アクセスを承認した後、必要に応じて Tuist にログインし、接続する組織を選択してください。管理している組織と個人アカウントのみ利用可能です。個人アカウントが唯一の選択肢であっても、Tuist は常に確認を行います。チームの Tuist 組織が一覧に表示されていない場合は、**Create an organization** を選択するか、その組織の管理者の一人に管理者権限を付与してもらうよう依頼してください。ページが開いている間は一覧が更新されるため、Tuist に戻ってから 10 分以内に選択すれば、やり直すことなく組織が表示されます。Tuist から開始した場合、組織はすでに選択されており、このステップはスキップされます。

**Add new project connection** を選択して、リポジトリ選択モーダルを開きます。未接続の Tuist プロジェクトと、接続された Origin アカウントから検出されたリポジトリのいずれかを選択し、**Create Connection** を選択してください。複数の Origin アカウントが接続されている場合は、最初にアカウントを選択してください。接続可能なのはネイティブな Origin リポジトリのみです。Tuist はプロジェクトを接続する前にプルリクエストへのアクセスを再度検証し、リポジトリのデフォルトブランチを採用します。

**Manage integration** を使用して、新しいタブで Cursor の同意フローを開き、リポジトリへのアクセスを調整したり、別の Origin アカウントを接続したりできます。リポジトリの読み込み失敗時には **Retry** が表示され、成功時の空のリポジトリ一覧とは区別されます。

結果のアップロードを認証するには、<.localized_link href="/guides/server/authentication#account-tokens">account token</.localized_link> を使用してください。

## レポートと権限 {#reports-and-permissions}

アプリを承認すると、リポジトリの接続とレポートの公開に必要な権限が付与されます。

| 権限 | 用途 |
| --- | --- |
| プルリクエスト: 読み取り | 報告されたコミットに対応するオープンなプルリクエストを検索します。 |
| プルリクエストレビュー: 読み取りおよび書き込み | Tuist Run Report コメントの読み取り、投稿、更新を行います。 |
| リポジトリメタデータ: 読み取り | リポジトリとそのデフォルトブランチを検出します。Origin によって自動的に含まれます。 |

Tuist はソースコードへのアクセスやプルリクエストのマージ権限を必要としません。

結果をプルリクエストに関連付けるには、アップロードにリポジトリの Origin クローン URL、Git ref、および完全なコミット SHA を含める必要があります。Tuist は、それらが現在のヘッドコミットにおける単一のオープンなプルリクエストを特定する場合にのみレポートを投稿します。置き換えられたコミットの結果は、現在のレポートを上書きしません。

Origin カードには、プロジェクトとリポジトリの接続が一覧表示されます。アプリをアンインストールせずにレポートを停止するには、プロジェクト接続で **Manage → Remove connection** を選択してください。Cursor でアプリをアンインストールしてアクセスを取り消します。Tuist はインストール通知を処理する際に、インストールとそのプロジェクト接続を削除します。

## セルフホストサーバー {#server-configuration}

独自の Tuist サーバーをホストしている場合は、まずデプロイメント用に Origin アプリを登録して構成してください。<.localized_link href="/guides/server/self-host/server#platform-origin">Origin self-hosting instructions</.localized_link> に従い、その後上記のセットアップ手順に戻ってアカウントとプロジェクトを接続してください。
