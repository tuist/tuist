# 번들 인사이트 {#bundle-insights}

앱에 기능을 추가할수록 번들 크기는 계속 증가합니다. 일부 증가는 불가피하지만, 중복된 에셋, 사용되지 않는 심볼, 플랫폼별 낭비 요소 등 상당 부분은 피할 수 있습니다. Tuist Bundle Insights는 **Apple**과 **Android** 번들을 모두 지원하며, 앱 크기를 작게 유지하는 데 도움이 되는 도구와 인사이트를 제공하고 시간에 따른 추이를 추적합니다.
