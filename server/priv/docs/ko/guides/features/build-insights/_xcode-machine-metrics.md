## 머신 메트릭 {#machine-metrics}

빌드 인사이트에는 빌드 중에 캡처된 머신 수준의 성능 메트릭(CPU, 메모리, 네트워크 및 디스크 사용량)이 포함될 수 있습니다. 이를 활성화하려면 시스템 메트릭을 지속적으로 샘플링하는 경량 백그라운드 데몬을 설정하세요:

```bash
tuist setup insights
```

이 명령은 백그라운드에서 메트릭을 샘플링하는 로컬 데몬을 실행합니다. 데이터는 `tuist inspect build`에 의해 자동으로 수집되어 빌드 리포트와 함께 업로드됩니다.

디스크 메트릭에는 읽기/쓰기 활동과 호환되는 CLI 및 서버가 있는 경우 macOS 시스템 데이터 볼륨(`/System/Volumes/Data`)의 총 공간과 사용 가능 공간이 포함됩니다. 사용 가능 공간에는 정리 가능한 공간이 제외됩니다. 디스크 공간 차트는 업로드 시점뿐만 아니라 빌드 전체 기간 동안의 총 용량과 함께 사용된 공간(총 공간에서 사용 가능 공간을 뺀 값)을 표시합니다. 체크아웃이나 DerivedData에 사용되는 별도의 외부 볼륨은 측정하지 않습니다.

CLI를 업그레이드한 후 `tuist teardown insights`를 실행하고 이어 `tuist setup insights`를 실행하여 기존 샘플러를 다시 시작하세요. 샘플링은 빌드 중에 실행되어야 합니다. 이전 리포트와 실패한 측정값에는 디스크 공간 값이 없으며 0으로 표시되지 않습니다. 디스크 공간 샘플은 기존 90일 머신 메트릭 보존 정책을 따릅니다.

> [!TIP]
> **CI**
>
> CI 머신에서도 머신 메트릭을 캡처하려면 빌드 전에 `tuist setup insights`를 실행하세요.

머신 메트릭 수집을 중지하려면 다음을 실행하세요:

```bash
tuist teardown insights
```

이 명령은 데몬의 LaunchAgent를 언로드하고 plist를 제거하며 `~/.local/state`에서 샘플링된 메트릭과 데몬 로그를 삭제하므로 백그라운드에서 실행되는 프로세스가 남지 않습니다.
