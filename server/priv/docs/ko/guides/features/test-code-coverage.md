# 코드 커버리지 {#code-coverage}

코드 커버리지는 테스트가 코드의 어떤 줄을 실행했는지 보여줍니다. Tuist는 모든 테스트 실행의 커버리지를 업로드하고 커밋의 실행 결과를 파일별 및 전체 프로젝트 기준으로 하나의 수치로 집계하므로, 대시보드에서 커밋별로 추이를 확인할 수 있습니다.
