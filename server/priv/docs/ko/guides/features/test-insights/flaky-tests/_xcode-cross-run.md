### 실행 간 감지 {#cross-run-detection}

테스트 재시도 없이도 Tuist는 동일한 커밋, 스킴, 보고된 대상(기기 이름, 플랫폼 및 OS 버전)에 대한 서로 다른 CI 실행의 결과를 비교하여 불안정한 테스트를 감지할 수 있습니다. 일치하는 한 CI 실행에서는 테스트가 통과하지만 다른 실행에서는 실패하면, 실패한 실행은 불안정하다고 표시됩니다. 이 기능은 어떤 결과가 먼저 도착하든 상관없이 작동합니다.

동일한 테스트라도 스킴이나 대상에 따라 일관되게 다르게 동작할 수 있습니다. 예를 들어 iOS 26에서는 통과하고 iOS 27에서는 실패하는 경우 불안정성이 확립되지 않습니다. 서로 다른 스킴, 기기, 플랫폼 또는 OS 버전의 결과는 서로를 불안정하다고 표시하지 않습니다.

대상 메타데이터가 없거나 여러 대상을 포함하는 실행은 서로만 비교되므로, 이들 간의 환경 차이는 여전히 불안정성으로 보고될 수 있습니다. 재시도 기반 감지도 계속 적용됩니다.

이는 재시도로 포착될 만큼 일관되게 실패하지는 않지만 여전히 간헐적인 CI 실패를 유발하는 불안정한 테스트를 포착하는 데 특히 유용합니다.
