### 격리된 테스트가 통과로 표시될 수 있는 이유 {#quarantined-passing}

- **음소거된 테스트**는 여전히 실행됩니다. 실패한 음소거된 테스트는 테스트 케이스 실행에서 **실패**로 기록되고 불안정하다고 플래그가 지정되지만, 개별 테스트 상태는 재작성되지 않습니다. 재정의되는 것은 **전체 테스트 실행**입니다. 실행 내의 모든 실패한 테스트 케이스가 음소거되면, 전체 실행이 통과로 보고되므로 음소거된 실패는 CI를 중단시키지 않습니다.
- **스킵된 테스트**는 전혀 실행되지 않으므로, 대시보드에는 해당 테스트의 마지막 실제 실행 상태가 계속 표시됩니다. 이 스냅샷은 몇 주 전 것일 수 있습니다.
