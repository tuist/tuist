## 불안정한 테스트 관리 {#managing-flaky-tests}

### 자동 초기화 {#automatic-clearing}

탐지 및 초기화는 프로젝트의 **자동화 알림**을 통해 실행됩니다. 모든 프로젝트에는 기본 "불안정한 테스트 탐지" 자동화가 제공되며, 이 자동화의 *트리거*는 테스트를 불안정하다고 표시하고 *복구*는 테스트가 재트리거 없이 구성된 복구 기간(기본값 **14일**) 동안 지속되면 플래그를 해제합니다. 복구 기간을 변경하거나 복구 동작(예: 테스트 격리 해제)을 수정하거나 복구를 완전히 비활성화하여 테스트가 수동으로 해제될 때까지 불안정하게 표시되도록 하려면 **설정 → 자동화**에서 편집하세요.

### 수동 관리 {#manual-management}

테스트 케이스 상세 페이지에서 테스트를 불안정하다고 수동으로 표시하거나 표시를 해제할 수도 있습니다. 이는 다음과 같은 경우에 유용합니다.
- 수정 작업을 진행하면서 이미 알려진 불안정한 테스트를 인지하고 싶을 때
- 인프라 문제로 인해 테스트가 잘못 플래그 지정되었을 때
