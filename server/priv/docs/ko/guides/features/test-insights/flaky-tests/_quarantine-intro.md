격리는 불안정한 테스트를 격리하여 수정하는 동안 CI가 차단되지 않도록 합니다. 기본적으로는 **수동 작업**입니다: 대시보드의 테스트 케이스 상세 페이지에서 테스트를 격리하고, 해제하며, 모드를 전환합니다. 또한 **설정 → 자동화**에서 **자동화 알림**으로 연결하여, 테스트가 불안정성 임계값을 초과하면 자동으로 음소거(또는 건너뛰기)되고, 복구되면 해제되도록 설정할 수 있습니다. 모든 전환(수동 또는 자동)은 테스트 케이스의 감사 로그에 기록됩니다.

기본적으로 복구는 트리거 조건이 더 이상 충족되지 않을 때까지 기다리므로, 이전의 불안정한 실행이 트리거 창을 벗어날 때까지 테스트는 격리된 상태로 유지됩니다. 더 빠르게 복구하려면 **복구 시점**을 **새로운 불안정한 실행 없음**으로 설정하세요: 새로운 불안정한 실행 없이 복구 창(일수 또는 실행 횟수)이 지나면 테스트가 복구되며, 새로운 불안정한 실행이 발생할 때마다 대기 시간이 초기화됩니다. 복구 후에는 새로운 불안정한 실행만 테스트를 다시 격리합니다.
