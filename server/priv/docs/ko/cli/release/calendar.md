# 릴리스 캘린더 {#release-calendar}

최신 CLI 버전, 최근 릴리스 및 예정된 릴리스 일정을 확인하세요. 채널 보장, 버전 고정 및 백포트 정책은 <.localized_link href="/cli/release/channels">릴리스 채널</.localized_link>을 참조하세요.

안정 버전 승격은 매주 월요일 06:00 UTC에 예약되어 있습니다. 예약된 승격이 성공하면 다음 릴리스 후보가 `main`에서 생성되며, 이후 카나리 빌드는 다음 마이너 버전으로 이동합니다. 실패 시 릴리스 일정이 지연될 수 있으며, 관리자는 예약 외 시간에 릴리스를 게시할 수 있습니다. 향후 일정은 계획일 뿐 약속된 게시 시간이 아닙니다.

패치 릴리스와 백포트는 주간 일정이 아닌 필요에 따라 제공됩니다. 아래 기록에는 게시된 릴리스와 해당 노트 및 실제 게시 날짜가 링크되어 있습니다.
