# Структура каталогов {#directory-structure}

Хотя проекты Tuist обычно используются для замены проектов Xcode, они не ограничиваются этим сценарием. Проекты Tuist также применяются для генерации других типов проектов, таких как пакеты SPM, шаблоны, плагины и задачи. В этом документе описывается структура проектов Tuist и способы их организации. В следующих разделах мы рассмотрим, как определять шаблоны, плагины и задачи.

## Стандартные проекты Tuist {#standard-tuist-projects}

Проекты Tuist — это **самый распространенный тип проектов, генерируемых Tuist.** Они используются для сборки приложений, фреймворков и библиотек. В отличие от проектов Xcode, проекты Tuist определяются на Swift, что делает их более гибкими и простыми в поддержке. Проекты Tuist также более декларативны, что упрощает их понимание и анализ. Следующая структура показывает типичный проект Tuist, который генерирует проект Xcode:

```bash
Tuist.swift
Tuist/
  Package.swift
  ProjectDescriptionHelpers/
Projects/
  App/
    Project.swift
  Feature/
    Project.swift
Workspace.swift
```

- **Каталог Tuist:** Этот каталог выполняет две функции. Во-первых, он указывает **расположение корня проекта**. Это позволяет строить пути относительно корня проекта, а также запускать команды Tuist из любого каталога внутри проекта. Во-вторых, он содержит следующие файлы:
  - **ProjectDescriptionHelpers:** Этот каталог содержит код Swift, общий для всех файлов манифестов. Файлы манифестов могут `import ProjectDescriptionHelpers`, чтобы использовать код, определенный в этом каталоге. Совместное использование кода помогает избежать дублирования и обеспечить согласованность между проектами.
  - **Package.swift:** Этот файл содержит зависимости Swift Package, которые Tuist интегрирует с помощью проектов и целей Xcode (например, [CocoaPods](https://cocoapods.org)), обеспечивая их настройку и оптимизацию. Подробнее <.localized_link href="/guides/features/projects/dependencies">здесь</.localized_link>.

- **Корневой каталог**: Корневой каталог вашего проекта, который также содержит каталог `Tuist`.
  - <.localized_link href="/guides/features/projects/manifests#tuistswift"><strong>Tuist.swift:</strong></.localized_link> Этот файл содержит конфигурацию Tuist, общую для всех проектов, рабочих областей и окружений. Например, его можно использовать для отключения автоматической генерации схем или для определения целевой платформы развертывания проектов.
  - <.localized_link href="/guides/features/projects/manifests#workspaceswift"><strong>Workspace.swift:</strong></.localized_link> Этот манифест представляет рабочую область Xcode. Он используется для группировки других проектов, а также позволяет добавлять дополнительные файлы и схемы.
  - <.localized_link href="/guides/features/projects/manifests#projectswift"><strong>Project.swift:</strong></.localized_link> Этот манифест представляет проект Xcode. Он используется для определения целей, входящих в состав проекта, и их зависимостей.

При работе с указанным выше проектом команды ожидают найти файл `Workspace.swift` или `Project.swift` в рабочем каталоге или в каталоге, указанном через флаг `--path`. Манифест должен находиться в каталоге или подкаталоге каталога, содержащего каталог `Tuist`, который представляет корень проекта.

> [!TIP]
> Рабочие области Xcode позволяли разделять проекты на несколько проектов Xcode, чтобы снизить вероятность конфликтов при слиянии. Если вы использовали рабочие области именно для этого, в Tuist они вам не нужны. Tuist автоматически генерирует рабочую область, содержащую проект и проекты его зависимостей.


## Пакет Swift <Badge type="warning" text="beta" /> {#swift-package-badge-typewarning-textbeta-}

Tuist также поддерживает проекты пакетов SPM. Если вы работаете над пакетом SPM, вам не нужно ничего обновлять. Tuist автоматически обнаруживает ваш корневой `Package.swift`, и все возможности Tuist работают так, как если бы это был манифест `Project.swift`.

Чтобы начать, выполните `tuist install` и `tuist generate` в вашем пакете SPM. Теперь ваш проект должен иметь те же схемы и файлы, что и при стандартной интеграции SPM в Xcode. Однако теперь вы также можете выполнить <.localized_link href="/guides/features/cache">`tuist cache`</.localized_link> и предварительно скомпилировать большинство ваших зависимостей и модулей SPM, что сделает последующие сборки чрезвычайно быстрыми.
