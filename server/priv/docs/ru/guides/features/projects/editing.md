# Редактирование {#editing}

В отличие от традиционных проектов Xcode или пакетов Swift, где изменения вносятся через интерфейс Xcode, проекты под управлением Tuist определяются кодом на Swift, содержащимся в **файлах манифестов**. Если вы знакомы с пакетами Swift и файлом `Package.swift`, подход очень похож.

Вы можете редактировать эти файлы в любом текстовом редакторе, но мы рекомендуем использовать предоставляемый Tuist рабочий процесс: `tuist edit`. Этот процесс создает проект Xcode, который содержит все файлы манифестов и позволяет их редактировать и компилировать. Благодаря использованию Xcode вы получаете все преимущества **автодополнения кода, подсветки синтаксиса и проверки ошибок**.

## Редактирование проекта {#edit-the-project}

Чтобы отредактировать проект, выполните следующую команду в каталоге проекта Tuist или его подкаталоге:

```bash
tuist edit
```

Команда создает проект Xcode в глобальном каталоге и открывает его в Xcode. Проект включает каталог `Manifests`, сборку которого можно выполнить, чтобы убедиться, что все ваши манифесты корректны.

> [!NOTE]
> **Манифесты, разрешаемые по шаблону glob**
>
> `tuist edit` определяет включаемые манифесты, используя шаблон glob `**/{Manifest}.swift` из корневого каталога проекта (того, который содержит файл `Tuist.swift`). Убедитесь, что в корне проекта есть корректный файл `Tuist.swift`.


### Исключение файлов манифестов {#ignoring-manifest-files}

Если ваш проект содержит файлы Swift с такими же именами, как у файлов манифестов (например, `Project.swift`), в подкаталогах, которые не являются настоящими манифестами Tuist, вы можете создать файл `.tuistignore` в корне проекта, чтобы исключить их из проекта для редактирования.

Файл `.tuistignore` использует шаблоны glob, чтобы указать, какие файлы следует игнорировать:

```gitignore
# Ignore all Project.swift files in the Sources directory
Sources/**/Project.swift

# Ignore specific subdirectories
Tests/Fixtures/**/Workspace.swift
```

Это особенно полезно, когда у вас есть тестовые фикстуры или примеры кода, которые случайно используют те же соглашения об именах, что и файлы манифестов Tuist.

## Рабочий процесс редактирования и генерации {#edit-and-generate-workflow}

Как вы могли заметить, редактирование нельзя выполнять из сгенерированного проекта Xcode. Это сделано намеренно, чтобы сгенерированный проект не имел зависимости от Tuist, что позволит вам в будущем легко отказаться от Tuist.

При работе над проектом мы рекомендуем запускать `tuist edit` в одном сеансе терминала, чтобы получить проект Xcode для редактирования, и использовать другой сеанс терминала для запуска `tuist generate`.
