## Треки с tuist share {#share-tracks}

Для рабочих процессов, публикующих артефакты через `tuist share`, используйте `--track` для выбора трека:

```bash
tuist share App --track beta
tuist share App --track nightly
```

## Примечания к выпуску {#release-notes}

Используйте треки для группировки окружений и примечания к выпуску для конкретной сборки:

```bash
tuist share App --track QA --release-notes "Fix sign-in and improve the checkout flow"
```

Замените `App` на имя вашего приложения, путь к файлу приложения или исполняемому дистрибутиву вместе с опцией `--executable`. Примечания к выпуску — это необязательный текст в формате plain text длиной до 10 000 символов. Первая непустая строка отображается как однострочный фрагмент в списках превью, поэтому номера сборок и другая идентифицирующая информация видны сразу. Длинные строки обрезаются; полные примечания отображаются на страницах деталей. Поиск сопоставляет отображаемые имена и полные примечания к выпуску, включая строки, не показанные во фрагменте. Поддерживаются многострочные примечания, например `--release-notes "$(< release-notes.txt)"`. Они не изменяют отображаемое имя приложения или его трек.

### Совместимость {#preview-metadata-compatibility}

Примечания к выпуску — это дополнительные метаданные, не являющиеся частью идентичности превью. Загрузки от старых и новых клиентов по-прежнему группируются в одно превью на всех платформах. Сохраняются первые непустые примечания: последующая загрузка может добавить примечания, которых ранее не было, но не может перезаписать существующие. Пропуск `release_notes`, отправка `null` или отправка пустой строки либо строки, состоящей только из пробельных символов, никогда не очищает примечания. Существующие превью не заполняются ретроспективно и остаются действительными без примечаний.

Необязательный параметр запроса `track` в API списков сопоставляется с полным именем трека без учёта регистра, что согласуется с существующим хранилищем треков. Опустите его или отправьте пустое значение (`?track=`), чтобы вывести список всех треков. Имена треков остаются произвольными строками, а не фиксированным набором значений. `GET /api/projects/:account_handle/:project_handle/previews/tracks` возвращает `{total_count, tracks: [{name, count}]}` с отсортированными, сгруппированными без учёта регистра именами треков, с теми же правами доступа на чтение превью, что и при перечислении сборок. Счётчики охватывают весь проект независимо от пагинации, поиска и выбранного трека; общее количество включает превью без трека. Учитываются только те превью, которые можно перечислить и у которых есть идентификатор пакета. API списков также принимает необязательный параметр `search` для поиска буквального подстрокового совпадения без учёта регистра в отображаемом имени или полных примечаниях к выпуску, применяемого совместно с треком до пагинации. Существующая фильтрация по `display_name` остаётся точной.

Старые клиенты могут продолжать загружать и перечислять превью, не отправляя ни одно из этих полей. Новые клиенты принимают более старые ответы, в которых отсутствуют трек или примечания, и игнорируют неизвестные свойства ответа, добавленные будущими версиями сервера. Интеграции с API также должны игнорировать неизвестные свойства ответа, чтобы дополнительные метаданные оставались совместимыми.

Для использования этих функций в развёртываниях на собственных серверах требуется версия сервера, поддерживающая примечания к выпуску и фильтрацию по трекам, а также обновлённый клиент. Более старые версии сервера могут игнорировать примечания или неизвестные параметры запроса.

## Автоматизации {#automations}

Используйте `--json`, чтобы получить вывод в формате JSON из `tuist share`:

```bash
tuist share --json
```

Используйте результат для пользовательских автоматизаций, например для публикации сообщения в Slack из CI. Ключ `url` содержит полную ссылку на превью; `qrCodeURL` указывает на изображение QR-кода для открытия превью на устройстве:

```json
{
  "id": 1234567890,
  "url": "https://cloud.tuist.io/preview/1234567890",
  "qrCodeURL": "https://cloud.tuist.io/preview/1234567890/qr-code.svg"
}
```
