# Предпросмотры Once {#once-previews}

[Once](https://buildonce.dev/docs/guide/infrastructure/tuist#publish-application-previews) может публиковать артефакты приложений в Tuist, чтобы коллеги могли опробовать сборку без её локальной пересборки. Для этого требуется Once версии 0.74.0+ и сервер Tuist с приёмником артефактов. Вместо этого Once версии 0.73.x использует устаревший адаптер для одного полезного груза.

## Настройка назначения

Завершите настройку по руководству <.localized_link href="/guides/get-started/once-project">Начало работы с Once</.localized_link>, затем добавьте привязку артефактов в файл `once.toml` вашего рабочего пространства. Используйте тот же провайдер, если он уже настроен для кэширования:

```toml
[infrastructures.tuist]
kind = "tuist"
account = "acme"
project = "app"

[infrastructure.artifacts]
name = "tuist"
```

```bash
once auth login --provider tuist
once artifact publish MyApplication --track review
```

Приёмник сохраняет полный набор, манифесты участников и полезные грузы, включая неизвестные интерфейсы. Поддерживаемые нативные интерфейсы асинхронно преобразуются в предпросмотры с использованием настроек видимости, доступа и распространения проекта по умолчанию. Содержимое общих артефактов остаётся приватным, даже в публичных проектах. Квитанция подтверждает хранение артефакта, а не завершение обработки предпросмотра; её URL открывает список предпросмотров проекта.

## Поддерживаемые приложения

Проекция Apple принимает метаданные `dev.once.apple-install.v2` для macOS-приложений и приложений для симулятора, подписанных ad-hoc и экспортированных на macOS. Приложения для физических устройств не поддерживаются. Проекция Android принимает метаданные `dev.once.android-install.v1` с проверенной подписью. Once одобряет автоматическую публикацию только для APK, подписанных отладочным ключом и не являющихся инструментальными. Неизвестные интерфейсы остаются доступными для скачивания как артефакты без создания предпросмотров. Ссылки на установку Android сохраняют имя файла с расширением `.apk`, хотя полезные грузы хранятся под хешами содержимого.

## Автоматическая публикация после сборок

```toml
[infrastructure]
publish_on_build = ["MyApplication"]
```

```bash
once artifact publish MyApplication --allow-on-build
once build MyApplication
```

Все запрошенные сборки должны успешно завершиться. Автоматическая публикация также требует одобрения продюсером всей замыкания и локальной авторизации для этой машины, рабочего пространства, точной конечной точки, цели и стабильного назначения проекта Tuist. Без политики или авторизации сетевые запросы на публикацию артефактов не выполняются. Обычные сборки Once не имеют побочных эффектов неявной публикации.

Повторное выполнение той же сохранённой публикации проверяет удалённую квитанцию и избегает повторной загрузки. Это отличается от поведения дублирования сборок в `tuist share`.

## Хранение

Публикации артефактов истекают через 30 дней на хостинге Tuist. Самостоятельно размещённые экземпляры используют переменную `TUIST_APP_PREVIEW_RETENTION_DAYS`; если она не установлена, срок действия для этой группы отключается. Истёкшие записи остаются как надгробия и не могут быть реактивированы повторением того же намерения. Существующие рабочие процессы подписи, видимости и распространения `tuist share` остаются неизменными.

См. раздел <.localized_link href="/guides/features/previews#run-a-preview">Запуск предпросмотра</.localized_link> для информации о запуске опубликованных сборок, доступе, треках и бейджах для README.

Для поддерживаемых предпросмотров симулятора Apple и macOS см. <.localized_link href="/guides/features/previews/run/macos">инструкции по приложению-компаньону Tuist для macOS</.localized_link>. Приложения для физических устройств по-прежнему не поддерживаются для публикации через Once.
