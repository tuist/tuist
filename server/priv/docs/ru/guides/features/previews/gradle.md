# Предпросмотры Gradle

Собирайте и делитесь Android-приложениями и нативными консольными инструментами прямо из Gradle. Начните с <.localized_link href="/guides/get-started/gradle-project">руководства по проекту Gradle</.localized_link>, чтобы подключить проект и пройти аутентификацию.

## Android-приложения

```bash
./gradlew :app:tuistShareDebug
```

Плагин настроек `dev.tuist` регистрирует задачу `tuistShare<Variant>` для каждого варианта приложения из Android Gradle Plugin (версии 8.8.2 или новее). Замените `app` и `Debug` на ваш модуль приложения и вариант, например `:app:tuistShareDemoDebug` для продуктового флейвора. Задача собирает APK через объявленные в Gradle зависимости артефактов перед его публикацией. Она также работает, когда выходные данные сборки актуальны или восстановлены из кэша сборки.

Поддерживается только один подписанный универсальный APK приложения. Отладочный вариант Android обычно использует отладочный ключ подписи; релизные варианты требуют вашей собственной конфигурации подписи. Задача проверяет подпись APK перед аутентификацией или загрузкой. Неподписанные, недействительные, инструментальные и разделённые APK отклоняются. Библиотечные модули, тестовые APK и пакеты Android App Bundles (`.aab`) не являются целями публикации.

## Нативные консольные инструменты

Проекты, использующие плагин Gradle `cpp-application` или `swift-application`, получают задачу публикации для каждого нативного бинарного файла:

```bash
./gradlew :app:tuistShareMainDebug
```

Задача собирает и упаковывает установленную дистрибуцию, включая её лаунчер и библиотеки времени выполнения. Используйте `tuistShareMainRelease` для релизного бинарного файла. Проекты, ориентированные на несколько машин, имеют задачу для каждого бинарного файла; выполните `./gradlew :app:tasks --all`, чтобы найти их имена.

Поддерживаются нативные исполняемые файлы macOS и Linux для arm64 или x86_64. Выполняйте сборку на целевой платформе с набором инструментов, требуемым вашим плагином Gradle. JVM-приложения и их сгенерированные скрипты запуска не поддерживаются этой интеграцией.

## Поведение при публикации

Задачи публикации используют существующие учётные данные Tuist плагина, не вызывая CLI Tuist. Обычные задачи `assemble`, `build` и тестирования никогда не публикуют предпросмотры.

После публикации откройте **Предпросмотры** в вашем проекте, чтобы скопировать ссылку. Повторная публикация той же сборки и трека повторно использует её публикацию, в том числе после попадания в кэш сборки. Неудачные или неподтверждённые загрузки приводят к сбою задачи публикации; они не отображаются как успешные предпросмотры.

## CI и треки

Настройте <.localized_link href="/guides/integrations/continuous-integration">аутентификацию CI</.localized_link> с теми же учётными данными, которые вы используете для других аутентифицированных функций плагина, затем явно запросите публикацию:

```bash
./gradlew :app:tuistShareDebug --track nightly
```

Добавьте `--track nightly` к задаче публикации нативного приложения аналогичным образом. Задачи используют настроенный проект Tuist, URL сервера и настройки прокси. Публикация предпросмотров всегда требует аутентификации. Метаданные ревизии Git, примечания к выпуску и автоматические комментарии к pull-запросам не прикрепляются этими задачами.

Публикации артефактов истекают через 30 дней на хостинге Tuist. Самостоятельно размещаемые экземпляры используют `TUIST_APP_PREVIEW_RETENTION_DAYS`; если оставить параметр неустановленным, истечение срока для этого семейства отключается. Истекшие публикации нельзя восстановить, повторив ту же операцию.

## Опубликовать существующий APK

Для APK, собранного вне этого рабочего процесса, или чтобы включить примечания к выпуску в устаревший поток загрузки, CLI остаётся доступным:

```bash
tuist share app/build/outputs/apk/debug/app-debug.apk \
  --track nightly --release-notes "Improve checkout"
```

См. <.localized_link href="/guides/features/previews#run-a-preview">Запуск предпросмотра</.localized_link> для информации о запуске опубликованных сборок, доступе, треках и бейджах README.
