# Запуск превью через CLI

Установите <.localized_link href="/guides/install-tuist">Tuist CLI</.localized_link>, затем запустите общую ссылку на превью. Вам не нужна система сборки, которая создала превью:

```bash
tuist run {url}
```

Tuist выбирает совместимую сборку для вашей операционной системы, архитектуры процессора и целевого устройства. Приватные превью требуют аутентификации и доступа к проекту.

## Мобильные приложения {#mobile-applications}

Выберите подключённое устройство или симулятор:

```bash
tuist run --device "My device" {url}
```

Устройства Android и эмуляторы должны быть подключены через ADB. Вы также можете скачать APK со страницы превью и установить его на устройство Android, которое разрешает установку из этого источника. Сборки Apple должны соответствовать целевой платформе и удовлетворять требованиям подписи. Для IPA откройте ссылку на превью на целевом устройстве, чтобы установить его.

## Превью командной строки {#command-line-previews}

Передавайте аргументы после `--`:

```bash
tuist run {url} -- --help
tuist run {url} -- build --configuration Release
```

Всё, что идёт после `--`, передаётся буквально, включая `--verbose`, `--quiet` и `--path`. Вложенные аргументы исключаются из аналитики команд Tuist.

Превью запускается с вашим рабочим каталогом, окружением и вводом/выводом терминала и возвращает код завершения исполняемого файла. Оно не заменяет установленный CLI и не добавляет его в `PATH`. Дистрибутивы CLI остаются в локальном кэше `previews` Tuist после выполнения, чтобы сгенерированные проекты могли продолжать ссылаться на них; удаление этого кэша также удаляет цели этих ссылок.

Десктопные превью и превью CLI запускаются от имени текущего пользователя, а не в песочнице. Запускайте только сборки от авторов и pull-запросов, которым вы доверяете.

## Выбор версии {#select-a-version}

`tuist run` также принимает имя приложения с `latest`, имя ветки или хэш коммита:

```bash
tuist run App@latest # Latest App preview associated with the project's default branch
tuist run App@my-feature-branch # Latest App preview associated with a branch
tuist run App@00dde7f56b1b8795a26b8085a781fb3715e834be # Preview associated with a commit
```

Эти селекторы требуют, чтобы соответствующие метаданные Git были опубликованы. Для рабочих процессов, которые не включают метаданные Git, используйте конкретный URL превью.

Сведения о доступе и организации см. в разделе <.localized_link href="/guides/features/previews#visibility">видимость и треки</.localized_link>.
