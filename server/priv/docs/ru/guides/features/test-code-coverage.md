# Покрытие кода {#code-coverage}

Покрытие кода показывает, какие строки вашего кода выполнялись тестами. Tuist загружает покрытие каждого запуска тестов и объединяет результаты всех запусков в рамках одного коммита в единый показатель — для каждого файла и для всего проекта в целом, чтобы вы могли отслеживать его в дашборде от коммита к коммиту.
