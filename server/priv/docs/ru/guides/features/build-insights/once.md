# Аналитика сборок Once {#once-build-insights}

Once передаёт данные о запусках в Tuist по мере их выполнения, чтобы вы могли отслеживать прогресс, не дожидаясь финального лога CI. Откройте ссылку на дашборд, которая выводится в начале запуска, чтобы просмотреть граф, статусы действий и решения кэша.

> [!IMPORTANT]
> **Требования**
>
> - Выполните шаги из руководства <.localized_link href="/guides/get-started/once-project">Начало работы с Once</.localized_link> и аутентифицируйте машину, на которой работает Once.

## Отправляйте данные о сборках {#report-your-builds}

Продолжайте использовать команды Once:

```bash
once build MyApplication
```

Отправка данных в реальном времени выполняется по принципу «best-effort». Недоступность конечной точки отчётов или истечение срока действия сессии не приводят к сбою сборки. Если сессия истекла, войдите снова с помощью `once auth login --provider tuist`.

## Что показывает дашборд {#what-the-dashboard-shows}

Используйте разделы **Сборки** и **Запуски сборок**, чтобы сравнивать запуски во времени, по веткам и между локальными или CI-окружениями. Каждый запуск может включать:

- Запрошенную команду, статус, время начала и длительность.
- Версию Once и информацию об узле.
- Действия и их зависимости, статус, длительность и результаты кэширования.
- Сообщённые ошибки действий.
- Ветку Git, коммит и контекст CI, если они переданы клиентом.

Ищите и фильтруйте действия, чтобы найти неудавшиеся или медленные задачи. Имена действий и исходные файлы помогают связать работу с кодом; старые клиенты могут предоставлять меньше деталей. Кэшированные или пропущенные действия не являются выполненной работой, а отсутствие данных о времени не означает выполнение нулевой длительности.

Tuist сейчас не принимает необработанный поток логов действий Once. Сохраняйте логи CI для полного вывода процесса; сводки запусков и структурированные ошибки не заменяют эти логи.

Раздел **Кэш** разделяет решения по действиям и передачу объектов контента. См. <.localized_link href="/guides/features/cache/once">Кэш Once</.localized_link> для интерпретации активности кэша.

## Тесты {#tests}

Команды тестирования также создают запуски Once. Сообщённые наборы и тест-кейсы отображаются в разделе **Тесты**; размещённые шарды дополнительно публикуют объединённый запуск тестов. См. <.localized_link href="/guides/features/test-insights/once">Аналитика тестов Once</.localized_link>.

## Агенты кодирования и Grafana {#coding-agents-and-grafana}

Инструменты <.localized_link href="/guides/features/agentic-coding/mcp#once-runs">Model Context Protocol</.localized_link> позволяют агенту получать список запусков Once и считывать суммарные показатели действий и кэша для запуска. Те же данные доступны через HTTP API.

Используйте <.localized_link href="/guides/integrations/grafana">интеграцию с Grafana</.localized_link> для финальных метрик здоровья сборок Once. Once сейчас не сообщает экономию времени кэша, поэтому эта метрика остаётся недоступной, а не равной нулю.
