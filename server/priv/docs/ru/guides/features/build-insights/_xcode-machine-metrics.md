## Метрики машины {#machine-metrics}

Аналитика сборок может включать метрики производительности на уровне машины (ЦП, память, сеть и использование диска), собранные во время сборки. Чтобы включить эту функцию, настройте легковесный фоновый демон, который постоянно собирает системные метрики:

```bash
tuist setup insights
```

Это запускает локальный демон, который собирает метрики в фоновом режиме. Данные автоматически подхватываются командой `tuist inspect build` и загружаются вместе с отчётом о сборке.

> [!TIP]
> **CI**
>
> Выполните `tuist setup insights` на ваших CI-машинах перед сборкой, чтобы также собирать метрики машины.

Чтобы прекратить сбор метрик машины, выполните:

```bash
tuist teardown insights
```

Это выгружает LaunchAgent демона, удаляет его plist-файл и стирает собранные метрики и логи демона из `~/.local/state`, поэтому в фоне ничего не остаётся работать.
