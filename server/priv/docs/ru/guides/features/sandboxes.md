# Песочницы {#sandboxes}

> [!IMPORTANT]
> **Только по приглашениям**
>
> Tuist Sandboxes для Linux и macOS сейчас доступны только по приглашениям, пока мы масштабируем мощности. [Свяжитесь с нами](mailto:contact@tuist.dev) или напишите нам в [Slack-сообществе](https://slack.tuist.dev), чтобы запросить доступ для вашего аккаунта. Цены будут объявлены, когда Sandboxes станут общедоступными.

Песочница — это виртуальная машина, где агент для написания кода выполняет команды и редактирует файлы. Каждая сессия агента получает собственную песочницу, которая хранит клон репозитория, артефакты сборки и установленные инструменты на протяжении всей сессии. Когда агент переходит в режим ожидания, песочница приостанавливается; следующее сообщение возобновляет работу с того места, где она остановилась.

Песочницы работают на том же парке машин, что и <.localized_link href="/guides/features/runners">Tuist Runners</.localized_link>, рядом с <.localized_link href="/guides/features/cache">кешем</.localized_link> вашей команды, поэтому сборки агента могут использовать те же кешированные артефакты, что и ваши CI-системы и локальные машины.

Вы можете использовать песочницы через:

- **<.localized_link href="/guides/features/sandboxes/amp">Amp</.localized_link>**: запускайте орбы вашего рабочего пространства Amp на Tuist.
- **<.localized_link href="/guides/features/sandboxes/claude">Claude</.localized_link>**: запускайте сессии Claude Managed Agents и облачные сессии Claude Code (claude.ai, десктопные и мобильные приложения, а также `claude --cloud`) на Tuist.
- **[The Tuist CLI](#cli)**: создавайте песочницы и выполняйте в них команды из терминала или из ваших собственных инструментов через API.

## Начало работы с CLI {#cli}

Создайте песочницу и выполняйте в ней команды из терминала с помощью `tuist sandbox`.

### 1. Войдите в аккаунт {#cli-log-in}

Для управления песочницами требуется администратор аккаунта:

```bash
tuist auth login
```

### 2. Создайте песочницу {#cli-create}

```bash
tuist sandbox create --platform macos
```

Опустите `--platform` для Linux. Укажите `--vcpus` вместе с `--memory-gb` для большей [конфигурации](#platforms) и `--workspace-gb` для большего диска. Команда завершится, когда песочница запустится, и выведет её данные, включая ID. Она использует аккаунт проекта Tuist в текущей директории; укажите `--account`, чтобы выбрать другой.

### 3. Выполняйте команды {#cli-exec}

```bash
tuist sandbox exec <sandbox-id> -- xcodebuild -version
```

Команда выполняется через `bash -lc` в песочнице, которая сначала возобновляется, если была приостановлена, а `tuist` завершается со статусом выполненной команды.

### Частые задачи {#cli-tasks}

| Задача | Команда |
| --- | --- |
| Список песочниц | `tuist sandbox list` |
| Показать одну | `tuist sandbox show <id>` |
| Приостановить или возобновить | `tuist sandbox pause <id>`, `tuist sandbox resume <id>` |
| Удалить | `tuist sandbox delete <id> --yes` |
| Посмотреть использование | `tuist sandbox analytics` |

Добавьте `--json` для вывода в машиночитаемом формате. См. <.localized_link href="/cli/sandbox">справочник CLI</.localized_link> для всех опций. Чтобы управлять песочницами из кода, используйте те же операции через [Tuist API](https://tuist.dev/api/docs) по пути `/api/accounts/{account_handle}/sandboxes`, или позвольте агенту использовать их через <.localized_link href="/guides/features/agentic-coding/mcp">MCP</.localized_link>.

## Linux и macOS {#platforms}

Песочницы **Linux** работают на Ubuntu 24.04:

- 2 vCPU, 4 GiB RAM (по умолчанию)
- 4 vCPU, 8 GiB RAM
- 8 vCPU, 16 GiB RAM

Песочницы **macOS** работают на Apple Silicon с Xcode:

- 8 vCPU, 8 GiB RAM (по умолчанию)
- 8 vCPU, 16 GiB RAM
- 8 vCPU, 24 GiB RAM

## Безопасность {#security}

- Каждая песочница — это отдельная виртуальная машина. Песочницы не разделяют файловую систему, память или процессы друг с другом или с задачами CI.
- Песочницы принадлежат аккаунту, и только его администраторы могут ими управлять. Сессии от интеграции имеют доступ только к песочницам аккаунта, к которому подключена интеграция.
- Учетные данные, которые вы предоставляете Tuist для подключения интеграции, такие как токен провайдера Amp или ключ среды Claude, хранятся в зашифрованном виде и больше никогда не отображаются.
- Песочница имеет доступ к интернету. Относитесь к тому, что агент может получить из неё, так же, как к задаче CI.
