# Кэш {#cache}

Артефакты сборки не разделяются между окружениями, из-за чего приходится многократно пересобирать один и тот же код. Функция кэширования Tuist позволяет удалённо обмениваться артефактами, чтобы ваша команда и CI получали более быстрые сборки без повторной сборки уже собранного.

> **Самая высокая скорость на Tuist Runners**
>
> На <.localized_link href="/guides/features/runners">Tuist Runners</.localized_link> кэш расположен в частной сети раннера и используется совместно с тем же кэшем, что и машины разработчиков, поэтому задачи CI сразу получают «тёплые» попадания без необходимости отдельного прогрева кэша CI.


## Ограничить загрузки только для CI {#restrict-uploads-to-ci}

Администраторы аккаунта могут настроить права разработчиков только на чтение, разрешив CI загружать артефакты кэша. Откройте настройки **Кэша** аккаунта в Tuist и установите **Доступ на загрузку в кэш** в значение **Только CI и токены аккаунта**. После этого участники, аутентифицированные через сеансы входа, по-прежнему смогут скачивать данные из кэша, но для загрузки потребуется аутентификация CI через OIDC или токен аккаунта с правами на запись в кэш, например `project:cache:write` или `ci`.

Используйте эту настройку, когда CI выступает доверенным источником кэша, а локальные машины должны только потреблять кэш. Настройка влияет только на авторизацию загрузки в кэш.
