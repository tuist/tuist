# Профили {#profiles}

**Профиль** — это именованная конфигурация машины, привязанная к аккаунту. Вы ссылаетесь на него через параметр `runs-on` в рабочем процессе, а Tuist направляет задачу на подходящий раннер. Профили позволяют хранить настройки инфраструктуры (платформа, размер, версия Xcode) в одном месте, вместо того чтобы разбрасывать их по всем файлам рабочих процессов, и дают вам стабильную метку для использования в CI.

```yaml
jobs:
  build:
    runs-on: tuist-macos
```

Метка представляет собой имя профиля с префиксом `tuist-`. Профиль с именем `macos` соответствует значению `runs-on: tuist-macos`; профиль с именем `linux-large` — значению `runs-on: tuist-linux-large`. Сравнение выполняется без учёта регистра.

Каждый аккаунт с включёнными раннерами изначально имеет два профиля, чтобы вы могли использовать пул машин без дополнительной настройки:

{{runner_default_profiles_table}}

Оба указывают на <.localized_link href="/guides/features/runners/profiles#machine-shapes">конфигурацию</.localized_link> по умолчанию для своей платформы. Они **защищены**, поэтому их нельзя удалить, а метки, от которых зависят ваши рабочие процессы, всегда будут разрешаться. Вы можете изменить их конфигурацию или версию Xcode, а также создать дополнительные профили для других размеров или версий Xcode.

## Конфигурации машин {#machine-shapes}

Раннеры доступны на macOS (Apple Silicon, виртуализированные в парке Mac) и Linux. Каждый профиль закрепляет одну конфигурацию машины — пару `(vCPUs, memory)`, выбранную из каталога ниже.

### Linux {#linux}

{{runner_linux_shapes_table}}

Каждый Linux-профиль поддерживает <.localized_link href="/guides/features/runners#android-emulators">аппаратно ускоренные эмуляторы Android</.localized_link> через `/dev/kvm`. Отдельный профиль KVM не требуется.

### macOS {#macos}

{{runner_macos_shapes_table}}

Более крупные конфигурации macOS работают на меньшем количестве машин в парке, поэтому задача, запрашивающая такую конфигурацию, может ждать запуска дольше, чем та же задача на меньшей конфигурации. Выбирайте более крупную конфигурацию, когда задача ограничена производительностью CPU, а для остальных случаев оставляйте конфигурацию по умолчанию. Если вы не уверены, запустите задачу на обеих конфигурациях и сравните длительность выполнения в панели управления.

Профили macOS также закрепляют **версию Xcode**. Версия выбирает образ раннера с предустановленным Xcode, поэтому задачи начинают выполнение с уже готовым инструментарием. Поддерживаемые версии на текущий момент:

> Каталог обновляется по мере добавления нового оборудования и выпусков Xcode. Форма **Новый профиль** в дашборде и `tuist runner profile catalog` всегда показывают конфигурации и версии Xcode, доступные вашему аккаунту прямо сейчас, поэтому считайте их источником истины.

Имя раннера macOS показывает версию macOS, на которой он работает, версию Xcode профиля и его конфигурацию, например `tuist-macos-26.6-xcode-27.0-6vcpu-14gb-1a2b3c4d5e6f`. Это имя отображается в шаге **Set up job** задания на GitHub и в деталях задания в дашборде Tuist.

## Создание профиля {#creating-a-profile}

1. Откройте раздел **Раннеры → Профили** в панели управления вашим аккаунтом.
2. Выберите **Новый профиль**.
3. Задайте имя, выберите платформу и конфигурацию. Для macOS также выберите версию Xcode.
4. Сохраните профиль, а затем ссылку на него из рабочего процесса с помощью `runs-on: tuist-<name>`

Профилями также можно управлять из командной строки. Создание, изменение и удаление профилей требует прав администратора аккаунта, как в дашборде, или токена аккаунта со скоупом `account:runners:write`:

```bash
tuist runner profile catalog
tuist runner profile create linux-large --platform linux --vcpus 8 --memory-gb 32
tuist runner profile update linux-large --vcpus 16 --memory-gb 32
tuist runner profile delete linux-large --yes
```

Агенты могут делать то же самое через <.localized_link href="/guides/features/agentic-coding/mcp">MCP-сервер</.localized_link>

Например, профиль с именем `linux-large` для конфигурации 8 vCPU / 32 ГБ:

```yaml
jobs:
  integration-tests:
    runs-on: tuist-linux-large
```

Или macOS-профиль с именем `xcode-26-4`, закреплённый за Xcode `26.4.1`, чтобы задание могло выполняться на более старой версии тулчейна, пока ваш профиль по умолчанию `macos` отслеживает последнюю:

```yaml
jobs:
  build-legacy:
    runs-on: tuist-xcode-26-4
```
