# Профили {#profiles}

**Профиль** — это именованная конфигурация машины, привязанная к аккаунту. Вы ссылаетесь на него из параметра `runs-on` рабочего процесса, и Tuist направляет задачу на подходящий раннер. Профили позволяют хранить настройки инфраструктуры (платформа, размер, версия Xcode) в одном месте, вместо того чтобы разбрасывать их по всем файлам рабочих процессов, и дают вам стабильную метку для указания в CI.

```yaml
jobs:
  build:
    runs-on: tuist-macos
```

Метка представляет собой имя профиля с префиксом `tuist-`. Профиль с именем `macos` соответствует `runs-on: tuist-macos`; профиль с именем `linux-large` соответствует `runs-on: tuist-linux-large`. Сравнение регистронезависимое.

## Профили по умолчанию {#default-profiles}

Каждый аккаунт с включенными раннерами изначально имеет два профиля, чтобы вы могли использовать пул машин без дополнительной настройки:

{{runner_default_profiles_table}}

Оба указывают на <.localized_link href="/guides/features/runners/profiles#machine-shapes">форму</.localized_link> по умолчанию для своей платформы. Они **защищены**, поэтому их нельзя удалить, и метки, от которых зависят ваши рабочие процессы, всегда разрешаются. Вы всё ещё можете изменить их форму или версию Xcode, а также создать дополнительные профили для других размеров или версий Xcode.

## Конфигурации машин {#machine-shapes}

Раннеры доступны на macOS (Apple silicon, виртуализированные в парке Mac) и Linux. Каждый профиль закрепляет одну форму машины — пару `(vCPUs, memory)`, — из каталога ниже.

### Linux {#linux}

{{runner_linux_shapes_table}}

Каждый Linux-профиль поддерживает <.localized_link href="/guides/features/runners#android-emulators">аппаратно ускоренные эмуляторы Android</.localized_link> через `/dev/kvm`. Отдельный KVM-профиль не требуется.

### macOS {#macos}

{{runner_macos_shapes_table}}

Более мощные конфигурации macOS работают на меньшем количестве машин в пуле, поэтому задача, запрашивающая такую конфигурацию, может ждать запуска дольше, чем та же задача на менее мощной конфигурации. Выбирайте более мощную конфигурацию, когда задача ограничена производительностью CPU, а для всего остального оставляйте конфигурацию по умолчанию. Если вы не уверены, запустите задачу на обеих конфигурациях и сравните время выполнения в дашборде.

Профили macOS также закрепляют **версию Xcode**. Версия выбирает образ раннера с предустановленным Xcode, поэтому задачи запускаются уже с готовым набором инструментов. Поддерживаемые версии на данный момент:

> Каталог обновляется по мере добавления нового оборудования и выпусков Xcode. Форма **Новый профиль** в панели управления и `tuist runner profile catalog` всегда показывают формы и версии Xcode, доступные вашей учетной записи в данный момент, поэтому считайте их источником истины.

Имя раннера macOS показывает версию macOS, на которой он работает, версию Xcode профиля и его форму, например `tuist-macos-26.6-xcode-27.0-6vcpu-14gb-1a2b3c4d5e6f`. Это имя отображается в шаге **Настройка задачи** на GitHub и в деталях задачи в панели управления Tuist.

## Создание профиля {#creating-a-profile}

1. Откройте раздел **Runners → Profiles** в дашборде вашего аккаунта.
2. Выберите **New profile**.
3. Задайте имя, выберите платформу и конфигурацию. Для macOS также выберите версию Xcode.
4. Сохраните, а затем используйте его в рабочем процессе с помощью `runs-on: tuist-<name>`.

Вы также можете управлять профилями из командной строки. Для создания, изменения и удаления профилей требуются права администратора аккаунта, как в панели управления, или токен аккаунта с областью действия `account:runners:write`:

```bash
tuist runner profile catalog
tuist runner profile create linux-large --platform linux --vcpus 8 --memory-gb 32
tuist runner profile update linux-large --vcpus 16 --memory-gb 32
tuist runner profile delete linux-large --yes
```

Агенты могут делать то же самое через <.localized_link href="/guides/features/agentic-coding/mcp">MCP-сервер</.localized_link>.

Например, профиль с именем `linux-large` на конфигурации с 8 vCPU / 32 ГБ:

```yaml
jobs:
  integration-tests:
    runs-on: tuist-linux-large
```

Или профиль macOS с именем `xcode-26-4`, привязанный к Xcode `26.4.1`, чтобы задание могло выполняться на более старой версии инструментария, пока ваш профиль по умолчанию `macos` использует последнюю:

```yaml
jobs:
  build-legacy:
    runs-on: tuist-xcode-26-4
```
