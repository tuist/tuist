# Профили {#profiles}

**Профиль** — это именованная конфигурация машины, привязанная к аккаунту. Вы указываете его в параметре `runs-on` рабочего процесса, и Tuist направляет задачу на подходящий раннер. Профили позволяют хранить настройки инфраструктуры (платформа, размер, версия Ubuntu или Xcode) в одном месте, а не разбрасывать их по всем файлам рабочих процессов, и дают стабильную метку для использования в CI.

```yaml
jobs:
  build:
    runs-on: tuist-macos
```

Метка представляет собой имя профиля с префиксом `tuist-`. Профиль с именем `macos` соответствует `runs-on: tuist-macos`; профиль с именем `linux-large` — `runs-on: tuist-linux-large`. Сравнение регистронезависимое.

Каждый аккаунт с включенными раннерами изначально имеет два профиля, чтобы вы могли использовать пул машин без дополнительной настройки:

{{runner_default_profiles_table}}

Оба указывают на <.localized_link href="/guides/features/runners/profiles#machine-shapes">конфигурацию</.localized_link> по умолчанию для своей платформы. Они **защищены**, поэтому их нельзя удалить, а метки, от которых зависят ваши рабочие процессы, всегда будут разрешаться. Вы можете изменить их конфигурацию или версию Xcode, а также создать дополнительные профили для других размеров или версий Xcode.

## Конфигурации машин {#machine-shapes}

Раннеры доступны на macOS (Apple Silicon, виртуализированные в пуле Mac-машин) и Linux. Каждый профиль фиксирует одну конфигурацию машины — пару `(vCPUs, memory)` — из каталога ниже.

### Linux {#linux}

{{runner_linux_shapes_table}}

Профили Linux также выбирают **версию Ubuntu**, аналогично тому, как профили macOS выбирают версию Xcode:

- **Ubuntu 24.04** (`ubuntu-24.04`), версия по умолчанию для новых профилей.
- **Ubuntu 22.04** (`ubuntu-22.04`), для рабочих процессов, которым она всё ещё нужна. GitHub объявил устаревшим свой хостированный образ 22.04 и удалит его 17 апреля 2027 года; запланируйте переход до этой даты.

Профиль остаётся на выбранной вами версии, пока вы её не измените, поэтому более новая версия по умолчанию никогда сама по себе не перенесёт ваши задачи на другую ОС. Бинарные файлы, собранные на 24.04, требуют более новой glibc (2.39) и могут не работать на старых системах, а системный Python отказывается выполнять `pip install` вне виртуального окружения (PEP 668). Раннер устанавливает переменную `ImageOS` (`ubuntu24` или `ubuntu22`), как это делают раннеры GitHub, чтобы действия настройки выбирали сборки для нужной версии.

Каждый профиль Linux поддерживает <.localized_link href="/guides/features/runners#android-emulators">аппаратно ускоренные эмуляторы Android</.localized_link> через `/dev/kvm`. Отдельный профиль KVM не требуется.

### macOS {#macos}

{{runner_macos_shapes_table}}

Более мощные конфигурации macOS работают на меньшем количестве машин в пуле, поэтому задача, запрашивающая такую конфигурацию, может ждать запуска дольше, чем та же задача на менее мощной конфигурации. Используйте более мощную конфигурацию, когда задача ограничена производительностью CPU, а для остальных случаев оставляйте конфигурацию по умолчанию. Если вы не уверены, запустите задачу на обеих конфигурациях и сравните длительность в дашборде.

Профили macOS также фиксируют **версию Xcode**. Версия выбирает образ раннера с предустановленным Xcode, поэтому задачи начинаются с уже готовым набором инструментов. Поддерживаемые версии на данный момент:

{{runner_macos_xcode_versions}}

> [!NOTE]
> Каталог обновляется по мере добавления нового оборудования и выпусков Xcode. Форма **Новый профиль** в дашборде и команда `tuist runner profile catalog` всегда показывают конфигурации, версии Xcode и выпуски Ubuntu, доступные вашему аккаунту в данный момент, поэтому считайте их источником истины.

Имя раннера macOS показывает версию macOS, на которой он работает, версию Xcode профиля и его конфигурацию, например `tuist-macos-26.6-xcode-27.0-8vcpu-24gb-1a2b3c4d5e6f`. Это имя отображается в шаге **Set up job** задачи на GitHub и в деталях задачи в дашборде Tuist.

## Создание профиля {#creating-a-profile}

1. Откройте раздел **Runners → Profiles** в дашборде вашего аккаунта.
2. Выберите **New profile**.
3. Задайте имя, выберите платформу и конфигурацию. Для Linux также выберите версию Ubuntu; для macOS — версию Xcode.
4. Сохраните, затем используйте профиль в рабочем процессе через `runs-on: tuist-<name>`.

Вы также можете управлять профилями из командной строки. Создание, изменение и удаление профилей требует прав администратора аккаунта, как в дашборде, или токена аккаунта с областью доступа `account:runners:write`:

```bash
tuist runner profile catalog
tuist runner profile create linux-large --platform linux --vcpus 8 --memory-gb 32
tuist runner profile update linux-large --vcpus 16 --memory-gb 32
tuist runner profile delete linux-large --yes
```

Агенты могут делать то же самое через <.localized_link href="/guides/features/agentic-coding/mcp">MCP-сервер</.localized_link>.

Например, профиль с именем `linux-large` на конфигурации 8 vCPU / 32 ГБ:

```yaml
jobs:
  integration-tests:
    runs-on: tuist-linux-large
```

Или профиль macOS с именем `xcode-26-4`, привязанный к Xcode `26.4.1`, чтобы задача могла выполняться на старой версии инструментария, пока ваш профиль `macos` по умолчанию отслеживает последнюю:

```yaml
jobs:
  build-legacy:
    runs-on: tuist-xcode-26-4
```
