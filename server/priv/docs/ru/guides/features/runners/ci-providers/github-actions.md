# GitHub Actions {#github-actions}

> [!IMPORTANT]
> **Только по приглашению**
>
> Туист Раннеры сейчас доступны только по приглашению. [Свяжитесь с нами](mailto:contact@tuist.dev) или напишите нам в [Slack-сообществе](https://slack.tuist.dev), чтобы запросить доступ для вашего аккаунта.

Чтобы запустить задачу в кластере, нужно сделать три изменения: подключить GitHub, указать `runs-on` на <.localized_link href="/guides/features/runners/profiles">профиль</.localized_link> Туист и отправить код.

1. **Запросите доступ.** Во время бета-тестирования раннеры доступны только по приглашению. [Свяжитесь с нами](mailto:contact@tuist.dev), указав аккаунт, который нужно активировать.
2. **Подключите GitHub.** Убедитесь, что ваш проект <.localized_link href="/guides/integrations/gitforge/github">подключён к вашей организации GitHub</.localized_link>. Туист получает события `workflow_job` для этой организации и отправляет соответствующие задачи в кластер. Без этого подключения задачи не попадут на ваши раннеры.
3. **Укажите `runs-on` на профиль Туист.** Каждый активированный аккаунт сразу получает два готовых к использованию <.localized_link href="/guides/features/runners/profiles">профиля</.localized_link>: `linux` и `macos`. Обращайтесь к ним с префиксом `tuist-`:

   ```yaml
   jobs:
     build:
       runs-on: tuist-macos # or tuist-linux
       steps:
         - uses: actions/checkout@v4
         - run: tuist test
   ```

   > [!IMPORTANT]
   > **Выбирайте Xcode через профиль раннера**
   >
   > Образ раннера macOS содержит одну версию Xcode, которую Туист выбирает до начала задачи на основе профиля. Если вы переходите с раннеров, размещённых на GitHub, удалите шаги, использующие `xcode-select --switch` (или `xcode-select -s`) или другие инструменты и действия для переключения версий Xcode. Такие шаги обычно ссылается на установки Xcode, специфичные для образов GitHub, и могут завершиться ошибкой на Туист Раннерах.
   >
   > Чтобы использовать другую версию Xcode, <.localized_link href="/guides/features/runners/profiles#creating-a-profile">создайте или выберите профиль</.localized_link> с этой версией и обновите `runs-on`, например `runs-on: tuist-xcode-26-4`. `xcodebuild`, `xcrun` и `swift` будут использовать выбранную в профиле версию Xcode без дополнительной настройки в рабочем процессе.

4. **Отправьте код и наблюдайте.** Задача ставится в очередь, захватывается раннером, а её логи, шаги и метрики машины транслируются обратно в раздел **Раннеры** вашей панели управления Туист.

## Кэш-тома {#cache-volumes}

Сохраняйте кэши Xcode, модулей и Gradle, а также другие директории между задачами с помощью <.localized_link href="/guides/features/runners/cache-volumes">кэш-томов</.localized_link>. Добавляйте их после 체크아웃 и перед командами, которые их используют.
