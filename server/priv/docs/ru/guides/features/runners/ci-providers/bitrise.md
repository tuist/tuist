# Bitrise {#bitrise}

<!-- @snippet: ./_invite-only -->

> [!WARNING]
> **Только для приватных репозиториев**
>
> Tuist доверяет каждой сборке Bitrise: сборки используют общий кеш вашего аккаунта и могут в него записывать. Не связывайте пул, рабочие процессы которого собирают pull-реквесты из форков публичного репозитория.

Tuist обслуживает пулы собственных раннеров вашего рабочего пространства Bitrise. Сборка, выбирающая один из таких пулов, выполняется на машине Tuist с <.localized_link href="/guides/features/runners/profiles">профилем</.localized_link>, который вы связали с этим пулом. Ваши рабочие процессы, триггеры и логи остаются в Bitrise; меняются только машины.

1. **Подключите рабочее пространство.** В Bitrise откройте **Workspace settings → Security → Workspace API tokens** и создайте токен с ролью рабочего пространства **Viewer** и доступом **Tester/QA** к Bitrise CI для всех проектов. В панели управления Tuist перейдите в **Settings → Integrations**, нажмите **Connect** на карточке Bitrise и вставьте токен. Tuist считывает рабочее пространство из токена, сохраняет его в зашифрованном виде и больше не показывает.
2. **Создайте пул раннеров.** В Bitrise откройте **Workspace settings → Infrastructure**, выберите **Add Runner pool** и дайте ему имя, соответствующее машине, которую он представляет, например `tuist-macos`. Скопируйте токен пула: Bitrise показывает его только один раз.
3. **Свяжите пул с профилем Tuist.** На карточке Bitrise в Tuist в разделе **Runner pools** выберите пул, профиль Tuist, на котором должны выполняться его сборки, вставьте токен пула и нажмите **Add pool**. Каждый активированный аккаунт изначально имеет два профиля: `tuist-linux` и `tuist-macos`. Добавьте по одному пулу для каждого профиля, который хотите использовать.
4. **Выберите пул в вашем рабочем процессе.** В редакторе рабочих процессов Bitrise откройте **Stacks & Machines** и выберите **Self-Hosted Runner: tuist-macos**. В `bitrise.yml` укажите стек пула, который Tuist отображает под названием пула:

   ```yaml
   meta:
     bitrise.io:
       stack: agent-pool-a0c641c0-142f-427d-a326-07f0f6c2a1be
   ```

5. **Запустите сборку.** В течение нескольких секунд машина Tuist подключится к пулу, возьмёт сборку и отключится после её завершения. Сборка появится в разделе **Runners** панели управления Tuist с метриками машины и ссылкой обратно в Bitrise, где хранятся её логи.

## Выделенные пулы {#dedicated-pools}

Используйте пулы, связанные с Tuist, только для Tuist. Если одна из ваших собственных машин также подключится к связанному пулу, она будет конкурировать с Tuist за сборки этого пула.

## Лимит раннеров {#runner-limit}

Каждая машина Tuist считается одним раннером Bitrise во время выполнения сборки и перестаёт учитываться после отключения. Таким образом, лимит раннеров вашего тарифного плана Bitrise ограничивает количество сборок, которые могут одновременно выполняться на Tuist, вместе с вашим лимитом параллельности Tuist.

## Отключение {#disconnecting}

Удаление пула с карточки Bitrace прекращает приём Tuist сборок этого пула. Уже запущенные сборки не затрагиваются.

Выбор **Disconnect** на карточке Bitrise удаляет рабочее пространство и все его пулы.
