# Bitrise {#bitrise}

> [!IMPORTANT]
> **Только по приглашению**
>
> Туист Раннеры сейчас доступны только по приглашению. [Свяжитесь с нами](mailto:contact@tuist.dev) или напишите нам в [Slack-сообществе](https://slack.tuist.dev), чтобы запросить доступ для вашего аккаунта.

> [!WARNING]
> **Только приватные репозитории**
>
> Туист доверяет каждой сборке Bitrise: сборки используют кеш вашего аккаунта и могут записывать в него. Не связывайте пул, чьи воркфлоу собирают pull request'ы из форков публичного репозитория.

Туист обслуживает пулы саморазмещенных раннеров вашего рабочего пространства Bitrise. Сборка, выбирающая один из этих пулов, выполняется на машине Туиста с <.localized_link href="/guides/features/runners/profiles">профилем</.localized_link>, который вы связали с пулом. Ваши воркфлоу, триггеры и логи остаются в Bitrise; меняются только машины.

1. **Запросите доступ.** Во время бета-тестирования раннеры доступны только по приглашению. [Свяжитесь с нами](mailto:contact@tuist.dev), указав аккаунт, который нужно активировать.
2. **Подключите рабочее пространство.** В Bitrise откройте **Настройки рабочего пространства → Безопасность → Токены API рабочего пространства** и создайте токен с ролью рабочего пространства **Viewer** и доступом **Tester/QA** к Bitrise CI для всех проектов. В панели управления Туист перейдите в **Настройки → Интеграции**, выберите **Подключить** на карточке Bitrise и вставьте токен. Туист считывает рабочее пространство из токена, хранит токен в зашифрованном виде и больше никогда его не показывает.
3. **Создайте пул раннеров.** В Bitrise откройте **Настройки рабочего пространства → Инфраструктура**, выберите **Добавить пул раннеров** и назовите его в честь машины, которую он представляет, например `tuist-macos`. Скопируйте токен пула: Bitrise показывает его только один раз.
4. **Свяжите пул с профилем Туист.** На карточке Bitrise в Туисте, в разделе **Пул раннеров**, выберите пул, профиль Туист, на котором должны выполняться его сборки, вставьте токен пула и выберите **Добавить пул**. Каждый активированный аккаунт начинает с двумя профилями: `tuist-linux` и `tuist-macos`. Добавьте по одному пулу для каждого профиля, который хотите использовать.
5. **Выберите пул в вашем воркфлоу.** В редакторе воркфлоу Bitrise откройте **Стеки и машины** и выберите **Саморазмещенный раннер: tuist-macos**. В `bitrise.yml` укажите стек пула, который Туист показывает под названием пула:

   ```yaml
   meta:
     bitrise.io:
       stack: agent-pool-a0c641c0-142f-427d-a326-07f0f6c2a1be
   ```

6. **Запустите сборку.** В течение нескольких секунд машина Туист подключается к пулу, берет сборку и отключается после ее завершения. Сборка появляется в разделе **Раннеры** панели управления Туист с метриками машины и ссылкой обратно в Bitrise, где остаются ее логи.

## Выделенные пулы {#dedicated-pools}

Используйте пулы, связанные с Туист, только для Туист. Если одна из ваших собственных машин также подключается к связанному пулу, она конкурирует с Туист за сборки этого пула.

## Лимит раннеров {#runner-limit}

Каждая машина Туист считается одним раннером Bitrise, пока выполняет сборку, и перестает учитываться после отключения. Лимит раннеров вашего плана Bitrise поэтому ограничивает количество ваших сборок, выполняющихся на Туист одновременно, вместе с лимитом параллельности Туист.

## Отключение {#disconnecting}

Удаление пула с карточки Bitrice прекращает прием сборок этого пула Туист. Уже запущенные сборки не затрагиваются.

Выбор **Отключить** на карточке Bitrise удаляет рабочее пространство и все его пулы.
