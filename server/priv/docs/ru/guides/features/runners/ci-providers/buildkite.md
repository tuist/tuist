# Buildkite {#buildkite}

Tuist отслеживает очереди с собственными агентами в вашем кластере Buildkite и выполняет найденные там задачи на флоте. Ваши пайплайны продолжают работать в Buildkite; меняется только вычислительная среда. Чтобы запустить задачу на флоте, нужно сделать три изменения: подключить кластер, назвать очередь по имени <.localized_link href="/guides/features/runners/profiles">профиля</.localized_link> Tuist и указать её в шаге.

1. **Подключите кластер.** В Buildkite откройте кластер, перейдите в раздел **Agent Tokens** и создайте токен; он начинается с `bkct_`. В панели управления Tuist перейдите в **Settings → Integrations**, нажмите **Connect** на карточке Buildkite и введите slug организации и токен. Токен хранится в зашифрованном виде и больше не отображается. Чтобы позже сменить организацию или обновить токен, отредактируйте поля на карточке и выберите **Save changes**. Tuist начнёт отслеживать кластер в течение минуты.
2. **Назовите очередь по имени профиля Tuist.** Каждый активированный аккаунт получает два готовых к использованию <.localized_link href="/guides/features/runners/profiles">профиля</.localized_link>: `linux` и `macos`. Задача будет подхвачена, если ключ её очереди совпадает с меткой профиля. Создайте в кластере очереди с собственными агентами с ключами `tuist-linux` и `tuist-macos`, затем укажите одну из них в шаге:

   ```yaml
   # .buildkite/pipeline.yml
   steps:
     - label: "Test"
       command: tuist test
       agents:
         queue: tuist-macos # or tuist-linux
   ```

3. **Отправьте код и наблюдайте.** Задача ставится в очередь, захватывается раннером, а её вывод транслируется обратно в раздел **Runners** панели управления Tuist, где можно следить за логами, шагами и метриками машины. Раннер отправляет лог изнутри задачи с учётными данными, ограниченными именно этой задачей, поэтому токен API Buildkite не требуется.

## Приостановка и отключение {#pausing-and-disconnecting}

Приостановка диспетчеризации для очереди Buildkite запрещает Tuist брать из неё новые задачи. Уже выполняющиеся задачи не затрагиваются.

Отключение кластера на карточке Buildkite в разделе **Settings → Integrations** полностью прекращает его отслеживание Tuist.

## Кэш-тома {#cache-volumes}

Сохраняйте кэши Xcode, модулей и Gradle, а также другие директории между задачами с помощью <.localized_link href="/guides/features/runners/cache-volumes">кэш-томов</.localized_link>. Добавляйте их после checkout и перед командами, которые их используют.
