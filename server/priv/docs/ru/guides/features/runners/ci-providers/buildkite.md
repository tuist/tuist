# Buildkite {#buildkite}

<!-- @snippet: ./_invite-only -->

Tuist отслеживает очереди с собственными агентами в вашем кластере Buildkite и выполняет найденные там задачи на флоте. Ваши пайплайны продолжают работать в Buildkite; меняется только вычислительная среда. Чтобы запустить задачу на флоте, нужно сделать три изменения: подключить ваш кластер, назвать очередь по имени <.localized_link href="/guides/features/runners/profiles">профиля</.localized_link> Tuist и указать её в шаге.

1. **Подключите ваш кластер.** В Buildkite откройте ваш кластер, перейдите в раздел **Agent Tokens** и создайте токен; он начинается с `bkct_`. В панели управления Tuist перейдите в **Settings → Integrations**, выберите **Connect** на карточке Buildkite и введите slug вашей организации и токен. Токен хранится в зашифрованном виде и больше не отображается. Чтобы изменить организацию или обновить токен позже, отредактируйте поля на карточке и выберите **Save changes**. Tuist начнёт отслеживать кластер в течение минуты.
2. **Назовите очередь по имени профиля Tuist.** Каждая активированная учётная запись начинает работу с двумя готовыми к использованию <.localized_link href="/guides/features/runners/profiles">профилями</.localized_link>: `linux` и `macos`. Задача будет взята в работу, когда ключ её очереди совпадёт с меткой профиля. Создайте в своём кластере очереди с собственными агентами с ключами `tuist-linux` и `tuist-macos`, затем укажите одну из них в шаге:

   ```yaml
   # .buildkite/pipeline.yml
   steps:
     - label: "Test"
       command: tuist test
       agents:
         queue: tuist-macos # or tuist-linux
   ```

3. **Отправьте изменения и наблюдайте.** Задача ставится в очередь, захватывается раннером, а её выполнение транслируется обратно в раздел **Runners** панели управления Tuist, где вы можете следить за логами, шагами и метриками машины. Раннер отправляет лог изнутри задачи с учётными данными, ограниченными этой одной задачей, поэтому токен API Buildkite не требуется.

## Приостановка и отключение {#pausing-and-disconnecting}

Приостановка диспетчеризации в очереди Buildkite предотвращает получение Tuist новых задач из неё. Уже выполняющиеся задачи не затрагиваются.

Отключение кластера на карточке Buildkite в разделе **Settings → Integrations** полностью прекращает его отслеживание Tuist.

## Кэш-тома {#cache-volumes}

Сохраняйте кэши Xcode, модулей и Gradle, а также другие директории между задачами с помощью <.localized_link href="/guides/features/runners/cache-volumes">кэш-томов</.localized_link>. Добавляйте их после checkout и перед командами, которые их используют.
