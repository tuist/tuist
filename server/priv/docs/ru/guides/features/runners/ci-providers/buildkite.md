# Buildkite {#buildkite}

> [!IMPORTANT]
> **Только по приглашению**
>
> Туист Раннеры сейчас доступны только по приглашению. [Напишите нам](mailto:contact@tuist.dev) или свяжитесь с нами в [Slack-сообществе](https://slack.tuist.dev), чтобы запросить доступ для вашего аккаунта.

Tuist отслеживает очереди с собственными агентами в вашем кластере Buildkite и запускает найденные там задачи на флоте. Ваши пайплайны продолжают работать в Buildkite; меняется только вычислительная среда. Чтобы запустить задачу на флоте, нужно сделать три изменения: подключить ваш кластер, назвать очередь в соответствии с <.localized_link href="/guides/features/runners/profiles">профилем</.localized_link> Tuist и указать её в шаге.

1. **Запросите доступ.** Во время бета-тестирования раннеры доступны только по приглашению. [Напишите нам](mailto:contact@tuist.dev), указав аккаунт, который нужно активировать.
2. **Подключите ваш кластер.** В Buildkite откройте ваш кластер, перейдите в раздел **Agent Tokens** и создайте токен; он начинается с `bkct_`. В панели управления Туист перейдите в **Settings → Integrations**, выберите **Connect** на карточке Buildkite и введите slug вашей организации и токен. Токен хранится в зашифрованном виде и больше не отображается. Чтобы изменить организацию или обновить токен позже, отредактируйте поля на карточке и выберите **Save changes**. Туист начнёт отслеживать кластер в течение минуты.
3. **Назовите очередь в соответствии с профилем Tuist.** Каждая активированная учётная запись начинается с двух готовых к использованию <.localized_link href="/guides/features/runners/profiles">профилей</.localized_link>, `linux` и `macos`, и задача подхватывается, когда ключ её очереди совпадает с меткой профиля. Создайте в своём кластере очереди с собственными агентами с ключами `tuist-linux` и `tuist-macos`, а затем укажите одну из них в шаге:

   ```yaml
   # .buildkite/pipeline.yml
   steps:
     - label: "Test"
       command: tuist test
       agents:
         queue: tuist-macos # or tuist-linux
   ```

4. **Отправьте изменения и наблюдайте.** Задача ставится в очередь, захватывается раннером, а её логи транслируются обратно в раздел **Runners** панели управления Туист, где вы можете следить за логами, шагами и метриками машины. Раннер отправляет лог изнутри задачи с учётными данными, ограниченными этой задачей, поэтому токен API Buildkite не требуется.

## Приостановка и отключение {#pausing-and-disconnecting}

Приостановка диспетчеризации в очереди Buildkite предотвращает получение новых задач Туистом. Уже выполняющиеся задачи не затрагиваются.

Отключение кластера на карточке Buildkite в разделе **Settings → Integrations** полностью прекращает его отслеживание Туистом.

## Кэш-тома {#cache-volumes}

Сохраняйте кэши Xcode, модулей и Gradle, а также другие директории между задачами с помощью <.localized_link href="/guides/features/runners/cache-volumes">томов кэша</.localized_link>. Добавляйте их после операции checkout и перед командами, которые их используют.
