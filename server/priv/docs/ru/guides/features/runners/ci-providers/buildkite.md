# Buildkite {#buildkite}

> [!IMPORTANT]
> **Только по приглашению**
>
> Tuist Runners в настоящее время доступны только по приглашению. [Свяжитесь с нами](mailto:contact@tuist.dev) или напишите нам в [Slack-сообществе](https://slack.tuist.dev), чтобы запросить доступ для вашей учетной записи.

Tuist отслеживает очереди с собственной инфраструктурой в вашем кластере Buildkite и выполняет найденные там задачи на флоте. Ваши пайплайны продолжают работать на Buildkite; меняется только вычислительная среда. Для запуска задачи на флоте требуется три изменения: подключите ваш кластер, назовите очередь в соответствии с <.localized_link href="/guides/features/runners/profiles">профилем</.localized_link> Tuist и укажите её в шаге.

1. **Запросите доступ.** Во время бета-тестирования Runners доступны только по приглашению. [Свяжитесь с нами](mailto:contact@tuist.dev), указав учетную запись, которую нужно активировать.
2. **Подключите ваш кластер.** В Buildkite откройте ваш кластер, перейдите в раздел **Agent Tokens** и создайте токен; он начинается с `bkct_`. В панели управления Tuist перейдите в **Settings → Integrations**, выберите **Connect** на карточке Buildkite и введите slug вашей организации и токен. Токен хранится в зашифрованном виде и больше не отображается. Чтобы изменить организацию или обновить токен позже, отредактируйте поля на карточке и выберите **Save changes**. Tuist начнет отслеживать кластер в течение минуты.
3. **Назовите очередь в соответствии с профилем Tuist.** Каждая активированная учетная запись начинает работу с двумя готовыми к использованию <.localized_link href="/guides/features/runners/profiles">профилями</.localized_link>, `linux` и `macos`, и задача подбирается, когда ключ её очереди совпадает с меткой профиля. Создайте в своем кластере очереди с собственной инфраструктурой с ключами `tuist-linux` и `tuist-macos`, затем укажите одну из них в шаге:

   ```yaml
   # .buildkite/pipeline.yml
   steps:
     - label: "Test"
       command: tuist test
       agents:
         queue: tuist-macos # or tuist-linux
   ```

4. **Отправьте код и наблюдайте.** Задача ставится в очередь, захватывается раннером, а её данные передаются обратно в раздел **Runners** панели управления Tuist, где вы можете отслеживать логи, шаги и метрики машины. Раннер отправляет лог изнутри задачи с учетными данными, ограниченными только этой задачей, поэтому токен API Buildkite не требуется.

## Приостановка и отключение {#pausing-and-disconnecting}

Приостановка диспетчеризации в очереди Buildkite предотвращает получение Tuist новых задач из неё. Уже выполняющиеся задачи не затрагиваются.

Отключение кластера на карточке Buildkite в разделе **Settings → Integrations** полностью прекращает его отслеживание Tuist.

## Кэширующие тома {#cache-volumes}

Сохраняйте кэши Xcode, модулей и Gradle, а также другие директории между задачами с помощью <.localized_link href="/guides/features/runners/cache-volumes">кэширующих томов</.localized_link>. Добавляйте их после получения кода и перед командами, которые их используют.
