# Buildkite {#buildkite}

> [!IMPORTANT]
> **Только по приглашениям**
>
> Tuist Runners сейчас доступны только по приглашениям. [Свяжитесь с нами](mailto:contact@tuist.dev) или напишите нам в [Slack-сообществе](https://slack.tuist.dev), чтобы запросить доступ для вашего аккаунта.

Tuist отслеживает очереди с собственными хостами в вашем кластере Buildkite и запускает найденные там задачи на флоте. Ваши пайплайны продолжают работать в Buildkite; меняется только вычислительная инфраструктура. Для запуска задачи на флоте нужно выполнить три действия: подключить ваш кластер, назвать очередь в соответствии с <.localized_link href="/guides/features/runners/profiles">профилем</.localized_link> Tuist и указать её в шаге.

1. **Запросите доступ.** Во время бета-тестирования Runners доступны только по приглашениям. [Свяжитесь с нами](mailto:contact@tuist.dev), указав аккаунт, который нужно активировать.
2. **Подключите ваш кластер.** В Buildkite откройте ваш кластер, перейдите в раздел **Agent Tokens** и создайте токен; он начинается с `bkct_`. В панели управления Tuist перейдите в **Settings → Integrations**, выберите **Connect** на карточке Buildkite и введите slug вашей организации и токен. Токен хранится в зашифрованном виде и больше не отображается. Чтобы изменить организацию или обновить токен позже, отредактируйте поля на карточке и выберите **Save changes**. Tuist начнёт отслеживать кластер в течение минуты.
3. **Назовите очередь в соответствии с профилем Tuist.** Каждый активированный аккаунт получает два готовых к использованию <.localized_link href="/guides/features/runners/profiles">профиля</.localized_link>, `linux` и `macos`, и задача будет подхвачена, когда ключ её очереди совпадёт с меткой профиля. Создайте в своём кластере очереди с собственными агентами с ключами `tuist-linux` и `tuist-macos`, затем укажите одну из них в шаге сборки:

   ```yaml
   # .buildkite/pipeline.yml
   steps:
     - label: "Test"
       command: tuist test
       agents:
         queue: tuist-macos # or tuist-linux
   ```

4. **Отправьте код и наблюдайте.** Задача попадает в очередь, захватывается раннером, и её вывод передаётся обратно в раздел **Runners** панели управления Tuist, где можно отслеживать логи, шаги и метрики машины. Раннер отправляет лог изнутри задачи, используя учётные данные, ограниченные этой задачей, поэтому токен API Buildkite не требуется.

## Приостановка и отключение {#pausing-and-disconnecting}

Приостановка диспетчеризации для очереди Buildkite останавливает получение новых задач Tuist из этой очереди. Уже запущенные задачи не затрагиваются.

Отключение кластера на карточке Buildkite в разделе **Settings → Integrations** полностью прекращает его отслеживание Tuist.

## Кэширующие тома {#cache-volumes}

Сохраняйте кэши Xcode, модулей и Gradle, а также другие директории между задачами с помощью <.localized_link href="/guides/features/runners/cache-volumes">кэширующих томов</.localized_link>. Добавляйте их после checkout и перед командами, которые их используют.
