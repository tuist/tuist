# Удалённое выполнение Once {#once-remote-execution}

Общий кэш позволяет избежать повторного выполнения работы, которую уже завершил другой компьютер. Удалённое выполнение также переносит допустимые промахи кэша с вашего компьютера: Once планирует действия команд графа на одноразовых Linux-воркерах Tuist и получает их результаты через тот же кэш проекта.

> [!IMPORTANT]
> **Требования**
>
> - Учётная запись Tuist с включённым удалённым выполнением и доступной вычислительной ёмкостью.
> - Версия Once с поддержкой удалённого выполнения Tuist.
> - Совместимый сервер, который объявляет образ воркера, конечную точку кэша, уровень параллелизма и абсолютный каталог выполнения. Серверы, не указывающие каталог, несовместимы с текущим клиентом Once; Once останавливается до начала загрузки работы.
> - Команды и тулчейны, которые могут выполняться на `linux/amd64` внутри объявленного образа воркера.

Это запускает действия графа, а не всю задачу CI. Настройка Once не устанавливает оркестрацию рабочих процессов GitHub или GitLab.

## Настройка {#setup}

Выполните шаги из руководства <.localized_link href="/guides/get-started/once-project">Начало работы с Once</.localized_link>. Выберите одного и того же провайдера Tuist для кэширования и выполнения и зафиксируйте образ воркера, объявленный сервисом:

```toml
[infrastructures.tuist]
kind = "tuist"
account = "acme"
project = "app"
execution_image = "sha-REPLACE_WITH_THE_IMAGE_TAG"

[infrastructure.cache]
provider = "tuist"

[infrastructure.execution]
provider = "tuist"
```

Аутентифицируйтесь с учётными данными, имеющими права на чтение и запись кэша проекта, затем запросите удалённое выполнение:

```bash
once build --remote MyTarget
```

Замените цель и тег образа на свои. Перед загрузкой работы Once проверяет объявленный образ, каталог выполнения, назначение кэша и ёмкость учётной записи. Кэш и выполнение должны указывать на один и тот же проект.

## Подготовка действий для воркеров {#prepare-actions-for-workers}

- Объявите входные и выходные данные. Выходные данные должны оставаться в пределах рабочего каталога действия.
- Разрешайте инструменты внутри образа воркера, а не по абсолютным путям на инициирующем компьютере.
- Используйте действия, безопасные для повторного выполнения: сбой воркера или перезапуск сервиса могут привести к ещё одному запуску.
- Укладывайтесь в лимит сервиса — десять минут на действие. Неподдерживаемые требования, включая запрет сетевого доступа, приводят к ошибке, а не к незаметному локальному выполнению.

Once учитывает объявленную параллельность действий учётной записи и применяет отсрочку, когда очередь сервиса заполнена. Смена образа разделяет конфигурацию сборки и закэшированные результаты, предотвращая повторное использование между несовместимыми образами воркеров.
