# Распределение тестов {#test-sharding}

Современные CI-хосты предоставляют многоядерные среды, которые позволяют в некоторой степени параллелизовать тесты. Однако бывают ситуации, когда возможностей одного хоста недостаточно — например, когда вы ограничены количеством одновременно запускаемых симуляторов или когда ваш набор тестов просто перерастает возможности одной машины.

В таких случаях нужна система, которая распределяет тесты по нескольким CI-раннерам и объединяет результаты в единое представление. Именно этим занимается распределение тестов.

Tuist использует исторические данные о времени выполнения тестов, чтобы интеллектуально сбалансировать нагрузку между шардами с помощью [алгоритма упаковки в контейнеры](https://en.wikipedia.org/wiki/Bin_packing_problem), благодаря чему каждый раннер завершает работу примерно в одно и то же время. Результаты со всех шардов автоматически агрегируются в разделе <.localized_link href="/guides/features/test-insights">Test Insights</.localized_link>, предоставляя единое представление о вашем наборе тестов по всем шардам.
