# Выборочное тестирование {#selective-testing}

По мере роста проектов запуск всех тестов при каждом пуше перестаёт быть целесообразным. Выборочное тестирование Tuist значительно сокращает время тестирования, запуская только те тесты, на которые повлияли изменения с момента последнего успешного запуска, используя наш <.localized_link href="/guides/features/projects/hashing">алгоритм хеширования</.localized_link>.
