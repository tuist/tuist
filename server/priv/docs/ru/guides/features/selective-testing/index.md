# Выборочное тестирование {#selective-testing}

По мере роста проектов запуск всех тестов при каждом пуше становится нецелесообразным. Выборочное тестирование Tuist радикально сокращает время тестирования, запуская только те тесты, на которые повлияли изменения с момента последнего успешного запуска, используя наш <.localized_link href="/guides/features/projects/hashing">алгоритм хеширования</.localized_link>.

## Поддерживаемые системы сборки {#supported-build-systems}

- <.localized_link href="/guides/features/selective-testing/generated-xcode-project">Generated Xcode project</.localized_link>

Планируется поддержка других систем сборки.
