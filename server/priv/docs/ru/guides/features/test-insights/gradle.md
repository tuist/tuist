# Аналитика тестов Gradle {#gradle-test-insights}

Плагин Gradle от Tuist автоматически загружает результаты тестов после каждого выполнения задачи тестирования, предоставляя вам видимость производительности тестов и нестабильных тестов непосредственно в панели управления Tuist.

Аналитика тестов собирается автоматически при применении плагина Tuist Gradle — никакой дополнительной настройки не требуется помимо первоначальной настройки плагина.

Вы можете получить доступ к аналитике тестов в панели управления Tuist и увидеть, как она меняется со временем:

![Панель управления с аналитикой тестов](/images/guides/features/build-insights/tests-dashboard.png)

## Что отслеживается {#what-is-tracked}

Плагин собирает результаты всех задач `Test` Gradle, включая:
- Статус прохождения/сбоя и длительность каждого отдельного тест-кейса
- Структуру наборов тестов и классов
- Обнаружение нестабильных тестов across запусков

## Настройка поведения загрузки {#configure-upload-behavior}

По умолчанию:
- Результаты тестов загружаются в фоновом режиме для локальных сборок.
- Результаты тестов загружаются в активном режиме для запусков в CI, чтобы избежать потери телеметрии на краткоживущих агентах.

Вы можете переопределить это поведение, используя `uploadInBackground` в блоке `tuist` в вашем файле `settings.gradle.kts`:

```kotlin
tuist {
    uploadInBackground = false // always upload in the foreground
}
```

### История Git {#git-history}

В CI плагин также загружает историю коммитов 체크아웃a при отчете о запуске тестов: SHA коммитов, их родительские коммиты, даты коммитов и ветку, в которой находился запуск и базовая ветка его pull request. Содержимое файлов, сообщения коммитов или авторы не загружаются. Это позволяет Tuist определить, какие коммиты попали в вашу основную ветку, например, те, которые тестировала очередь слияния. Плагин читает историю, которая уже есть в 체크아웃е, а если в 체크아웃е нет базовой ветки, запрашивает у удаленного репозитория его последний коммит (`git ls-remote`). Он не загружает историю.

| Переменная | Эффект |
| --- | --- |
| `TUIST_GIT_UPLOAD_ENABLED=false` | Не читает и не загружает никакую историю Git. |
| `TUIST_GIT_UNSHALLOW_ENABLED=false` | Читает только текущий 체크아웃, не обращаясь к удаленному репозиторию. |
