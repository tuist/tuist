# Аналитика тестов Gradle {#gradle-test-insights}

> [!IMPORTANT]
> **Требования**
>
> - Подключён плагин Gradle `dev.tuist`, как описано в руководстве <.localized_link href="/guides/get-started/gradle-project">Начало работы с проектом Gradle</.localized_link>.

Плагин Gradle от Tuist автоматически загружает результаты тестов после каждого запуска задачи тестирования, обеспечивая видимость производительности тестов и нестабильных тестов прямо в панели управления Tuist.

Данные аналитики тестов собираются автоматически после подключения плагина. Дополнительная настройка не требуется.

Вы можете просмотреть аналитику тестов в панели управления Tuist и отслеживать её изменения со временем:

![Панель управления с аналитикой тестов](/images/guides/features/build-insights/tests-dashboard.png)

## Что отслеживается {#what-is-tracked}

Плагин собирает результаты всех задач `Test` Gradle, включая:
- Статус прохождения/сбоя и длительность каждого тест-кейса
- Структуру наборов тестов и классов
- Обнаружение нестабильных тестов across запусков

## Настройка поведения загрузки {#configure-upload-behavior}

По умолчанию:
- Результаты тестов загружаются в фоновом режиме для локальных сборок.
- Результаты тестов загружаются в основном потоке для запусков в CI, чтобы избежать потери телеметрии на краткоживущих агентах.

Вы можете переопределить это поведение, используя `uploadInBackground` в блоке `tuist` в файле `settings.gradle.kts`:

```kotlin
tuist {
    uploadInBackground = false // always upload in the foreground
}
```

### История Git {#git-history}

В CI плагин также загружает историю коммитов 체크아웃a при отчёте о запуске тестов: SHA коммитов, их родительские коммиты, даты коммитов и ветку, в которой выполнялся запуск, а также базовую ветку pull request'а. Содержимое файлов, сообщения коммитов и авторы не загружаются. Это позволяет Tuist определить, какие коммиты попали в вашу основную ветку, например, те, которые проверяла очередь слияний. Плагин читает историю, уже имеющуюся в 체크아웃е, а если в нём нет базовой ветки, запрашивает у удалённого репозитория последний коммит (`git ls-remote`). Он не загружает историю.

| Переменная | Эффект |
| --- | --- |
| `TUIST_GIT_UPLOAD_ENABLED=false` | Не читает и не загружает историю Git. |
| `TUIST_GIT_UNSHALLOW_ENABLED=false` | Читает только содержимое 체크아웃а, не обращаясь к удалённому репозиторию. |
