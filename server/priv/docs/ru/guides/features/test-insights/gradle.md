# Аналитика тестов Gradle {#gradle-test-insights}

Gradle-плагин Tuist автоматически загружает результаты тестов после каждого выполнения задачи тестирования, предоставляя вам видимость производительности тестов и нестабильных тестов прямо в панели управления Tuist.

Данные аналитики тестов собираются автоматически при подключении Gradle-плагина Tuist — дополнительной настройки помимо первоначальной установки плагина не требуется.

Вы можете получить доступ к аналитике тестов в панели управления Tuist и отслеживать её изменения со временем:

![Панель управления с аналитикой тестов](/images/guides/features/build-insights/tests-dashboard.png)

## Что отслеживается {#what-is-tracked}

Плагин собирает результаты всех задач Gradle `Test`, включая:
- Статус прохождения/сбоя и длительность каждого отдельного тест-кейса
- Структуру наборов тестов и классов
- Обнаружение нестабильных тестов across запусков

## Настройка поведения загрузки {#configure-upload-behavior}

По умолчанию:
- Результаты тестов загружаются в фоновом режиме для локальных сборок.
- Результаты тестов загружаются в активном режиме для запусков в CI, чтобы избежать потери телеметрии на кратковременно работающих агентах.

Вы можете переопределить это поведение, используя `uploadInBackground` в блоке `tuist` в вашем файле `settings.gradle.kts`:

```kotlin
tuist {
    uploadInBackground = false // always upload in the foreground
}
```

### История Git {#git-history}

В CI плагин также загружает историю коммитов из рабочей копии при отчёте о запуске тестов: SHA коммитов, их родительские коммиты, даты коммитов и ветку, в которой выполнялся запуск, а также базовую ветку pull request'а. Содержимое файлов, сообщения коммитов и авторы не загружаются. Это позволяет Tuist определить, какие коммиты попали в вашу основную ветку, например те, которые проверяла очередь слияния. Плагин читает историю, уже имеющуюся в рабочей копии, а если в рабочей копии нет базовой ветки, запрашивает у удалённого репозитория последний коммит (`git ls-remote`). История не выкачивается.

| Переменная | Эффект |
| --- | --- |
| `TUIST_GIT_UPLOAD_ENABLED=false` | Не читает и не загружает никакую историю Git. |
| `TUIST_GIT_UNSHALLOW_ENABLED=false` | Читает только рабочую копию, без обращения к удалённому репозиторию. |
