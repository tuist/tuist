# Аналитика тестов Gradle {#gradle-test-insights}

Плагин Tuist для Gradle автоматически загружает результаты тестов после каждого выполнения задачи тестирования, предоставляя вам видимость производительности тестов и нестабильных тестов непосредственно в панели управления Tuist.

Аналитика тестов собирается автоматически при применении плагина Tuist для Gradle — никакой дополнительной настройки не требуется помимо первоначальной установки плагина.

Вы можете получить доступ к аналитике тестов в панели управления Tuist и увидеть, как она меняется со временем:

![Панель управления с аналитикой тестов](/images/guides/features/build-insights/tests-dashboard.png)

## Что отслеживается {#what-is-tracked}

Плагин собирает результаты всех задач `Test` Gradle, включая:
- Статус прохождения/падения и длительность отдельных тестовых случаев
- Структура наборов тестов и классов
- Обнаружение нестабильных тестов между запусками

## Настройка поведения загрузки {#configure-upload-behavior}

По умолчанию:
- Результаты тестов загружаются в фоновом режиме для локальных сборок.
- Результаты тестов загружаются в активном режиме для запусков CI, чтобы избежать потери телеметрии на кратковременно существующих агентах.

Вы можете переопределить это поведение, используя `uploadInBackground` в блоке `tuist` в вашем файле `settings.gradle.kts`:

```kotlin
tuist {
    uploadInBackground = false // always upload in the foreground
}
```

### История Git {#git-history}

В CI плагин также загружает историю коммитов 체크아웃a при отчете о запуске теста: SHA коммитов, их родительские коммиты, даты коммитов и ветку, в которой выполнялся запуск, а также базовую ветку pull request'а. Содержимое файлов, сообщения коммитов или авторы не загружаются. Это позволяет Tuist определить, какие коммиты попали в вашу основную ветку, например, те, которые тестировала очередь слияния. Плагин читает историю, которая уже есть в чек-ауте, и если в чек-ауте нет базовой ветки, запрашивает у удаленного репозитория последний коммит (`git ls-remote`). Он не загружает историю.

| Переменная | Эффект |
| --- | --- |
| `TUIST_GIT_UPLOAD_ENABLED=false` | Не читает и не загружает никакую историю Git. |
| `TUIST_GIT_UNSHALLOW_ENABLED=false` | Читает только чек-аут, не обращаясь к удаленному репозиторию. |
