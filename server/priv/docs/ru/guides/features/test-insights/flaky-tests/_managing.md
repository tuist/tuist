## Управление нестабильными тестами {#managing-flaky-tests}

### Автоматическая очистка {#automatic-clearing}

Обнаружение и очистка выполняются через **автоматизированное оповещение** в проекте. Каждый проект получает автоматизацию «Обнаружение нестабильных тестов» по умолчанию, чей *триггер* помечает тест как нестабильный, а *восстановление* снимает эту пометку, когда тест проходит настроенный период восстановления (по умолчанию **14 дней**) без повторного срабатывания. Отредактируйте её в разделе **Настройки → Автоматизации**, чтобы изменить период восстановления, действия при восстановлении (например, также вывести тест из карантина) или полностью отключить восстановление, чтобы тесты оставались помеченными как нестабильные, пока вы не снимете пометку вручную.

### Ручное управление {#manual-management}

Вы также можете вручную помечать тесты как нестабильные или снимать эту пометку на странице сведений о тест-кейсе. Это полезно, когда:
- Вы хотите отметить известный нестабильный тест, пока работаете над исправлением
- Тест был ошибочно помечен из-за проблем с инфраструктурой
