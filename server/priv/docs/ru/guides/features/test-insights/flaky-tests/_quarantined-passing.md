### Почему тесты в карантине могут отображаться как пройденные {#quarantined-passing}

- **Тесты с игнорированием сбоев** всё равно выполняются. Если такой тест завершается ошибкой, она фиксируется как **ошибка** в запуске тест-кейса и помечается как нестабильная; статус отдельного теста не перезаписывается. Переопределяется только **общий результат запуска тестов**: если все упавшие тест-кейсы в запуске имеют игнорирование сбоев, весь запуск считается успешным, поэтому такие сбои не ломают CI.
- **Пропущенные тесты** вообще не запускаются, поэтому панель продолжает показывать статус последнего фактического выполнения теста. Эти данные могут быть недельной давности.
