### Почему карантинированные тесты могут отображаться как пройденные {#quarantined-passing}

- **Тесты с игнорированием сбоев** всё равно выполняются. Если такой тест завершается ошибкой, она фиксируется как **неудачная** в рамках запуска тест-кейса и помечается как нестабильная; статус отдельного теста не перезаписывается. Переопределяется только **общий результат запуска тестов**: если все неудачные тест-кейсы в запуске имеют игнорирование сбоев, весь запуск считается успешным, поэтому такие сбои не ломают CI.
- **Пропущенные тесты** вообще не выполняются, поэтому на панели управления продолжает отображаться статус последнего фактического выполнения теста. Этот снимок может быть недельной давности.
