### Почему карантинные тесты могут отображаться как пройденные {#quarantined-passing}

- **Тесты с игнорированием сбоев** всё равно выполняются. Если такой тест завершается ошибкой, это фиксируется как **сбой** в запуске тест-кейса и помечается как нестабильный; статус отдельного теста не перезаписывается. Переопределяется только **общий результат запуска тестов**: если все упавшие тест-кейсы в запуске находятся в режиме игнорирования сбоев, весь запуск считается успешным, поэтому такие сбои не ломают CI.
- **Пропущенные тесты** вообще не выполняются, поэтому на панели управления продолжает отображаться статус последнего фактического выполнения теста. Эти данные могут быть устаревшими на несколько недель.
