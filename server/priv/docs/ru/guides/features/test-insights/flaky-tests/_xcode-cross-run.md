### Обнаружение нестабильности между запусками {#cross-run-detection}

Даже без повторных запусков тестов Tuist может обнаруживать нестабильные тесты, сравнивая результаты разных сборок в CI для одного и того же коммита, схемы и указанного назначения (имя устройства, платформа и версия ОС). Если тест проходит в одной подходящей сборке CI, но падает в другой, упавшее выполнение помечается как нестабильное. Это работает независимо от того, какой результат поступил первым.

Один и тот же тест может стабильно вести себя по-разному в разных схемах или на разных назначениях. Например, успешное прохождение на iOS 26 и падение на iOS 27 не свидетельствует о нестабильности. Результаты из разных схем, устройств, платформ или версий ОС не помечают друг друга как нестабильные.

Запуски без метаданных назначения или охватывающие несколько назначений сравниваются только между собой, поэтому различия в окружении между ними всё ещё могут быть отмечены как нестабильность. Обнаружение на основе повторных запусков также применяется.

Это особенно полезно для выявления нестабильных тестов, которые падают недостаточно регулярно, чтобы их поймали повторные запуски, но всё же вызывают периодические сбои в CI.
