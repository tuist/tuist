### Когда проверка не запускается {#when-the-gate-does-not-run}

- Первый проход уже завершился неудачей. Сначала исправьте эти тесты.
- В проекте нет ветки по умолчанию, или в CI ещё ничего не запускалось для неё.
- Более 30% тестовых сценариев проекта выглядят новыми. Повторный запуск такого количества займёт больше времени, чем это оправдано. Это ожидаемо для проекта, который только начал отправлять данные в Tuist, или после переименования, при котором одновременно перемещается много тестов.
