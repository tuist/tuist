### Когда проверка не запускается {#when-the-gate-does-not-run}

- Первый прогон уже завершился с ошибкой. Сначала исправьте эти тесты.
- В проекте нет ветки по умолчанию, или в CI на ней ещё ничего не запускалось.
- Более 30% тест-кейсов проекта выглядят новыми. Повторный запуск такого количества займёт больше времени, чем это оправдано. Это нормально для проекта, который только начал отправлять отчёты в Tuist, или после переименования, при котором одновременно перемещается много тестов.
