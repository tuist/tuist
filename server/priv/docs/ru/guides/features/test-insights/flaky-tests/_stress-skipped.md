### Когда проверка не запускается {#when-the-gate-does-not-run}

- Первый проход уже завершился неудачей. Сначала исправьте эти тесты.
- В проекте нет ветки по умолчанию, или в CI на ней ещё ничего не запускалось.
- Более 30% тестовых случаев проекта выглядят как новые. Повторный запуск такого количества займёт больше времени, чем того стоит. Это ожидаемо для проекта, который только начал отправлять отчёты в Tuist, или после переименования, которое перемещает сразу много тестов.
