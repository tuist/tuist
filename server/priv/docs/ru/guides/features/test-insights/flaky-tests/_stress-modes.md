### Включение {#enabling-stress-testing}

По умолчанию шлюз отключён. Задайте режим:

- **`report`**: предупреждает о каждом нестабильном тест-кейсе. Запуск завершается с собственным кодом возврата.
- **`enforce`**: нестабильный тест-кейс приводит к сбою запуска с тем же кодом выхода, что и при обычном падении теста.

Начните с `report` на пару недель, чтобы понять, что бы заблокировал `enforce`.
