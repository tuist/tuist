### Включение {#enabling-stress-testing}

По умолчанию этот механизм отключён. Задайте режим:

- **`report`**: выводит предупреждение для каждого нестабильного тест-кейса. Завершение прогона определяется его собственным результатом.
- **`enforce`**: нестабильный тест-кейс приводит к сбою прогона с тем же кодом завершения, что и при обычном падении теста.

Начните с `report` на пару недель, чтобы понять, что заблокировал бы `enforce`.
