### Включение {#enabling-stress-testing}

По умолчанию механизм отключён. Выберите режим:

- **`report`**: выводит предупреждение для каждого нестабильного тест-кейса. Завершение прогона определяется его собственным результатом.
- **`enforce`**: нестабильный тест-кейс приводит к сбою прогона с тем же кодом завершения, что и обычный упавший тест.

Начните с `report` на пару недель, чтобы понять, что бы заблокировал `enforce`.
