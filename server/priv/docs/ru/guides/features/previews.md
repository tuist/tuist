# Предпросмотры {#previews}

Tuist Previews позволяют коллегам тестировать мобильные и десктопные приложения, а также инструменты командной строки без локальной пересборки. Опубликуйте сборку в вашем проекте Tuist, а затем поделитесь ссылкой на предпросмотр.

## Что можно просматривать {#what-you-can-preview}

- **Мобильные приложения:** APK для Android и пакеты приложений Apple или IPA. Поддерживаемые устройства, симуляторы и требования к подписи зависят от рабочего процесса публикации.
- **Десктопные приложения:** пакеты приложений macOS.
- **Инструменты командной строки:** исполняемые файлы для macOS или Linux, самостоятельно или вместе с зависимостями.

См. <.localized_link href="/guides/features/previews/types">Поддерживаемые типы</.localized_link> для требований к упаковке и совместимости. Тип артефакта определяет, где может запускаться предпросмотр; он не диктует, какая система сборки его производит.

## Видимость {#visibility}

Предпросмотры используют видимость проекта по умолчанию. Приватные предпросмотры требуют аутентификации и доступа к проекту. Делайте предпросмотры публичными в настройках проекта только тогда, когда сборку можно делиться с кем угодно. Публичная видимость не обходит требования платформы к подписи или установке на устройство.

## Треки {#tracks}

Треки организуют предпросмотры в именованные группы, например `beta` для внутренних тестировщиков или `nightly` для автоматизированных сборок. Укажите трек в команде публикации для вашего рабочего процесса; треки создаются лениво при первом использовании. Используйте их для группировки предпросмотров по назначению и фильтрации предпросмотров в панели управления Tuist.

## Значок для README {#readme-badge}

Добавьте значок в `README` вашего репозитория, который указывает на последний предпросмотр:

[![Tuist Preview](https://tuist.dev/Dimillian/IcySky/previews/latest/badge.svg)](https://tuist.dev/Dimillian/IcySky/previews/latest)

Замените идентификаторы аккаунта и проекта на свои:

```markdown
[![Tuist Preview](https://tuist.dev/{account-handle}/{project-handle}/previews/latest/badge.svg)](https://tuist.dev/{account-handle}/{project-handle}/previews/latest)
```

Если проект содержит несколько приложений с разными идентификаторами пакетов, добавьте параметр запроса `bundle-id`, чтобы выбрать приложение:

```markdown
[![Tuist Preview](https://tuist.dev/{account-handle}/{project-handle}/previews/latest/badge.svg)](https://tuist.dev/{account-handle}/{project-handle}/previews/latest?bundle-id=com.example.app)
```
