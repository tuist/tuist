# Проект Xcode {#xcode-project}

Чтобы добавить пакеты через реестр в проект Xcode, используйте стандартный интерфейс Xcode. Вы можете искать пакеты в реестре, нажав кнопку `+` на вкладке `Package Dependencies` в Xcode. Если пакет доступен в реестре, вы увидите реестр `tuist.dev` в правом верхнем углу:

![Добавление зависимостей пакетов](/images/guides/features/build/registry/registry-add-package.png)

## Разрешение пакетов из системы контроля версий {#resolving-source-control-packages}

Пакеты, объявленные с URL-адресом системы контроля версий (например, транзитивные зависимости добавляемых вами пакетов), по умолчанию разрешаются из системы контроля версий. Команда `tuist registry setup` настраивает Xcode так, чтобы они разрешались из реестра, записывая следующий параметр пользователя:

```bash
defaults write com.apple.dt.Xcode IDEPackageDependencySCMToRegistryTransformation useRegistryIdentityAndSources
```

Затем Xcode разрешает пакет из системы контроля версий через реестр, если в реестре есть эквивалент, и возвращается к системе контроля версий, если его нет.

> [!NOTE]
> Это настройка Xcode для конкретного компьютера, а не параметр проекта, поэтому фиксация файла конфигурации реестра не сделает его доступным для остальной команды. Каждому разработчику нужно один раз выполнить команду `tuist registry setup` на своём компьютере. После этого настройка будет применяться ко всем проектам Xcode на этом компьютере.
