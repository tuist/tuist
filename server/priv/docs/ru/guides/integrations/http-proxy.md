# HTTP-прокси {#http-proxy}

Если в среде задана переменная `HTTPS_PROXY` или `HTTP_PROXY`, Tuist автоматически направляет управляемые им HTTP-соединения через этот прокси. Это относится как к CLI Tuist, так и к плагину Tuist для Gradle, без необходимости дополнительной настройки.

Такое поведение соответствует соглашению, используемому `curl`, `git` и большинством инструментов разработчика, поэтому любая среда, где эти переменные уже настроены для других инструментов, работает с Tuist из коробки.

## Что проксируется {#what-is-proxied}

Через прокси направляются только HTTP-клиенты, принадлежащие Tuist:

- эндпоинты кэша, превью, аналитики и реестра,
- а также вызовы, которые плагин Gradle выполняет к сервисам Tuist (удалённый кэш сборок, аналитика сборок, аналитика тестов, карантин тестов, шардирование тестов).

## Порядок поиска переменных {#variable-lookup-order}

Tuist считывает первое непустое значение в следующем порядке:

1. `HTTPS_PROXY`
2. `https_proxy`
3. `HTTP_PROXY`
4. `http_proxy`

Значение должно быть URL-адресом, например `http://proxy.corp:8080`. Встроенные учётные данные (`http://user:password@proxy.corp:8080`) поддерживаются.
