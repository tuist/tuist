# Интеграция с Origin {#origin}

Tuist может публиковать отчёты о сборках, тестах, превью и бандлах в пул-реквестах нативных репозиториев [Cursor Origin](https://cursor.com/docs/api/origin). Он обновляет существующий отчёт Tuist Run Report приложения вместо того, чтобы оставлять новый комментарий для каждой загрузки.

Установка приложения не запускает сборки или тесты. Ваши существующие рабочие процессы продолжают загружать результаты в Tuist, а интеграция добавляет эти результаты в ваши пул-реквесты.

## Настройка {#setup}

Администратор аккаунта Tuist должен открыть **Settings → Integrations**, выбрать **Install Origin App** в карточке Origin и предоставить доступ в Cursor. Выберите аккаунт или пространство имён Origin и репозитории, к которым Tuist должен получить доступ, затем вернитесь в Tuist. Подключение относится к аккаунту Tuist, а не к отдельному проекту.

Вы также можете установить приложение напрямую из Origin. После предоставления доступа войдите в Tuist, если это необходимо, и выберите организацию для подключения. Доступны только организации, которыми вы управляете, и ваш личный аккаунт. Tuist всегда запрашивает выбор, даже если ваш личный аккаунт — единственный вариант. Если организация Tuist вашей команды не отображается в списке, выберите **Create an organization** или попросите одного из её администраторов сделать вас администратором. Список обновляется, пока страница открыта, поэтому организация появится без необходимости начинать заново, если вы выберете её в течение десяти минут после возвращения в Tuist. Если вы начинаете процесс из Tuist, организация уже выбрана, и этот шаг пропускается.

Выберите **Add new project connection**, чтобы открыть модальное окно выбора репозитория. Выберите неподключённый проект Tuist и один из репозиториев, обнаруженных в подключённом аккаунте Origin, затем выберите **Create Connection**. Если подключено несколько аккаунтов Origin, сначала выберите аккаунт. Для подключения доступны только нативные репозитории Origin. Tuist повторно проверяет доступ к пул-реквестам перед подключением проекта и использует ветку по умолчанию репозитория.

Используйте **Manage integration**, чтобы открыть поток согласия Cursor в новой вкладке и настроить доступ к репозиториям или подключить другой аккаунт Origin. При ошибках загрузки репозиториев отображается кнопка **Retry**, отдельно от успешного пустого списка репозиториев.

Используйте <.localized_link href="/guides/server/authentication#account-tokens">токен аккаунта</.localized_link> для аутентификации загрузки результатов.

## Отчёты и разрешения {#reports-and-permissions}

При одобрении приложения вы предоставляете разрешения, необходимые для подключения репозиториев и публикации отчётов:

| Разрешение | Для чего используется |
| --- | --- |
| Пул-реквесты: чтение | Поиск открытого пул-реквеста для указанного коммита. |
| Ревью пул-реквестов: чтение и запись | Чтение, публикация и обновление комментария Tuist Run Report. |
| Метаданные репозитория: чтение | Обнаружение репозиториев и их веток по умолчанию. Предоставляется автоматически через Origin. |

Tuist не требует доступа к вашему исходному коду или разрешения на слияние пул-реквестов.

Чтобы связать результаты с пул-реквестом, загрузки должны включать URL клонирования Origin репозитория, Git-ссылку и полный SHA коммита. Tuist публикует отчёт только тогда, когда эти данные однозначно идентифицируют один открытый пул-реквест на его текущем головном коммите. Результаты для заменённых коммитов не перезаписывают текущий отчёт.

В карточке Origin перечислены подключения проектов к репозиториям. Выберите **Manage → Remove connection** для подключения проекта, чтобы остановить его отчётность без удаления приложения. Удалите приложение в Cursor, чтобы отозвать его доступ; Tuist удалит установку и её подключения проектов при обработке уведомления об установке.

## Собственные серверы {#server-configuration}

Если вы размещаете собственный сервер Tuist, сначала зарегистрируйте и настройте приложение Origin для вашего развёртывания. Следуйте <.localized_link href="/guides/server/self-host/server#platform-origin">инструкциям по самостоятельному хостингу Origin</.localized_link>, затем вернитесь к шагам настройки выше, чтобы подключить аккаунты и проекты.
