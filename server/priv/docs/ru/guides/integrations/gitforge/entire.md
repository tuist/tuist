# Интеграция с Entire {#entire}

Tuist ведёт сводное обсуждение для каждого открытого или черновика [Trail](https://docs.entire.com/guides/trails/overview) подключённого репозитория. Сводка включает доступные результаты сборки, сбои тестов и нестабильные тесты, размеры бандлов и превью приложений со ссылками на полные отчёты в Tuist.

> [!IMPORTANT]
> **Ранний доступ**
>
> Плагины Entire требуют регистрации партнёра, а обсуждения Trail и контракты вебхуков носят экспериментальный характер. Ваш администратор Tuist может включить интеграцию для всех аккаунтов или выбранных аккаунтов. Ваш проект Entire также должен иметь разрешение на установку зарегистрированного плагина.

## Настройка {#setup}

Установка следует тому же потоку, что и интеграция с GitHub: установите плагин для своего аккаунта, затем подключите репозитории к проектам Tuist. В управляемом Tuist ваш администратор занимается регистрацией плагина и настройкой сервера; вам нужно лишь выполнить шаги ниже.

1. Откройте раздел **Settings → Integrations** вашего аккаунта.
2. В разделе **Entire** выберите **Install Entire plugin**. Выберите проект Entire и репозитории, которыми хотите поделиться с Tuist.

   ![Установите плагин Entire из раздела интеграций аккаунта](/images/guides/integrations/gitforge/entire/integrations.png)

3. Вернувшись в Tuist, выберите **Add new project connection**. В поле **Choose repository to connect to** выберите свой проект Tuist и репозиторий Entire, затем нажмите **Create Connection**. Если доступен только один проект Tuist, он выбирается автоматически.

   ![Подключите проект Tuist к репозиторию Entire](/images/guides/integrations/gitforge/entire/add-project-connection.png)

4. Продолжайте загружать данные аналитики из CI, используя ваши существующие аутентифицированные команды Tuist. Tuist сопоставляет их с текущим SHA коммита каждого Trail; специальные флаги CLI для Entire не нужны.

Проект Tuist может сохранять подключение к GitHub и одновременно публиковать сводки в Entire. Это полезно для зеркал GitHub. Сводки Trail не требуют использования исполнителя CI от Tuist и не меняют вашего текущего провайдера CI.

Tuist обновляет одно и то же обсуждение по мере поступления данных аналитики. При открытии или повторном открытии Trail также подтягиваются ранее загруженные данные для его головного коммита. Закрытые и объединённые Trails не обновляются. Результаты старых коммитов никогда не выдаются за результаты текущего головного коммита. Если для текущего коммита нет данных аналитики, Tuist оставляет существующую сводку без изменений; каждый результат содержит хеш своего коммита.

Чтобы удалить подключение проекта, откройте его меню **Manage** и выберите **Remove connection**, как в случае с GitHub. Это остановит будущие обновления и удалит локальные указатели на обсуждения в Tuist. Уже опубликованные комментарии останутся в Entire. Повторное подключение восстановит существующую сводку, если она всё ещё доступна. Чтобы изменить доступ плагина к репозиториям или удалить его, используйте настройки **Plugins** проекта в Entire.

## Конфигурация сервера {#server-configuration}

Этот раздел предназначен для операторов сервера Tuist. Зарегистрируйте плагин в Entire, используя [руководство по регистрации плагинов](https://docs.entire.com/guides/api/plugins/register). Запросите разрешения `contents:read` и `discussions:write`. Разрешение на чтение необходимо для событий Trail и обнаружения обсуждений; права на запись в репозиторий не требуются.

Настройте следующие переменные окружения сервера:

| Переменная | Назначение |
| --- | --- |
| `TUIST_ENTIRE_PLUGIN_SLUG` | Слаг, подтверждённый Entire |
| `TUIST_ENTIRE_PLUGIN_PRIVATE_KEY` | Закрытый ключ Ed25519 в формате PEM, предоставляемый через ваше хранилище секретов |
| `TUIST_ENTIRE_PLUGIN_KEY_ID` | Идентификатор ключа при использовании регистрации ключей на основе JWKS; в остальных случаях необязательно |
| `TUIST_ENTIRE_CORE_URL` | Entire Core, используемый для запросов на установку; по умолчанию `https://eu.auth.entire.io` |
| `TUIST_ENTIRE_DELIVERY_JWKS_URL` | URL ключа подписи вебхуков, предоставленный Entire при регистрации |

Для управляемых развёртываний Helm сохраните закрытый PEM-ключ в хранилище 1Password среды как `ENTIRE_PLUGIN/private_key`, затем включите `server.config.entirePluginKey.enabled` вместе с `server.config.managedSecrets`. External Secrets передаёт `TUIST_ENTIRE_PLUGIN_PRIVATE_KEY` через существующий Secret server-config, не обрезая многострочный PEM. Имена элемента и поля настраиваются через `server.config.entirePluginKey.item` и `.field`. Это сопоставление по умолчанию отключено и не настраивает слаг или URL ключа подписи вебхуков; укажите их отдельно после регистрации. Каждая среда должна использовать свой собственный ключ подписи. Делитесь с Entire только открытым PEM-ключом, никогда не передавайте закрытый ключ.

Зарегистрируйте `https://<your-tuist-host>/integrations/entire/callback` как URL после установки и `https://<your-tuist-host>/webhooks/entire` как URL вебхука. После применения миграций сервера включите флаг функции `entire_trails` глобально, чтобы предложить интеграцию всем аккаунтам, или включите его для выбранных аккаунтов. Для публичного развёртывания попросите вашего контактного лица в Entire разрешить установку вне проекта-владельца плагина; включение флага функции в Tuist не меняет политику установки в Entire. Сводки Entire Trail не зависят от конфигурации выполнения CI в Tuist и флагов функций.

Tuist проверяет квитанции установки и подписи вебхуков, выпускает краткосрочные токены с областью действия репозитория и определяет текущий регион обработки каждого репозитория перед публикацией. Токены никогда не встраиваются в ссылки на отчёты.
