# Календарь релизов {#release-calendar}

Следите за текущими версиями сервера и Kura, последними релизами и предстоящими окнами выпуска. Информацию о гарантиях каналов, привязке образов и политике бэкпортирования см. в разделе <.localized_link href="/guides/server/self-host/release/channels">Каналы релизов</.localized_link>.

Стабильные обновления запланированы на понедельник в 06:00 UTC вместе с <.localized_link href="/cli/release/calendar">релизным циклом CLI</.localized_link>. Следующий кандидат в релизы формируется только после успешного планового обновления. Сбои могут независимо задержать любой из компонентов, а сопровождающие могут публиковать обновления вне графика. Будущие окна — это планы, а не обещанные сроки публикации.

Патч-релизы и бэкпорты выпускаются по мере необходимости, а не по еженедельному расписанию. В истории ниже опубликованные релизы связаны с их примечаниями и фактическими датами публикации.
