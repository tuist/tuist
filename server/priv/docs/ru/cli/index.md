# CLI {#cli}

Интерфейс командной строки Tuist — один из способов взаимодействия с Tuist и самый распространённый, если вы используете <.localized_link href="/guides/features/projects">сгенерированные проекты</.localized_link>. Он предоставляет команды для генерации проектов, кэширования бинарных артефактов, запуска тестов, обмена превью и многое другое.

## Начало работы {#getting-started}

Если вы ещё не установили Tuist, следуйте <.localized_link href="/guides/install-tuist">руководству по установке</.localized_link>, чтобы начать.

После установки вы можете выполнить `tuist` в терминале, чтобы увидеть список доступных команд:

```bash
tuist --help
```

## Конфигурация {#configuration}

Поведение CLI можно настроить через файл `tuist.toml`. См. <.localized_link href="/references/tuist-toml">справочник по tuist.toml</.localized_link> для всех доступных опций.

## Устранение неполадок {#troubleshooting}

Если возникают проблемы, обратитесь к <.localized_link href="/cli/debugging">руководству по отладке</.localized_link>: там описаны инструменты для диагностики, включая логи сессий и сетевые дампы.
