# Календарь релизов {#release-calendar}

Следите за текущими версиями CLI, последними релизами и предстоящими окнами выпуска. Информацию о гарантиях каналов, фиксации версий и политике бэкпортирования см. в разделе <.localized_link href="/cli/release/channels">Каналы релизов</.localized_link>.

Планируемое продвижение стабильной версии происходит по понедельникам в 06:00 UTC. После успешного запланированного продвижения следующий релиз-кандидат создается из ветки `main`, а последующие канареечные сборки переходят к следующей минорной версии. Сбои могут задержать процесс, а мейнтейнеры могут публиковать обновления вне графика. Будущие окна — это планы, а не обещанные сроки публикации.

Патч-релизы и бэкпорты выпускаются по мере необходимости, а не по еженедельному графику. В истории ниже опубликованные релизы связаны с их примечаниями и фактическими датами публикации.
