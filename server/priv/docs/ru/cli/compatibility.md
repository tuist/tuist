# Совместимость {#compatibility}

Tuist CLI взаимодействует с сервером Tuist для таких возможностей, как кэш, аналитика сборок и тестов, превью и реестр. Сервер обновляется непрерывно и независимо от того, когда вы обновляете CLI, поэтому изменения на сервере не должны ломать используемую вами версию CLI. Чтобы гарантировать это, сервер сохраняет совместимость с недавними релизами CLI в течение определённого периода.

## Период поддержки {#support-window}

Сервер Tuist поддерживает релизы CLI за **последние 3 месяца**. В течение этого периода сервер остаётся обратно совместимым: любой CLI, выпущенный за последние 3 месяца, продолжает выполнять сборки, кэширование и запуск тестов через сервер, и вы можете обновлять CLI по своему графику без риска поломки из-за изменений на сервере.

CLI придерживается [семантического версионирования](https://semver.org). Поддерживаются любые релизы, опубликованные за последние 3 месяца.

## За пределами периода поддержки {#outside-the-window}

Релизы CLI старше периода поддержки считаются устаревшими. Сервер всё ещё отвечает, но:

- Новые серверные возможности могут не работать с этой версией.
- Команды, зависящие от сервера, могут выводить предупреждение с предложением обновиться.

Поведение на устаревших версиях не гарантируется. Если вы используете такую версию, обновитесь до релиза в пределах периода поддержки.

## Как мы выполняем обещание {#how-we-keep-the-promise}

Обратная совместимость проверяется, а не предполагается. Каждое развёртывание сервера запускает автоматизированный приёмочный тест против **самого старого релиза CLI, всё ещё входящего в период поддержки**, которым сейчас является `{{minimum_supported_cli_version}}`, полностью проверяя путь получения данных из кэша. Если изменение сломает эту версию, развёртывание блокируется до попадания в продакшен. Это выполняется параллельно с тестами против последней версии CLI, поэтому регрессии для старых клиентов обнаруживаются так же, как и для самой новой.

## Рекомендация {#recommendation}

Обновляйте CLI как минимум раз в 3 месяца, чтобы оставаться в пределах поддерживаемого периода. Закрепление версии CLI в CI и её регулярное обновление позволяют вашей команде использовать согласованную и поддерживаемую версию.
