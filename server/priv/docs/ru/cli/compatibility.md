# Совместимость {#compatibility}

CLI Tuist взаимодействует с сервером Tuist для использования таких возможностей, как кэш, аналитика сборок и тестов, превью и реестр. Сервер обновляется непрерывно и независимо от того, когда вы обновляете CLI, поэтому изменения на сервере не должны нарушать работу используемой вами версии CLI. Чтобы гарантировать это, сервер сохраняет совместимость с недавними выпусками CLI в течение определённого периода.

## Период поддержки {#support-window}

Сервер Tuist поддерживает выпуски CLI за **последние 3 месяца**. В течение этого периода сервер сохраняет обратную совместимость: любой CLI, выпущенный за последние 3 месяца, продолжает выполнять сборки, кэширование и запуск тестов через сервер, и вы можете обновлять CLI по своему графику без риска поломки из-за изменений на сервере.

CLI следует [семантическому версионированию](https://semver.org). Поддерживаются любые выпуски, опубликованные за последние 3 месяца.

## За пределами периода поддержки {#outside-the-window}

Выпуски CLI старше периода поддержки считаются устаревшими. Сервер всё ещё отвечает, но:

- Новые серверные возможности могут не работать с этой версией.
- Команды, зависящие от сервера, могут выводить предупреждение с просьбой выполнить обновление.

Поведение устаревших версий не гарантируется. Если вы используете такую версию, обновитесь до выпуска, входящего в период поддержки.

## Как мы выполняем обещание {#how-we-keep-the-promise}

Обратная совместимость проверяется, а не предполагается. При каждом развёртывании сервера запускается автоматизированный приёмочный тест против **самой старой версии CLI, всё ещё входящей в период поддержки**, которой сейчас является `{{minimum_supported_cli_version}}`, полностью проверяющий путь получения данных из кэша. Если изменение могло бы нарушить работу этой версии, развёртывание блокируется до попадания в продакшен. Это выполняется параллельно с тестами против последней версии CLI, поэтому регрессии для старых клиентов обнаруживаются так же, как и для новейшей.

## Рекомендация {#recommendation}

Обновляйте CLI как минимум раз в 3 месяца, чтобы оставаться в пределах поддерживаемого периода. Фиксация версии CLI в CI и её регулярное повышение позволяют вашей команде использовать согласованный и поддерживаемый выпуск.
