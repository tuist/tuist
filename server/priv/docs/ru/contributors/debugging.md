# Отладка {#debugging}

Открытость — это практическое преимущество: код доступен, его можно запускать локально, а с помощью AI-агентов для программирования можно быстрее получать ответы и отлаживать возможные ошибки в кодовой базе.

Если во время отладки вы обнаружите недостающую или неполную документацию, обновите англоязычные документы в каталоге `docs/` и создайте pull request.

## Снимки стеков потоков в CI {#thread-dump-ci}

Если CLI периодически зависает, вы можете сделать снимок стеков потоков без остановки процесса. Включите обработчик сигналов и отправьте сигнал `SIGUSR1` работающему процессу `tuist` .

```bash
export TUIST_THREAD_DUMP_SIGNAL=1
export TUIST_THREAD_DUMP_SAMPLE=1 # macOS only, captures all threads via /usr/bin/sample
tuist generate &
TUIST_PID=$!
sleep 600
kill -USR1 "$TUIST_PID"
wait "$TUIST_PID"
```

Если переменная `TUIST_THREAD_DUMP_SAMPLE` не установлена, обработчик выводит стек текущего потока. Вывод записывается в stderr, поэтому он отображается в логах CI.

## Использование AI-агентов для программирования {#use-coding-agents}

AI-агенты для программирования полезны для:

- поиска в кодовой базе мест, где реализовано определённое поведение;
- воспроизведения проблем локально и быстрой итерации;
- отслеживания прохождения входных данных через Tuist для выявления корневой причины.

Предоставьте минимально возможный пример воспроизведения и направьте агента на конкретный компонент (CLI, сервер, кэш, документация или handbook). Чем уже область исследования, тем быстрее и точнее проходит отладка.

### Часто используемые подсказки (FNP) {#frequently-needed-prompts}

#### Неожиданная генерация проекта {#unexpected-project-generation}

Генерация проекта выдаёт результат, который я не ожидаю. Запустите Tuist CLI для моего проекта по пути `/path/to/project`, чтобы понять, почему это происходит. Проследите конвейер генератора и укажите участки кода, ответственные за полученный вывод.

#### Воспроизводимая ошибка в сгенерированных проектах {#reproducible-bug-in-generated-projects}

Похоже, это ошибка в сгенерированных проектах. Создайте воспроизводимый проект в каталоге `examples/`, используя существующие примеры в качестве образца. Добавьте приёмочный тест, который падает, запустите его через `xcodebuild`, выбрав только этот тест, исправьте проблему, повторно запустите тест, чтобы убедиться, что он проходит, и создайте pull request.
