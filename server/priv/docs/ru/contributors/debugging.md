# Отладка {#debugging}

Открытость — это практическое преимущество: код доступен, его можно запустить локально, а с помощью агентов для работы с кодом можно быстрее получать ответы на вопросы и отлаживать потенциальные ошибки в кодовой базе.

Если во время отладки вы обнаружите недостающую или неполную документацию, обновите англоязычную документацию в каталоге `server/priv/docs/en` и создайте PR.

## Снимки стеков потоков в CI {#thread-dump-ci}

Если CLI периодически зависает, можно сделать снимок стека потоков без остановки процесса. Включите обработчик сигналов и отправьте сигнал `SIGUSR1` работающему процессу `tuist`.

```bash
export TUIST_THREAD_DUMP_SIGNAL=1
export TUIST_THREAD_DUMP_SAMPLE=1 # macOS only, captures all threads via /usr/bin/sample
tuist generate &
TUIST_PID=$!
sleep 600
kill -USR1 "$TUIST_PID"
wait "$TUIST_PID"
```

Если переменная `TUIST_THREAD_DUMP_SAMPLE` не установлена, обработчик выводит стек текущего потока. Вывод записывается в stderr, поэтому он отображается в логах CI.

## Использование агентов для работы с кодом {#use-coding-agents}

Агенты для работы с кодом полезны для:

- Поиска в кодовой базе мест, где реализовано определённое поведение.
- Воспроизведения проблем локально и быстрой итерации.
- Отслеживания того, как входные данные проходят через Tuist, чтобы найти первопричину.

Предоставляйте минимально возможный пример воспроизведения и направляйте агента к конкретному компоненту (CLI, сервер, кэш, документация или handbook). Чем уже область исследования, тем быстрее и точнее проходит отладка.

### Часто используемые промпты (FNP) {#frequently-needed-prompts}

#### Неожиданный результат генерации проекта {#unexpected-project-generation}

Генерация проекта выдаёт результат, которого я не ожидаю. Запустите Tuist CLI для моего проекта по пути `/path/to/project`, чтобы понять, почему это происходит. Проследите конвейер генератора и укажите участки кода, ответственные за такой вывод.

#### Воспроизводимая ошибка в сгенерированных проектах {#reproducible-bug-in-generated-projects}

Похоже, это ошибка в сгенерированных проектах. Создайте воспроизводимый проект в каталоге `examples/`, используя существующие примеры как образец. Добавьте падающий приёмочный тест, запустите его через `xcodebuild`, выбрав только этот тест, исправьте проблему, повторно запустите тест, чтобы подтвердить успешное выполнение, и создайте PR.
