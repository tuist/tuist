# Отладка {#debugging}

Открытость — это практическое преимущество: код доступен, его можно запускать локально, а также использовать агентов для программирования, чтобы быстрее получать ответы на вопросы и отлаживать потенциальные ошибки в кодовой базе.

Если во время отладки вы обнаружите отсутствующую или неполную документацию, обновите англоязычные документы в каталоге `docs/` и создайте PR.

## Снимайте дампы потоков в CI {#thread-dump-ci}

Когда CLI периодически зависает, можно сделать дамп потоков без остановки процесса. Включите обработчик сигналов и отправьте сигнал `SIGUSR1` запущенному процессу `tuist` .

```bash
export TUIST_THREAD_DUMP_SIGNAL=1
export TUIST_THREAD_DUMP_SAMPLE=1 # macOS only, captures all threads via /usr/bin/sample
tuist generate &
TUIST_PID=$!
sleep 600
kill -USR1 "$TUIST_PID"
wait "$TUIST_PID"
```

Если переменная `TUIST_THREAD_DUMP_SAMPLE` не установлена, обработчик выводит стек текущего потока. Вывод направляется в stderr, поэтому он отображается в логах CI.

## Используйте агентов для программирования {#use-coding-agents}

Агенты для программирования полезны для:

- Поиска в кодовой базе мест, где реализовано определённое поведение.
- Воспроизведения проблем локально и быстрой итерации.
- Отслеживания того, как входные данные проходят через Tuist, чтобы найти корневую причину.

Предоставляйте минимально возможный пример воспроизведения и направляйте агента на конкретный компонент (CLI, сервер, кэш, документация или handbook). Чем уже область исследования, тем быстрее и точнее проходит отладка.

### Часто используемые запросы (FNP) {#frequently-needed-prompts}

#### Неожиданный результат генерации проекта {#unexpected-project-generation}

Генерация проекта выдаёт результат, который я не ожидаю. Запустите Tuist CLI для моего проекта по пути `/path/to/project`, чтобы понять, почему это происходит. Проследите конвейер генератора и укажите участки кода, ответственные за полученный вывод.

#### Воспроизводимая ошибка в сгенерированных проектах {#reproducible-bug-in-generated-projects}

Похоже, это ошибка в сгенерированных проектах. Создайте воспроизводимый проект в каталоге `examples/`, используя существующие примеры в качестве образца. Добавьте приёмочный тест, который падает, запустите его через `xcodebuild`, выбрав только этот тест, исправьте проблему, повторно запустите тест, чтобы убедиться, что он проходит, и создайте PR.
