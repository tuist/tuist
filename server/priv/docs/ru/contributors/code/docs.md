# Документация {#docs}

Исходный код: [github.com/tuist/tuist/tree/main/server/priv/docs](https://github.com/tuist/tuist/tree/main/server/priv/docs)

## Назначение {#what-it-is-for}

Сайт документации содержит документацию по продукту Tuist и материалы для контрибьюторов. Он является частью сервера Tuist — приложения на Phoenix, которое отображает Markdown-страницы из каталога `server/priv/docs/en` по адресу `/docs`.

## Как внести вклад {#how-to-contribute}

Редактируйте англоязычные страницы в каталоге `server/priv/docs/en`. Переводы управляются отдельно, поэтому не редактируйте каталоги других локалей. Боковая панель определяется в файле `server/lib/tuist/docs_sidebar.ex`; добавляйте новые страницы туда, чтобы читатели могли их найти.

Если несколько страниц содержат одинаковый текст, например один и тот же раздел для разных систем сборки, поместите его в файл с именем, начинающимся с `_`, рядом с этими страницами и включите его с помощью HTML-комментария `@snippet:`, указывающего на файл, как это сделано на страницах о нестабильных тестах. Файлы, имена которых начинаются с `_`, не публикуются как отдельные страницы.

### Локальная настройка {#set-up-locally}

Запустите сервер из каталога `server`, следуя [инструкциям по настройке](https://github.com/tuist/tuist/blob/main/server/AGENTS.md):

```bash
cd server
mise install
mise run dev
```

Затем откройте [http://localhost:8080/en/docs](http://localhost:8080/en/docs).

### Сгенерированный контент {#generated-content}

Справочник CLI генерируется на основе спецификации команд последнего релиза CLI, поэтому его не нужно собирать локально.

Справочник API ProjectDescription размещается отдельно как сайт DocC по адресу [projectdescription.tuist.dev](https://projectdescription.tuist.dev). Чтобы собрать его локально, выполните команду `mise run docs:project-description` из корня репозитория.
