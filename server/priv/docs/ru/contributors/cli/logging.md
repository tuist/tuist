# Логирование {#logging}

CLI использует интерфейс [swift-log](https://github.com/apple/swift-log) для логирования. Пакет абстрагирует детали реализации логирования, позволяя CLI не зависеть от бэкенда логирования. Логгер внедряется через зависимости с помощью task locals и доступен в любом месте через:

```bash
Logger.current
```

> [!NOTE]
> Task locals не передают значение при использовании `Dispatch` или detached tasks, поэтому если вы их используете, вам нужно получить его и передать в асинхронную операцию.


## Что логировать {#what-to-log}

Логи — это не пользовательский интерфейс CLI. Это инструмент для диагностики проблем, когда они возникают. Поэтому чем больше информации вы предоставите, тем лучше. При разработке новых возможностей поставьте себя на место разработчика, столкнувшегося с неожиданным поведением, и подумайте, какая информация была бы ему полезна. Убедитесь, что вы используете правильный [уровень логирования](https://www.swift.org/documentation/server/guides/libraries/log-levels.html). В противном случае разработчики не смогут отфильтровать шум.
