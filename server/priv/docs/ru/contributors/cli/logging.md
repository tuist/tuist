# Логирование {#logging}

CLI использует интерфейс [swift-log](https://github.com/apple/swift-log) для логирования. Пакет скрывает детали реализации логирования, позволяя CLI не зависеть от бэкенда логирования. Логгер внедряется через task locals и доступен в любом месте с помощью:

```bash
Logger.current
```

> [!NOTE]
> Task locals не передают значение при использовании `Dispatch` или detached tasks, поэтому при их использовании нужно получить его и передать в асинхронную операцию.


## Что логировать {#what-to-log}

Логи — это не пользовательский интерфейс CLI. Это инструмент для диагностики проблем по мере их возникновения. Поэтому чем больше информации вы предоставите, тем лучше. При разработке новых возможностей поставьте себя на место разработчика, столкнувшегося с неожиданным поведением, и подумайте, какая информация была бы ему полезна. Убедитесь, что вы используете правильный [уровень логирования](https://www.swift.org/documentation/server/guides/libraries/log-levels.html). Иначе разработчики не смогут отфильтровать лишний шум.
