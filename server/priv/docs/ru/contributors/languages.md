# Языки {#translate}

Языковые барьеры могут мешать пониманию. Мы хотим, чтобы Tuist был доступен как можно большему числу людей. Если вы говорите на языке, который Tuist пока не поддерживает, вы можете помочь проекту освоить этот язык, улучшив исходные тексты на английском и контекст локализации, который использует [Glossia](https://glossia.ai) для перевода.

Поддержка языков — это непрерывный процесс, поэтому мы добавляем новые языки по мере появления участников, готовых помогать с их сопровождением. Сейчас поддерживаются следующие языки:

- Английский
- Арабский
- Испанский
- Японский
- Грузинский
- Корейский
- Русский
- Кантонский
- Упрощённый китайский
- Традиционный китайский

> [!TIP]
> **Запросить новый язык**
>
> Если вы считаете, что Tuist выиграет от поддержки нового языка, создайте новую [тему на форуме сообщества](https://community.tuist.io/c/general/4), чтобы обсудить это с сообществом.


## Как помочь {#how-to-translate}

Поддержка языков в Tuist управляется через репозиторий. Участники обновляют исходные тексты на английском и контекст перевода, а [Glossia](https://glossia.ai) автоматически генерирует локализованные файлы.

Рабочий процесс:

1. Обновите исходное содержимое на английском.
2. При необходимости дополните соответствующий контекст `L10N.md`, чтобы переводчикам было проще.
3. Откройте pull request с этими изменениями в источнике.
4. После того как изменения попадут в `main`, Glossia переведёт всё, что изменилось, и оставит открытым pull request с обновлёнными локализованными файлами.

> [!WARNING]
> **Не изменяйте сгенерированный локализованный контент**
>
> Не редактируйте сгенерированный локализованный контент напрямую. Вместо этого обновляйте исходные тексты на английском и языковой контекст.


## Структура L10N.md {#l10n-md-structure}

Файлы `L10N.md` определяют контекст, который Glossia использует при переводе. Проще всего воспринимать их как инструкции для конкретного языка, которые могут находиться на разных уровнях каталогов.

Например:

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## Контекст каталога {#directory-context}

Glossia проходит от корня репозитория до переводимого каталога и объединяет все найденные на этом пути файлы `L10N.md`.

В примере выше:

- `L10N.md` применяется глобально.
- `server/L10N.md` добавляет контекст, специфичный для сервера.
- `server/L10N/es.md` добавляет переопределения только для испанского языка в той же области.

Это значит, что контекст можно размещать там, где он уместен:

- общие рекомендации для всего репозитория — в корне
- рекомендации для конкретной области — в подкаталоге
- рекомендации для конкретного языка — в `L10N/<locale>.md`
