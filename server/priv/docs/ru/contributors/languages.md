# Языки {#translate}

Языковые барьеры могут мешать пониманию. Мы хотим, чтобы Tuist был доступен как можно большему числу людей. Если вы говорите на языке, который Tuist пока не поддерживает, вы можете помочь проекту освоить этот язык, улучшая исходные тексты на английском и контекст локализации, используемый нашим конвейером перевода.

Поскольку поддержка языков — это непрерывный процесс, мы добавляем новые языки по мере появления участников, готовых помогать с их поддержкой. В настоящее время поддерживаются следующие языки:

- Английский
- Испанский
- Японский
- Грузинский
- Корейский
- Русский
- Кантонский
- Упрощённый китайский
- Традиционный китайский

> [!TIP]
> **Запросить новый язык**
>
> Если вы считаете, что Tuist выиграет от поддержки нового языка, создайте новую [тему на форуме сообщества](https://community.tuist.io/c/general/4), чтобы обсудить это с сообществом.


## Как помочь {#how-to-translate}

Поддержка языков в Tuist управляется через репозиторий. Участники обновляют исходные тексты на английском и контекст перевода, а наш конвейер перевода автоматически генерирует локализованные файлы.

Рабочий процесс:

1. Обновите исходное содержимое на английском языке.
2. Обновите соответствующий контекст `L10N.md`, если переводчикам нужны дополнительные указания.
3. Откройте pull request с этими изменениями в источниках.
4. После того как изменения попадут в ветку `main`, рабочий процесс перевода заново сгенерирует целевые файлы `.po` и откроет следующий pull request с переведёнными обновлениями.

> [!WARNING]
> **Не изменяйте сгенерированный локализованный контент**
>
> Не редактируйте сгенерированный локализованный контент напрямую. Вместо этого обновляйте исходные тексты на английском и языковой контекст.


## Структура L10N.md {#l10n-md-structure}

Файлы `L10N.md` определяют контекст, передаваемый модели перевода. Проще всего рассматривать их как инструкции для конкретного языка, которые могут находиться на разных уровнях каталогов.

Например:

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## Контекст каталога {#directory-context}

Скрипт перевода проходит от корня репозитория до переводимого каталога и объединяет все найденные на этом пути файлы `L10N.md`.

В приведённом выше примере:

- `L10N.md` применяется глобально.
- `server/L10N.md` добавляет контекст, специфичный для сервера.
- `server/L10N/es.md` добавляет переопределения только для испанского языка в той же области.

Это значит, что вы можете размещать контекст там, где ему место:

- руководства для всего репозитория — в корне
- руководства для конкретной области — в подкаталоге
- руководства для конкретного языка — в `L10N/<locale>.md`
