# Языки {#translate}

Языки могут мешать пониманию. Мы хотим, чтобы Tuist был доступен как можно большему числу людей. Если вы говорите на языке, который Tuist пока не поддерживает, вы можете помочь Tuist заговорить на этом языке, улучшив исходные тексты на английском и контекст локализации, который использует [Glossia](https://glossia.ai) для перевода.

Поддержка языков — это непрерывный процесс, поэтому мы добавляем новые языки, когда находим участников, готовых помогать с их поддержкой. В настоящее время поддерживаются следующие языки:

- Английский
- Арабский
- Испанский
- Японский
- Грузинский
- Корейский
- Русский
- Кантонский
- Упрощённый китайский
- Традиционный китайский

> [!TIP]
> **Запросить новый язык**
>
> Если вы считаете, что Tuist выиграет от поддержки нового языка, создайте новую [тему на форуме сообщества](https://community.tuist.io/c/general/4), чтобы обсудить это с сообществом.


## Как помочь {#how-to-translate}

Поддержка языков в Tuist управляется из репозитория. Участники обновляют исходные тексты на английском и контекст перевода, а [Glossia](https://glossia.ai) автоматически генерирует локализованные файлы.

Рабочий процесс:

1. Обновите исходное содержимое на английском.
2. Обновите соответствующий контекст `L10N.md`, если переводчикам нужны дополнительные указания.
3. Откройте pull request с этими изменениями в источниках.
4. После того как изменения попадут в `main`, Glossia переведёт всё, что изменилось, и оставит открытым pull request с переводом, содержащий обновлённые локализованные файлы.

> [!WARNING]
> **Не изменяйте сгенерированное локализованное содержимое**
>
> Не редактируйте сгенерированное локализованное содержимое напрямую. Вместо этого обновите исходные тексты на английском и языковой контекст.


## Структура L10N.md {#l10n-md-structure}

Файлы `L10N.md` определяют контекст, который Glossia использует при переводе. Проще всего воспринимать их как инструкции по языку с определённой областью действия, которые могут находиться на разных уровнях каталогов.

Например:

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## Контекст каталога {#directory-context}

Glossia проходит от корня репозитория до переводимого каталога и объединяет все найденные на этом пути файлы `L10N.md`.

В приведённом выше примере:

- `L10N.md` применяется глобально.
- `server/L10N.md` добавляет контекст, специфичный для сервера.
- `server/L10N/es.md` добавляет переопределения только для испанского языка в той же области.

Это значит, что вы можете размещать контекст там, где ему место:

- руководство для всего репозитория — в корне
- руководство для конкретной области — в подкаталоге
- руководство для конкретного языка — в `L10N/<locale>.md`
