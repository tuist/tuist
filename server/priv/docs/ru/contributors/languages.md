# Языки {#translate}

Языки могут быть барьером для понимания. Мы хотим, чтобы Tuist был доступен как можно большему числу людей. Если вы говорите на языке, который Tuist ещё не поддерживает, вы можете помочь ему заговорить на этом языке, улучшив исходный текст на английском и контекст локализации, который использует [Glossia](https://glossia.ai) для перевода.

Поскольку поддержка языков — это непрерывный процесс, мы добавляем новые языки по мере появления контрибьюторов, готовых помогать с их поддержкой. В настоящее время поддерживаются следующие языки:

- Английский
- Испанский
- Японский
- Грузинский
- Корейский
- Русский
- Кантонский
- Упрощённый китайский
- Традиционный китайский

> [!TIP]
> **Запросить новый язык**
>
> Если вы считаете, что Tuist выиграет от поддержки нового языка, создайте новую [тему на форуме сообщества](https://community.tuist.io/c/general/4), чтобы обсудить это с сообществом.


## Как помочь {#how-to-translate}

Поддержка языков в Tuist осуществляется через репозиторий. Контрибьюторы обновляют исходный текст на английском и контекст перевода, а [Glossia](https://glossia.ai) автоматически генерирует локализованные файлы.

Рабочий процесс:

1. Обновите исходный контент на английском.
2. Обновите соответствующий контекст `L10N.md`, если переводчикам нужны дополнительные указания.
3. Откройте pull request с этими изменениями в источнике.
4. После того как изменения попадут в `main`, Glossia переведёт изменённые части и оставит открытым pull request с обновлёнными локализованными файлами.

> [!WARNING]
> **Не изменяйте сгенерированный локализованный контент**
>
> Не редактируйте сгенерированный локализованный контент напрямую. Вместо этого обновляйте исходный текст на английском и языковой контекст.


## Структура L10N.md {#l10n-md-structure}

Файлы `L10N.md` определяют контекст, который Glossia использует при переводе. Проще всего думать о них как об инструкциях для конкретного языка, которые могут находиться на разных уровнях директорий.

Например:

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## Контекст директории {#directory-context}

Glossia проходит от корня репозитория до переводимой директории и объединяет все найденные на этом пути файлы `L10N.md`.

В приведённом выше примере:

- `L10N.md` применяется глобально.
- `server/L10N.md` добавляет контекст, специфичный для сервера.
- `server/L10N/es.md` добавляет переопределения только для испанского языка в той же области.

Это означает, что вы можете размещать контекст там, где ему место:

- руководства для всего репозитория в корне
- руководства для конкретной области в поддиректории
- руководства для конкретного языка в `L10N/<locale>.md`
