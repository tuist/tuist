# Языки {#translate}

Языки могут быть барьером для понимания. Мы хотим, чтобы Tuist был доступен как можно большему числу людей. Если вы говорите на языке, который Tuist ещё не поддерживает, вы можете помочь Tuist заговорить на этом языке, улучшив исходные тексты на английском и контекст локализации, который управляет нашим конвейером перевода.

Поскольку поддержка языков — это непрерывный процесс, мы добавляем новые языки по мере появления участников, готовых помогать нам с их поддержкой. В настоящее время поддерживаются следующие языки:

- Английский
- Испанский
- Японский
- Грузинский
- Корейский
- Русский
- Кантонский
- Упрощённый китайский
- Традиционный китайский

> [!TIP]
> **Запросить новый язык**
>
> Если вы считаете, что Tuist выиграет от поддержки нового языка, создайте новую [тему на форуме сообщества](https://community.tuist.io/c/general/4), чтобы обсудить это с сообществом.


## Как помочь {#how-to-translate}

Поддержка языков в Tuist обеспечивается через репозиторий. Участники обновляют исходные тексты на английском и контекст перевода, а наш конвейер перевода автоматически создаёт локализованные файлы.

Рабочий процесс выглядит так:

1. Обновите исходное содержимое на английском языке.
2. Обновите соответствующий контекст `L10N.md`, если переводчикам требуются дополнительные указания.
3. Откройте pull request с этими изменениями в исходных файлах.
4. После того как изменения попадут в ветку `main`, рабочий процесс перевода заново сгенерирует целевые файлы `.po` и откроет последующий pull request с переведёнными обновлениями.

> [!WARNING]
> **Не изменяйте сгенерированное локализованное содержимое**
>
> Не редактируйте сгенерированное локализованное содержимое напрямую. Вместо этого обновите исходные тексты на английском и языковой контекст.


## Структура L10N.md {#l10n-md-structure}

Файлы `L10N.md` определяют контекст, который передаётся модели перевода. Проще всего думать о них как об инструкциях для конкретного языка, которые могут находиться на разных уровнях каталогов.

Например:

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## Контекст каталога {#directory-context}

Скрипт перевода проходит от корня репозитория до переводимого каталога и объединяет все файлы `L10N.md`, которые находит на этом пути.

В приведённом выше примере:

- `L10N.md` применяется глобально.
- `server/L10N.md` добавляет контекст, специфичный для сервера.
- `server/L10N/es.md` добавляет переопределения только для испанского языка для той же области.

Это означает, что вы можете размещать контекст там, где ему место:

- руководство для всего репозитория в корне
- руководство для конкретной области в подкаталоге
- руководство для конкретного языка в `L10N/<locale>.md`
