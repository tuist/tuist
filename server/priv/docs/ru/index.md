# Платформа сборки для команд и их агентов кодирования

**Tuist — это платформа сборки для инженерных команд и их агентов кодирования.** Она поддерживает процессы сборки и тестирования в Xcode, Gradle, Bazel, Elixir и Rust; поддержка Once находится в стадии canary. Tuist работает с уже используемыми вами системами сборки, не заменяя их. Доступные возможности зависят от вашего инструментария: проекты на Rust получают аналитику сборок и тестов Cargo, включая doctests, обнаружение нестабильных тестов и экспериментальное кэширование компиляции. Once подключается нативно для общего кэширования, аналитики сборок и тестов, шардирования и поддерживаемых превью приложений.

Выберите один из <.localized_link href="/guides/get-started">путей начала работы</.localized_link> для вашей системы сборки. Once подключается напрямую без CLI Tuist; другие пути объясняют, какие инструменты Tuist нужно установить.
