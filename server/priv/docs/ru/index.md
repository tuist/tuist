# Платформа сборки для команд и их агентов программирования

**Tuist — это платформа сборки для инженерных команд и их агентов программирования.** Она поддерживает рабочие процессы сборки и тестирования в Xcode, Gradle, Bazel, Elixir и Rust; поддержка Struo доступна в канареечном выпуске. Tuist работает с уже используемыми вами системами сборки, не заменяя их. Доступные возможности зависят от вашего инструментария: проекты на Rust получают аналитику по сборкам и тестам Cargo, включая doctests, обнаружение нестабильных тестов и экспериментальное кэширование компиляции. Struo обеспечивает нативную интеграцию для общего кэша, аналитики сборок и тестов, шардирования и поддерживаемых превью приложений.

Выберите один из <.localized_link href="/guides/get-started">путей начала работы</.localized_link> для вашей системы сборки. Struo подключается напрямую без CLI Tuist; другие пути объясняют, какие инструменты Tuist нужно установить.
