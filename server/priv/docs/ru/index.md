# Виртуальная команда платформы для разработчиков, выпускающих обновления

**Tuist помогает командам масштабировать разработку приложений и быстрее выпускать обновления**, превращая сложность больших кодовых баз в продуктивный опыт, который растёт вместе с вашей командой. Он работает с уже используемыми вами системами сборки для проектов на Xcode, Gradle, Bazel, Elixir, Rust и Once. Доступные возможности зависят от вашего инструментария: проекты на Rust получают аналитику сборок и тестов Cargo, включая doctests, обнаружение нестабильных тестов и экспериментальное кэширование компиляции. Once подключается нативно для общего кэширования, аналитики сборок и тестов, шардирования и поддерживаемых превью приложений.

Выберите один из <.localized_link href="/guides/get-started">путей начала работы</.localized_link> для вашей системы сборки. Once подключается напрямую без Tuist CLI; другие пути объясняют, какие инструменты Tuist нужно установить.
