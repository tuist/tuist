# tuist.toml {#tuist-toml}

`tuist.toml` — это конфигурационный файл, не зависящий от системы сборки, и эволюция `Tuist.swift`. В отличие от `Tuist.swift`, он не требует Swift, что позволяет использовать его на любой платформе и с любой системой сборки. Он идеально подходит для сред, где Swift недоступен, например для CI-раннеров на базе Linux, или когда нужно настроить только серверные параметры без полного манифеста `Tuist.swift`.

Tuist ищет `tuist.toml`, поднимаясь вверх по иерархии каталогов от текущего рабочего каталога и останавливаясь на первом совпадении. Это значит, что файл можно разместить в корне проекта и запускать команды Tuist из любого подкаталога.

## Поддерживаемые ключи {#supported-keys}

| Ключ | Тип | Обязательный | По умолчанию | Описание |
| --- | --- | --- | --- | --- |
| `project` | `String` | Да | — | Полный идентификатор вашего проекта (например, `"tuist/tuist"`). |
| `url` | `String` | Нет | `https://tuist.dev` | URL-адрес сервера Tuist. |

### Сеть {#network}

Таблица `[network]` настраивает исходящие HTTP-соединения Tuist.

| Ключ | Тип | Обязательный | По умолчанию | Описание |
| --- | --- | --- | --- | --- |
| `proxy` | `Boolean` | Нет | `true` | Когда `true`, Tuist использует прокси, заданный переменными `HTTPS_PROXY`/`HTTP_PROXY`, если они установлены. См. <.localized_link href="/guides/integrations/http-proxy">руководство по HTTP-прокси</.localized_link>. |
| `ca_certificate` | `String` | Нет | — | Путь к набору CA-сертификатов в формате PEM или DER, которым следует доверять поверх системного хранилища корневых сертификатов, например для самостоятельно размещённого сервера, использующего частный CA. Переменная окружения `TUIST_CA_CERTIFICATE` имеет приоритет. См. <.localized_link href="/cli/debugging#trusting-a-custom-ca-certificate">доверие пользовательскому CA-сертификату</.localized_link>. |

## Пример {#example}

```toml
project = "tuist/tuist"
url = "https://tuist.dev"

[network]
proxy = true
ca_certificate = "/etc/ssl/certs/self-hosted-ca.pem"
```

## Приоритет конфигурации {#configuration-precedence}

Если один и тот же параметр задан в нескольких местах, Tuist определяет его значение согласно следующему порядку приоритета (от высшего к низшему):

1. **Флаги CLI**
2. **Переменные окружения**
3. **Tuist.swift**
4. **tuist.toml**
5. **Значения по умолчанию**
