# Примеры сгенерированных проектов

В этом разделе вы найдете примеры <.localized_link href="/guides/features/projects">сгенерированных проектов</.localized_link>, которые мы используем как [примеры](https://github.com/tuist/tuist/tree/main/examples/xcode) для запуска приемочных тестов.
