# 語言 {#translate}

語言可能造成理解上的障礙。我們希望盡可能讓更多人能夠使用 Tuist。如果你使用的語言尚未受到 Tuist 支援，你可以透過改進英文原始內容以及 [Glossia](https://glossia.ai) 用於翻譯的本機化上下文，協助 Tuist 支援該語言。

由於語言支援是一項持續投入的工作，當我們看到有貢獻者願意協助維護時，就會新增對應的語言。目前支援的語言包括：

- 英文
- 西班牙文
- 日文
- 喬治亞文
- 韓文
- 俄文
- 粵語
- 簡體中文
- 繁體中文

> [!TIP]
> **要求新增語言**
>
> 如果你認為 Tuist 應該支援新的語言，請在[社群論壇建立主題](https://community.tuist.io/c/general/4)，與社群一起討論。


## 如何協助 {#how-to-translate}

Tuist 的語言支援由儲存庫驅動。貢獻者更新英文原始內容與翻譯上下文，[Glossia](https://glossia.ai) 則會自動產生本機化檔案。

工作流程如下：

1. 更新英文原始內容。
2. 如果譯者需要更多指引，請更新相關的 `L10N.md` 上下文。
3. 針對這些原始內容變更開啟 Pull Request。
4. 當變更合併至 `main` 後，Glossia 會翻譯異動內容，並保持一個包含更新後本機化檔案的翻譯 Pull Request 處於開啟狀態。

> [!WARNING]
> **請勿修改產生的本機化內容**
>
> 不要直接編輯產生的本機化內容。請改為更新英文原始內容與語言上下文。


## L10N.md 結構 {#l10n-md-structure}

`L10N.md` 檔案定義 Glossia 在翻譯時使用的上下文。最簡單的理解方式是，將它們視為可放置在不同目錄層級的範圍化語言指示。

例如：

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## 目錄上下文 {#directory-context}

Glossia 會從儲存庫根目錄往下走到正在翻譯的目錄，並合併該路徑上找到的每個 `L10N.md` 檔案。

在上述範例中：

- `L10N.md` 適用於全域。
- `server/L10N.md` 新增伺服器專屬的上下文。
- `server/L10N/es.md` 為相同區域新增僅限西班牙文的覆寫設定。

這表示你可以將上下文放在適當的位置：

- 在根目錄提供整個儲存庫的指引
- 在子目錄中提供特定區域的指引
- 在 `L10N/<locale>.md` 中提供特定語言的指引
