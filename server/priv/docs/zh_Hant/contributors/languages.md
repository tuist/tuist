# 語言 {#translate}

語言可能造成理解上的障礙。我們希望盡可能讓更多人能夠使用 Tuist。如果你使用的語言尚未獲得 Tuist 支援，你可以透過改善英文原始內容與驅動我們翻譯管線的本地化上下文，幫助 Tuist 支援該語言。

由於語言支援是一項持續投入的工作，當我們看到有志貢獻者願意協助維護時，就會新增語言支援。目前支援的語言包括：

- 英文
- 西班牙文
- 日文
- 喬治亞文
- 韓文
- 俄文
- 粵語
- 簡體中文
- 繁體中文

> [!TIP]
> **請求新增語言**
>
> 如果你認為 Tuist 應該支援新語言，請在社群論壇建立新的[討論主題](https://community.tuist.io/c/general/4)，與社群一起討論。


## 如何協助 {#how-to-translate}

Tuist 的語言支援由專案儲存庫驅動。貢獻者更新英文原始內容與翻譯上下文，我們的翻譯管線會自動產生本地化檔案。

工作流程如下：

1. 更新英文原始內容。
2. 如果譯者需要更多指引，請更新相關的 `L10N.md` 上下文。
3. 針對這些原始內容變更開啟拉取請求。
4. 當變更合併至 `main` 後，翻譯工作流程會重新產生目標 `.po` 檔案，並開啟後續的拉取請求以提供翻譯更新。

> [!WARNING]
> **請勿修改已產生的本地化內容**
>
> 不要直接編輯已產生的本地化內容。請改為更新英文原始內容與語言上下文。


## L10N.md 結構 {#l10n-md-structure}

`L10N.md` 檔案定義了傳送給翻譯模型的上下文。最簡單的理解方式是，將它們視為可在不同目錄層級設定的範圍化語言指示。

例如：

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## 目錄上下文 {#directory-context}

翻譯腳本會從儲存庫根目錄向下走訪至待翻譯的目錄，並組合該路徑上找到的每個 `L10N.md` 檔案。

在上述範例中：

- `L10N.md` 適用於全域。
- `server/L10N.md` 新增伺服器專屬的上下文。
- `server/L10N/es.md` 為該區域新增僅限西班牙文的覆寫設定。

這表示你可以將上下文放在適當的位置：

- 在根目錄放置適用於整個儲存庫的指引
- 在子目錄放置特定區域的指引
- 在 `L10N/<locale>.md` 放置特定語言的指引
