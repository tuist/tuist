# 相容性 {#compatibility}

Tuist CLI 會與 Tuist 伺服器通訊，以提供快取、建置與測試洞察、預覽以及 Registry 等功能。伺服器會持續獨立更新，不受你升級 CLI 的時間影響，因此伺服器的變更不應破壞你正在執行的 CLI 版本。為了確保這一點，伺服器會在定義的時間範圍內保持與近期 CLI 版本的相容性。

## 支援時間範圍 {#support-window}

Tuist 伺服器支援 **最近 3 個月**內發布的 CLI 版本。在此時間範圍內，伺服器會保持向後相容：任何在最近 3 個月內發布的 CLI 都能繼續對伺服器進行建置、快取和執行測試，你可以依照自己的時程升級 CLI，而不會因伺服器變更而中斷。

CLI 遵循 [語意化版本控制](https://semver.org)。任何在最近 3 個月內發布的版本都受到支援。

## 超出時間範圍 {#outside-the-window}

超出支援時間範圍的 CLI 版本被視為已棄用。伺服器仍會回應，但：

- 較新的伺服器端功能可能無法在該版本上運作。
- 依賴伺服器的指令可能會印出警告，要求你升級。

不保證棄用版本的行為。如果你使用的是棄用版本，請升級至支援時間範圍內的版本。

## 我們如何履行承諾 {#how-we-keep-the-promise}

向後相容性是經過驗證的，而非假設。每次伺服器部署都會針對 **仍在支援時間範圍內的最舊 CLI 版本**（目前為 `{{minimum_supported_cli_version}}`）執行自動化的驗收測試，完整演練快取拉取路徑。如果某項變更會破壞該版本，部署會在進入生產環境前被阻擋。這項測試會與針對最新 CLI 的測試並行執行，因此舊版用戶端的回歸問題會與最新版用戶端的回歸問題一樣被捕捉到。

## 建議 {#recommendation}

至少每 3 個月升級一次 CLI，以保持在支援時間範圍內。在 CI 中鎖定 CLI 版本並定期更新，可讓你的團隊持續使用一致且受支援的版本。
