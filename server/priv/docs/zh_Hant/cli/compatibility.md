# 相容性 {#compatibility}

Tuist CLI 會與 Tuist 伺服器溝通，以支援快取、建置與測試洞察、預覽以及 Registry 等功能。伺服器會持續獨立發布，不受你升級 CLI 的時間影響，因此伺服器的變更不得破壞你目前執行的 CLI 版本。為確保這一點，伺服器會在既定的時間範圍內，保持與近期 CLI 版本的相容性。

## 支援期間 {#support-window}

Tuist 伺服器支援**最近 3 個月**內發布的 CLI 版本。在此期間內，伺服器維持向後相容：過去 3 個月內發布的任何 CLI 版本都能繼續對伺服器進行建置、快取與執行測試；你可以依照自己的時程升級 CLI，而不會因伺服器變更而中斷。

CLI 遵循[語意化版本控制](https://semver.org)。過去 3 個月內發布的任何版本皆受支援。

## 超出支援期間 {#outside-the-window}

超出支援期間的 CLI 版本視為已棄用。伺服器仍會回應，但：

- 較新的伺服器端功能可能無法在該版本上運作。
- 由伺服器支援的命令可能會顯示警告，要求你升級。

已棄用版本的行為不保證穩定。若你正在使用這類版本，請升級至支援期間內的版本。

## 我們如何履行承諾 {#how-we-keep-the-promise}

向後相容性是經過驗證，而非假設。每次伺服器部署都會針對**仍在支援期間內的最舊 CLI 版本**執行自動化驗收測試，目前為`{{minimum_supported_cli_version}}`，並端到端演練快取拉取流程。若某項變更會破壞該版本，部署會在進入生產環境前遭到封鎖。這項測試會與針對最新 CLI 的測試並行執行，因此舊版用戶端的回歸問題能與最新版一樣被及時發現。

## 建議 {#recommendation}

至少每 3 個月升級一次 CLI，以保持在支援期間內。在 CI 中固定 CLI 版本，並依定期節奏更新，可讓團隊持續使用一致且受支援的版本。
