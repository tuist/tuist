# 相容性 {#compatibility}

Tuist CLI 會與 Tuist 伺服器通訊，以提供快取、建置與測試洞察、預覽以及 Registry 等功能。伺服器持續獨立發布，不受你升級 CLI 的時間影響，因此伺服器變更不得破壞你正在執行的 CLI 版本。為了確保這一點，伺服器會在定義的時間區間內維持與近期 CLI 版本的相容性。

## 支援時間區間 {#support-window}

Tuist 伺服器支援 **最近 3 個月**內的 CLI 版本。在此區間內，伺服器維持向後相容：過去 3 個月內發布的任何 CLI 都能繼續對伺服器執行建置、快取與測試，你可以依照自己的時程升級 CLI，而不會因伺服器變更導致中斷。

CLI 遵循 [語意化版本](https://semver.org)。任何在最近 3 個月內發布的版本都受支援。

## 超出支援區間 {#outside-the-window}

超過支援時間區間的 CLI 版本視為已棄用。伺服器仍會回應，但：

- 較新的伺服器端功能可能無法在該版本上運作。
- 由伺服器支援的指令可能會印出警告，要求你升級。

不保證棄用版本的行為。若你使用的是棄用版本，請升級至支援時間區間內的版本。

## 我們如何履行承諾 {#how-we-keep-the-promise}

向後相容性是經過驗證，而非假設。每次伺服器部署都會針對 **仍在支援區間內最舊的 CLI 版本**（目前為 `{{minimum_supported_cli_version}}`）執行自動化驗收測試，完整演練快取拉取路徑。若某項變更為破壞該版本，部署會在進入生產環境前被阻擋。此測試會與針對最新 CLI 的測試並行執行，因此舊版用戶端的回歸問題會與最新版一樣被及時發現。

## 建議 {#recommendation}

至少每 3 個月升級一次 CLI，以保持在支援區間內。在 CI 中固定 CLI 版本並定期更新，可讓團隊持續使用一致且受支援的版本。
