# 版本發布時程表 {#release-calendar}

追蹤目前的 CLI 版本、近期發布，以及即將到來的發布時段。如需頻道保證、版本鎖定與回溯移植政策，請參閱 <.localized_link href="/cli/release/channels">Release channels</.localized_link>。

穩定版升級排定於每週一 UTC 06:00 進行。在預定的升級成功後，下一個候選版本將從 `main` 分支切出，後續的 Canary 版本則移至下一個次版本。若發生失敗，可能會延遲發布時程；維護者也可能在非預定時間發布。未來的發布時段僅為計畫，並非承諾的發布時間。

修補版本與回溯移植會依需求發布，而非按每週固定時程。下方的歷史記錄將已發布的版本連結至其說明文件與實際發布日期。
