### 跨執行偵測 {#cross-run-detection}

即使沒有測試重試，Tuist 也能透過比較相同提交、方案與回報目的地（裝置名稱、平台與作業系統版本）在不同 CI 執行之間的結果，來偵測不穩定測試。若某項測試在一個相符的 CI 執行中通過，但在另一個中失敗，則將該次失敗的執行標記為不穩定。不論哪一個結果先到達，此機制皆能運作。

同一項測試在不同方案或目的地上可能持續呈現不同行為。例如，在 iOS 26 上通過而在 iOS 27 上失敗，並不會被認定為不穩定。來自不同方案、裝置、平台或作業系統版本的結果，不會互相標記為不穩定。

缺少目的地中繼資料，或涵蓋多個目的地的執行，只會彼此相互比較，因此它們之間的環境差異仍可能被回報為不穩定。基於重試的偵測機制仍然適用。

這對於捕捉那些失敗頻率不足以被重試機制發現、但仍會導致 CI 間歇性失敗的不穩定測試特別有用。
