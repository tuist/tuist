### 跨執行偵測 {#cross-run-detection}

即使未啟用測試重試，Tuist 也能透過比對相同提交、Scheme 與回報的目標裝置（裝置名稱、平台與作業系統版本）在不同 CI 執行中的結果，來偵測不穩定測試。若某個測試在一個相符的 CI 執行中通過，但在另一個中失敗，該失敗的執行會被標記為不穩定。無論哪個結果先到達，此機制皆能運作。

同一個測試在不同 Scheme 或目標裝置上可能呈現一致但不同的行為。例如，在 iOS 26 通過而在 iOS 27 失敗，並不會被判定為不穩定。來自不同 Scheme、裝置、平台或作業系統版本的結果，不會互相標記為不穩定。

缺少目標裝置中繼資料，或涵蓋多個目標裝置的執行，只會彼此相互比對，因此它們之間的環境差異仍可能被回報為不穩定。基於重試的偵測機制仍然適用。

這對於捕捉那些失敗頻率不足以被重試機制抓到，但仍會導致 CI 間歇性失敗的不穩定測試特別有用。
