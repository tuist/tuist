## 管理不穩定測試 {#managing-flaky-tests}

### 自動清除 {#automatic-clearing}

偵測與清除會透過專案上的 **自動化警示** 執行。每個專案都會有一個預設的「不穩定測試偵測」自動化，其 *觸發條件* 會將測試標記為不穩定，而 *復原* 則會在測試於設定的復原視窗（預設為 **14 天**）內未再次觸發後清除標記。前往 **設定 → 自動化** 進行編輯，以變更復原視窗、調整復原動作（例如，同時將測試從隔離中解除），或完全停用復原，讓測試保持標記為不穩定，直到你手動清除為止。

### 手動管理 {#manual-management}

你也可以在測試案例詳情頁面手動將測試標記或取消標記為不穩定。以下情況特別有用：
- 希望在修復已知不穩定測試的同時予以確認
- 測試因基礎設施問題而被錯誤標記
