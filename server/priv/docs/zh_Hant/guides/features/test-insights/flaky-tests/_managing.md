## 管理不穩定測試 {#managing-flaky-tests}

### 自動清除 {#automatic-clearing}

偵測與清除流程會透過專案上的 **自動化警示** 執行。每個專案都會有一個預設的「不穩定測試偵測」自動化規則，其 *觸發條件* 會將測試標記為不穩定，而當測試在設定的恢復期間（預設為 **14 天**）內未再次觸發時，其 *恢復動作* 就會清除該標記。你可以在 **設定 → 自動化** 中編輯此規則，以變更恢復期間、調整恢復動作（例如，同時將測試從隔離區移除），或完全停用恢復功能，讓測試維持不穩定標記，直到你手動清除為止。

### 手動管理 {#manual-management}

你也可以在測試案例詳情頁面中，手動將測試標記為不穩定或取消標記。以下情況特別實用：
- 你想在修補問題的同時，確認已知的不穩定測試
- 測試因基礎設施問題而被錯誤標記
