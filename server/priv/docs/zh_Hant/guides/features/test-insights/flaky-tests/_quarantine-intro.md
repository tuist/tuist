隔離功能可將不穩定測試隔離，使其在您修復期間不會阻礙 CI。預設為**手動操作**：您可在儀表板的測試案例詳情頁面中隔離測試、解除隔離並切換模式。您也可以將其設定為**Settings → Automations**下的**自動化警示**，讓測試在超過不穩定閾值時自動靜音（或略過），並在恢復後解除隔離。每次轉換（無論手動或自動化）都會記錄在測試案例的稽核日誌中。

預設情況下，恢復會等待觸發條件不再成立，因此測試會保持隔離狀態，直到其舊有的不穩定執行離開觸發視窗。若要更快恢復，請將**Recover when**設為**No new flaky runs**：只要在恢復視窗（天數或執行次數）內沒有新的不穩定執行，測試就會恢復；每次出現新的不穩定執行都會重新開始等待；恢復後，只有新的不穩定執行才會再次將其隔離。
