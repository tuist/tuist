# 套件分析 {#bundle-insights}

隨著你為應用程式新增更多功能，套件的體積也會持續成長。其中一部分的成長無法避免，但許多情況其實可以避免：重複的資源、未使用的符號，以及特定平台的浪費都會累積起來。Tuist Bundle Insights 同時支援 **Apple** 與 **Android** 套件，提供工具與分析結果，協助你將應用程式的大小維持在較小範圍，並追蹤其隨時間變化的趨勢。
