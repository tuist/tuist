# 套件洞察 {#bundle-insights}

隨著你為應用程式新增更多功能，套件大小會持續增加。其中部分增長不可避免，但許多並非如此：重複的資源、未使用的符號以及特定平台的浪費都會累積。Tuist Bundle Insights 同時支援 **Apple** 與 **Android** 套件，提供工具與洞察協助你維持較小的應用程式體積，並追蹤隨時間變化的趨勢。
