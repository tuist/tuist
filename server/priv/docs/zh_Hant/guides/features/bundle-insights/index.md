# 套件分析 {#bundle-insights}

隨著你為應用程式新增更多功能，套件大小也會持續增加。其中部分增長不可避免，但許多其實可以避免：重複的資源、未使用的符號，以及特定平台的浪費都會累積起來。Tuist Bundle Insights 同時支援 **Apple** 與 **Android** 套件，提供工具與分析資訊，協助你控制應用程式大小，並追蹤長期趨勢。
