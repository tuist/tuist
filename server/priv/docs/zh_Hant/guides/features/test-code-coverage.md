# 程式碼涵蓋率 {#code-coverage}

程式碼涵蓋率告訴你測試執行了哪些程式碼行。Tuist 會上傳每次測試執行的涵蓋率，並將同一個提交的所有執行結果合併為單一數值，提供每個檔案與整個專案的數據，讓你能在儀表板上逐次追蹤每個提交的進展。
