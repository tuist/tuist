# 程式碼涵蓋率 {#code-coverage}

程式碼涵蓋率告訴你測試執行了哪些程式碼行。Tuist 會上傳每次測試執行的涵蓋率，並將一次提交的多次執行合併為單一數值（按檔案與整個專案），讓你能在儀表板上逐次提交追蹤。
