# 版本發布時程 {#release-calendar}

追蹤目前的 Server 與 Kura 版本、近期發布版本，以及即將到來的發布視窗。如需了解頻道保證、映像檔固定版本及回溯移植政策，請參閱<.localized_link href="/guides/server/self-host/release/channels">發布頻道</.localized_link>。

穩定版升級排定於每週一 UTC 06:00 進行，並與<.localized_link href="/cli/release/calendar">CLI 發布列車</.localized_link>同步。只有在排定的升級成功後，才會建立下一個候選版本。失敗可能會分別延遲任一元件，維護者也可能在非排定時間發布。未來的發布視窗僅為計畫，並非承諾的發布時間。

修補版本與回溯移植會依需求交付，而非按每週時程。下方的歷史記錄將已發布的版本連結至其說明與實際發布日期。
