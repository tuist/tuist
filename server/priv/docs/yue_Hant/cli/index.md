# CLI {#cli}

Tuist CLI 係同 Tuist 互動嘅其中一個介面；如果你使用<.localized_link href="/guides/features/projects">生成項目</.localized_link>，佢就係最常用嘅一個。佢提供生成項目、快取二進制檔案、執行測試、分享預覽等指令。

## 開始使用 {#getting-started}

如果你尚未安裝 Tuist，請跟隨<.localized_link href="/guides/install-tuist">安裝指南</.localized_link>開始。

安裝後，你可以在終端機執行 `tuist` 以查看可用指令清單：

```bash
tuist --help
```

## 設定 {#configuration}

你可以透過 `tuist.toml` 檔案設定 CLI 行為。請參閱<.localized_link href="/references/tuist-toml">tuist.toml 參考文件</.localized_link>了解所有可用選項。

## 疑難排解 {#troubleshooting}

如果遇到問題，請查閱<.localized_link href="/cli/debugging">除錯指南</.localized_link>，當中提供診斷問題嘅工具，包括工作階段記錄同網絡錄製。
