# 相容性 {#compatibility}

Tuist CLI 會與 Tuist 伺服器通訊，以支援快取、構建與測試洞察、預覽及註冊表等功能。伺服器會持續獨立更新，唔受你升級 CLI 嘅時間影響，因此伺服器變更唔應該破壞你目前運行嘅 CLI 版本。為確保這一點，伺服器會在指定時間內保持與近期 CLI 版本相容。

## 支援期 {#support-window}

Tuist 伺服器支援 **過去 3 個月**內發布嘅 CLI 版本。在此期間，伺服器保持向後相容：任何於過去 3 個月內發布嘅 CLI 都可以繼續對伺服器進行構建、快取同運行測試，你可以按自己嘅節奏升級 CLI，而唔會因為伺服器變更而中斷。

CLI 遵循 [語義化版本控制](https://semver.org)。過去 3 個月內發布嘅任何版本都獲支援。

## 超出支援期 {#outside-the-window}

超出支援期嘅 CLI 版本會被視為已棄用。伺服器仍然會回應，但：

- 較新嘅伺服器端功能可能無法與該版本配合使用。
- 由伺服器支援嘅命令可能會顯示警告，提示你升級。

已棄用版本嘅行為不獲保證。如果你正使用其中一個版本，請升級至支援期內嘅版本。

## 我哋如何履行承諾 {#how-we-keep-the-promise}

向後相容性係經過驗證，而非假設。每次伺服器部署都會針對 **仍處於支援期內最舊嘅 CLI 版本**（目前為 `{{minimum_supported_cli_version}}`）運行自動化驗收測試，完整測試快取拉取流程。如果某項變更會破壞該版本，部署會在進入生產環境前被阻止。此測試會與針對最新 CLI 嘅測試一併運行，因此舊版客戶端嘅回歸問題會同最新版一樣被及時發現。

## 建議 {#recommendation}

每 3 個月至少升級一次 CLI，以保持處於支援期內。在 CI 中固定 CLI 版本並定期更新，可確保團隊始終使用一致且獲支援嘅版本。
