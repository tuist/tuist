# 版本日曆 {#release-calendar}

追蹤目前 CLI 版本、最近發布，以及即將到來嘅發布窗口。如需頻道保證、版本鎖定同回溯政策，請參閱 <.localized_link href="/cli/release/channels">Release channels</.localized_link>。

穩定版升級定於星期一 UTC 06:00 進行。成功完成預定升級後，下一個候選版本會從 `main` 切出，隨後嘅 Canary 版本會轉入下一個次要版本。失敗可能會延誤進度，維護者亦可能喺預定時間以外發布。未來窗口僅屬計劃，並非承諾嘅發布時間。

修補版本同回溯按需發布，而非按每週時間表。以下歷史記錄將已發布版本連結到其說明同實際發布日期。
