# 發佈日曆 {#release-calendar}

追蹤最新 CLI 版本、近期發佈以及即將到來的發佈窗口。如需了解頻道保證、版本鎖定及回溯移植政策，請參閱 <.localized_link href="/cli/release/channels">Release channels</.localized_link>。

穩定版升級定於每週一 UTC 06:00 進行。成功完成預定升級後，下一個候選發佈版將從 `main` 分支建立，隨後的 Canary 版本則會移至下一個次要版本。若出現失敗可能會延誤整體進度，而維護者亦可在預定時間之外進行發佈。未來的時間窗口僅屬計劃，並非承諾的具體發佈時間。

修補版本及回溯移植會按需提供，而非遵循每週排程。下方的歷史記錄會將已發佈的版本連結至其相關說明及實際發佈日期。
