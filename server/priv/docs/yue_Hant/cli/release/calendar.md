# 發布日曆 {#release-calendar}

追蹤最新 CLI 版本、近期發布及即將到來的發布時段。如要了解頻道保證、版本鎖定及回溯移植政策，請參閱 <.localized_link href="/cli/release/channels">發布頻道</.localized_link>。

穩定版升級定於每週一 UTC 06:00 進行。成功完成預定升級後，會從 `main` 建立下一個候選發布版本，後續的 Canary 版本則移至下一個次要版本。若出現失敗，可能會延誤發布進程；維護者亦可在預定時間以外發布。未來的發布時段僅屬計劃，並非承諾的發布時間。

修補版本及回溯移植按需提供，而非按每週排程。以下歷史記錄將已發布的版本連結至其說明文件及實際發布日期。
