# 語言 {#translate}

語言可能會成為理解的障礙。我哋希望確保 Tuist 能夠盡可能讓更多人使用。如果你識講一種 Tuist 尚未支援的語言，你可以透過改進英文原文同 [Glossia](https://glossia.ai) 用於翻譯的本地化上下文，幫助 Tuist 支援該語言。

由於語言支援係一項持續的工作，我哋會喺見到有貢獻者願意協助維護時，先至加入新語言。目前支援以下語言：

- 英文
- 西班牙文
- 日文
- 格魯吉亞文
- 韓文
- 俄文
- 廣東話
- 簡體中文
- 繁體中文

> [!TIP]
> **請求新增語言**
>
> 如果你認為 Tuist 支援新語言會有幫助，請建立一個新的 [社區論壇主題](https://community.tuist.io/c/general/4) 同社區討論。


## 如何提供幫助 {#how-to-translate}

Tuist 的語言支援由儲存庫驅動。貢獻者更新英文原文同翻譯上下文，然後 [Glossia](https://glossia.ai) 會自動產生本地化檔案。

工作流程如下：

1. 更新英文原文內容。
2. 如果譯者需要更多指引，請更新相關的 `L10N.md` 上下文。
3. 開啟包含這些原始碼變更的拉取請求。
4. 當變更合併到 `main` 後，Glossia 會翻譯變更部分，並保持一個包含更新本地化檔案的翻譯拉取請求處於開啟狀態。

> [!WARNING]
> **請勿修改生成的本地化內容**
>
> 切勿直接編輯生成的本地化內容。請改為更新英文原文同語言上下文。


## L10N.md 結構 {#l10n-md-structure}

`L10N.md` 檔案定義咗 Glossia 翻譯時使用的上下文。最簡單的理解方式，係將佢哋視為可以放喺唔同目錄層級的範圍化語言指示。

例如：

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## 目錄上下文 {#directory-context}

Glossia 會從儲存庫根目錄向下遍歷至正在翻譯的目錄，並組合喺該路徑上找到的每個 `L10N.md` 檔案。

喺上面的例子中：

- `L10N.md` 全局適用。
- `server/L10N.md` 添加伺服器特定的上下文。
- `server/L10N/es.md` 為同一區域添加僅限西班牙文的覆蓋設定。

這意味著你可以將上下文放在合適的位置：

- 喺根目錄放置適用於整個儲存庫的指引
- 喺子目錄中放置特定區域的指引
- 喺 `L10N/<locale>.md` 中放置特定語言的指引
