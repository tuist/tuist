# 語言 {#translate}

語言可能會成為理解嘅障礙。我哋希望確保盡可能多嘅人都可以使用 Tuist。如果你講一種 Tuist 尚未支援嘅語言，你可以透過改善英文原文同埋 [Glossia](https://glossia.ai) 用於翻譯嘅本地化上下文，幫助 Tuist 支援該語言。

由於語言支援係一項持續進行嘅工作，當我哋發現有貢獻者願意協助維護時，就會新增語言支援。目前支援以下語言：

- 英文
- 阿拉伯文
- 西班牙文
- 日文
- 格魯吉亞文
- 韓文
- 俄文
- 粵語
- 簡體中文
- 繁體中文

> [!TIP]
> **請求新增語言**
>
> 如果你認為 Tuist 應該支援新語言，請喺[社區論壇](https://community.tuist.io/c/general/4)開一個新主題，同社區成員討論。


## 如何參與 {#how-to-translate}

Tuist 嘅語言支援由儲存庫驅動。貢獻者更新英文原文同翻譯上下文，然後由 [Glossia](https://glossia.ai) 自動生成本地化檔案。

工作流程如下：

1. 更新英文原文內容。
2. 如果譯者需要更多指引，請更新相關嘅 `L10N.md` 上下文。
3. 就呢啲來源變更開啟拉取請求。
4. 當變更合併到 `main` 之後，Glossia 會翻譯變更部分，並保持一個包含更新後本地化檔案嘅翻譯拉取請求處於開啟狀態。

> [!WARNING]
> **切勿修改生成嘅本地化內容**
>
> 唔好直接編輯生成嘅本地化內容。請改為更新英文原文同語言上下文。


## L10N.md 結構 {#l10n-md-structure}

`L10N.md` 檔案定義咗 Glossia 翻譯時使用嘅上下文。最簡單嘅理解方式係將佢哋視為可以存放喺不同目錄層級嘅範圍化語言指令。

例如：

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## 目錄上下文 {#directory-context}

Glossia 會從儲存庫根目錄向下遍歷至被翻譯嘅目錄，並組合沿途找到嘅每一個 `L10N.md` 檔案。

喺上面嘅例子中：

- `L10N.md` 全局適用。
- `server/L10N.md` 添加伺服器特定嘅上下文。
- `server/L10N/es.md` 為同一區域添加僅限西班牙文嘅覆蓋設定。

這意味著你可以將上下文放置喺適當嘅位置：

- 喺根目錄放置適用於整個儲存庫嘅指引
- 喺子目錄放置特定區域嘅指引
- 喺 `L10N/<locale>.md` 放置特定語言嘅指引
