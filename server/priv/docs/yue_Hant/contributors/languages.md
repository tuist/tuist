# 語言 {#translate}

語言可能會成為理解的障礙。我哋希望確保 Tuist 能夠讓盡可能多的人使用。如果你講嘅語言 Tuist 尚未支援，你可以透過改進英文原文同驅動我哋翻譯流程的本地化上下文，幫助 Tuist 支援該語言。

由於語言支援係一項持續的工作，當我哋見到有貢獻者願意協助維護時，就會加入新語言。目前支援以下語言：

- 英文
- 西班牙文
- 日文
- 格魯吉亞文
- 韓文
- 俄文
- 粵語
- 簡體中文
- 繁體中文

> [!TIP]
> **請求新增語言**
>
> 如果你認為 Tuist 支援新語言會帶來好處，請建立一個新的[社區論壇主題](https://community.tuist.io/c/general/4)，與社區討論。


## 如何提供幫助 {#how-to-translate}

Tuist 的語言支援由代碼庫驅動。貢獻者更新英文原文同翻譯上下文，我哋的翻譯流程會自動生成本地化文件。

工作流程如下：

1. 更新英文原文內容。
2. 如果譯者需要更多指引，請更新相關的 `L10N.md` 上下文。
3. 提交包含這些源更改的拉取請求。
4. 當更改合併到 `main` 後，翻譯工作流程會重新生成目標 `.po` 文件，並開啟一個後續拉取請求以包含翻譯更新。

> [!WARNING]
> **切勿修改生成的本地化內容**
>
> 請勿直接編輯生成的本地化內容。應更新英文原文同語言上下文。


## L10N.md 結構 {#l10n-md-structure}

`L10N.md` 文件定義了發送給翻譯模型的上下文。最簡單的理解方式係將它們視為可以存在於不同目錄層級的範圍化語言指令。

例如：

```text
.
|-- L10N.md
|-- server
|   |-- L10N.md
|   |-- L10N
|   |   `-- es.md
|   `-- priv
|       `-- gettext
|           `-- marketing.pot
```


## 目錄上下文 {#directory-context}

翻譯腳本會從代碼庫根目錄向下遍歷到正在翻譯的目錄，並組合在該路徑上找到的每個 `L10N.md` 文件。

在上述例子中：

- `L10N.md` 全局適用。
- `server/L10N.md` 添加服務器特定的上下文。
- `server/L10N/es.md` 為同一區域添加僅限西班牙文的覆蓋。

這意味著你可以將上下文放置在合適的位置：

- 根目錄下的全庫指引
- 子目錄中的區域特定指引
- `L10N/<locale>.md` 中的語言特定指引
