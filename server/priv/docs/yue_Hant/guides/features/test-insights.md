# 測試洞察 {#test-insights}

使用「測試洞察」識別緩慢測試、追蹤不穩定測試，並快速了解失敗的 CI 執行，以監控你的測試套件健康狀況。目前支援 Xcode、Gradle、Bazel、Elixir 和 Rust。
