# 測試洞察 {#test-insights}

使用測試洞察，透過識別慢速測試、追蹤不穩定測試，以及快速了解失敗的 CI 運行，來監控你的測試套件健康狀況。目前支援 Xcode、Gradle、Bazel、Elixir 和 Rust。
