# 測試洞察 {#test-insights}

使用測試洞察來監控你的測試套件健康狀況，方法包括識別緩慢的測試、追蹤不穩定的測試，以及快速了解失敗的 CI 運行。目前支援 Xcode、Gradle、Bazel、Elixir 和 Rust。
