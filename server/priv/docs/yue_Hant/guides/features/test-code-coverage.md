# 代碼覆蓋率 {#code-coverage}

代碼覆蓋率顯示你嘅測試執行咗邊啲代碼行。Tuist 會上傳每次測試執行嘅覆蓋率，並將同一個 commit 內嘅多次執行合併為單一數值，按每個檔案同整個項目計算，讓你可以喺儀表板逐個 commit 追蹤進度。
