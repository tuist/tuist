## 管理不穩定測試 {#managing-flaky-tests}

### 自動清除 {#automatic-clearing}

偵測同清除會透過項目上嘅 **自動化警示** 執行。每個項目都會有一個預設嘅「不穩定測試偵測」自動化，佢嘅 *觸發條件* 會將測試標記為不穩定，而 *恢復動作* 會在測試於設定嘅恢復期（預設 **14 日**）內冇再觸發時清除標記。你可以喺 **設定 → 自動化** 編輯它，以更改恢復期、更改恢復動作（例如，同時將測試從隔離中釋放），或者完全停用恢復，令測試保持標記為不穩定，直到你手動清除。

### 手動管理 {#manual-management}

你亦可以喺測試案例詳情頁面手動將測試標記為或不標記為不穩定。以下情況會好有用：
- 你想喺修復已知不穩定測試期間確認它
- 測試因為基礎設施問題而被錯誤標記
