隔離會將不穩定測試案例獨立處理，令佢喺你修復期間唔會阻塞 CI。預設係**手動操作**：你可以從儀表板嘅測試案例詳情頁面隔離測試案例、解除隔離同切換模式。你亦可以將佢接駁到**設定 → 自動化**底下嘅**自動化警示**，當測試案例跨越不穩定閾值時自動靜音（或跳過），並於恢復時解除隔離。每次轉換，無論手動定自動化，都會記錄喺測試案例嘅審核日誌中。

預設情況下，恢復會等待觸發條件不再成立，所以測試案例會保持隔離狀態，直到舊有不穩定執行離開觸發視窗。如需更快恢復，請將**恢復時機**設為**無新不穩定執行**：一旦恢復視窗（以日數或執行次數計）內沒有新不穩定執行，測試案例就會恢復；每次出現新不穩定執行都會重新開始等待；恢復後，只有新不穩定執行會再次將其隔離。
