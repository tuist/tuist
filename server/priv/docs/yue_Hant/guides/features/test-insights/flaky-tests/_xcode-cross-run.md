### 跨執行檢測 {#cross-run-detection}

即使唔設測試重試，Tuist 都可以透過比較同一個 commit、scheme 同報告嘅目的地（裝置名稱、平台同 OS 版本）喺唔同 CI 執行中嘅結果，偵測到不穩定測試。如果一個測試喺某個相符嘅 CI 執行中通過，但喺另一個中失敗，嗰次失敗嘅執行就會被標記為不穩定。無論邊個結果先到達，呢個機制都有效。

同一個測試喺唔同 scheme 或目的地之間可能表現出持續性差異。例如，喺 iOS 26 通過但喺 iOS 27 失敗，並唔代表係不穩定。來自唔同 scheme、裝置、平台或 OS 版本嘅結果，唔會互相標記為不穩定。

冇目的地元數據，或者涵蓋多個目的地嘅執行，只會互相比較，所以佢哋之間嘅環境差異仍然可能被報告為不穩定。基於重試嘅檢測仍然適用。

呢個功能特別有用於捕捉嗰啲唔夠頻繁失敗以致重試無法捕捉，但仍然會導致間歇性 CI 失敗嘅不穩定測試。
