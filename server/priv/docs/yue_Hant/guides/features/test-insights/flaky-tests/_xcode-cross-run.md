### 跨執行檢測 {#cross-run-detection}

即使沒有測試重試，Tuist 仍可透過比較相同提交、scheme 及回報目的地（裝置名稱、平台與作業系統版本）下不同 CI 執行的結果，偵測不穩定測試。如果某項測試在一個相符的 CI 執行中通過，但在另一個中失敗，則該次失敗的執行會被標記為不穩定。無論哪個結果先到達，此機制皆有效。

同一項測試在不同 scheme 或目的地上的表現可能持續不同。例如，在 iOS 26 上通過而在 iOS 27 上失敗，並不代表不穩定。來自不同 scheme、裝置、平台或作業系統版本的結果不會互相標記為不穩定。

缺少目的地中繼資料，或涵蓋多個目的地的執行，只會彼此互相比較，因此它們之間的環境差異仍可能被回報為不穩定。基於重試的偵測仍然適用。

這對於捕捉那些失敗頻率不足以被重試機制抓到、但仍會導致間歇性 CI 失敗的不穩定測試特別有用。
