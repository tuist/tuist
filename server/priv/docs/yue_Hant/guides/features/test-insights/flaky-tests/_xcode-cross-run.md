### 跨執行檢測 {#cross-run-detection}

即使沒有測試重試，Tuist 仍可透過比較同一個 commit、scheme 及回報目的地（裝置名稱、平台同作業系統版本）嘅唔同 CI 執行結果，偵測到不穩定測試。如果一個測試喺某個相符嘅 CI 執行中通過，但喺另一個中失敗，該次失敗嘅執行就會被標記為不穩定。無論邊個結果先到達，此機制都有效。

同一個測試喺唔同 scheme 或目的地之間可能表現 consistently 唔同。例如，喺 iOS 26 通過但喺 iOS 27 失敗，並唔代表係不穩定。來自唔同 scheme、裝置、平台或作業系統版本嘅結果，唔會互相標記為不穩定。

冇目的地元數據，或者涵蓋多個目的地嘅執行，只會互相比較，因此佢哋之間嘅環境差異仍然可能被報告為不穩定。基於重試嘅檢測機制仍然適用。

呢個功能特別有用於捕捉嗰啲因為失敗頻率唔夠高而無法透過重試捕捉到，但仍然會導致 CI 間歇性失敗嘅不穩定測試。
