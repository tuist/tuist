# 套件分析 {#bundle-insights}

當你為應用程式加入更多功能時，套件體積會不斷增長。部分增長無可避免，但許多其實可以避免：重複的資源、未使用的符號，以及平台特定的浪費都會累積起來。Tuist Bundle Insights 同時支援 **Apple** 和 **Android** 套件，提供工具和分析數據，協助你控制應用程式大小，並追蹤其長期趨勢。
