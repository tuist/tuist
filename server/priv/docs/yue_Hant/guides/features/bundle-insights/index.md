# Bundle 分析 {#bundle-insights}

當你為應用程式加入更多功能時，bundle 會不斷增大。部分增長不可避免，但許多情況可以避免：重複的資源、未使用的符號以及特定平台的浪費都會累積起來。Tuist Bundle Insights 同時支援 **Apple** 和 **Android** bundle，提供工具和見解協助你保持應用程式體積小巧，並追蹤隨時間變化的趨勢。
