# 發佈日曆 {#release-calendar}

追蹤最新嘅 Server 同 Kura 版本、近期發佈，以及即將到來嘅發佈時段。如要了解頻道保證、映像固定同回溯移植政策，請參閱 <.localized_link href="/guides/server/self-host/release/channels">Release channels</.localized_link>。

穩定版升級定於星期一 UTC 06:00 進行，並與 <.localized_link href="/cli/release/calendar">CLI release train</.localized_link> 同步。只有喺預定升級成功之後，才會建立下一個候選版本。故障可能會獨立延遲任一組件，而維護者可以喺排程之外發佈。未來嘅時間窗口只係計劃，並非承諾嘅發佈時間。

修補程式版本同回溯移植會按需提供，而非按照每週排程。以下歷史記錄將已發佈嘅版本連結到其說明同實際發佈日期。
