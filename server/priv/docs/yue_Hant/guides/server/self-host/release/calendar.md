# 發布日曆 {#release-calendar}

追蹤目前 Server 同 Kura 版本、近期發布，以及即將到來嘅發布窗口。如需頻道保證、映像固定同回溯政策，請參閱 <.localized_link href="/guides/server/self-host/release/channels">發布頻道</.localized_link>。

穩定版升級定於星期一 UTC 06:00 進行，並與 <.localized_link href="/cli/release/calendar">CLI 發布列車</.localized_link> 同步。下一個候選版本只會在排程升級成功後先會建立。任何元件失敗都可能獨立造成延遲，維護者亦可以喺排程之外發布。未來窗口僅屬計劃，並非承諾嘅發布時間。

修補程式發布同回溯會按需要發佈，而非每週排程。以下歷史記錄將已發布嘅版本連結到其說明同實際發布日期。
