# CLI {#cli}

Tuist CLI, Tuist ile etkileşim kurmak için kullanılan arayüzlerden biridir ve <.localized_link href="/guides/features/projects">oluşturulan projeler</.localized_link> kullanıyorsanız en yaygın olanıdır. Proje oluşturma, ikili dosyaları önbelleğe alma, testleri çalıştırma, önizlemeleri paylaşma ve daha fazlası için komutlar sunar.

## Başlarken {#getting-started}

Tuist'i henüz yüklemediyseniz başlamak için <.localized_link href="/guides/install-tuist">kurulum kılavuzunu</.localized_link> takip edin.

Kurulum tamamlandıktan sonra, mevcut komutların listesini görmek için terminalinizde `tuist` çalıştırabilirsiniz:

```bash
tuist --help
```

## Yapılandırma {#configuration}

CLI davranışı bir `tuist.toml` dosyası aracılığıyla yapılandırılabilir. Tüm kullanılabilir seçenekler için <.localized_link href="/references/tuist-toml">tuist.toml referansına</.localized_link> bakın.

## Sorun Giderme {#troubleshooting}

Sorunlarla karşılaşırsanız, oturum günlükleri ve ağ kayıtları dahil olmak üzere sorunları teşhis etmeye yönelik araçlar için <.localized_link href="/cli/debugging">hata ayıklama kılavuzuna</.localized_link> bakın.
