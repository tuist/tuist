# Paket içgörüleri {#bundle-insights}

Uygulamanıza daha fazla özellik ekledikçe paket boyutunuz büyümeye devam eder. Bu büyümenin bir kısmı kaçınılmazdır, ancak büyük bir kısmı değildir: yinelenen varlıklar, kullanılmayan semboller ve platforma özel israf birikerek büyür. Tuist Paket İçgörüler hem **Apple** hem de **Android** paketlerini destekler; uygulama boyutunuzun küçük kalmasına yardımcı olacak araçlar ve içgörüler sunar ve zaman içindeki eğilimi takip eder.
