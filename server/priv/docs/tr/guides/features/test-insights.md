# Test İçgörüleri {#test-insights}

Yavaş testleri belirleyerek, kararsız testleri izleyerek ve başarısız CI çalıştırmalarını hızla anlayarak test paketinizin sağlığını izlemek için Test İçgörülerini kullanın. Şu anda Xcode, Gradle, Bazel, Elixir, Rust ve Once'ı destekler. Mevcut sonuçlar ve zamanlamalar runner'ınıza bağlıdır. Desteklenen derleme sistemlerinde testlerinizin hangi kodu yürüttüğünü takip etmek için <.localized_link href="/guides/features/test-code-coverage">Kod Kapsamı</.localized_link> bölümüne bakın.
