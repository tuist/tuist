# Tuist customer stories

An entry point to case studies and testimonials from teams using Tuist.

## What this area provides

The [customer directory](/customers) links to case studies. Each describes a team's own project, the Tuist features it adopted, and the results it reported. **Current entries** at the end of this guide links up to 20 stories; the [sitemap](/sitemap.xml) covers the rest. Request a story hosted on Tuist with `Accept: text/markdown` for the full article. Some stories are published on another site and are served in that publisher's format.

## How to use the evidence

1. Find a story with a comparable toolchain, project size, and bottleneck.
2. Identify which feature produced the result (for example module cache vs Xcode compilation cache, or selective testing vs sharding) and what baseline it was measured against.
3. Check the current integration guide; a story may describe an earlier version or setup.
4. Measure your own workload before projecting savings.

## Limitations

One team's improvement is not a guarantee for another project, and a story is not evidence that every feature supports its toolchain.
