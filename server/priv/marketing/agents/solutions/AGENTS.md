# Problem-focused marketing guides

These English sources serve both browser pages at `/solutions/<slug>` and explicit Markdown at `/marketing-markdown/solutions/<slug>`. The HTML is derived from the same content, not a second hand-maintained copy. Follow the parent `AGENTS.md` for delivery and measurement.

- Start with the user's symptom and diagnostic measurements; map interventions to documented features and toolchain requirements.
- Include `## Diagnose`, `## Investigate with an agent`, `## First experiment`, and `## Limitations` sections. Link to feature guides instead of duplicating full setup instructions or support matrices.
- Distinguish insight from automatic optimization, build outputs from persistent directories, selective testing from line-level impact analysis, sharding from reduced total work, and quarantine from fixing a test.
- Agent examples must name tools present in the MCP documentation and distinguish reading evidence from authorized writes. Mention separate integration authentication when relevant.
- Cost guidance must use measured total usage and current commercial terms, not guaranteed savings or unpublished compute prices.
- The marketing maintainers own these guides. Review them alongside changes to linked feature guides; review the complete set quarterly.
- New files automatically enter the public-page inventory. Update inventory assertions and test HTML delivery, English-only behavior, Markdown negotiation, sitemap, and `/llms.txt` discovery.
