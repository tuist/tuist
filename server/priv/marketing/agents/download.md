# Tuist downloads

Choose between the Tuist CLI, which integrates with builds and CI, and the macOS and iOS apps, which make previews easy to find and run.

## Which tool to use

- **Tuist CLI**: the interface for project generation, cache setup, test and build reporting, and sharing or running previews, locally and in CI. Install it with [Install Tuist](/en/docs-markdown/guides/install-tuist). Gradle projects use the [Gradle plugin](/en/docs-markdown/guides/install-gradle-plugin) and Elixir projects the [Hex package](/en/docs-markdown/guides/install-hex-package) for their integrations.
- **macOS app**: a menu bar app that lists recent previews and installs and launches them on simulators or connected devices. Get it from the [download page](/download) or with `brew install --cask tuist/tuist/tuist`.
- **iOS app**: browse and run previews on an iPhone; the download page also describes release and commit views. Get it from the [App Store](https://apps.apple.com/us/app/tuist/id6748460335).

## When to use the apps

Use them when reviewers need to run [Previews](/marketing-markdown/previews) without a terminal. Use the CLI for anything automated.

Private previews require project access, and device builds require appropriate signing. Find current app versions on the [download page](/download).
