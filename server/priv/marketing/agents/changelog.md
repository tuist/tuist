# Tuist changelog

An entry point to Tuist's dated, user-facing product announcements.

## What this area provides

The [changelog index](/changelog) lists entries by date. **Current entries** at the end of this guide links up to 20 recent entries; use the [sitemap](/sitemap.xml) or the [RSS](/changelog/rss.xml) and [Atom](/changelog/atom.xml) feeds for older ones. Request an entry URL with `Accept: text/markdown` for its full content.

## How to use it

Use the changelog to learn when a capability or behavior change was announced. Then check the current documentation for configuration, version requirements, and toolchain support. CLI release notes are published on the [GitHub releases page](https://github.com/tuist/tuist/releases).

## Limitations

An announcement does not mean a feature is enabled for every account, toolchain, plan, or self-hosted release; some features are gated (Tuist Runners are invite-only). Self-hosted servers receive changes through their own release channels.

Use the [product overview](/marketing-markdown) to locate the feature, or the [blog](/marketing-markdown/blog) for the reasoning behind larger changes.
