---
title: Public project links now show live project insights
description: "Links to public Tuist projects now include the project identity and relevant build, test, cache, bundle, or preview data in their social image."
category: "Product"
---

Links to public project pages now produce an Open Graph image for the page being shared. Each image identifies the project and highlights the information that makes the link worth opening, such as build duration, cache effectiveness, test results, or preview metadata.

Projects with an administrator-supplied logo include it in the image. Projects without one receive a generated initial, while private projects continue to use generic images that contain no project information.
