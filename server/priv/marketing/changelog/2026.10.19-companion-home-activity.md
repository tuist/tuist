Home in the Tuist companion apps now brings together recent build failures, failed test runs, newly flaky tests, and the latest app previews for the selected project.

Each activity section shows up to three records from the last seven days. New flaky tests are based on when a test entered its current flaky state, not just when it last ran; tests that have since been unmarked are excluded. Open a run or test in the dashboard for more context, or share its link with a teammate. These are recent recorded outcomes, not a queue of unresolved incidents.

Recent previews remain available for trying a build, with full browsing and installation in Previews. Switching projects updates the overview without moving you out of your current section. On macOS, Home and Previews live in a native desktop window with a sidebar, while the menu-bar companion is optional.

Activity availability depends on the project's build system and requires an updated server for self-hosted deployments. Older servers keep preview browsing available when activity cannot be loaded.
