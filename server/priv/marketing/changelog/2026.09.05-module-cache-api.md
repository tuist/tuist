The Modules page answers which modules keep missing the cache and why, but only in the dashboard. The same analytics are now available programmatically: ranking modules by invalidations, one module's summary, the builds it took part in with the reason each one missed, and the daily series behind the charts.

The dependency graph the CLI reports gets a read path for the first time. A module now carries what it depends on, what depends on it, and everything it invalidates downstream, so an agent can weigh a change to a module against the modules that have to be rebuilt with it.

Coding agents reach this through the Model Context Protocol server, and scripts through the project's API. Both cover the same window, environment and branch filters the dashboard offers.
