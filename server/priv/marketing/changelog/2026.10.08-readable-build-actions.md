Once action tables now show the readable names reported by Once, and source files link to your connected repository at the run's recorded revision. Search by an action name or source path to find the work you are looking for. Actions with many source files show a compact preview while keeping every path searchable.

Bazel cache actions can also show readable descriptions from an uploaded build profile when its output, target, and mnemonic metadata match the cache telemetry unambiguously. Search works with both these descriptions and the original mnemonics. Generated output paths are used only for correlation, not presented as repository source links.

Older clients and historical runs keep their existing labels when this metadata is unavailable. Cache keys, replay handling, and hit/miss counts are unchanged.
