You can now install the Tuist app directly from **Cursor Origin** or **GitHub** and finish connecting it in Tuist. After signing in, choose the Tuist organization or personal account to connect. The chooser only lists accounts you can administer; if there is just one, Tuist connects it automatically. GitHub organization installations must be connected by a GitHub organization owner.

If you start from **Settings → Integrations** in Tuist, your selected organization is retained, so there is no extra selection step. GitHub Enterprise Server continues using the App registration flow started in Tuist.

See the [Origin integration guide](/en/docs/guides/integrations/gitforge/origin) or [GitHub integration guide](/en/docs/guides/integrations/gitforge/github) to get started. Self-hosted administrators should also review the updated [GitHub App settings](/en/docs/guides/server/self-host/server#platform-github), including the additional OAuth callback and organization membership permission.
