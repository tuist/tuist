---
title: "Export build history with filters and stable pagination"
description: "Pull Xcode build data into your data warehouse with date and CI filters, cursor pagination, and larger pages."
category: "added"
author: "pepicrft"
---

The Xcode build list API now supports **date ranges, CI filtering, and cursor pagination** for exporting build history to tools such as BigQuery. Use `from` and `to` Unix timestamps to select an inclusive creation-time range, and `is_ci=false` to focus on local builds.

Follow `pagination_metadata.end_cursor` with `after` to fetch older builds without new uploads shifting page boundaries. Use `before` with `start_cursor` to navigate back. Pages can contain up to **1,000 builds**. Existing clients that explicitly send `page` keep offset pagination; omit it to use cursors.

Build list and detail responses also include `started_at`, the actual build start recorded in newly processed activity logs. This is separate from upload time (`inserted_at`) and stays null for historical builds or reports without a recorded start time.
