---
title: Let coding agents react to newly flaky tests
description: Subscribe to flaky test events and let your connected agent investigate them.
category: "Product"
---

Coding agents connected through Tuist's [MCP](/en/guides/features/agentic-coding/mcp) server can now subscribe to events when a test is marked flaky. The client chooses the project and provides a verified callback, so it controls which events reach it and what to do next.

Each event includes the test case identifier and a link to its details. The agent can use Tuist's existing tools to inspect the failure history and start debugging. Subscriptions expire unless the client refreshes them, and delivery stops if access to the project is removed.
