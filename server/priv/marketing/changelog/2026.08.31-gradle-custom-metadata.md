---
title: Richer Gradle build metadata
description: "Gradle Build Insights now captures machine context and works alongside the Common Custom User Data Gradle plugin."
category: "Product"
---

Gradle Build Insights now records the operating system, processor model, processor count, total memory, and power source when the build machine makes them available. You can add your own tags and key-value metadata from `settings.gradle.kts` or environment variables, then filter builds by tags and inspect the values on a build's detail page.

If your build also uses the [Common Custom User Data Gradle plugin](https://github.com/gradle/common-custom-user-data-gradle-plugin), Tuist recognizes it and records normalized build context alongside the existing Develocity build scan. That includes the invocation source, continuous-integration provider and run details, checkout state, and supported coding agents. Tuist only records whether a checkout is dirty, not the raw Git status and its file paths.
