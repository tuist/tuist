---
title: Reuse dependency directories with Linux cache volumes
description: "Keep dependency caches between GitHub Actions jobs on Tuist Linux runners, with private copies for each job and a dashboard to track reuse."
category: "Product"
---

GitHub Actions workflows on Tuist Linux runners can now reuse dependency directories with **cache volumes** on fleets where the feature is enabled. Choose a cache key and a directory, such as Gradle's dependency cache, and each job gets its own writable copy without downloading and extracting a cache archive.

Successful jobs on the default branch save changes for future runs. Pull requests can reuse the cache in private copies, so parallel jobs can work independently. Volumes start with a **20 GB capacity** and expire after seven days without a job mount.

![The Runners Volumes dashboard showing used space, cache hit rate, and a searchable list of Linux volumes](/marketing/images/changelog/2026.09.22-linux-cache-volumes.png)

The new **Runners → Volumes** page brings storage trends, cache hit rates, and job history together. Open a volume to see which workflows used it, follow a job back to its volumes, or clear its saved contents to start fresh.

See the [setup guide](https://tuist.dev/en/docs/guides/features/runners/docker#persistent-dependency-directories) to add a volume to your workflow. This first version supports Linux; macOS support will follow separately.
