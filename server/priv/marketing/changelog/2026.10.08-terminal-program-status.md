title: Terminal-native status for Tuist commands
description: "Compatible terminals can now show when Tuist is working, finished, failed, or waiting for browser sign-in."
category: "Product"
pull_request: 13956
---

Tuist now supports the [Program Status Protocol (OSC 7501)](https://www.superlogical.com/rex/docs/build/program-status), giving compatible terminals a reliable way to know what a command is doing without parsing its output.

Commands report `working` while they run, `done` when they succeed, and `error` when they fail. During browser sign-in, Tuist reports `blocked` with `kind=auth` until authentication completes, then returns to `working`. Supporting terminals can use these states for status indicators or notifications when a command finishes or needs your attention.

No configuration is required. Terminals without protocol support ignore the status messages, and redirected output, machine-readable output, quiet mode, and continuous integration runs remain unchanged.
