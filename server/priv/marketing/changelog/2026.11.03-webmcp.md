---
title: Browser agents can use Tuist's tools through WebMCP
description: "Tuist's website, documentation and dashboard now register Tuist's tools with WebMCP, so agents built into the browser can search the docs and read your projects' builds, tests and previews without any setup."
category: "Product"
---

[WebMCP](https://webmachinelearning.github.io/webmcp) is a browser API that lets a web page offer tools to the agents built into the browser. Tuist's pages now use it to register Tuist's [MCP](/en/guides/features/agentic-coding/mcp#webmcp) tools, so in a browser that supports WebMCP, its agent can call them without you adding an MCP server.

On the website and in the documentation, the agent can search Tuist's documentation and source code without you signing in. On the dashboard, once you're signed in, it gets the same read-only tools coding agents use. With them it can look up your projects, builds, test runs, flaky tests, bundles and previews. The calls run on the Tuist server as you, so the agent only sees data you can already see in the dashboard.

Tools that create, change or delete data aren't offered in the browser, because a browser agent reads content that builds and tests produce and gets the tools without you choosing to add them. To use those tools, connect an MCP client to Tuist's MCP endpoint. If your organization enforces single sign-on, sign in with that provider to use the dashboard's tools.
