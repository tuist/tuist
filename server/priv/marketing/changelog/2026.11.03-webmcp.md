[WebMCP](https://webmachinelearning.github.io/webmcp) is a browser API that lets a web page offer tools to the agents built into the browser. Tuist's pages now use it to register Tuist's [MCP](/en/guides/features/agentic-coding/mcp#webmcp) tools, so in a browser that supports WebMCP, its agent can call them without you adding an MCP server.

On the website and in the documentation, the agent can search Tuist's documentation and source code without you signing in. On an account's dashboard pages, once you're signed in, it gets the same read-only tools coding agents use for that account. With them it can look up the account's projects, builds, test runs, flaky tests, bundles and previews. The calls run on the Tuist server as you, and only reach the account you're looking at; when you move to another account, the tools follow.

Tools that create, change or delete data aren't offered in the browser, because a browser agent reads content that builds and tests produce and gets the tools without you choosing to add them. To use those tools, connect an MCP client to Tuist's MCP endpoint.

Single sign-on enforcement now also covers the browser tools and sign-in for the Tuist CLI, the Tuist app and MCP clients. When an organization you belong to enforces single sign-on, Tuist asks you to sign in with its provider before it connects them. See the [single sign-on guide](/en/guides/integrations/authentication/sso#choose-an-enrollment-policy) for details.
