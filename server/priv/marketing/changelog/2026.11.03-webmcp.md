[WebMCP](https://webmachinelearning.github.io/webmcp) lets a web page offer tools to the agent built into the browser. In a browser that supports it, Tuist's pages now register Tuist's [MCP](/en/guides/features/agentic-coding/mcp#webmcp) tools, so you don't need to add an MCP server first.

- **Website and documentation:** the agent can search Tuist's documentation and source code, without you signing in.
- **Dashboard:** once you're signed in, an account's pages offer the read-only tools coding agents use, so the agent can look up that account's projects, builds, test runs, bundles and previews. The calls run as you and only reach the account you're looking at. When you switch accounts, the tools switch with you.

Tools that create, change or delete data aren't offered in the browser, because the agent gets these tools without you choosing to add them and reads content that builds and tests produce. To use those tools, connect an MCP client to Tuist's MCP endpoint. If an organization enforces single sign-on, sign in to the dashboard with its provider to use its tools.
