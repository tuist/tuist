---
title: Explore Gradle and Bazel build timelines
description: "See recorded Gradle and Bazel operations in an interactive build timeline."
category: "Product"
---

The **Timeline** tab is now available on Gradle and Bazel build reports. Zoom into a slow interval, search for an operation, and select a bar to inspect its timing and recorded metadata.

![A real Kura Bazel build timeline showing CPU utilization as a percentage, memory and network usage, and categorized build steps](/marketing/images/changelog/2026.09.09-bazel-build-timeline.jpg)

For Gradle, the timeline combines task execution, configuration, and artifact transforms with synchronized CPU, memory, network, and disk charts. Reports from the updated plugin align these recordings to the build start; older reports identify their origin as the first recorded timestamp. Cache hits, skipped tasks, and failed tasks retain their recorded outcomes.

Bazel timelines use the JSON trace profile to show recorded build intervals, targets, and resource samples. Published action results add outcomes and compiler logs to individual steps. Run `tuist bazel setup` to enable profile uploads; older builds retain their existing summary.

Recorded steps are also available through the API and the `list_gradle_build_steps`, `get_gradle_build_step`, `list_bazel_build_steps`, and `get_bazel_build_step` MCP tools, with search, time filters, and pagination. Records retain their existing 90-day lifetime.
