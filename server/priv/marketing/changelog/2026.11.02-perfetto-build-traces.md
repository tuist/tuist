Build pages for Xcode, Gradle, Bazel, and Mix now have a **Download trace** button in the header whenever the build has a timeline. It downloads the build's recorded steps as a trace file that you can open at [ui.perfetto.dev](https://ui.perfetto.dev), `chrome://tracing`, or Perfetto's `trace_processor`. Steps are laid out in lanes by how many ran at the same time, so the number of lanes shows the build's peak parallelism. CPU and memory appear as counter tracks when the build recorded machine metrics.

Coding agents connected to the Tuist [MCP server](/en/guides/features/agentic-coding/mcp#build-traces) can use the new **`get_build_trace`** tool to get the same file. It returns a download link that is valid for one hour, so an agent can fetch the trace with `curl`, query it, or hand it to you to explore in Perfetto. The trace contains the same steps as the build's Timeline tab, without logs.
