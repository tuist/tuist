---
title: Understand Bazel builds and cache behavior
description: "Bazel projects now have build and cache dashboards with timelines, critical paths, command details, logs, and per-request cache diagnostics."
category: "Product"
---

Bazel projects now show completed builds and tests alongside the build systems already supported by Tuist. Each invocation includes its command, targets, result, duration, processor time, action counts, package counts, build timeline, and critical path when Bazel reports them.

The new cache view connects action-cache and content-cache requests to the invocation that produced them. It shows hit rates, transfer volume, latency, throughput, action names, target labels, and individual request outcomes. Invocation pages also include captured Bazel output and downloadable logs, so a slow or failed build can be investigated without reproducing it locally.

Existing Bazel projects receive these views automatically after configuring Tuist as their build event and remote cache service.
