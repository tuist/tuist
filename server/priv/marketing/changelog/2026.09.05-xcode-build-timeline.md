See where your Xcode build spends its time with the new **Timeline** tab in build insights. Compilation, linking, scripts, and resource processing appear across targets in one interactive view, so you can see what ran in parallel and spot long operations.

![The Tuist workspace build timeline with a time cursor and TuistServer's Swift module emission selected, showing project and target details, type and outcome badges, duration, and its log in the resizable side panel](/marketing/images/changelog/2026.09.05-xcode-build-timeline.png)

Pinch to zoom, drag across a time range to focus, or search for a step or target. Select an operation to inspect its project, target, duration, outcome, and recorded log alongside the chart. Resize the details panel to give commands and output more room.

When machine metrics were collected, CPU, memory, network, and disk charts appear above the steps. They share the timeline's zoom range and synchronized cursors, making it easier to correlate a slow operation with what the machine was doing at that moment.

Timelines use the standard Xcode activity log already uploaded with build insights, with no extra Xcode timing setting required. Open **Build Runs**, choose a newly processed Xcode build, and select **Timeline**.
