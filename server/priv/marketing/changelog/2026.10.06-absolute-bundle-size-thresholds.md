---
title: Limit bundle growth by a fixed size
description: "Bundle size thresholds now support absolute MB limits for install and download size, alongside existing percentage limits."
category: "Product"
---

You can now block a pull request when its bundle grows by more than a **fixed size**, such as 1.5 MB, instead of a percentage of the baseline. The allowed increase stays the same as your app grows.

In **Settings → Bundles**, add or edit a threshold, choose **Install size** or **Download size**, and select **Absolute size (MB)**. MB uses decimal units: 1 MB = 1,000,000 bytes.

Existing percentage thresholds are unchanged, including fractional values such as 0.47%. Both types compare against the latest matching bundle on your baseline branch and keep the same GitHub check and approval flow.

See the [bundle insights guide](https://tuist.dev/en/docs/guides/features/bundle-insights) for configuration details.
