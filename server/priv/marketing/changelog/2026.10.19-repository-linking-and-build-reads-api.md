You can now link a Tuist project to a GitHub repository without opening the dashboard. Run `tuist project repository connect owner/name`, call `PUT /api/projects/{account_handle}/{project_handle}/vcs-connection`, or use the `connect_project_repository` Model Context Protocol tool. The repository must be one your GitHub App installation can access, and the project adopts its default branch. Account tokens need the `project:admin:write` scope. `tuist project repository disconnect` and the matching endpoint and tool remove the link.

Cargo builds, Mix builds and Once runs are now readable outside the dashboard too. Run `tuist build cargo list`, `tuist build mix list` or `tuist build once list` (and `show` for one build or run), use the list and detail endpoints under `/api/projects/{account_handle}/{project_handle}/cargo/builds`, `/mix/builds` and `/once/runs`, or the `list_cargo_builds`, `get_cargo_build`, `list_mix_builds`, `get_mix_build`, `list_once_runs` and `get_once_run` tools.

See the [GitHub integration guide](/en/docs/guides/integrations/gitforge/github) and the [Model Context Protocol guide](/en/docs/guides/features/agentic-coding/mcp) for details.
