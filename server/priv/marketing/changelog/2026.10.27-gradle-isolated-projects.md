---
title: Gradle Isolated Projects support
description: "Use Gradle's configuration cache and Isolated Projects while keeping Tuist build insights, test insights, and sharding."
category: "Product"
---

Tuist's Gradle plugin now supports [Isolated Projects](https://docs.gradle.org/current/userguide/isolated_projects.html) and configuration-cache reuse. Keep build insights, test insights, test quarantine, and sharding enabled while Gradle configures projects independently and reuses configuration between builds.

Build and test reports stay correctly linked when configuration is reused, and task-cache insights retain local and remote cache-hit details.

This requires Gradle 8.12.1 or later. Update the Tuist Gradle plugin before opting in; your build scripts and other plugins must also support these features. See the [setup guide](/en/guides/install-gradle-plugin#configuration-cache-and-isolated-projects) for the configuration.
