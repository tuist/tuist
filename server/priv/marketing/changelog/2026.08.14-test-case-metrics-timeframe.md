---
title: Choose the timeframe for test case metrics
description: "The metrics on a test case page now follow a date range you pick, instead of each one covering a different fixed window."
category: "Product"
pull_request: 12352
---

The summary metrics on a test case page now respond to a date range picker, with presets for the last 24 hours, 7 days, 30 days and 12 months, plus a custom range. The selection lives in the URL, so a link to a test case carries the window you were looking at.

Previously each metric covered its own window and none of them said which: flakiness rate looked at the last 30 days, while reliability, run counts and average duration were computed over the test's entire history. A lifetime average is slow to react by design, so a test that has passed for months and started failing this week still reads as healthy, and a test that stopped running when it was quarantined keeps reporting the pass rate it had beforehand. Narrowing the window surfaces both immediately. Every metric's tooltip now describes the period it actually uses, including average duration, which described a window it was never applying.
