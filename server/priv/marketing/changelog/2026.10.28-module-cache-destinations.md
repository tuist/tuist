Module caching for generated Xcode projects now supports `--destination simulator` and `--destination device` when warming and generating. Cache only the iOS slices you need for supported modules, then add missing slices later without rebuilding cached ones.

Both modes preserve native macOS targets, including macros. The default, `--destination all`, keeps all declared destinations, including Mac Catalyst.

See the [module cache guide](/en/docs/guides/features/cache/module-cache#destination-selection) for usage and support limits.
