New Tuist CLI releases include a signed [Packslip](https://packslip.dev/) manifest. Packslip authenticates Tuist's GitHub release workflow and checks the downloaded archive against its signed digest before installing it.

With [Packslip installed](https://packslip.dev/cli/), run:

```bash
packslip install github.com/tuist/tuist
```

Each new **canary, release candidate, stable release, and backport** includes a `packslip.sigstore.json` file on its [GitHub release](https://github.com/tuist/tuist/releases). The manifest covers the universal macOS archive and the Linux x86_64 and ARM64 archives, so Packslip can select the download for your platform.

Existing installation methods continue to work. Previously published releases are not retroactively signed.
