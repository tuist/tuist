---
title: Previews for desktop apps and command-line tools
description: "Share macOS apps and CLI distributions with a preview link, and try a build without replacing your installed tools."
category: "Product"
---

Tuist Previews now support **macOS application bundles and command-line tools**, alongside iOS and Android apps. Share a build from a branch or pull request so teammates can try it without rebuilding locally or replacing an installed CLI.

```bash
tuist share path/to/MyApp.app
tuist share path/to/distribution --executable bin/my-tool
```

Recipients run the preview with `tuist run`, forwarding CLI arguments after `--`:

```bash
tuist run {preview-url} -- --help
```

Distributions keep their bundled resources and libraries, while execution preserves the recipient's working directory, environment, terminal input/output, and exit status. Tuist selects a build compatible with the recipient's operating system and CPU architecture.

Package the dependencies your tool needs; previews do not bundle them automatically. macOS signing requirements and Linux system-library compatibility still apply. Desktop previews run as your user and are not sandboxed, so only run builds you trust.

See the [Previews guide](/en/docs/guides/features/previews#desktop-apps-and-clis) for packaging and usage details.
