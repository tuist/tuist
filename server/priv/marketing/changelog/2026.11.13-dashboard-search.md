---
title: Search the dashboard with Command-K
description: "Press Command-K, or Ctrl-K, anywhere in the Tuist dashboard to jump to a page, project, test case, preview, build, or test run."
category: "Product"
---

The Tuist dashboard now has a search menu. Press **⌘K** on macOS or **Ctrl+K** elsewhere, or click **Search** at the top of the sidebar, then start typing.

![The dashboard search menu with the query "test", listing pages such as Tests › Test Runs and Tests › Flaky Tests, followed by matching test cases with their module and suite](/marketing/images/changelog/2026.11.13-dashboard-search.png)

- **Pages:** jump to any dashboard page you have access to, such as **Tests › Flaky Tests** or **Settings › Integrations**. With an empty query, the menu lists the pages you visited recently.
- **Projects, test cases, and previews:** find them by name.
- **Builds and test runs:** paste a run's ID or its dashboard link, or ask for runs with `is:build` or `is:test-run`.

Search follows where you are. On a project's pages it searches that project, and on account pages it searches all of the account's projects. Add `project:` to search another project. To open the selected page in a different project, press **Shift+Enter**.

Combine filters to narrow results, for example `is:test-run status:failed branch:main`. The available filters are `is:`, `project:`, `branch:`, `commit:`, `status:`, `date:`, and `pr:`, and the menu suggests them as you type. Build and test run lookups cover the last 30 days.
