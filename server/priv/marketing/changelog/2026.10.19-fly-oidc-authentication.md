---
title: Authenticate Fly Machines with OIDC
description: Use Fly.io workload identities to authenticate to Tuist without storing long-lived Tuist secrets.
category: "Product"
---

Fly.io Machines can now authenticate to Tuist using OpenID Connect. In your project's **Settings → General**, add a trust policy for your Fly organization's issuer URL, organization ID, and application ID. Only Machines in that app can exchange their identity tokens for CI access to the projects that explicitly trust them.

Set `TUIST_OIDC_ACCOUNT` to your Tuist account handle, request an identity token with audience `tuist` from the Machine's local Fly API, then pass it through `TUIST_OIDC_TOKEN` to `tuist auth login` or `mix tuist.login`. No GitHub repository connection or long-lived Tuist secret is required.

See the [Fly.io authentication guide](/en/docs/guides/server/authentication#flyio-machines) for setup and token acquisition. Removing a policy stops new exchanges; already-issued Tuist access tokens remain valid until their one-hour expiration.
