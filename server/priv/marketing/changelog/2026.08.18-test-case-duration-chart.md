The test case page reported four numbers for the window you picked: how many times the test ran, how often it flaked, how reliable it was, and how long it took. Each was a single figure, so it could tell you where the test stands but not how it got there.

Every one of them is now a chart. Click a metric and the card below draws it across the period.

**Runs** is one bar per day, split by how those runs came out: successful, failed, flaky, quarantined, skipped. The bar's height is the number of runs, and the composition is the story: a bar that grows a red band on the same day every week is a different problem from one that has always had it. The widget itself counts all runs, or just the failed or flaky ones, from a dropdown on its title.

**Flakiness rate** and **reliability** are drawn against a fixed 0-100% axis, so a test that sat between 98% and 100% all month reads as steady rather than as a cliff.

**Duration** draws the average with p50, p90 and p99 together. Reading them side by side separates a test that got slower for everyone from one that is usually fast and occasionally stalls: when the p50 climbs, the test itself changed; when only the p99 climbs, something intermittent did.

Each metric also carries what it was over the window before this one, so "93% reliable" comes with whether that is a recovery or a slide. A window with no runs before it is not a baseline, so a test case that only started running this week shows no trend rather than a change of nothing.

The test's own history runs down the side of the card as a timeline, so a state change and the chart it explains are read together: the day a test was quarantined sits beside the bar where its failures stop mattering.

The charts follow the date range picker, bucketing by hour, day or month to match the window. A period the test case never ran in says so instead of drawing a flat line at zero, and a single quiet day inside the window is left as a gap in the duration and rate lines rather than plotted as a test that suddenly took no time or failed every run.
