The test case page told you how long a test takes right now, as a single number over the window you picked. It could not tell you whether that number is where the test has always been or where it arrived last week.

It now charts the duration of that one test case over the period, with the average and p50, p90 and p99 drawn together. Reading them side by side separates a test that got slower for everyone from one that is usually fast and occasionally stalls: when the p50 climbs, the test itself changed, and when only the p99 climbs, something intermittent did.

The chart follows the same date range picker as the summary above it, and buckets by hour, day or month to match the window.

A day the test case did not run is left as a gap in the line rather than drawn as zero, so a quiet week reads as a quiet week and not as a test that suddenly took no time at all.
