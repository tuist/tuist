Coding agents connected to the hosted Tuist [MCP](/en/guides/features/agentic-coding/mcp#feedback) endpoint can now use a **`report_feedback`** tool when a Tuist tool or prompt does not work the way they expected: a confusing or wrong result, an error, missing data, an unclear parameter, or a capability they needed but could not find.

Agents suggest a report and send it only once you agree. Each report describes what was expected, what actually happened, and optionally a suggestion for a better tool, and it can name the account and project the problem happened in. The report opens a conversation with Tuist support under your name, so we can follow up with you by email and turn the feedback into improvements to the tools your agents rely on.

Reports should not include source code, secrets, or personal data. The tool is available to agents signed in to a Tuist account.
