Test runs that gather code coverage now show it in Tuist. Open a run's **Coverage** tab for its line coverage, a per-target breakdown, and the files sorted from least to most covered, down to each file's uncovered lines and functions. Runs that skip tests are marked as partial and left out of the trend, so skipped tests never drag the figure down. The tests overview gets a **Line coverage** widget with a trend against the previous period.

Coverage is read from the result bundle, so schemes that already gather it, or runs with `-enableCodeCoverage YES`, need nothing else. Teams that prefer not to upload it can turn it off in `Tuist.swift`.
