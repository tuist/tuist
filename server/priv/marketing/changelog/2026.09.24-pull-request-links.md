title: Open the pull request behind a test or build run
description: "Test runs show the pull request they ran for, and test and build run pages link straight to it."
category: "Product"

---

The **Test Runs** list has a new **Pull request** column next to **Branch**. Runs from a pull request show its number, linked to the pull request on GitHub, and other runs show **None**.

![Test runs list with a Pull request column linking runs to pull requests #13557 and #13561](/marketing/images/changelog/2026.09.24-pull-request-links-test-runs.png)

Test run and build run pages now have a **PR** button in the header, next to **CI Run**, so you can open the pull request from any tab.

![Test run page with a PR #13557 button in the header](/marketing/images/changelog/2026.09.24-pull-request-links-test-run.png)

Tuist reads the pull request number from the Git reference your CI reports, such as `refs/pull/123/merge` on GitHub Actions, and links to the GitHub repository connected to your project, including GitHub Enterprise Server. Without a connected repository, the list shows the number without a link.
