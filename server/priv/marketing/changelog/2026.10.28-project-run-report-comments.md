---
title: Control run report comments per project
description: "Turn GitHub run report comments on or off without disconnecting your repository."
category: "Product"
---

You can now turn **Run report comments** on or off in **Project Settings → Integrations → GitHub**. Existing integrated projects keep comments enabled, and each project controls its own preference.

Turning comments off keeps your repository connection, build and test uploads, and CI job summaries. Existing comments remain on GitHub.
