---
title: Publish Once applications as project previews
description: "Publish eligible Android and Apple applications from Once using your existing Tuist project."
category: "Product"
---

Once application artifacts can now appear in your Tuist project's **Previews**, using existing project access and distribution. Supported outputs include verified Android APKs and ad-hoc signed Apple simulator and macOS applications. Physical-device Apple distribution remains a separate signing workflow.

With Once 0.74.0 or later, configure artifact publication and explicitly authorize each target's destination once. Selected successful builds can then publish automatically, including builds restored from cache. Replaying the same retained publication does not upload or create another preview. Ordinary builds remain unpublished unless you opt in and authorize the destination.

Publication confirms artifact storage; preview processing follows asynchronously. Project previews use the project's default visibility, while the complete generic artifact closure stays private.

See the [Once preview guide](/en/docs/guides/features/previews#publish-from-once) for setup, eligibility, and retention.
