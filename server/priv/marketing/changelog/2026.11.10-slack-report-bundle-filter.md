---
title: Filter bundle sizes in Slack reports by tag
description: "Choose which uploaded bundles contribute to the bundle-size section of your project's Slack reports."
category: "Product"
---

You can now filter the bundle-size section of your Slack reports by an uploaded bundle tag. For example, select `production` to report production app sizes while continuing to upload debug builds to the same project.

Open **Project Settings → Notifications → Reports → Included in reports → Bundles → Edit**, search for a tag, and save your selection. Scheduled reports and test reports use the same filter, and size comparisons use a previous bundle with the same tag, app identifier, and artifact type. If no bundle matches, the report leaves out the bundle-size section rather than using an unrelated upload.

Select **All bundles** to remove the filter. Other report metrics are unchanged.
