## Russian-specific translation rules

- In pricing and billing contexts, translate "pay as you go" as "платите по мере использования" or "оплачивайте по факту использования". Never use forms of "плакать" such as "плачьте".
- Translate usage-based pricing as "ценообразование на основе использования" or a shorter natural equivalent when the UI needs concise copy.

## Voice and Typography

- Use clear, professional Russian for developers. Use lowercase "вы" when direct address is needed, but omit unnecessary pronouns. Avoid bureaucratic phrasing, chains of abstract nouns, and English sentence order.
- Use sentence case. Omit final periods in headings, buttons, navigation, and short labels; retain sentence punctuation in body copy.
- Use natural Russian grammar around preserved product names, acronyms, counts, and placeholders. Rephrase when an uninflected name would otherwise make the sentence awkward.

## Developer Vocabulary and Marketing

- Use "сборка" for a software build and "запуск" or "прогон тестов" for an execution, as context requires. Prefer "разрешение зависимостей" for dependency resolution rather than an unexplained literal reference to resolving packages.
- "Shipping" means "выпускать обновления" or "доставлять изменения пользователям", not shipping physical goods. Do not introduce English "shipping" where ordinary Russian developer vocabulary is clearer.
- For "Less waiting. More shipping.", a natural direction is "Меньше ожидания, больше времени на разработку". For "More in the toolbox", use a clear section heading such as "Больше инструментов для вашей команды", not a literal description of a box.
- A newsletter issue is a "выпуск", not a "проблема". "Mute" for a test means "Игнорировать сбои теста", with a state such as "Сбои игнорируются"; it does not disable notifications or prevent execution.
- Preserve the reason in cache labels, for example "Промахи из-за изменения входных данных" for changed misses. Read split headings together: "Faster tests you can" / "actually trust." can be "Быстрые тесты, которым можно" / "действительно доверять", without a final period.
