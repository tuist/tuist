# Standalone cluster verification

Standalone scripts in this directory are included in the server's normal formatter and Credo checks. Keep them compliant with the same style rules as application code; declarations such as aliases belong at module scope. Static checks do not execute these probes or qualify their runtime behavior.

`cluster_formation.exs` runs in an isolated named VM with owned peers, no server/database startup and no production access. It exercises `RuntimeChildren.cluster/1`, DNS joining and failed-poll retention in a three-node mesh, a rejected wrong-cookie peer, and actual departure. Names are unique and peer listeners are ephemeral. This is not a release/Helm cookie-wiring or fixed-listener test: `test/tuist/application/release_environment_test.exs` separately exercises the actual release shell template, and Helm lint/render checks cover manifest wiring.

`cluster_scale_out.exs` extracts the useful display-invalidation checks from the historical integration harness, updated for the dedicated `:display` cache. It runs real Cachex and PubSub processes in two owned loopback-bound VMs, verifies remote key eviction and local replacement, and observes actual peer departure while general, license, proof and subject cache markers remain warm. The transport readiness barrier must be acknowledged by the remote node, not the local subscriber. Peer names are unique, listeners are ephemeral, and cache supervisors stop when their controller exits. It does not start the application or databases, and protected markers are not an authentication or bcrypt load test. Do not restore old assumptions about distributed image exclusion, immediate cached-subject revocation or supervised optional-task draining.

These checks do not prove authorization, loaded mixed-version rolling replacement, enforced Kubernetes NetworkPolicy or real partition recovery. Run a real two-replica canary before promotion. Retaining peers after DNS failure does not disable OTP partition prevention or prevent disconnects after actual TCP/node loss. Private experiments must touch only owned resources and distinguish reported historical evidence from current inspected results.
