# Tuist App Translation Context

The Tuist app is a SwiftUI companion app. On iOS it lists a project's previews, which are app builds shared by a team, and installs them on the device. On macOS it lives in the menu bar and installs previews on connected devices, simulators, and Android emulators. The source catalog holds every user-facing string from both platforms.

## Catalog format

- The source is an Apple `.strings` file. Keys are the English source strings and must never change; translate only the value after `=`.
- Locale codes are Apple localization identifiers (`zh-Hans`, `zh-Hant`, `yue-Hant`) because they name the `.lproj` directories the app loads.
- Preserve every format argument exactly, including `%@`, `%lld`, `%%`, and positional forms such as `%1$@`. When word order requires reordering, use positional arguments (`%2$@ ... %1$@`) instead of dropping or duplicating one.
- Preserve escapes such as `\n` and `\"`. Keep the value on one line.

## Meaning

- A "preview" is a shareable app build that can be installed and run, not a visual preview or a draft. "Run" and "Launch" install and open that build on a device.
- A "track" groups previews by release channel, such as beta or nightly. "All" in the track selector means every track.
- "Self-hosted" refers to a Tuist server the customer operates, as opposed to the Tuist-hosted service.
- "Simulator" and "Android Emulator" are Apple and Google development tools. Use the established developer terms for each locale.
- Error messages are shown in alerts. Keep them helpful and specific about the action the user can take.
