# Berlin tax-certificate request template

This is the official Berlin form for an application for a *Bescheinigung in
Steuersachen* (tax certificate). It is deliberately stored as a binary PDF so
that prepared requests retain the government form that was used.

- Official service page: <https://verwaltung.bund.de/leistungsverzeichnis/DE/leistung/99102037012000/herausgeber/BE-L100108_324713/region/11>
- Direct official source: <https://www.berlin.de/sen/finanzen/dokumentendownload/steuern/informationen-fuer-steuerzahler-/steuerklassen/antrag-auf-erteilung-einer-bescheinigung-in-steuersachen-2016.pdf>
- Downloaded: 2026-08-26
- SHA-256: `86d4ce6bfea5252ff288beecf32ef56b9d01b3300bd87237f984fa2b30b8918f`

The template is specific to Berlin. It must only be selected after leadership
has confirmed that the responsible tax office accepts this form. Atlas fills
the non-signature fields and leaves the signature line for an authorized
person to sign.
