# Public documentation rendering

`AtlasWeb.Docs.Markdown` compiles trusted documentation source into sanitized markup. It renders fenced code through the snippet markup adapted from Tuist and Markdown admonitions through Noora alerts. Fenced snippets reuse `AtlasWeb.CodeBlock.highlight/2` for bounded server-side Lumis highlighting with GitHub light/dark colors; no client highlighter is needed. Only generated highlighter markup may be raw. Unsupported languages, parser errors, and sources over 256 KiB retain escaped, untruncated plain text. Keep the copy-source template independent of highlighted markup and preserve its original text. Inline code and snippet styles use Noora tokens in the documentation bundle.

The public controller does not start a live session. The header's Guides/References selector uses ordinary links and the server docs' Noora button-group pattern; render only the current category's sidebar. Within References, group tool-domain pages (such as AI accounts) under the MCP section rather than a redundant References heading. The mobile sidebar includes the same selector. Use short `sidebar_title` labels independently of article titles, and derive the selected category from the requested page, never client-side state. The copy-page dropdown uses the actual Noora component and its menu runtime, mounting its portal on these static pages. Preserve keyboard navigation, clipboard feedback, and the plain-text source route when changing this behavior.

Markdown tables use the same Noora wrapper, scroll regions, and table runtime as Tuist documentation. Preserve inline markup and native horizontal scrolling on narrow screens. The header copies Tuist’s Noora theme and primary action buttons for desktop and mobile, including its neutral GitHub icon link to Atlas’s source directory.
