# Native read projections

`Atlas.Native` owns resource pagination, editable fields and shared record serialization. These modules add read-only account detail and finance overview data to the existing bearer-authenticated routes; they do not introduce new storage or mutation capabilities. The controller authorizes before loading them. See [the HTTP contract](../../atlas_web/controllers/AGENTS.md).

- `AccountDetails` reuses `Accounts.get_account/1` and the web's contract-value calculation. Return explicit string-field allowlists, not Ecto structs or arbitrary metadata. Related records belong only to the requested account. Account document titles/dates/status follow the account card; document summaries additionally require `documents:read`. Never expose storage keys, signed URLs, document bytes, or provider payloads.
- `FinanceOverview` reuses the web's `Finance.Runway` window in the configured reporting currency (EUR by default), with six calendar months of bank income/expenses and cash/burn/runway. Internal transfers do not affect income/expenses. Preserve exact decimal strings and nullable burn/runway. No accounts or missing conversion rates must not appear as valid zero/partial totals. Include the FX publication date and excluded currencies. Keep the older original-currency invoice `summary` contract unchanged; it is not cash flow.
- Controller regression coverage lives in `test/atlas_web/controllers/native_controller_test.exs`, including cross-scope denial, document summaries, OAuth revocation, multi-currency conversion, month boundaries and transfer exclusion. Existing MCP account and finance tools already expose these domain reads; this is a mobile projection, not a new domain action.
