# Provider-topology resource fixture

This is an owner-specific private-peer resource fixture, not a publisher, native-client construction benchmark or physical provider-network qualification. See [`README.md`](README.md) and the [`build-only entry point`](../certificate-trust/AGENTS.md).

- Compare identical completed writes, reads, retained objects, full handshakes and application/replication bytes. Treat bounded convergence retries as measured cost, not an equality filter that selects performance outcomes.
- Preserve all one-to-three ABBA blocks on the same host. Do not discard a slow run or repeat until a budget flag disappears. Positive deltas beyond baseline spread require investigation; completion is not approval.
- Keep raw network transmit alongside transmit minus stored metrics body bytes. The latter excludes only known body payload, not HTTP/TCP/IP overhead or scrape CPU. Do not claim full observer-cost removal.
- Record success/failure probe counts and statuses, sample phase boundaries and per-node peaks. Missing legacy or unsampled phase/status detail remains null, never fabricated zero.
- Only the three source-verified lazy Counter families may begin empty. A TYPE declaration alone cannot zero an unknown counter; wrong kinds and missing gauges fail.
- Output directories contain private synthetic keys. Retain only the public artifact allowlist; cleanup only owned sources/images/containers/networks.
- Run `node --test test/e2e/provider-topology/{compare,corpus,metric-schema,summarize}.test.mjs` from `kura/` after changes. Validate the shell/workflow separately when their interfaces change.
